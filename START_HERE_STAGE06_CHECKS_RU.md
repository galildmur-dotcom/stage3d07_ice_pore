# Stage 3D-06 — проверка времени и диагностика концентрации, 10.10.2026

## Область применения

Этот пакет **не переопределяет** утверждённую постановку Stage 3D-00 v4. Механические законы E, ED, EDV, параметры и сетки не изменены. Добавлены независимые диагностические поля и Qt Creator-конфигурации для исследования временной сходимости.

**Важно:** патч следует накладывать на уже работающую у вас папку `Stage3D06` (поверх файлов исходного проекта), не удаляя `LOCAL_RUNS` с результатами H1/H2 и файлами `restart.bin`. Для надёжности перед заменой скопируйте `LOCAL_RUNS` на другой диск.

## Сборка из Qt Creator без PowerShell

1. Закройте текущий расчёт; распакуйте PATCH в корень проекта (должны замениться `src/spatial_reology.cpp`, `src/mechanical.cpp`, `src/qt_creator_runner.cpp`, `CMakeLists.txt`).
2. В Qt Creator откройте `CMakeLists.txt` проекта, выберите **Desktop MinGW / Release**.
3. Вызовите **Сборка → Запустить CMake**, затем соберите проект (`Ctrl+B`).
4. В выпадающем списке запуска выберите одну из перечисленных ниже целей и нажмите `Ctrl+R`.

| Цель в Qt Creator | Что выполняет | Выходные данные |

| `stage3d06_qt_H0_dt150` | H0 EDV_VAR 150 с, 24 шага | `LOCAL_RUNS/H0_dt150_q3` |
| `stage3d06_qt_H0_dt75` | H0 EDV_VAR 75 с, 48 шагов | `LOCAL_RUNS/H0_dt75_q3` |
| `stage3d06_qt_H1_dt150` | H1 EDV_VAR 150 с, 24 шага | `LOCAL_RUNS/H1_dt150_q3` |

Диагностика H1/H2 выполняет **только** вычисление напряжений при известной истории `e_d,e_v`, имеющихся перемещениях и температуре в t=3600 c. Не запускает решение по времени, не изменяет `restart.bin` и старые VTU. Условие: исходная папка с рассчитанными H1/H2 и файлом `restart.bin` должна оставаться на месте.

После диагностики пришлите из каждой ветви только `qp_diagnostics_3600s.csv` и `qp_top100_3600s.csv` (поле `qp_diagnostics_3600s.vtu` можно приложить позднее). Это позволит локализовать точку максимума на сетках H1 и H2 без повторных дорогостоящих расчётов.

Для уменьшения объёма файлов в режиме `stage3d06_qt_H0_dt75` сохраняется поле VTU только на последнем шаге; численные ряды CSV и контрольные точки сохраняются **каждый** шаг. Для H0/H1/H2 при dt=150 VTU по-прежнему сохраняются каждый шаг.

## Сопоставление трёх временных шагов

При наличии установленного Python обычная (стандартная библиотека, без дополнительных пакетов) команда из каталога проекта:

```text
python scripts/check_temporal_and_qp.py --root . --mesh H0 --dt 300 150 75 --tfinal 3600 --out VERIFICATION_H0
```

Если Python отсутствует, достаточно передать `time_series.csv` от каждой модели — анализ можно выполнить здесь.

**Важные правила сравнения:** одна сетка, один ξ, один номер квадратуры, одинаковые законы E(T), одинаковый общий интервал t=0–3600 с. Температура решается заново на каждом шаге; она не интерполируется из более грубой сетки. 1ьчтение `j6` выполняется трапециями с фоном Ψ(σ=0)=7.5×10⁻⁷. Не смешивайте `Principal_max_MPa` (объёмное среднее по элементу) с `Principal_QP_max_MPa` (максимум по точкам квадратуры этого элемента).

## Новые поля VTU

- `Principal_QP_max_MPa` — максимум главного напряжения по **объёмным точкам квадратуры данного Tet10**;
- `QP_max_x_m`, `QP_max_y_m`, `QP_max_z_m` — глобальные координаты точки, где он достигнут;
- `QP_max_index` — нумерация точки квадратуры, начиная с 0;
- ранее существующее `Principal_max_MPa` — **среднее σ₁ по элементу**, не следует сравнивать напрямую с точечным максимумом.

`qp_diagnostics_3600s.csv` содержит абсолютный максимум и расстояние от поверхности сферической поры; `qp_top100_3600s.csv` — 100 наибольших элементных QP-максимумов с координатами.
