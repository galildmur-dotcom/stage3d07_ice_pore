# Stage 3D-10I — сопряжённый обратный проход на основном механическом коде

Дата 05.11.2026. Требуется ранее установленный Stage 3D-10H
(`P10H_PRODUCTION_REPLAY_OK`).

## Объём новой проверки

Проверяется не собственный упрощённый прямой решатель, а действительно
используемый `nonlinear_step()` из `src/spatial_reology.cpp`, с реальными
реологическими моделями E/ED/EDV, BCSR и нормировкой `zeroMeanZ()`.
Все контрольные точки записываются и читаются через Stage10H-модуль.

- Тестовая геометрия: **две Tet10 внутри области B6**, со свободными
  перемещениями и закреплением грани. Это ещё не сферическая пора H0.
- 6 сочетаний: E/ED/EDV × CONST/VAR, 12 шагов с dt=150 с.
- 3 физические наблюдаемые: j6, степенной p=8 момент j_peak, j_en.
- 4 контрольные точки (0,4,8,12) на модель; обратный проход хранит
  **не более четырёх кадров** и заново считает последовательность между
  соседними точками.
- Полный геометрический градиент в тесте составляется из дискретного
  сопряжённого метода и *локальных конечных разностей при замороженных
  полях* для явных частных производных по форме. Это пока не Hadamard
  поверхностный градиент.
- Независимая проверка: полное нелинейное переравновешивание для двух
  соседних геометрий и двух температурных историй, по каждой модели.
- Инвариантность функционалов при удалении жёсткого переноса `zeroMeanZ`
  проверена отдельно; этот результат пока относится к данной тестовой сетке.

### Математическая рекурсия

Полностью дискретные уравнения на шаге n:

$R_n(u_n,z_{n-1};T_n,\Omega)=0$,

$z_n=F_n(u_n,z_{n-1};T_n,\Omega)$.

Для вычисления $J=\sum_n w_n\phi_n$ вводится сопряжённая переменная
$\lambda_n$ для механического равновесия и котангенс $\eta_n$ для будущей
истории $z_n$. Для фиксированного набора физических дискретных координат:

$R_{u,n}^{\mathsf T}\lambda_n=-w_n\phi_{u,n}-F_{u,n}^{\mathsf T}\eta_n$,

$\eta_{n-1}=R_{z,n}^{\mathsf T}\lambda_n+F_{z,n}^{\mathsf T}\eta_n+w_n\phi_{z,n}$.

В общем производная по параметру $p$ содержит прямой вклад $w_n\phi_{p,n}$,
остаточную часть $\lambda_n^{\mathsf T} R_{p,n}$ и память
$\eta_n^{\mathsf T} F_{p,n}$, суммируемые по времени.

В программе `P10C` рассчитывает аналитические JVP/VJP локального шага,
`P10E` собирает разреженный BCSR-оператор и решает транспонированную
линейную систему, `P10F` даёт источники функционалов, `P10H` сохраняет
историю. Текущий этап связывает эти компоненты с **настоящими**
производственными `nonlinear_step()` и `zeroMeanZ()`.

## Установка на вашем компьютере

Исходный каталог: `G:\ildar\Stage3D07`.

1. Сохраните копию `tests/stage3d10h_production_preflight.cpp`.
2. Скопируйте новую реализацию
   `src/stage3d10i_production_adjoint.hpp` в `src`.
3. Замените только `tests/stage3d10h_production_preflight.cpp` на файл из
   архива, если не было собственных изменений. Если были — используйте
   приложенный `PATCH_TEST_Stage3D10I.diff`.
4. Добавьте блок `PATCH_CMAKE_Stage3D10I.txt` **один раз** в конце вашего
   `CMakeLists.txt`; не заменяйте весь CMake-файл.
5. `spatial_reology.cpp`, `restart.bin`, большие результаты и каталог `build`
   **не трогать**. Этот этап не требует новых параметров производственного
   расчёта и не создаёт тяжёлые VTU.

## Qt Creator — единственная команда запуска

- Конфигурация: **Desktop MinGW Release**.
- Цель: **`stage3d10i_production_adjoint`**.
- Аргументы: **пустая строка**.
- Рабочий каталог: `G:\ildar\Stage3D07\build\Desktop_MinGW_Release`.
- Потоки: 4 (задаются тестом).
- Примерное время на i7-7700K: сборка **1–5 мин**; расчёт **10–120 с**;
  RAM небольшой, оценочно менее 1 ГБ. Эти интервалы предварительные;
  фактическое время покажет ваш Qt Creator.

Пришлите **только последнюю строку** `P10I_PRODUCTION_ADJOINT_OK ...`.
При ошибке — полностью текст сообщения вместо всей папки результатов.

Локальный результат GCC/OpenMP:

```
P10I_PRODUCTION_ADJOINT_OK models=6 functionals=3 cases=18 replayed_steps=216 max_window=4 j6_temp_FD_rel=3.195489345685e-10 j6_shape_FD_rel=2.967581909493e-07 jpeak_temp_FD_rel=8.102737341419e-11 jpeak_shape_FD_rel=5.595618775652e-08 jen_temp_FD_rel=2.184810646703e-10 jen_shape_FD_rel=4.433433409555e-08 gauge_functional_rel=6.452189131574e-16 dropped_history_rel=6.388824166451e-01 adjoint_equilibrium_rel=5.967189189981e-13
```

`dropped_history_rel≈0.639` — преднамеренно неверный контроль, когда
искусственно обнуляется сопряжённая память материала между шагами. Такая
большая ошибка подтверждает необходимость обратной рекурсии для EDV.

## Границы утверждений

Это количественная проверка полной нестационарной механической сопряжённой
рекурсии, но пока на маленьком синтетическом домене. Следующая техническая
ступень — запуск на настоящей сетке сферической поры H0, согласование
реального переноса температуры между геометриями и корректное определение
нормального вариационного поля $V_n$ на поверхности поры. Только после
этого можно заявлять фактически вычисленный поверхностный градиент формы,
а не низкомодовую направленную производную.
