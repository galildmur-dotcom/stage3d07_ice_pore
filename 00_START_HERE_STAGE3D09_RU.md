# Stage3D09 — Qt Creator / MinGW Release

## Что нового

1. Новая исполняемая цель `stage3d09a_models` для сравнения E, ED, EDV с `CONST`, `VAR`. Поддерживает 3 узла GH3 и повторное использование расчётов при повторном запуске.
2. Проверочный автономный тест `stage3d09b_local_adjoint_preflight` проверяет локальную линеаризацию материальной модели с внутренними переменными. **Не является полным глобальным сопряжённым решателем.**
3. Канонические решатели `stage3d02_thermal`, `stage3d06_spatial` и прежние цели GH3/GH5 не менялись. Данные `LOCAL_RUNS` не включены в архив.

## Точный первый научный запуск

В Qt Creator откройте CMakeLists.txt, выберите Desktop MinGW Release, соберите и запустите цель `stage3d09a_models` с аргументами:

`--mesh H2 --laws ALL --moduli ALL --xi-set GH3 --dt 300 --tend 3600 --quad 3 --threads 4`

Каталог результатов:

`Stage3D07/LOCAL_RUNS/MODEL_STAGE09/P09A/H2_dt300_q3_t3600_GH3_lawsALL_EALL/`

Прислать **только**:

- `P09A_STATUS.txt`
- `P09A_COMPARISON.csv`
- `P09A_MODULUS_EFFECT.csv`
- `P09A_SCENARIOS.csv`

Программа выполняет три независимых тепловых расчёта (по ξ) и шесть механических моделей на каждом тепловом поле. Результаты других Stage не изменяются. Повторный запуск пропускает полностью завершённые механические ветви.

Если сборка без OpenMP, задайте `--threads 1`. Первоначально можно выполнить `--selftest` без FEM.

## Классификация готовности

- Выполнено: компиляция Release Linux, OpenMP/on и OpenMP/off, проверки касательных операторов, пилот H0/GH3 за 300 c и проверка независимого агрегирования.
- Ещё не выполнено: запуск приложения на Windows MinGW; полная временная сравнительная серия H2/H3/H4 до 3600 c.
- Не реализовано: полный дискретный сопряжённый FEM-решатель и полный поверхностный градиент формы (этапы 09B2–09B6 описаны в `STAGE3D09_SCIENCE_PLAN_RU.md`).
