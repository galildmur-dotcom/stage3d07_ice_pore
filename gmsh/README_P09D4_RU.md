# Stage 3D-09D4 — серия локально уточнённых сеток HP2 / HP4 / HP8

Исходная HP имеет фактическую медианную длину ребра на поре 0,08452 мм. Новые уровни рассчитаны на 0,04226 / 0,02113 / 0,010565 мм. Уменьшается размер у поверхности поры, а не во всём объёме: добавлено ограничивающее поле с постоянным размером на расстоянии до 0,060 мм от поры, плавным переходом далее и минимумом с проверенным полем HP. Исходная геометрия, группы и Tet10 сохранены.

Для генерации, если нет готовой сетки, запустите в cmd из `Stage3D07\gmsh`: `GENERATE_HP_LEVELS.cmd HP8` (аналогично HP2/HP4). `gmsh.exe` должен быть в PATH, либо предварительно задайте `set "GMSH_EXE=C:\полный\путь\gmsh.exe"`. Генерация HP8 может занимать значительно больше времени и RAM, чем HP4. Никогда не удаляйте `LOCAL_RUNS`.

Проверка геометрии: `python tools\audit_wall_refinements.py`; основная проверка C++ в составе `--dry-run`.

**Обязательная проверка деформаций** перед продолжительной кампанией: Stage3D08 `stage3d08_geometry` автоматически вызывается из Stage3D09C. Она проверяет положительность якобианов Tet10 в узлах квадратуры исходной и возмущённых сеток, сохранение внешней границы и интерфейса B6. Если геометрия не прошла, не запускайте FEM.

Расчёт для ОДНОГО уровня в Qt Creator Release (не три подряд):

Цель: `stage3d09c_shape_three`

`--mesh HP2 --modes y20 --laws EDV --moduli VAR --dt 300 --tend 3600 --quad 3 --peak-p 8 --delta-um 5 --cutoff-mm 5 --threads 4 --reuse-p08d off`

Для HP4/HP8 замените только `--mesh HP2` на `--mesh HP4` / `--mesh HP8`. Сначала дополните аргументы `--dry-run` и убедитесь в `P09D4_MESH_OK`. Затем удалите `--dry-run` и запускайте основной режим.

Новые тепловые траектории требуются для каждой сетки; прежние HP, H4 несовместимы. Расчёты и результаты с различными сетками сохраняются в разных директориях. Перед запуском HP4 или HP8 контролируйте свободную RAM и размер файлов, особенно с учётом 64 GB RAM и CPU 4C/8T. Никаких экстраполяций к предельной сетке до проверки HP2/HP4 не делать.

**Статус окончательной геометрической проверки:** все HP2/HP4/HP8 прошли проверку Tet10 при 27 квадратурных точках на каждом элементе для исходной и обеих возмущённых сеток. HP8: 76,070,313 точек на состояние; min detJ(0,+,-)=(5.30436e-17,5.33516e-17,5.27354e-17).
