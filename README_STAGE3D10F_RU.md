# Stage 3D-10F — сопряжённые производные функционалов статьи

**Дата:** 04.11.2026. Предусловие: `P10E_BCSR_TRANSIENT_ADJOINT_OK` в Qt Creator.

## ВАЖНО: установленные определения функционалов

При просмотре реального кода `src/stage3d09b_functionals.hpp`, `src/spatial_reology.cpp` и `src/stage3d09c_shape_three.cpp` обнаружено: **фактически работающая кампания Stage09C содержит `j6`, `jpeak`, `jen`**, а не ранее обсуждавшийся набор `j6`, `jpeak`, `j_safety`.

Stage10F строго сохраняет эти три действующих наблюдаемых:

1. `j6`: сглаженная сумма квадратов положительных главных напряжений, нормированная на `sigma_ref_pa`.
2. `jpeak`: корень степени $1/p$ из интегрированного во времени $p$-момента ($p=8$).
3. `jen`: интегрированная во времени свободная энергия, нормированная на `energy_ref_pa`.

Добавлен четвёртый `safety_smooth_TEST` — **исключительно диагностический прототип** гладкой пороговой функции. Его `test_threshold` и ширины сглаживания условные, НЕ установленные значения прочности пресноводного льда. Он не изменяет прошлые CSV и не подменяет `j_safety` в статье.

## Что проверяется

- Аналитическая производная мгновенных локально-пространственных функционалов по смещениям, температуре, внутренним переменным прошлого шага.
- Производная полной 12-шаговой нестационарной истории через ранее проверенные E/ED/EDV, Stage10C VJP и Stage10E BCSR.
- Нормировка на текущий объём при геометрическом изменении.
- Трапециевидное интегрирование по времени с сохранением точных начальных значений из Stage09C (`7.5e-7` для `j6`, `initial_peak_power(p)` для `jpeak`, 0 для энергии).
- Нелинейная цепная производная итогового корня $1/p$ у `jpeak`.
- Независимые повторные ПОЛНЫЕ нелинейные расчёты для параметров температуры и геометрии.

В тестовой двухэлементной области интегрируется весь объём. В реальной задаче поры нужно дополнительно обеспечить точное совпадение с поддоменом B6, его поведением при изменении формы и физически обоснованным отсечением.

## Патч и установка

В архиве:

- `src/stage3d10f_functional_adjoint.hpp` — новый модуль функционалов и аналитических источников сопряжённой задачи;
- `tests/stage3d10d_transient_adjoint.cpp` — обновлённый тест, сохраняющий старые режимы Stage10D/E и добавляющий условный режим Stage10F;
- `PATCH_CMAKE_Stage3D10F.txt` — блок для добавления в конец действующего `CMakeLists.txt`;
- `STAGE3D10F_SCIENTIFIC_NOTE_RU.md` — научная записка.

1. Скопируйте новый заголовок `stage3d10f_functional_adjoint.hpp` в `src`.
2. Замените **только тестовый файл** `tests/stage3d10d_transient_adjoint.cpp` обновлённым из архива (если сами изменяли этот тест, сохраните резервную копию).
3. Добавьте блок `PATCH_CMAKE_Stage3D10F.txt` в конец существующего CMakeLists.txt **один раз**. Не заменяйте CMakeLists.txt целиком.
4. В Qt Creator обновите конфигурацию CMake и соберите новую цель.

## Строгие ограничения

Это пока **верификация математической и программной схемы на двух Tet10**, не результаты вычисления прочности реальной сферической поры. Для геометрического блока используется центральная разность частной производной при фиксированном состоянии и численная проверка полного градиента. Не выведен непрерывный поверхностный градиент формы; не включено сопряжение расчёта нестационарной температуры. Для реальной поры остаётся необходимой организация checkpoint/recompute, чтобы не хранить всю историю HP8 в памяти, и перенос источников функционалов в основную сборку.

После теста Stage10F следующий шаг — организация восстановления истории и подключение этих источников сопряжённой задачи к реальному пространственному решателю на **малой** сетке, прежде чем переходить к дорогим HP4/HP8.
