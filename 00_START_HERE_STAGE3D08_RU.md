# Stage 3D-08A — геометрические возмущения сферической поры и первые центральные разности j₆

## Назначение и границы работы

Это ПОЛНЫЙ C++20/CMake-проект Stage3D07 со **сохранёнными** тепловым, механическим и постпроцессорными решателями. Добавлены только два новых исходника и новые CMake-цели. Прежние данные H0–H4 и другие `LOCAL_RUNS` не меняются.

В P08A введены:

1. Геометрический генератор MSH2.2 `stage3d08_geometry`: контролируемые возмущения радиуса, точные переносы центра по трём осям и пять независимых действительных гармоник l=2.
2. Запускаемая непосредственно из Qt Creator без аргументов цель `stage3d08_qt_radius_fd_H0`: **для каждого R±δ** заново рассчитывает Т-поле и квазистатическую EDV/VAR-механику в t=300,600,...,3600 c, затем интегрирует j₆ по времени и составляет центральные разности.

Этап P08A не содержит сопряжённой формовой производной, стохастического GH3-усреднения, производных по l=1/l=2 или доказательства предельной сходимости `D_R j₆`.

## Контролируемая геометрия

Базовая полость: центр c=(0,0,0.03) м, R=0.001 м. Направление `n=(x-c)/|x-c|` **из поры в лёд**: положительная радиальная скорость увеличивает полость, уменьшает объём льда. Мода `radius`: `x↦x+δχ(r)n`. Для `tx,ty,tz`: `x↦x+χ(r)δe_k` — точные конечные переносы центра поверхности. Квадруполи `l=2` — ортонормированные действительные Y₂m с обычной сферической нормировкой (см. исходник), карта `x↦x+δχ(r)Y₂m(n)n`.

`χ` — C¹-кубическое затухание на r∈[1,5] мм; снаружи 5 мм смещение в точности равно нулю. Поэтому поверхность B6 при r≈6 мм и все **внешние границы** неподвижны. Топология, номера узлов и элементы Gmsh сохранены побайтово; в MSH заменяются только координаты узлов.

Контроль MSH: положительные `detJ` в q3/q4 точках Tet10, точная новая сфера по узлам её квадратичной аппроксимации, неизменность внешних узлов и B6, контроль первой вариации объёма: `dV_ice/dR≈−4πR²`; в первом порядке `dV_ice/dδ≈0` для переносов и l=2. Сетка Tet10 аппроксимирует поверхность сферы, поэтому погрешность геометрической производной не равна строго нулю.

## Численная оценка j₆

Для Δt=300 с, T=3600 с, EDV/VAR, ξ=0, q3, Jacobi/Projected SpMV:

`j₆(R)≈(1/T)Σ_i Δt [Φ₆(t_(i-1);R)+Φ₆(t_i;R)]/2`.

Используется ранее принятое **фиксированное** `Φ₆(0)=7.5e−7`, исходя из модели регуляризации напряжений. Для каждого изменённого R тепловая история и механическое поле вычисляются заново. Затем

`D_R j₆(δ) ≈ [j₆(R+δ)−j₆(R−δ)]/(2δ)`; нормированная чувствительность равна `(R/j₆)D_R j₆`.

При использовании `--tend` меньше 3600 программа считает **среднее на сокращённом временном интервале**, а не канонический функционал статьи на [0,3600]. Выходной CSV тогда нужен только как диагностический пилот.

## Проверки данной версии на Linux

- GCC Release с OpenMP: 5 из 5 P08 CTest пройдены; без OpenMP: 5 из 5.
- Все девять мод: `radius`, `tx`, `ty`, `tz`, `y20`, `y21c`, `y21s`, `y22c`, `y22s`: q4 тесты H0, проверка граничных узлов, объёма и ориентации Tet10.
- H4: R±5 мкм, q3; все проверенные Tet10-якобианы положительны; погрешность первой вариации объёма льда относительно сферы ~3.06×10⁻⁶.
- **Сквозной запуск H0 (6 изменённых сеток × 12 временных шагов)** пройден: `D_R j₆ = 0.106681387; 0.106678779; 0.106678127` м⁻¹ для δ=10,5,2.5 мкм; Richardson ~0.106677910 м⁻¹. Отношение последовательных разностей ~3.999.
- Нативная Windows/MinGW проверка нового кода остаётся за пользователем.

Приведённые числа — **дискретная чувствительность** при H0, dt300 и ξ=0; пока нет сходимости по сетке и времени, нет дискретно-сопряжённого градиента и математического ожидания по ξ. Нельзя интерпретировать их как доказанную shape-производную непрерывной задачи.
