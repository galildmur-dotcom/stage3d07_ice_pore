# Отчёт о разработке Stage 3D-09C

**Дата:** 23 октября 2026 г.

## Разработка

Создан автономный запускатель `src/stage3d09c_shape_three.cpp`, добавлена цель
`stage3d09c_shape_three` в CMake и независимая проверка CSV `tests/p09c_validate.py`.
Существующие решатели Stage08D/09B не изменены.

Сохранены определения трёх функционалов из Stage09B:
- `j6`: прежний интеграл сглаженных положительных главных напряжений;
- `jpeak`: p-корень из интегрированного по пространству и времени p-момента;
- `jen`: усреднённая по времени и объёму энергия, нормированная на один фиксированный эталон.

Вычисляются производные ожидания и дисперсии GH3 по трём модам R, tz, y20.
Программа допускает отдельные E/ED/EDV, CONST/VAR, но первый полный запуск
назначен для EDV/VAR.

## Проверки

- Сборка Release без OpenMP: успешна.
- Сборка Release с OpenMP: успешна.
- Два специальных теста P09C (самотест и dry-run): успешны в обоих сборочных вариантах.
- Совместные профильные тесты P08D, P09B и P09C: 4/4 успешно.
- Сквозной FEM-тест H0/EDV/VAR/GH3/y20 при Δt=300 с, t_f=300 с: 6/6 механических траекторий успешно.
- Перезапуск: 0 новых дочерних FEM-процессов; `--report-only` выдаёт те же моменты.
- Независимый Python-аудит короткого теста: 3/3 строки производных, 9 узловых строк, 6 проб — корректны.
- Проверено использование 6/6 совместимых температурных траекторий из отдельного P08D-подобного тестового источника при расчёте ED/VAR; новые механические решения действительно выполняются заново.
- `--reuse-p08d require` без источника завершается ошибкой до записи данных.
- Численная контрольная производная короткого теста:
  `D_y20 E[j6] = -0.0011275978830461136 m^-1`, согласована с прежним H0-пилотом Stage08D.

Пробные производные `jpeak`, `jen` на H0, t_f=300 c, демонстрируют работу
алгоритма, **не являются исследовательскими результатами** для статьи с t_f=3600 c.

## Важные ограничения

- Не проводилась непосредственная сборка Windows MinGW в контейнере. Сборка под Windows
  и полная H2-кампания требуют запуска у пользователя.
- Не реализован полный сопряжённый термомеханический поверхностный градиент формы.
- Результаты H2 для новых геометрических производных ещё не получены, их нельзя включать
  в статью как установленные численные результаты.
