# Исправление сборки на Windows / MinGW GCC 13.1

Если Qt Creator выдаёт `reference to byte is ambiguous` или ошибку на `Modulus::CONST`,
эта версия уже содержит исправление. Исходники следует распаковать **в новую папку**,
например `C:\Users\Admin\Downloads\Stage3D06_WinFix\Stage3D06`, и открыть
в Qt Creator именно **новый** `CMakeLists.txt`. Используйте комплект Desktop MinGW 64-bit
и Release. Соберите и запустите `stage3d06_qt_check`, затем `stage3d06_qt_run`.
PowerShell для расчёта не требуется. Если Qt Creator использует старый CMakeCache,
выберите «Сборка → Очистить конфигурацию CMake» / «Переконфигурировать»
либо новую пустую папку сборки. Подробнее: `WINDOWS_MINGW_FIX.txt`.

# Stage 3D-06: запуск H2 непосредственно из Qt Creator (Windows)

**Важное:** не нужно открывать PowerShell, отдельно запускать `cmake`, `g++`, `gmsh` или Python. Компиляция выполняется самим Qt Creator через выбранный **Kit**. Установка C++-компилятора и CMake всё же необходима внутри **Kit** — исходники не являются готовыми Windows `.exe`.

## 1. Распакуйте ZIP

Рекомендуемый путь `D:\Ice3D\Stage3D06\` (без кириллицы в именах каталогов). Внутри этой папки должны находиться `CMakeLists.txt`, `src`, `meshes`, `reference`, `START_HERE_QT_CREATOR_RU.md`. Если вы уже распаковали старую версию, используйте **отдельную новую папку** или замените полностью проект, чтобы не оставить старый `CMakeLists.txt`.

## 2. Откройте в Qt Creator

1. **Файл → Открыть файл или проект** → выберите `D:\Ice3D\Stage3D06\CMakeLists.txt`.
2. В мастере настройки проекта выберите **Desktop Kit с 64-битным компилятором C++**: MinGW GCC, MSVC или Clang. Для 64-битного компьютера не выбирайте 32-битный Kit.
3. Выберите **Release** (не Debug). Если Release недоступен, в **Проекты → Сборка → CMake** установите `CMAKE_BUILD_TYPE=Release` для одноконфигурационного генератора. Для Visual Studio выбирайте конфигурацию Release.
4. Дождитесь завершения **Configure**. Qt Creator сам вызовет CMake и компилятор — вводить команды в терминале не нужно.

Если Qt Creator сообщает `No CMake tool`, `No suitable kit`, `C++ compiler not found`: откройте **Инструменты → Параметры → Комплекты (Kits)**. Проверьте вкладки **Компиляторы** и **CMake**. Если они пустые, добавьте компоненты CMake, Ninja и 64-битный MinGW через Qt Maintenance Tool или установите инструменты Visual Studio Build Tools. **Без работающего Kit собрать C++-исходники нельзя**. Ошибки `cmake` / `g++` в обычном PowerShell при этом НЕ имеют значения, если Qt Creator использует эти программы по абсолютным путям своего Kit.

## 3. Короткая проверка: H0 / E_CONST / 300 секунд

1. Выберите в Qt Creator исполняемую конфигурацию **`stage3d06_qt_check`** (список цели для запуска, в левой части «Проекты → Запуск» / нижняя панель выбора конфигурации запуска).
2. Убедитесь, что поле **Аргументы командной строки** пустое.
3. Нажмите зелёную кнопку **Запустить** (обычно `Ctrl+R`). Qt Creator соберёт целевой исполняемый файл и его зависимости.
4. В панели **Вывод приложения / Application Output** появятся строки `[1/2] Calculating full thermal history`, затем `[2/2] Solving 3D quasistatic equilibrium`.
5. В конце ожидается строка **`SUCCESS`**. При первом запуске этого проекта на Linux контрольный пример завершился корректно (результат на Windows требуется проверить отдельно).

Результаты контрольного запуска появятся в:

`D:\Ice3D\Stage3D06\LOCAL_RUNS\H0_dt300_q3\`

Содержит `thermal/thermal_300s.vtu`, `mechanics/E_CONST/mechanics_300s.vtu` и `QT_RUN_STATUS.txt`.

## 4. Основной расчёт: H2 / EDV_VAR / 3600 секунд

1. Выберите в Qt Creator исполняемую конфигурацию **`stage3d06_qt_run`**.
2. Оставьте поле аргументов **пустым**. Значения по умолчанию: H2, EDV, E_VAR, `Δt=300 с`, `t_end=3600 с`, квадратура 3 (27 точек на Tet10).
3. Нажмите **Запустить**. При первом запуске автоматически рассчитывается температурная история, затем 12 шагов нелинейной механики.
4. В панели вывода следите за строками `EDV VAR time=300`, `... time=600` ... `time=3600`.
5. Итоговые файлы в `LOCAL_RUNS\H2_dt300_q3\`:

- `thermal\thermal_300s.vtu` ... `thermal_3600s.vtu` — температурные поля;
- `mechanics\EDV_VAR\mechanics_300s.vtu` ... `mechanics_3600s.vtu` — поля для ParaView;
- `mechanics\EDV_VAR\time_series.csv` — локальные показатели и невязки;
- `mechanics\G06_campaign.csv` — сводная таблица с памятью/итерациями;
- `mechanics\EDV_VAR\restart.bin` — контрольная точка;
- `QT_RUN_STATUS.txt` — отметка о завершении запуска.

Повторное нажатие **Запустить** использует готовые поля температуры; решатель восстанавливает `restart.bin`, если расчёт не закончился. Удалять или изменять `restart.bin` вручную не нужно.

## 5. Открытие ParaView

В ParaView откройте `LOCAL_RUNS/H2_dt300_q3/mechanics/EDV_VAR/mechanics_3600s.vtu`, нажмите **Apply**, выберите `Principal_max_MPa`, затем, при необходимости, `Surface With Edges`. Тёпловую последовательность можно просмотреть по набору VTU.

## 6. Параметры (необязательно)

Изменять исходники не нужно. В Qt Creator → **Проекты → Запуск → Аргументы командной строки** можно указать, например:

- `--mesh H1 --law EDV --modulus VAR --dt 300 --tend 3600`
- `--mesh H2 --law ED --modulus CONST`
- `--mesh H0 --law E --modulus CONST --tend 300`
- `--dry-run` — проверить пути к файлам/исполнимым программам без расчётов;
- `--clean` — **удалить** результаты для выбранной комбинации `H*_dt*_q*` и начать заново; используйте только когда это действительно необходимо.

**Не меняйте** шаг `dt` между запусками, использующими один и тот же `restart.bin`. При изменении числа точек квадратуры или шага расчёты размещаются в отдельной папке.

## 7. Известные ограничения

- Проверены сборка и запуск в Linux GCC 14/CMake 3.31; **сборка на вашем Windows/Qt Creator здесь недоступна и ещё не проверена**.
- Программа пока однопоточная, без GPU/OpenMP; не ожидайте загрузки всех 8 логических потоков.
- В этой версии не реализованы полноценные сеточно-временные исследования H2 и оценка производных по форме.
- Не редактируйте и не заменяйте файлы `.msh` в середине расчёта с контрольной точкой.
- Объём VTU/checkpoint H2 может быть значительным; предусмотрите несколько гигабайт свободного места.
- Если нажать **Остановить** во время длительного расчёта, проверьте в Диспетчере задач, что дочерний процесс решателя действительно завершился, прежде чем запускать новую копию.
- Если появляется ошибка, пришлите **текст из «Вывод приложения» или «Проблемы» Qt Creator** — не из PowerShell.
