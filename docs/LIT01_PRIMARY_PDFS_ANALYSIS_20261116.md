# LIT-01 — Проверка новых полных первоисточников (16.11.2026)

**Тип:** научное приложение к `docs/LIT01_SHAPE_GRADIENT_CONVERGENCE_REVIEW_20261116.md`. Обновлённый статус: три PDF получены от исследователя, четвёртая статья открыта у издателя. Эта записка **не содержит** новых результатов FEM и **не доказывает** сходимость `D_RJ_h`.

## 1. Meric R. A. (1990), ZAMM 70(11), 509–516

**Точный источник:** *Shape Variations for Viscoelastic Solids Under Transient Response*, DOI https://doi.org/10.1002/zamm.19900701108. Пользовательский файл `meric1990.pdf`, оригинальные с. 509–516, 8 страниц.

- На с. 509 (Introduction) автор ставит задачу геометрической чувствительности **трёхмерных** вязкоупругих тел при нестационарном нагружении; рассматривает дифференциальную трёхпараметрическую линейную модель и интегральную историю. В §2 учитывается инерционное уравнение движения (4), в отличие от нашей квазистатики.
- На с. 510–513, формулы (9)–(19), вводится общий функционал пространственно-временного интегрирования, материалальная производная (10), граничная формула (12b), терминальная сопряжённая задача (13)–(18) и производная формы (19). Следовательно, континуальный метод сопряжённых переменных для **вязкоупругой истории** к 1990 году уже существовал.
- На с. 513–514, §3, (20)–(31) рассмотрена наследственная модель Больцмана–Вольтерры `σ_ij(t)=∫_0^t a(t-s) t_ij(s) ds` при линейной изотропии, гладком ядре, нулевых начальных напряжениях. Сопряжённое определяющее уравнение (30) содержит интегрирование из текущего времени до финального: **сопряжённая память идёт в обратную сторону времени**. Это содержательная проверка структуры нашего adjoint для `z_n`.
- На с. 515–516, §4, сравнение производной из сопряжённого метода (47) с прямым аналитическим дифференцированием (49) выполнено только для *одномерного* стержня Кельвина–Фойгта. **Нет** сеточного FEM-эксперимента или оценки `|D_RJ-D_RJ_h|`.

**Для Stage3D07:** считать доказанным исторический приоритет Meric в самой постановке shape adjoint для линейной вязкоупругости; задача у нас отличается нелинейным EDV_VAR, `E_inst(T)`, квазистатикой, внутренней 3D-порой, локальными напряжёнными функциями и анализом пространственного дискретизационного градиента. Подробную проверку формы дискретного обращения времени `R_n,z_n` проводить по исходному коду, не из аннотации статьи.

## 2. Ciarlet P. G., Raviart P.-A. (1972), с. 409–474

**Источник:** *The combined effect of curved boundaries and numerical integration in isoparametric finite element methods*, DOI https://doi.org/10.1016/B978-0-12-068650-6.50020-4; пользовательский `ciarlet1972.pdf`, 66 страниц.

- Теорема 1 на **с. 414**, (1.12), для коэрцитивной дискретной билинейной формы раскладывает ошибку решения на лучшее конечномерное приближение и **две разности вариационных форм**, включая погрешности квадратуры, без необходимости делать вид, что `Ω_h=Ω`.
- §2, с. 419–432: определения изопараметрических отображений, k-регулярности и оценка интерполяции, включая изопараметрические симплексы; важны невырожденность `F_h`, границы для `DF_h`, обратного отображения и якобиана (`(2.16)`–`(2.20)`). Гарантия порядка **не** следует лишь из присутствия десяти узлов на Tet10.
- Теоремы 9, 10, 11 далее анализируют **совместное** влияние геометрии и квадратуры на нормы ошибок скалярного эллиптического решения. Доказательства не охватывают нелинейный history-dependent лагранжиан и не дают автоматического порядка `D_Rjpeak`.

**Перенос:** разделить три фактора `G` (домен и изопараметрическая карта), `Q` (численная интеграция), `U` (пространство состояния), не вычисляя «чистую ошибку квадратуры» в EDV_VAR без согласованного пересчёта истории на других QP.

## 3. Lenoir M. (1986), SIAM J. Numer. Anal. 23(3), 562–580

**Источник:** *Optimal isoparametric finite elements and error estimates for domains involving curved boundaries*, DOI https://doi.org/10.1137/0723036; пользовательский `lenoir1986.pdf`, 19 страниц.

- **Теорема 1, с. 565:** достаточные условия, восходящие к Ciarlet–Raviart, для регулярного изопараметрического диффеоморфизма. **Теорема 2, с. 571:** рекурсивная конструкция криволинейных симплексов, удовлетворяющая этим условиям в пространстве 3D.
- §5, предложения 2–3, с. 575–576, строят отображение между приближённой `Ω_h` и точной `Ω`, контролируют производные и якобиан. По этим формулам можно ориентировать аудит ошибки нормалей поры/границы B6 и геометрии Tet10.
- Теорема 3, с. 580 (итог §6), даёт оценку **погрешности решения** для коэрцитивной эллиптической модельной задачи, при гладкости данных; не предназначена для производной формы `DJ` и не включает вычислительное напряжение нелинейного EDV.

**Перенос:** нужен отдельно геометрический lift для сопоставления сеток и проверки согласованности `V_R`, радиуса, нормали/ориентации и сохранения B6; нельзя присваивать наблюдаемому `D_Rjpeak` порядок сходимости из теоремы о решении.

## 4. Li J., Li W., Zhu S. (2025), ESAIM M2AN 59, 2141–2170

**Источник:** *Convergence analysis of approximate shape gradients for shape optimization in parabolic problems*, DOI https://doi.org/10.1051/m2an/2025058. **Полный текст открыто:** https://www.esaim-m2an.org/articles/m2an/pdf/2025/04/m2an240290.pdf. Проверены постановка §2, доказательства §3 и опыты §4.

- Рассмотрено скалярное линейное параболическое уравнение `(∂_tu − div(κ∇u)=f)` на `Ω⊂R^d`, `d=2,3`, со скалярным функционалом `J=∫_0^T∫_Ω j(u)`. В частности, предполагается Lipschitz непрерывность `j'`, соответствующие условия на `κ`, `u_0`, `f`, решения и поле деформации.
- **Теорема 2 (§3.2, формулы (3.30)–(3.31):** при её предпосылках, включая `f∈L∞(0,T;H¹(R^d))`, `u_0∈H²(Ω)`, `θ∈W^{3,∞}(Ω)` и `h²≲k`, для **объёмной производной в фиксированном направлении θ** доказано
  `|d_D J−d_D^{k,h}J| ≲ (h²+k)||θ||_{W^{3,∞}}` (неявный Эйлер) и
  `|d_D J−d_D^{k,h}J| ≲ (h²+k²)||θ||_{W^{3,∞}}` (BDF2).
- **Теорема 3 (§3.3, (3.53))** при дополнительных двумерных условиях и `l_h=max(1,|log(h)|)` оценивает *пространственную полудискретную* граничную производную `O(h l_h)`. Не выдавать её за полную трёхмерную пространственно-временную оценку.
- **Опыты §4** на квадрате, эллипсе и L-образной области: на гладких примерах получены порядка `h²` для volume и `h` для boundary; на негладкой L-образной области приводятся уменьшенные наблюдаемые порядки (примерно `h^{1.5}` / `h^{0.5}`), не являющиеся теоремой про нашу пору. Погрешность измеряется нормой оператора на ограниченном семействе полей θ.

**Ограничения переноса:** это не механика напряжений, не вязкоупругая память, не термомеханическая обратная связь, и геометрическая ошибка искривлённого 3D Tet10 не дана теми же предпосылками. Mutti–Ulbrich (2025) особо рассматривают **полигональную аппроксимацию кривой границы**, а полный текст их статьи пока не получен. Li—Li—Zhu — не авторский arXiv-препринт Mutti.

## 5. Следующие исследовательские действия — без FEM

1. Проверить на уже существующих данных разложение градиента по времени/компонентам, не выдавая компенсацию `ΣΔg_i` за оценку полной ошибки.
2. Составить таблицу предпосылок трёх линий доказательств: `G,Q` (Ciarlet/Lenoir), `U,P,t` (Li—Li—Zhu), история `Z` (Meric); определить, какие из них выполняются в коде Stage3D07, а какие требуют отдельной теоремы.
3. Пока не объявлять доказанной пространственную сходимость `D_Rjpeak`; P10AO сохраняется (одна сетка для forward/adjoint в каждом прогоне).
