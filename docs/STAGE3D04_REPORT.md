# Stage 3D-04. Материальная точка ED — научно-технический отчёт

**Дата:** 09.10.2026. **Постановка:** Stage 3D-00 v4, без изменений. **Тестовый критерий:** G04 = «Material point response, tangent, recovery». **Статус:** G04 PASS в пределах перечисленных испытаний. **Объём:** только материальная точка, **не пространственный расчёт ED**.

## 1. Закон и смысл внутренних переменных

При малых деформациях и квазистатическом механическом равновесии утверждённый ED-закон имеет вид

\[
 e=\varepsilon-\alpha(T-T_0)I,\quad d=\operatorname{dev}e,\quad
 \sigma=K(T)\operatorname{tr}(e)I+2G(T)(d-e_d),
\]
\[
 \dot e_d=A_d(T)\left[\tfrac32 K_d\,s-e_d\right],\qquad s=\operatorname{dev}\sigma.
\]

Здесь \(e_d\) — **запаздывающая девиаторная деформация**, \(e_v=0\), \(E_{\rm inst}\) — именно *мгновенный* модуль, а не эффективный модуль. Власть применимости — принятая феноменологическая модель ED при небольших деформациях и малом охлаждении, не претендующая на универсальную калибровку льда.

Основные величины: \(\nu=0.35\), \(E_{ref}=9.5\) ГПа при \(T_0=253.15\) K, \(\alpha=149\cdot10^{-6}/3\) K\(^{-1}\), \(K_d=1.2\cdot10^{-3}\) MPa\(^{-1}\), \(A_{d,r}=1.5\cdot10^{-3}\) s\(^{-1}\), \(Q=66.9\) kJ/mol, \(T_r=263.15\) K; \(K=E/[3(1-2\nu)]\), \(G=E/[2(1+\nu)]\). Переход в СИ: \(K_d=1.2\cdot10^{-9}\) Pa\(^{-1}\), \(a=\tfrac32 K_d=1.8\cdot10^{-9}\) Pa\(^{-1}\).

\[
 A_d(T)=1.5\cdot10^{-3}\exp\left[-\frac{66900}{8.31446261815324}\left(\frac1T-\frac1{263.15}\right)\right]\ \mathrm{s}^{-1}.
\]

В основной температурной паре \(E_{CONST}=E_{ref}\), \(E_{VAR}=E_{ref}[8.93-0.012(T-273.15)]/9.17\). Оба варианта имеют **один и тот же** аррениусовский закон, параметры и входные истории.

## 2. Неявный шаг без итераций Ньютона

Для шага \(\Delta t\) введём \(b=\Delta t A_d(T_{n+1})\), \(a=3K_d/2\), \(Z=1+b(1+2Ga)\). Неявное уравнение разрешается аналитически:

\[
 \boxed{e_d^{n+1}=\frac{e_d^n+2Gb a\,d^{n+1}}{Z}},\qquad
 \boxed{s^{n+1}=2G(d^{n+1}-e_d^{n+1})}.
\]

Это обновление девиаторно при девиаторной исходной истории. Объёмная часть напряжения не релаксирует. Для согласованного касательного оператора по **тензорным** компонентам деформаций при фиксированных \(T_{n+1},e_d^n\):

\[
 \boxed{\mathbb C_{alg}=K I\otimes I+2G_{alg}\mathbb P_{dev}},\qquad
 G_{alg}=G\frac{1+b}{1+b(1+2Ga)}.
\]

Компоненты Voigt: \((xx,yy,zz,xy,yz,zx)\); записаны **\(\varepsilon_{xy}\), а не инженерная \(\gamma_{xy}=2\varepsilon_{xy}\)**. Поэтому \(\partial\sigma_{xy}/\partial\varepsilon_{xy}=2G_{alg}\).

В коде дополнительно реализована полная аналитическая \(\partial\sigma/\partial T\) при фиксированных полной деформации и *предыдущем состоянии* \(e_d^n\). Производная учитывает одновременно \(dE/dT\), \(dA_d/dT=A_d Q/(R_g T^2)\) и тепловую деформацию. Эта производная нужна при последующей сборке полностью дискретной сопряжённой задачи; на текущем этапе сопряжённая задача не решалась.

## 3. Аналитические эталоны

**Релаксация при постоянной девиаторной деформации \(d\):**

\[
 \lambda=A_d(1+2Ga),\quad e_{d,\infty}=\frac{2Ga}{1+2Ga}d,\quad
 e_d(t)=e_{d,\infty}+(e_d(0)-e_{d,\infty})e^{-\lambda t}.
\]

Верификация выполнена для \(T=245.15,253.15,263.15\) K, для обеих ветвей модуля, при \(\Delta t=300,150,75,37.5,18.75,9.375\) s, \(t_f=600\) s. Для \(E_{CONST},T=253.15\) K абсолютная ошибка \(\sigma_{xy}\) (Па) последовательно: **438355, 214740, 103105, 49809, 24355, 12024**. Установлен ожидаемый *первый* порядок во времени; точечный тест не объявляется сеточной сходимостью.

**Восстановление при снятии заданного касательного напряжения:** под постоянным \(s_{xy}=1.7\) МПа модель описывает \(\dot e_{d,xy}=A_d(a s_{xy}-e_{d,xy})\), после снятия напряжения при \(t=600\) s — \(\dot e_d=-A_d e_d\). Обе части сопоставлены с точными экспонентами. Максимальная абсолютная ошибка пилота с \(\Delta t=5\) s в диапазоне 0–1800 s — **\(7.04\cdot10^{-7}\)** по безразмерной величине \(e_{d,xy}\) (не по напряжению). Разгрузка при заданной полной деформации проверялась отдельно, там скорость обратного хода другая вследствие возникающего напряжения.

`ctest` **15/15 PASS**: 8 новых G04 и 7 тестов предыдущего Stage 3D-03. Прямая проверка GCC/Clang: **обе PASS**. Независимая Python-проверка CSV: **PASS** (`G04_independent_readback.json`). Графики: `G04_relaxation.png`, `G04_temporal_convergence.png`, `G04_recovery.png`.

Для проверки диссипации при постоянной T используется удельная свободная энергия с упрочняющим/возвратным членом
\[
 \psi=\tfrac12 K(\operatorname{tr}e)^2+G\lVert d-e_d\rVert^2+\tfrac1{2a}\lVert e_d\rVert^2,\quad
 \mathcal D=A_da\lVert s-e_d/a\rVert^2\ge0.
\]
Это математическая функция накопленной энергии, совместимая с использованной формой ED-закона; **не** является независимо измеренной энергией реального льда. При изменяющейся температуре отдельная проверка полного термодинамического баланса не выполнена; проверки неотрицательности произведены изотермически.

## 5. Отдельный демонстрационный сценарий охлаждения (не поле 3D FEM)

Материальная точка под **предписанным постоянным** \(\varepsilon\) получала \(T_C(t)=-20-3[1-\exp(-t/300)]\) °C. Это просто демонстрационный сценарий без внешней задачи равновесия и без решения теплопроводности. При \(t=3600\) s:

| Выход материальной точки | E_CONST | E_VAR |
|---|---:|---:|
| \(\sigma_{xy}\), МПа | 0.35013674 | 0.35023693 |
| \((e_d)_{xy}\) | 0.000630244 | 0.000630424 |

**Нельзя** трактовать значения таблицы как величины напряжения около поры или как результат сеточного исследования: это лишь иллюстрация поведения локального интегратора. Фактическая форма температурного поля H0/H1/H2 при вычислении этих точек не используется.

## 6. Ограничения и следующий этап

- В Stage 3D-04 **нет** решения пространственной ED-задачи Tet10, обновления \(e_d\) в точках квадратуры реальной сетки или связанного временного решения с Candidate A.
- Нет EDV, инерции, adjoint, shape-derivative, M/D, j6 и случайной GH3/GH5-кампании.
- Нельзя пока делать количественные выводы о влиянии ED на трёхмерное растяжение вблизи воздушной поры и тем более о сеточной сходимости разности E_CONST/E_VAR.
- Упругий E-only решатель из Stage 3D-03 сохранён для будущей сверки; новая ED-точка не меняет предыдущие результаты.
- **Следующий Stage 3D-05 — проверка нелинейной EDV-точки**, включая алгоритмический касательный оператор и термодинамический контроль; после этого Stage 3D-06 объединит модели с полным Tet10 FEM.
