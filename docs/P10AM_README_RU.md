# P10AM — план контролируемого исследования источников сеточной погрешности

**Что сделано сейчас**: сформулирован научный протокол, критерии перехода от геометрии к новым FEM, подготовлена самостоятельно протестированная лёгкая программа `P10AM0` и сводка уже известных метрик P10Z. **Никаких новых тяжёлых FEM-расчётов не выполнено.**

## Файлы

- `docs/P10AM_THREE_SOURCE_ERROR_PROTOCOL_20261115.md` — основное научное решение P10AM, матрица G/V/Q и контроль B6/погрешностей решателя, условия принятия результатов.
- `tools/p10am0_surface_geometry.py` — проверка криволинейной поверхности поры на **существующих** Gmsh ASCII MSH2.2; Python stdlib, без Gmsh, numpy и FEM.
- `tools/P10AM0_RUN_W2_W4_W5.cmd` — один запуск Windows, пути к трём существующим сеткам.
- `experiments/P10AM_EXISTING_P10Z_QP_INDICATORS.csv` — небольшая сводка **уже выполненного** аудита Q3/Q4 индикаторов оболочек, не оценка ошибки `D_R`.
- `experiments/P10AM0_SURFACE_METRICS_TEMPLATE.csv` — определения столбцов и ожидаемые уровни W2/W4/W5, без выдуманных результатов.
- `tests/P10AM0_SELFTEST_REPORT.txt` — результат проверки квадратур и тестовой замкнутой Tri6-сферы (сама тестовая `.msh` **не** включена в Git-патч).

## Безопасное внесение в репозиторий

После скачивания ZIP распаковать его **не в репозиторий** и применить **готовый ADD-ONLY Git-патч** `P10AM_ADD_ONLY.patch` через `PORE - 1 Apply patch and push`.

В патче **нет изменений** `CMakeLists.txt`, P10W, физики, статьи, существующих реестров и ранее зафиксированных CSV. Новые файлы добавляются по уникальным именам. `git apply --index --check` должен пройти независимо от локальных изменений существующих файлов.

Если PORE остановился, не надо делать reset/clean/stash вручную; прислать журнал операции.

## Первый запуск

1. `py -3 "G:\ildar\Stage3D07\tools\p10am0_surface_geometry.py" --selftest` → `P10AM0_SELFTEST_OK`.
2. Двойной щелчок `G:\ildar\Stage3D07\tools\P10AM0_RUN_W2_W4_W5.cmd`.
3. Ожидаемые строки: `P10AM0_MESH_OK mesh=W2`, `... mesh=W4`, `... mesh=W5`, `P10AM0_AUDIT_OK meshes=3`.
4. Результат: `G:\ildar\Stage3D07\LOCAL_RUNS\P10AM0_SURFACE_W2_W4_W5_20261115\P10AM0_SURFACE_GEOMETRY.csv` и `P10AM0_MANIFEST.txt`.
5. Прислать два названных текстовых файла, **не** сетки и не папку `LOCAL_RUNS`.

Если имя `H4W4B2.msh` отличается, проверьте фактическое название в `P10M_MESHES` и исправьте только этот путь в CMD. Папка `--out` для запуска должна быть **новой**.

### Почему не стартуем W6 и Q4 сразу

На W4/W5 полная производная может мало отличаться из-за компенсации изменений компонент. У нас нет корректного Q4 EDV cache и гарантированной изоляции ступенчатой маски B6. Поэтому сначала нужна независимая диагностика реальной поверхности Tri6, затем полный аудит границ/B6, и только затем — один целевой новый FEM опыт.
