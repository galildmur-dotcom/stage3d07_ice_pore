# LIT-08C — протокол поиндексной проверки индикаторов B6

Дата: 16.11.2026. Исходный Git HEAD: 7255625450a6c524e7abeb48e97be10aea5b2086. Статус: программа создана и проверена на синтетических Tet10; реальные W4B2/W4B20 ещё не проверены.

## Научный вопрос

В LIT-08B для каждой W4-сетки два способа выбора области B6 (по центроиду целого Tet10 и по расстоянию индивидуальных Q3-точек при r<6 мм) дали одинаковые объёмы, восьмые моменты, значения jpeak и число точек. Такое агрегатное совпадение НЕ доказывает равенства наборов самих интеграционных точек. Проверяем строгое булево сравнение по индексам Q3 на каждой исходной сетке.

## Алгоритм

- Сетки H4W4B2.msh и H4W4B20_P10AB.msh загружаются независимо через MSH2-reader tools/lit06_b20_geometry_audit.py, включая установленный порядок узлов Tet10.
- Для каждого элемента вычисляется индикатор c_e = [|centroid угловых вершин - центр поры| < 0.006 м].
- В его 27 точках Q3 вычисляются x_q по изопараметрическим функциям формы Tet10 и q_{eq} = [|x_q - центр поры| < 0.006 м].
- Подсчитываются симметрическая разность c_e XOR q_{eq}, число отличающихся точек в каждой стороне, доля/объём, смешанные элементы и контроль узких радиальных интервалов [5.99,6.00) и [6.00,6.01) мм.
- Никакие значения напряжений, внутренние EDV-состояния, FEM-операторы или сопряжённые системы не рассчитываются. Это **геометрическая проверка выбора области**, а не D_Rjpeak.

## Решение о следующей стадии

Если симметрическая разность при 6 мм равна нулю, простую гипотезу о несовпадении двух реализаций **номинального** B6-индикатора можно исключить на этих сетках. При этом сеточная погрешность самого числителя (поля, масса, интеграл и геометрия сеток) ещё не разделена. Тогда изучать N8 по радиальным оболочкам на собственной фиксированной истории каждой сетки, не смешивая эту диагностику с D_Rjpeak. Если симметрическая разность ненулевая, зарегистрировать её вес и радиальное положение, затем отдельно оценить вклад в N8, не нарушая P10AO.
