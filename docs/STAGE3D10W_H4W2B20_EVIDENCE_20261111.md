# P10W: контроль объёмного сгущения H4W2 → H4W2B20

**Дата регистрации:** 2026-11-11. **Статус:** результат одного законченного
численного эксперимента; **пространственная сходимость не доказана**.
Источник регистрации — переданные исследователем два CSV и две строки
`P10W_..._OK`. Привязка к Git SHA, SHA-256 исполняемого файла и исходной
сетки на пользовательском ПК **ещё не подтверждена**.

## 1. Научный вопрос и ограничения

Цель — оценить, насколько полные производные по радиусу `R` меняются при
дополнительном **объёмном** сгущении в слое 0.25–2 мм от поверхности поры,
при практически неизменном разрешении самой поверхности.

Режим: 3D, EDV_VAR, нестационарная температура, квазистатическая механика;
одна номинальная траектория; `mode=R`, `steps=6`, `dt=150 s`,
`t_end=900 s`, `cutoff-mm=5`, `threads=4`; дискретный сопряжённый метод
с `geometry_partial=ANALYTIC_TET10`. `cutoff-mm=5` задаёт носитель
геометрической скорости, а не границу интегрирования функционалов.

Область наблюдения `B6` фиксирована относительно исходной геометрии,
радиус 6 мм от центра поры. Обозначение `jen` относится к диагностической
нормированной энергии, **не к критерию разрушения или безопасности**.

Сравниваются конкретные неналоженные друг на друга сетки; совпадение
агрегатных характеристик поверхности не доказывает побитовую идентичность
поверхностных координат и связности.

## 3. Функционалы и полные геометрические производные

Производные приведены в м⁻¹. Относительное изменение —
`100*(H4W2B20/H4W2 - 1)`.

| Величина | H4W2 | H4W2B20 | Изменение, % |
|---|---:|---:|---:|
| `j6` | 0.002177524843279178 | 0.002177530763855357 | +0.000272 |
| `D_R j6` | 0.026160773271399956 | 0.026153944272524578 | −0.026104 |
| `jpeak` | 0.04720585728914482 | 0.04720588507250239 | +0.000059 |
| `D_R jpeak` | 2.3628628788146244 | 2.362792897877064 | −0.002962 |
| `jen` | 0.0008727346646200358 | 0.0008727378866071007 | +0.000369 |
| `D_R jen` | 0.016699342206409604 | 0.016698447208677941 | −0.005359 |

Для `jpeak` абсолютная разность полных производных составляет
`-6.99809375604e-05 1/m`. Значение из пары H4→H4W2 ранее менялось
примерно на +1.2165% (2.3344633453→2.3628628788 м⁻¹), но это **не**
разрешает приписывать всё отличие только дискретизации поверхности.

## 4. Разложение производной D_R jpeak

Все значения в м⁻¹.

| Слагаемое | H4W2 | H4W2B20 |
|---|---:|---:|
| Явная геометрическая часть | −9.809479545789413 | −9.811425294145332 |
| Механическое равновесие | +10.538196453192576 | +10.539876580443494 |
| Реологическая история EDV | +1.574311436787695 | +1.574480114826180 |
| Тепловая сопряжённая часть | +0.059834534623766 | +0.059861496752718 |
| **Полная производная** | **+2.362862878814624** | **+2.362792897877064** |

Отдельные составляющие `jpeak` меняются по модулю менее чем на 0.05%.
Вместе с тем имеются большие слагаемые противоположных знаков
(порядка 10 м⁻¹), поэтому малую разность полных производных нельзя
автоматически считать оценкой погрешности непрерывной производной.

Численно обусловленная компенсация слагаемых характеризуется также
отношением `sum_of_abs_components_per_m / abs(total_mechanical_shape_per_m)`
из CSV (речь о **механической** части, а не о полной производной):

| Функционал | H4W2 | H4W2B20 |
|---|---:|---:|
| `j6` | 27.5928 | 27.6012 |
| `jpeak` | 9.5188 | 9.5208 |
| `jen` | 6.2964 | 6.2968 |

В частности, для `j6` механическая производная порядка 0.024 м⁻¹
получается сложением слагаемых порядка 0.3 м⁻¹. Это **не** оценка
ошибки, но дополнительный мотив отдельно контролировать сходимость
каждой части сопряжённой производной.

разность при нулевом шаге.

## 6. Научный вывод, пригодный для отчёта

В эксперименте `H4W2 → H4W2B20` при близком поверхностном разрешении
и дополнительном уменьшении медианного объёмного шага примерно на 20% в
слое 0.25–2 мм изменения трёх полных производных по радиусу составили
не более 0.0262%, для `D_R jpeak` — около 0.0030%.

Это свидетельствует о слабой чувствительности рассмотренных дискретных
результатов к **данному способу** объёмного сгущения. **Не доказаны**:
предел при h→0, наблюдаемый порядок сходимости, оценка абсолютной
погрешности производных, перенос вывода на `tz` и `y20`, временная
сходимость и стохастическое GH3-усреднение. Не установлена также полная
независимость результата от способа построения неналоженных сеток.

4. Запланировать независимое, последовательное сгущение с количественными

5. После результатов по `R` повторить релевантные проверки `tz`/`y20`,
   затем временную и стохастическую кампании.
