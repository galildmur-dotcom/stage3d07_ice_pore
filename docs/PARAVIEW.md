# ParaView: просмотр тепловых полей

1. В ParaView откройте `results/H2_dt300_xi0/H2_thermal.pvd`, затем нажмите `Apply`.
2. `Color By` → `Temperature_C` или `dT_K`. Выберите `Rescale to Data Range Over Time`, чтобы цветовая шкала не менялась при проигрывании.
3. На временной панели доступны 900, 1800, 3600 секунд. Для сравнения сеток откройте одноимённые `.pvd` внутри каталогов H0/H1.
4. `Filters` → `Slice` с нормалью (1,0,0), через x=0, чтобы видеть поле по глубине и зону поры; при необходимости `Clip`.
5. `Information` подтвердит тип ячейки `VTK_QUADRATIC_TETRA`, поля `Temperature_C`, `Temperature_K`, `dT_K`.

`B6` — внутренний раздел сетки, не отдельное теплофизическое тело. Архив не содержит GUI-скриншота ParaView; VTK независимым образом проверил девять выходных `.vtu`.
