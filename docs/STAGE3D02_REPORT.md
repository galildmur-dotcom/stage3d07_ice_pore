# Отчёт Stage 3D-02 — теплопроводность и тесты G02

**Дата:** 09.10.2026. **Версия постановки:** Stage 3D-00 v4. **Статус:** вычислительная программа построена, запущена и прошла G02-01, G02-02. Исследование строго трёхмерное, без сравнения физических результатов с предыдущей 2D-рукописью.

## 1. Принятое уравнение и граничные условия

Все данные соответствуют `reference/3D_BASELINE_SPEC_v4.md`. Решается линейная нестационарная теплопроводность для льда с теплоизолированной сферической воздушной порой; воздух как объёмный теплопроводник не моделируется. Robin только сверху. Источник охлаждения — описанная в спецификации случайная временная история с постоянным во времени параметром ξ.

### Метод

10-узловые изопараметрические тетраэдры на исходных Gmsh H0/H1/H2; Galerkin, согласованная массa, неявный Euler. Теплопроводность, тепловая ёмкость и теплоотдача постоянны. Интегралы вычисляются квадратурой на реальных криволинейных элементах; положительность jac детектируется. Sparse CSR и Jacobi PCG. Параметры приведены в `README.md`.

## 3. G02-01 — постоянное поле и одномерный аналитический эталон

**Постоянное поле.** При начальной θ=1 K и θ∞=1 K каждая сетка с двухшаговым расчётом сохранила однородное значение: max|θ−1|=0 (в напечатанном выводе и текущем типе double). Матрица K имеет нулевую сумму строк с учётом граничного R; максимальная абсолютная невязка `max|1ᵀ(K+R)_row−b_i|` на H0 порядка 8.74×10⁻¹⁷.

**Аналитическая задача.** Дополнительно независимо решена 1D задача теплообмена в однородной пластине **без поры**: нижняя грань теплоизолирована, верхняя имеет конвекционный Robin. Для нестационарного ambient T∞ используется собственное разложение по `cos(λ_n z/H)`, где `λ_n tan λ_n = Bi`, `Bi=hH/k=0.5`; в разложении 250 корней, аналитически интегрована экспоненциальная временная история. Начальное поле однородно.

Параллельно реализован отдельный P1 Galerkin FEM по z (согласованная масса, неявный Euler, прямое решение трёхдиагональной системы). Контроль ошибки по всем одномерным узлам:

| Элементов 1D | Δt, c | max|T_FE−T_analytic|, K |
|---:|---:|---:|
| 50 | 300 | 0.0052490 |
| 100 | 150 | 0.0045626 |
| 200 | 75 | 0.0027891 |
| 400 | 37.5 | 0.0015239 |

Точность улучшается по этой последовательности, последний шаг лучше принятого порога 0.002 K.

**Прямой тест 3D-солвера.** Дополнительно построена независимая сетка `SLAB3D_G02.msh` (Gmsh, 890 квадратичных тетраэдров) того же 3D объёма **без поры** с теми же тепловыми тегами и условиями Robin/Neumann. Тот же исполняемый файл `stage3d02_thermal --slab --check-analytic` решает 3D задачу и сравнивает каждую узловую температуру с точным 1D-эталоном по её собственной координате z. Получено:

| 3D Tet10 | Δt, c | max по всем узлам |T_3D−T_analytic|, K |
|---:|---:|---:|
| 890 | 300 | 0.00525877 |
| 890 | 75 | 0.00279325 |
| 890 | 37.5 | 0.00152786 |

Погрешность монотонно убывает, для dt=37.5 выполнен порог 0.002 K. Это непосредственная проверка **той же 3D тепловой реализации** на области, допускающей аналитическое 1D решение, а не только проверка отдельно написанного 1D кода. Геометрия без поры используется лишь как верификационный аналитический эталон, не как сравнение физического эффекта 2D/3D.
 **Важно:** аналитическая 1D пластина не совпадает по геометрии с нашей 3D областью со сферической порой; её сравнение с 3D данными — дополнительная инженерная проверка вдали от поры, а не доказательство точности 3D решения через точную формулу.

## 4. G02-02 — знак Робина, глобальный баланс и временной шаг

Дискретный закон сохранения для каждого шага, проверенный по собранным M и b:

`(1ᵀ M(θ_{n+1}−θ_n)) + dt [bᵀ θ_{n+1}−θ∞(t_{n+1},ξ)·1ᵀ b] = 0`.

При охлаждении ξ=0 температура верха ниже средней температуры льда, что соответствует правильному знаку потока из льда в охлаждающую среду. Неизвестное теплоизолирующее значение на B6 не задано: сквозь него проходит тепловой поток по Galerkin.

Максимальная относительная невязка энергетического баланса для H2 dt=150 с: **2.9815×10⁻¹²**, при требовании 1×10⁻⁸. PCG — относительная невязка не хуже 5×10⁻⁹ после прямого пересчёта. Временной прогон H0 при dt 300 → 150 → 75 → 37.5 с демонстрирует уменьшение отклонения средней температуры верхней грани от одномерного reference: **0.00418 → 0.00364 → 0.00224 → 0.00123 K**. Это контроль времени и общего поведения, не прямая оценка полной пространственной ошибки 3D.

## 5. Стохастические сценарии (пилот тепловой задачи)

Сценарии GH3 на H0 и H2; GH5 на H0. В GH3 стандартно-нормальные ξ=0,±√3 с весами 2/3 и 1/6. В GH5 ξ=0,±1.35562618,±2.85697001; веса 0.53333333, 0.222075922, 0.011257411. GH3 и GH5 рассчитаны на одной сетке H0 и одном шаге dt=150 с.

Для средней по верхней границе температуры в t=3600 с получено:

- M_top(H0,dt=150) = **−21.79589895654 °C**;
- D_top(H0,dt=150) = **0.08848414706 K²**;
- расхождение GH3 и GH5 по M_top = **6.40×10⁻¹⁴ K**, по D_top = **4.02×10⁻¹⁴ K²**.

Практически точное совпадение здесь ожидаемо: тепловая подсистема **линейна по ξ**, а GH3 и GH5 точно интегрируют полиномы степени 1 и 2. Это **не** является основанием не проверять GH5 на будущей EDV-механике или чувствительности формы; для них предписанная проверка остаётся обязательной.

## 6. Файлы и воспроизводимость

Скрипт `scripts/reproduce_all.py` компилирует проект, повторяет baseline и GH, создаёт CSV; `scripts/check_campaign.py` независимо по сохранённым CSV проверяет G02-01 и G02-02 и формирует `G02_verification.json`. CTest: 3/3. Независимый VTK-reader проверил 9 VTU (все `VTK_QUADRATIC_TETRA` с тремя температурными полями). Временные последовательности `.pvd` созданы для ParaView. Физические файлы сеток, исходники и подтверждающие CSV включены в архив.

## 7. Ограничения и переход к G03

- Контроль якобианов выполнен на точках квадратуры, а не математически на каждой точке элемента.
- Пора теплоизолирована, перенос в воздухе и связанная термомеханика не учитываются согласно v4.
- Общая теплоэнергетическая невязка и сеточное совпадение температуры не удостоверяют будущих чувствительностей напряжений у поверхности поры.
- Проверка GH3/GH5 только для температуры и линейной тепловой подсистемы.
- Для G03 нужно реализовать квазистатическую механическую равновесную задачу Tet10 с Candidate A, интегральной z-калибровкой и контролируемой парой E_CONST/E_VAR; затем провести patch-тесты и MAT-T01..06. **На Stage 3D-02 это НЕ делалось.**
