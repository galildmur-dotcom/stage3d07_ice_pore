# Stage 3D-06. Трёхмерное квазистатическое равновесие E/ED/EDV

**Статус на 09.10.2026:** шесть ветвей на H0 с шагом 300 с завершены и независимо проверены; H1 — только одноступенчатый EDV_VAR-пилот; H2 — НЕ завершён. Граница Stage 3D-06: прямая детерминированная задача ξ=0. Вопросы сходимости, стохастических квадратур и производных формы остаются открытыми. Канонический документ `reference/3D_BASELINE_SPEC_v4.md` имеет приоритет.

## Постановка, численная реализация

- Область — кубоид 60×60×50 мм со сферической воздушной полостью R=1 мм, c=(0,0,30 мм), неструктурированная криволинейная сетка Tet10. Неподвижная сфера B6 для локального интегрирования.
- Теплопроводность: прежний Stage 3D-02, односторонняя связь, ρc_p и k постоянны, верхний Робин со случайным охлаждением; для данного этапа ξ=0. Перерасчёт H0 с `--every-step` создаёт 12 VTU при Δt=300 c.
- Candidate A: ux=0 при x=±30 мм, uy=0 при y=±30 мм; все прочие поверхности свободны, включая пору. Для исключения единственной жёсткой моды используется численное закрепление одного uz с последующим вычитанием объёмного среднего uz. Это не физическая дополнительная опора.
- Три материальные ветви E (только упругость), ED (обратимая запаздывающая деформация), EDV (ED + необратимая нелинейная вязкая). Для каждой неизменный/температурно-зависимый **мгновенный** E. Материальные константы и единицы СИ совпадают с утверждённым Stage 3D-00 v4 и тестами G04/G05.
- После разбиения по времени `e_d`,`e_v` (по 6 тензорных компонент каждая) хранятся для каждой из 27 точек квадратуры каждого Tet10. Предыдущее состояние фиксировано в ходе глобального Ньютона; новое сохраняется только после выполнения критерия невязки. Местное уравнение EDV решается защищённым скалярным Ньютоном (предыдущий Stage 3D-05).
- Глобальный нелинейный Ньютон использует **согласованную** матрицу dσ/dε, умноженную на тензорные B-матрицы с метрическим весом 2 у сдвиговых компонент. Блочно-разреженная 3×3 CSR, линейный PCG с блочным Якоби, уменьшающий поиск шага в глобальном Ньютоне. Сила: ∫Ω Bᵀσ dV, нулевые внешние нагрузки.
- Значения `Phi6`, `PhiOmega` суть **мгновенные** средние объёмные индикаторы Ψ(σ), интегрированные по точкам квадратуры и геометрической B6. Временны́е `j6` и `jOmega` рассчитываются интегрированием этих значений методом трапеций и фиксированной нормировкой. Локальный максимум σ1 — только диагностика; не подменяет j6 и не принимается за сошедшийся максимум.
- Выгрузка: CSV, 6 временных рядов VTU/PVD, бинарные файлы checkpoint на конечном шаге; встроены FNV-подпись координат и связности, контроль размерности и версии формата. Бинарные контрольные точки для локального воспроизведения той же сборкой и сеткой, а не переносимый архивный формат между произвольными архитектурами.

Все шесть ветвей использовали **одну** сетку H0, одну историю T(x,t,ξ=0), одинаковую квадратуру и временные слои 300…3600 с. Две E-ветви сошлись за 1 глобальную итерацию Ньютона на шаг, ED — за 1, EDV — за 2. Контроль свободной невязки — не больше 9.69×10^-8 относительно силы начала шага; у EDV ~10^-10. Пик RSS/HWM H0 в протоколе ~70–89 МБ, в зависимости от ветви/запуска. Статистика включает только CPU RAM и не является предсказанием времени запуска на Windows.

**Верификация против Stage 3D-03 E:** сравнение nodal displacement после калибровки на точно одинаковых H0 и T(3600): относительная L2-разность 1.2144×10^-7 (CONST), 1.2134×10^-7 (VAR). Полные данные `results/G06_validation.json` и повторяемая проверка `scripts/check_stage06.py`.

**Сходимость по времени ещё НЕ установлена.** Предварительные прогоны с нерегулярными крупными механическими шагами (900,900,1800 с) дали EDV_CONST Φ6(3600)=0.01498375 против 0.01356223 при шаге 300 с (различие ~10.5%). EDV max σ1: 0.769287 против 0.749298 МПа (~2.7%). Эти два набора не используются как исследование строгого порядка аппроксимации: шаги 900,900,1800 неравномерны. Нужен расчёт 150 с и 75 с после подготовки согласованных тепловых полей.

**H1 пилот:** только EDV_VAR, t=900 с, Δt=900 с: 27 757 узлов, 19 412 Tet10, 2 глобальных Ньютона, 1517 итераций CG суммарно, max σ1=0.375459 МПа, Φ6=0.004098606, peak RSS ≈177 440 кБ, elapsed≈12.8 с в данном Linux-окружении. Числа нельзя сравнивать как сеточную сходимость с H0 Δt=300 с без совпадения временной истории.

**H2:** 70 389 узлов, 50 486 Tet10; попытка EDV_VAR t=900 с была **прервана ограничением продолжительности одной команды** до завершения второй глобальной итерации Ньютона. Ни одно поле напряжений или функционал H2 от этой попытки **не выдаётся как результат**. Подтверждения нарушения лимита памяти не было. Запуск подготовлен для Windows-компьютера с 64 ГБ ОЗУ (`scripts/run_stage06_windows.ps1`).

## Приёмка и ограничения

- `ctest`: 28/28 PASS (проверки предыдущих этапов, пространственный smoke, 72-row H0 и битово-идентичный checkpoint после разделённого расчёта EDV).
- Верификатор всех 72 строк G06: физическая B6, ненулевые мгновенные Psi, свободные невязки, контроль нулевой средней uz, конечность полей, совпадение E-смещений с независимым E-решателем.
- Контрольная точка: два шага EDV из начального состояния vs расчёт первого шага+`--resume` второго дали идентичный двоичный checkpoint и Psi по времени; тест проверяет совместимость одной машины и версии.
- VTU — квадратичные VTK Tet10 (`type=24`) с перемещением, температурой, средними напряжениями по элементам и max-принципальным напряжением. Для просмотра временных слоёв открыть `results/G06_H0_dt300/EDV_VAR/mechanics_time_series.pvd`; прямое открытие нового PVD в GUI ParaView пользователем ещё не выполнено.
- Для крупной серии необходимо завершить на H1/H2 шесть ветвей с Δt=300 с, затем временное и пространственное уточнение. Нет ни GH3/GH5, ни дискретного сопряжения, ни производных формы. Стабильность маленькой разности CONST–VAR **не** доказана.
- Проект Stage06 пока **однопоточный (CPU)**; поддержка OpenMP не заявляется как сделанная. OpenMP/GPU не используется. `VmHWM_kB` на Linux / PeakWorkingSetSize на Windows измеряют пик процесса; процессор i7-7700K 4C/8T пригоден для последовательных расчётов, но выгода от 8 потоков ещё не измерена.

## Быстрый старт

Linux: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j2 && ctest --test-dir build --output-on-failure`.

Пилот: `./build/stage3d06_spatial --mesh meshes/H0.msh --temp-dir results/G06_thermal_H0_dt300 --out results/local_G06 --law EDV --modulus VAR --times 300,600,900 --quad 3`.

Полная Windows H2: `powershell -ExecutionPolicy Bypass -File scripts/run_stage06_windows.ps1 -Mesh H2 -Law EDV` из корня проекта. Это **запуск на компьютере пользователя**, не запуск внутри этой сессии. При повторном вызове `--resume` продолжает после сохранённой точки. **Обязательна** одновременная согласованность календаря температурных и механических временных слоёв.
