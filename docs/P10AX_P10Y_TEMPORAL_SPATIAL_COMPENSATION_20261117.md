## 2. Определения коэффициентов

Пусть `δ_(t,c)` — разность межсеточных вкладов *в производную итогового функционала J(900 с)* на шаге `t` и в компоненте `c`. Тогда `δ_t=Σ_c δ_(t,c)` и `Δ=Σ_t δ_t`.

- **Временная компенсация:** `K_t=(Σ_t |δ_t|)/|Δ|`.
- **Пространственная компенсация:** `K_r=(Σ_s |δ_s|)/|Δ|`, где δ_s — межсеточное изменение суммарного механического вклада, разложенного P10Y на пространственные оболочки.
- **Смешанная временно-компонентная:** `K_(t,c)=Σ_(t,c)|δ_(t,c)|/|Δ|`.

Эти коэффициенты НЕ являются обусловленностями FEM-системы, числом потерянных значащих разрядов double, нормой ошибки относительно неизвестного точного решения или формальными апостериорными оценками.

| 900 | -2.33502333e-4 | 6.50612423e-5 | 0.00000000e+0 | -1.68441091e-4 |

В этом сравнении все шесть δ_t строго отрицательны, следовательно `K_t=1.000000`. На последние шаги 600–900 с приходится **83.19578%** подписанного изменения, на 750–900 с — **63.95863%**. Наибольшая по модулю отдельная разность на шаге **750 с**.

При этом явная, равновесная и EDV-компоненты одного шага могут иметь разные знаки: на 750 с δ_explicit<0, δ_equilibrium>0, δ_history<0, что даёт локальную компенсацию внутри временного шага. Для финального шага 900 с δ_history=0, поскольку в формуле P10W отсутствует будущая внутренняя история после последнего шага.

Глобальная механическая разность `Δ=-5.82577434133681e-4 м⁻¹` совпадает с ранее зарегистрированной P10Y разностью на уровне ~1e−12 м⁻¹.

## 4. Сопоставление временной и пространственной компенсации

| Переход | Подписанная Δ, м⁻¹ | K_t | K_r | Знаки шести Δ по времени |
|---|---:|---:|---:|---|
| H4→W2B2 | 2.8514642209e-2 | 8.342717 | 38.656597 | `----++` |
| W2B2→W4B2 | 3.6771602351e-3 | 5.015732 | 49.104539 | `----++` |
| W4B2→W4B20 | -5.8257743413e-4 | 1.000000 | 13.971508 | `------` |

При пристеночных уточнениях H4→W2B2 и W2B2→W4B2 первые четыре шага дают отрицательную разность, последние два — положительную, поэтому временная компенсация `K_t>1`. Но при изменении только объёмной сетки W4B2→W4B20 временная компенсация итоговой механической разности отсутствует, хотя **пространственная компенсация сильна** (`K_r≈13.97`).

Наблюдение сильной пространственной компенсации при `K_t=1` является важным результатом: малая механическая межсеточная разность B2/B20 не создаётся простым сокращением вкладов разных времён.

**Строгое ограничение идентификации:** из одних двух наборов маргинальных сумм (по времени из P10AX и по оболочкам из P10Y) нельзя восстановить совместную матрицу `δ_(t,s)`. Можно добавлять к любым четырём ячейкам прямоугольника `[[+a,-a],[-a,+a]]` без изменения сумм каждой строки и каждого столбца. Поэтому нельзя заключить, в каком радиальном слое возникла отрицательная разность на конкретном шаге. Нужны истинные `P10Y_STEP_SHELL_COMPONENTS.csv` для обеих W4-сеток.

## 6. Следующий необходимый контроль (без FEM)

Получить только два маленьких файла `P10Y_STEP_SHELL_COMPONENTS.csv` из уже завершённых ночных прогонов W4B2 и W4B20 (по 180 строк каждый), и, если доступны, два `RUN_MANIFEST.json`. Эти файлы отсутствуют в текущем снимке GitHub и среди полученных в разговоре приложений. Программа P10Y создаёт их по коду `src/stage3d10p_partial_audit.cpp`, строки 809–851.

Следующий анализ обязан проверить для каждого `(t,s,c)` вклад трёх компонент, совпадение 6-шагового суммирования с P10Y_SHELL_SUMMARY на каждой сетке, совпадение сумм по 10 слоям с P10AX/P10W_STEP_COMPONENTS и долю компенсации внутри каждого временного шага. Из сумм по времени и пространству без совместных данных делать эту реконструкцию запрещено.

**Итог:** уменьшение послойной сеточной разности при пристеночном сгущении не отменяет компенсаций; для W4B2→W4B20 пространственная компенсация является реальной особенностью разложения, отличной от временной. Доказательства полной пространственной сходимости D_R jpeak, порядка h, оценки ошибки прямого/сопряжённого решения ещё нет. Методическое решение P10AO сохраняется.
