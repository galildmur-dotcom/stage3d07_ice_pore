# P10BB: пространственное сравнение H4W5B2, H4W4B2 и H4W4B20

**Дата:** 18.11.2026. **Статус:** выполнен независимый анализ предоставленных CSV, пространственная сходимость производной **не установлена**.

## Объект сравнения

- Функционал: `jpeak`, геометрическая производная по радиусу поры `R`.
- Анализируется **только механическая часть** производной; термическая геометрическая часть по локальным ячейкам в P10BA отсутствует (`thermal_shape_by_shell=NOT_INCLUDED`).
- Время: `t=750` и `900 с` (в обоих случаях расчёт на одной временной сетке `dt=150 с`, всего шесть шагов).
- Область: две сферические оболочки на расстоянии `s=r-R` от стенки: `0.020–0.050 мм` и `0.050–0.100 мм`.
- Пространственный разрез: 10 радиальных подслоёв на оболочку и 10 полярных зон по `μ=cos θ`; **интегрирование по азимуту `φ` уже выполнено**. Имеется по 200 общих физических ячеек для каждого шага.
- Сетки: `H4W4B2`, `H4W4B20`, `H4W5B2_P10AC`. В каждом полном расчёте прямая и сопряжённая задачи должны использовать одну и ту же сетку (решение P10AO). Запись `RESULT(2).txt` указывает сетку `H4W5B2_P10AC.msh` и историю `P10AC_H4W5B2_R_FULL_20261114/forward_history.bin`; независимая проверка fingerprint сетки по самому бинарному файлу не выполнялась.

## Локальные различия при t=900 с

Определения для одинаковых сферических ячеек `K`:

`δ_K = (D_R jpeak)_K(M_candidate) − (D_R jpeak)_K(M_base)`;

`relative_net = |Σ_K δ_K| / |Σ_K (D_R jpeak)_K(M_base)|`;

`relative_local_L1 = Σ_K |δ_K| / Σ_K |(D_R jpeak)_K(M_base)|`;

`cancellation = Σ_K |δ_K| / |Σ_K δ_K|`.

| Сравнение, базовая → новая | Оболочка `s`, мм | Отличие сумм | Локальное L1 | Компенсация |
|---|---|---:|---:|---:|
| W4B2 → W4B20 | 0.020–0.050 | 0.602953% | 3.696520% | 6.59 |
| W4B2 → W4B20 | 0.050–0.100 | 0.291353% | 4.351299% | 16.48 |
| W4B2 → W4B20 | обе | **0.157056%** | **4.027331%** | **27.92** |
| W4B2 → W5B2 | 0.020–0.050 | 2.502252% | 5.432276% | 2.33 |
| W4B2 → W5B2 | 0.050–0.100 | 1.222988% | 4.852773% | 4.38 |
| W4B2 → W5B2 | обе | **0.644862%** | **5.139497%** | **8.68** |

В двух оболочках W4B2 → W5B2 суммарный абсолютный локальный сдвиг `0.041149149346 м⁻¹`, при этом подписанный суммарный сдвиг `−0.004741915925 м⁻¹`. Большая часть локальных изменений компенсируется при суммировании.

## Угловая локализация

При W4B2 → W5B2 **87.7966%** локального L1 различия приходятся на две крайние полярные зоны:

- `μ=+0.8…+1.0`, то есть `θ=0…36.87°` от `+z`: **55.553%**;
- `μ=−1.0…−0.8`, то есть `θ=143.13…180°`: **32.244%**.

Для W4B2 → W4B20 совокупная доля крайних полярных зон равна **87.0058%**.

Наибольшая по модулю ячейка разности W4B2 → W5B2 лежит в `s=0.020–0.023 мм`, `μ=0.8…1.0` и имеет signed `δ_K = −0.003261850565 м⁻¹`. Для W4B2 → W4B20 максимальная ячейка `s=0.023–0.026 мм`, `μ=0.8…1.0` и `δ_K = +0.002492203549 м⁻¹`.

Вывод: различия сильно локализованы по полярному углу, но *не* только в ближайшем радиальном подслое. Следующий алгоритм адаптации должен распределять бюджет изменения размера элемента по всей анализируемой области и использовать физически нормированные индикаторы ячеек (с учётом объёма, градиентов и знака), а не один максимум суммарного вклада.

**Интерпретация.** Приполюсная область — устойчивый кандидат на дополнительное разрешение *в среднем по полосам*. Однако положения отдельных радиальных максимумов и знаки локальных изменений воспроизводятся лишь частично. Использование одного максимума среди 200 ячеек как жёсткой цели адаптации преждевременно. Эти различия возникают в двух разных направлениях изменения сетки и не являются независимой оценкой точной погрешности. Следующий полноценный этап P10BD по влиянию `Δt` остаётся приоритетным по уже утверждённому исследовательскому плану.

## Временная гипотеза

На одной и той же временной сетке отношение `Σ |cell(step6) − 2×cell(step5)| / Σ |cell(step6)|` составляет `14.71%` (W4B2), `14.76%` (W4B20), `14.52%` (W5B2). Множитель 2 применён потому, что диагностика P10BA взвешивает последний шаг иначе, чем предыдущий. Это лишь индикатор изменения *временной картины*, а **не погрешность по времени**: сравниваются два разных физических момента `750` и `900 с`.

Принятая в проекте теплопроводность Фурье является диффузионной, механика — квазистатической. Истинные распространяющиеся упругие волны этой постановкой не моделируются. Вариации по радиусу могут быть физическим следствием диффузии тепла и взаимодействия прямой и сопряжённой задач, но также могут быть обусловлены сеткой, знакопеременными вкладами, формой поля переноса границы, дискретными квадратурами. Для различения причин нужен контрольный опыт с несколькими `Δt` **на одной фиксированной пространственной сетке**.
