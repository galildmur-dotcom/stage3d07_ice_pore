## Границы применимости статуса OK

`OK` означает выполнение конкретных программных критериев. **Пока не закрыты**: независимая проверка всех геометрических частных производных после отказа от центральных разностей; сеточная и временная сходимость всех целевых функционалов; интерпретация компенсации слагаемых; полная воспроизводимость этих запусков по фиксированному SHA исходников и хешам входной сетки.

Перед публикацией каждая итоговая строка для статьи должна иметь связку: `run_id` → параметры → версия программы → файл данных → метод независимой проверки → научный вывод.
