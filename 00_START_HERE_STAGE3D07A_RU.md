# Stage 3D-07A — инвентаризация сходимости перед вычислительной кампанией

**Назначение:** прочитать уже выполненные расчёты H0–H4 из Stage 3D-06, не пересчитывая их. Версия P5 (Jacobi, SGS, MC-SGS, IC(0), Schwarz) сохранена; физика E/ED/EDV, температура и j6 не изменены. Название `07A` — технический этап подготовки временной и сеточной проверки, **не** закрытие научной задачи G07 в утверждённом плане (обоснование функционала) и не G12 (доказанная сходимость).

## Что уже установлено на основании P5 ZIP

- В комплекте имеются рабочие исходники, Gmsh-сетки H0–H4, протоколы верификации и короткие пилотные расчёты.
- **Полных временных историй EDV_VAR до 3600 с в этом ZIP нет**. Старые завершённые расчёты, в том числе H4/Δt=25 с, могли сохраниться в предыдущих папках Windows. Пилот на одном шаге или сравнение одного checkpoint не считается полной историей.
- Матрица плановой серии — **16 случаев** из `START_HERE_REFINEMENT_RU.md`, плюс ранее ожидавшиеся варианты H0–H2 при 300/150/75 с (всего 23 уникальных сочетания).

## Что сделать в Qt Creator — ТОЛЬКО один короткий запуск

1. Распакуйте полный архив `Stage3D07_Convergence_Audit_QtCreator_FULL.zip` рядом с папками `Stage3D06`, `Stage3D06P2`, `Stage3D06P5`, если эти папки остались на диске. **Не перемещайте и не удаляйте прежние LOCAL_RUNS**.
2. В Qt Creator откройте новый `Stage3D07/CMakeLists.txt`, выберите **MinGW Release**.
3. Соберите и запустите цель **`stage3d07_inventory`**. **Аргументы не нужны.** Обе настоящие FEM-программы не вызываются; H4 не рассчитывается.
4. Если результаты лежат не в соседнем проекте, в Qt Creator для этой цели можно указать `--scan-root "D:\\имя_старого_проекта"`; программа проверит в нём `LOCAL_RUNS`, `LOCAL_RUNS_OPTIMIZED` и сам заданный каталог. Не изменяйте и не копируйте checkpoint вручную.

**Результаты** будут помещены в:

`Stage3D07/LOCAL_RUNS/REFINEMENT_CAMPAIGN/`

Пришлите только **три небольших файла**:

1. `P07_INVENTORY.csv` — список 16 плановых и 7 дополнительных сценариев, статус и источник файлов;
2. `P07_CONVERGENCE_DATA.csv` — сопоставимые пары, если есть законченные истории;
3. `P07_NEXT_ACTION_RU.md` — сводка и недостающие данные.

`restart.bin`, все VTU, папки с сетками, большие архивы **не присылайте** на этом шаге.

## Как определяется статус

- **COMPLETE**: 3600 с; полный непрерывный ряд `time_series.csv`, одинаковый dt, все строки корректны; заголовок `restart.bin` согласован по времени, числу шагов, квадратуре, модели и варианту модуля. Это формальная проверка заголовка, **а не** полное побайтовое сравнение с другой реализацией и **не** проверка сигнатуры сетки.
- **HISTORY_ONLY**: вся временная история корректна, но checkpoint отсутствует или не соответствует; значения можно использовать для статистики с оговоркой, но возобновлять расчёт без восстановления состояния опасно.
- **PARTIAL**: начала временного ряда достаточно, но t=3600 ещё не достигнуто.
- **INVALID_HISTORY**: пропуск или дублирование времени, неправильный формат; автоматическое сопоставление запрещено.
- **MISSING**: результатов не обнаружено в проверенных каталогах. **Не означает, что расчёт не выполнялся.**

## Величины для будущей статьи

- `j6`: временно усреднённая Φ6, интегрирование составной формулой трапеций, Φ6(0)=7.5·10⁻⁷ в соответствии с существующим отчётом.
- Φ6 и максимальное первое главное напряжение при t=3600 с; отдельно средние напряжения в фиксированных полярных областях, если есть `polar_caps_history.csv`.
- Для сопоставимых пар сохраняется расхождение всей начальной истории до 900 с в совпадающие моменты времени.
- Попарная таблица **не утверждает** наличия асимптотической сходимости. Ненестированные H3/H4 и квадратичные Tet10 требуют независимой оценки характерного h около сферы; экстремальные QP-напряжения нельзя автоматически считать пределом на гладкой поверхности.
- Чувствительность к радиусу, смещению и сферическим гармоникам, GH3/GH5 и сопряжённые задачи **на этом этапе не вычисляются**.

## Техническая проверка

`stage3d07_inventory --help` показывает параметры. Независимый регрессионный CTest `P07_inventory_synthetic_regression` проверяет частичные, завершённые и некорректные данные, переносимый заголовок checkpoint и поиск внешнего корня. C++20 не требует Python для обычной работы из Qt Creator.
