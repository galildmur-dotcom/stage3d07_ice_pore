# Stage 3D-06-P3 — полный FEM-проект со встроенным MC-SGS

**Дата:** 14.10.2026. **Состав:** полный P2 (включая исходники, сетки H0–H4, исторические проверки и baseline_serial) с интегрированным предобусловливателем P3.

## Как запустить в Qt Creator (Windows, MinGW)

1. Распаковать `Stage3D06P3` в отдельную папку, **не поверх P2**.
2. В Qt Creator открыть `Stage3D06P3/CMakeLists.txt`, выбрать набор **Desktop Qt/MinGW, Release**. Qt-библиотеки не требуются, только рабочий C++20 CMake toolchain.
3. В выпадающем списке запуска выбрать **`stage3d06_p3_qt_H0_mcsgs`**; аргументы запуска оставить пустыми, нажать **Run**.
4. Цель сама выполнит теплопроводность для H0, ξ=0, Δt=300 с, 0–300 с, затем EDV_VAR с P2 `projected` SpMV и P3 MC-SGS (4 потока при OpenMP, иначе 1). Повторный Run безопасно использует проверенную температуру/checkpoint (если запуск завершился).
5. Отчёты появятся в `Stage3D06P3/LOCAL_RUNS_OPTIMIZED/benchmark_p3_mcsgs/H0_dt300_q3/`.

**После первого H0-расчёта передайте только четыре файла:**

- `LOCAL_RUNS_OPTIMIZED/benchmark_p3_mcsgs/H0_dt300_q3/QT_RUN_STATUS.txt`
- `LOCAL_RUNS_OPTIMIZED/benchmark_p3_mcsgs/H0_dt300_q3/mechanics/profile_cg.csv`
- `LOCAL_RUNS_OPTIMIZED/benchmark_p3_mcsgs/H0_dt300_q3/mechanics/profile_per_step.csv`
- `LOCAL_RUNS_OPTIMIZED/benchmark_p3_mcsgs/H0_dt300_q3/mechanics/G06_campaign.csv`

**H4 (экспериментально):** цель `stage3d06_p3_qt_H4_mcsgs` без аргументов делает один шаг H4 Δt=300 с, EDV_VAR. **Не запускайте длительную кампанию H4, пока не измерим скорость MC-SGS на вашем компьютере:** на H2 здесь возникло существенное замедление MC-SGS; автоматическое ускорение не гарантировано.

Для ручного запуска существующей цели `stage3d06_benchmark_p2_projected` можно использовать параметры `--mesh H0 --law EDV --modulus VAR --dt 300 --tend 300 --threads 4 --preconditioner jacobi --spmv projected` (контрольное сравнение). А `stage3d06_p3_qt_H0_mcsgs` принимает такие же параметры, включая `--preconditioner jacobi|sgs|mcsgs`.

## Математическая реализация

В неизменённом FEM-операторе P2 решается `Ku=f` (BCSR 3×3). Используется **симметричный многокрасочный блоковый GS**: `M=(D+L_c)D^{-1}(D+U_c)`, где порядок определяется детерминированной раскраской графа узлов, `U_c=L_c^T` по той же цветовой перестановке. Прямой и обратный проходы идут в противоположном порядке цветов, узлы одного цвета обрабатываются независимо. Проекция закреплённых компонент обеспечивает нулевые значения на Дирихле, для свободных компонент остаётся SPD-предобусловливатель при SPD-матрице.

Граф и раскраска кэшируются через `BCSRTopology`, но 3×3 инверсии диагональных блоков обновляются при новой матрице Ньютона. Пространственная дискретизация Tet10, термоупругость, законы E/ED/EDV, переменный модуль E(T), j6, граничные условия, шаги расчёта и формат checkpoint не изменены. Старые `jacobi` и последовательный `sgs` сохранены. MC-SGS **не тождественен** последовательному SGS: это иной симметричный порядок блоковых неизвестных.

## Проверки и ограничения

- Linux GCC 14.2, Release, OpenMP: **47/47 отобранных CTest PASS**, включая 6 P3. Все шесть реологических сочетаний E/ED/EDV × CONST/VAR на H0 проверены по значениям функционалов и полным checkpoint (`u`, `ed`, `ev`) с относительным порогом `1e-6`; тесты использовали ужесточённый `--cg-tol 1e-9` для исключения погрешности остановки PCG.
- Отдельная конфигурация без OpenMP: CMake/компиляция целей P3 и **5/5 быстрых тестов PASS** (полная физическая регрессия без OpenMP отдельно не запускалась).
- Нативный двухэтапный путь Qt-runner H0 запущен в Linux: **PASS**. Полный EDV_VAR checkpoint P2 Jacobi против P3 MC-SGS: `u~2.0e-10`, `ed~2.5e-9`, `ev~3.3e-9` нормированных максимальных отличий — PASS.
- На одном H0-замере при 4 потоках: Jacobi PCG 842 ит., 0.535 с, полная механика 1.355 с; MC-SGS PCG 347 ит., 0.964 с, полная механика 1.942 с. Уменьшение итераций **не означает** ускорения на малых сетках.
- На H2 Jacobi завершился (1577 ит., 13.18 с по отчёту решателя); экспериментальный MC-SGS H2 не завершился в ограниченное время тестирования. Результаты H2 MC-SGS и производительность H4 отсутствуют: **не заявлять PASS/ускорение для H2/H4**.
- **Windows/MinGW на вашем i7-7700K не проверялся здесь**: нужен короткий локальный H0-тест из Qt Creator.
- Архив не содержит ни скомпилированных Windows .exe, ни больших расчётных полей. Сетки, тесты и исходники для компиляции включены полностью.

В `P3_VERIFICATION/` находятся протоколы CTest и сравнения, в `P2_VERIFICATION/` — **исторические** результаты предыдущей версии; перечисленные там старые SHA256-хэши для изменённых файлов P3, естественно, устарели. Новый SHA256-манифест настоящего дерева — `P3_SHA256SUMS.txt`.
