# Минимальный пакет Stage 3D-06-P

Этот ZIP содержит файлы CMake, новый C++20 решатель и исходные файлы baseline для независимого сравнения, скрипты приемки и протокол. Это **не самостоятельный проект**: в нём отсутствуют сетки и старые результаты теплопроводности.

Для гарантированной воспроизводимости рекомендуется **полный архив** `Stage3D06P_COMPLETE_QTCREATOR_2026-10-11.zip`, а не патч. Если используете патч, копируйте перечисленные файлы в отдельную копию корня проекта Stage 3D-06 (не в пользовательскую рабочую папку), сохраняя относительные пути.

Сетку `meshes/H0.msh` и другие исходные данные возьмите из HANDOFF. Прочтите `README_QTCREATOR_RU.md`; откройте CMakeLists.txt в Qt Creator, соберите Release под MinGW x64. Windows/MinGW еще требует локальной проверки.
