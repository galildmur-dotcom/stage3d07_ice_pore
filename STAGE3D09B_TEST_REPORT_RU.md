# Stage 3D-09B — отчёт об изменениях и проверках

Дата: 22.10.2026. Назначение: новая наблюдаемая тройка `j6`, `jpeak`, `jen` в одном прямом FEM-расчёте; сравнение шести материалов на GH3.

## Выполнено

- Новый необязательный расчёт пары `jpeak`, `jen` на той же геометрии B6 и в тех же точках Тет10-квадратуры, что исходный `j6`. Вычисление добавлено в обе ветви сборки: последовательную и OpenMP. Конечная механическая невязка, касательная матрица, внутренние переменные и исходное значение `Psi6` не меняются.
- Напряжённый показатель `jpeak` использует `p=8` (разрешены `p=4` и `p=12`), степень интегрируется по B6 и времени, затем извлекается корень `1/p`.
- Энергетический показатель `jen` использует `free_energy` из конститутивной модели `EDV`, в том числе в случаях E и ED при соответствующих выключенных ветвях, с постоянным для всех моделей `psi_ref=sigma_ref^2/E_ref`.
- Новый исполняемый запускатель Qt Creator `stage3d09b_three_functionals` формирует `P09B_SCENARIOS.csv`, `P09B_COMPARISON.csv`, `P09B_MODULUS_EFFECT.csv`, `P09B_STATUS.txt`.
- Прежние `P09A` и `P08D/08E` не изменены; результаты в собственной папке `P09B`. Результаты P09A при `xi=0` и других узлах используются повторно **только для тепловой задачи**, после проверки сигнатуры геометрии и параметров. Неполные старые механические истории не считаются новыми функционалами.

## Выполненные тесты

1. CMake Release под Linux, OpenMP ON: сборка `stage3d06_spatial`, `stage3d09b_three_functionals`, `stage3d09b_functionals_unit` успешна; `ctest -R P09B_` = 3/3 PASS.
2. CMake Release под Linux, OpenMP OFF: обе новые цели успешно собраны, `ctest -R P09B_three_` = 2/2 PASS.
3. Один полный сквозной H0/ZERO сценарий EDV/VAR, `dt=300`, `tf=300`, QUAD3: SUCCESS.
4. Пробная матрица H0/GH3 (3 точки) × (E, ED, EDV) × (CONST,VAR), `dt=tf=300`: 18/18 завершённых траекторий.
5. Пересчёт арифметики: 18/18 строк `P09B_SCENARIOS.csv`, средние и дисперсии всех трёх характеристик во всех шести сочетаниях совпадают с выходным CSV.
6. **Регрессия:** все 6 средних, дисперсий и значения при xi=0 для `j6` P09B совпадают с сохранённой таблицей Stage 3D-09A (критерий относительного отклонения `1e-13` при масштабе `max(1,|a|,|b|)`).
7. Последовательная и параллельная механические сборки для H0 EDV/VAR при xi=0 и tf=300: все безразмерные наблюдаемые в `P09B_functionals_history.csv` совпадают по записанным цифрам (время выполнения различается).
8. Режим `--report-only` прочёл существующие 18 сценариев без новых вызовов FEM-решателя.
9. Отдельно продемонстрировано чтение теплового поля из существующей совместимой кампании P09A по сообщению `[REUSE P09A THERMAL]`.

## Ограничения

- Исполняемый код **не проверен непосредственно на Windows MinGW**: требуется локальная конфигурация Qt Creator Release.
- Три функционала реализованы для прямой задачи и GH-моментов. Модальные производные и поверхностный дискретный сопряжённый градиент **ещё не реализованы в Stage 3D-09B**; это Stage 3D-09C / Stage 3D-10.
- Нельзя восстановить новые функционалы только из старой таблицы `Psi6` или одиночного финального VTU. Для первого вычисления потребуются полные механические траектории, хотя старые совместимые температурные поля используются повторно.
- `jpeak` сглаженный приближённый показатель пиков, а не точный максимум; сравнение p=4/8/12 обязательно перед окончательной физической интерпретацией.
