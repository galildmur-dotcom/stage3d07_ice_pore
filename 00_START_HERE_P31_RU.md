# Stage 3D-06-P3.1: контрольная оптимизация MC-SGS (C++20, Qt Creator)

Это ПОЛНОЕ дерево P2+P3+P3.1. Предыдущие схемы `jacobi`, `sgs`, `mcsgs` доступны без изменений. Новая экспериментальная ветка — `mcsgs-fast` (прединдексированные нижние/верхние цветовые связи BCSR, повторно использующиеся при итерациях Ньютона). Физические E/ED/EDV и функционал Psi6 не изменены.

## Что запустить на Windows в Qt Creator

1. Распаковать архив в отдельную папку `Stage3D06P31`, открыть её `CMakeLists.txt` в Qt Creator.
2. Выбрать тот же MinGW Release Kit, что использовался в Stage3D06P3. Собрать `stage3d06_p31_qt_H0_mcsgs_fast`.
3. Запустить цель БЕЗ аргументов. Генерация теплового поля H0 и FEM расчёт EDV/VAR, dt=300, конец=300, q=3, 4 потока выполняются автоматически.
4. Новые результаты лежат в `LOCAL_RUNS_OPTIMIZED/benchmark_p31_mcsgs_fast/H0_dt300_q3/`, результаты P2/P3 НЕ перезаписываются.
5. Прислать только 4 файла: `QT_RUN_STATUS.txt`, `mechanics/profile_cg.csv`, `mechanics/profile_per_step.csv`, `mechanics/G06_campaign.csv`. Никаких тяжёлых папок, VTU или архивов результатов.

## Если нужно повторить для статистики

В Qt Creator в поле аргументов запуска ввести `--clean` (только для НОВОЙ P3.1 цели!) — её локальные результаты будут заново посчитаны и перезаписаны. Для честного профилирования следует проводить серию из нескольких прогонов каждым вариантом в перемежающемся порядке.

## Проверки и ограничения

`P31_VERIFICATION/P31_RESULTS_RU.md` — сопоставление с фактическими Windows замерами P2/P3 и отчёт о независимых Linux испытаниях. `P31_VERIFICATION/P31_LINUX_H0_SIX_TRIALS.csv` — 6 замеров исходного и индексированного MC-SGS. Новая реализация проверена сравнением полных FEM checkpoint на H0 (6 моделей, допуск 1e-6), проверена сборка с/без OpenMP; Windows MinGW и H4 остаются для проверки на компьютере пользователя. Пока нельзя считать MC-SGS более быстрым, чем Jacobi.

## Точные CLI параметры решателя

`--preconditioner jacobi|sgs|mcsgs|mcsgs-fast` при всех прежних ключах. Для `mcsgs-fast` по-прежнему поддерживаются `--spmv projected` и `--threads 1|2|4|8`.
