# Stage 3D-10C — глобальная аналитическая линеаризация Tet10

Дата: 04.11.2026. Применяется ПОСЛЕ успешно пройденного Stage 3D-10B.

## Что содержится в патче

- `src/stage3d10c_tet10_global_adjoint.hpp` — повторно используемый оператор одного механического шага Tet10: невязка и новое локальное состояние, аналитический JVP и точный VJP.
- `tests/stage3d10c_tet10_global_adjoint.cpp` — независимый регрессионный тест на двух связанных Tet10 (14 узлов, 42 степени свободы, 54 точки интегрирования, ненулевые закрепления).
- `PATCH_CMAKE_Stage3D10C.txt` — блок **для добавления в конец существующего** CMakeLists.txt.

Код использует действующие `src/mechanical.cpp`, `src/tet10_shared.hpp`, `src/edv_material.hpp` и ранее установленный `src/stage3d10b_edv_linearization.hpp`. Не заменять их файлами из старых архивов.

## Установка в Qt Creator / Windows / MinGW Release

1. Закройте выполняющиеся задачи проекта; менять ваши результаты и папку `runs` не требуется.
2. Скопируйте **только** два новых файла в соответствующие каталоги `src/` и `tests/` текущего проекта (не в `build/`).
3. Добавьте один раз блок из `PATCH_CMAKE_Stage3D10C.txt` **в конец существующего** `CMakeLists.txt`. Если аналогичная цель уже существует, повторно её не добавляйте.
4. В Qt Creator выполните **Build → Run CMake**, затем соберите цель `stage3d10c_tet10_global_adjoint` в конфигурации **Desktop MinGW Release**.
5. Запуск: цель `stage3d10c_tet10_global_adjoint`; **аргументы — пустые**; рабочий каталог — стандартный каталог сборки Qt Creator (тест не читает внешние файлы).

Ориентир для i7-7700K/64 ГБ: подготовка CMake 5–30 с, компиляция теста 20–120 с, **сам тест обычно менее 1 с**. Это оценка, не измерение на Windows. Память для тестовой задачи мала; больших CSV/VTU нет.

### Ожидаемое завершение

```
P10C_TET10_GLOBAL_ADJOINT_OK models=6 tet10=2 qp=54 dof=42 worst_residual_FD_rel=... worst_history_FD_rel=... worst_transpose_rel=...
```

**Пришлите только одну строку вывода** (или скриншот/текст ошибки). Файлы результатов от прошлых расчётов HP2/HP4/HP8 пока не нужны.

## Проверено на стороне разработчика

Компилятор GCC, C++20, оптимизация `-O2`:

```
P10C_TET10_GLOBAL_ADJOINT_OK models=6 tet10=2 qp=54 dof=42 worst_residual_FD_rel=8.735940686189e-10 worst_history_FD_rel=1.725816617016e-08 worst_transpose_rel=1.443289932013e-15
```

- Шесть сочетаний `E/ED/EDV × CONST/VAR`, с переносом истории в модели ED и EDV.
- Аналитическое глобальное JVP против независимых двухсторонних конечных разностей **по всем входам сразу**: смещения, узловая температура, старые внутренние переменные.
- Тождество транспонирования в глобальных и локальных переменных, включая закрепления и множитель `2` для тензорных сдвигов в `Bᵀσ`.
- Дополнительно, для E/CONST: невязка и касательная из нового оператора сравнены с `assemble_elastic()` и BCSR SpMV действующего базового МКЭ-кода.

## Ограничения результата

Тест проверяет блок *одного механического шага* на синтетической сетке. Он **ещё не означает**, что построен сопряжённый решатель для полной нестационарной истории, что вычислен поверхностный градиент формы или что подтверждены результаты на HP8.

Следующий осмысленный этап после подтверждения в Qt Creator — Stage 3D-10D: дискретное сопряжение по времени с решением сопряжённой системы равновесия `K_nᵀ λ_n = rhs_n`, обратной передачей внутренних переменных между временными слоями, а затем независимая проверка полной геометрической производной (R, tz, y20) методом конечных разностей. До проверки последнего этапа не объявлять полноценную shape-adjoint производную.
