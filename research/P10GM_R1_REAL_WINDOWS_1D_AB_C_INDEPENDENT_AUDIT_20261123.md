В B и C native exit code `1` является следствием предписанного `WALL_LIMIT` (не отдельный доказанный Gmsh error). Windows Job private memory limit 8 ГиБ не достигнут. Сценарий завершился штатным диагностическим статусом `DIAG_FIELD_1D_TIMEOUT_OR_STOP_NO_3D` и сохранил полный текстовый архив.

**Ограничение первичных данных:** архив включает оригиналы GEO, native журналы и манифесты, но **не включает** даже малый фактический `A_F3_BASELINE/P10GM_1D.msh`. В манифесте A записаны mesh SHA и 280 байт, однако сырые байты `.msh` независимо не проверены; именно завершение 1D, время и команду подтверждает собственный Gmsh log. Не выдавать это за КЭ-контроль количества/качества 1D элементов.

## Научный вывод и границы причинности

**Доказано операционно:** на проверенной геометрии исходный background F3 быстро завершает Gmsh 1D, тогда как два пути реализации южного поля P10GK воспроизводимо останавливаются на круговых кривых на 30-секундном пределе. Это подтверждает наличие проблемы при нативном вычислении/применении нового size-field в данном Gmsh-проходе, а не геометрический сбой, общий для всех трех случаев.

**Не доказано:** конкретная причина внутри Gmsh, возникновение нулевого/отрицательного размера, корректность реализации MathEval reference в данном контексте, фактическое число запрашиваемых сегментов, эффективность или пригодность южного адаптивного сгущения в 3D. C всё ещё ссылается на `F3`, поэтому C TIMEOUT **не исключает** проблемы именно с **переиспользованием сложного исходного `F3` из другого `MathEval`**. Нельзя говорить, что `F4/F5` сами по себе виноваты.

## Один следующий минимальный P10GN — только проект, не разрешённый запуск

Отдельная короткая native `-1` диагностика на той же неизменной геометрии:

Если D/E PASS, следующий изолированный тест нового множителя с заранее установленной консервативной **нижней границей `Mesh.MeshSizeMin`** (например, 0.2 мм, что ниже номинального near-wall ~0.407 мм), чтобы выявить потенциально аномально малый native h; не интерпретировать 1D PASS как доказательство исходной корректности field или 3D M1.
