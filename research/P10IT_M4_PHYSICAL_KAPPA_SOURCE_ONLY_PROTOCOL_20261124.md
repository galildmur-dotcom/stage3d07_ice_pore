## 2. Предварительно зарегистрированный индикатор

На общих физических bins i=(r,μ,φ), шагах n=1..36 и пяти ненулевых частях a∈{mechanical explicit, equilibrium, history, thermal mass, diffusion} определить подписанное изменение
```
ΔG[i,n,a] = G_M3[i,n,a] − G_M2[i,n,a].
A[i,a] = Σ_n |ΔG[i,n,a]|.
P[i,a] = A[i,a] / Σ_j A[j,a], если знаменатель >0.
m[i] = (P[i,explicit]+P[i,equilibrium]+P[i,history])/3.
t[i] = (P[i,mass]+P[i,diffusion])/2.
s_beta[i] = (1−beta)*m[i] + beta*t[i].
```
В качестве **основной гипотезы** β=0.10 (утверждён для M3, но для M4 необходим новый научный выбор). Отдельно рассчитать β=0 и β=0.25 для проверки устойчивости пространственного приоритета. Thermal Robin=0 хранить отдельно, не нормировать на 0. Сохранить подписанные ΔG в выходном CSV; модуль используется лишь для положительного индикатора, а не заменяет signed global closure.

Для сравнения вычислить также `A4D_total[i]=Σ_n |Σ_a ΔG[i,n,a]|`, `Aspatial_signed[i]=|Σ_n Σ_a ΔG[i,n,a]|` и индикатор знаковой компенсации `C[i]=Σ_{n,a}|ΔG[i,n,a]|/(|Σ_{n,a}ΔG[i,n,a]|+ε)` исключительно как диагностику; не смешивать эти три нормы. Основная `s_beta` защищает от взаимной компенсации по времени и компонентам. Отдельно сформировать первые/последние 12 шагов и полярные север/юг, чтобы заметные различия на шагах 34–36 не скрылись агрегированием.

## 3. Обязательные проверки до κ

1. Неподменённые hash/manifest M2/M3; 36 шагов, 1200 физических bins, 43200 объёмных строк и отдельные Robin; одинаковые числовые границы bins, отсутствие повторов и пропусков, finite components, положительная QP-поддержка.
2. Глобальная signed closure: `Σ_{i,n,a} ΔG = D_R jpeak(M3)−D_R jpeak(M2)` с явной абсолютной/относительной невязкой. Сверить раздельные пять компонент с P10IS. Несовпадение: STOP.
3. Для каждой компоненты ненулевой знаменатель перед нормировкой; сохранение суммы `Σ_i P[i,a]=1`. Любой NaN/Inf: STOP.
4. Физические поддержанные полярные области: radial bins 0..4, μ-bin 9 север / μ-bin 0 юг, d≤0.5 мм, |μ|≥.8. Отдельно показывать `N_eff`, signed, L1, peak κ и долю индикатора; слабая поддержка → диагностический статус, не ложный hard gate.
5. Сопоставить с картами κ(P10IM) и P10HA в одинаковых пространственных bins. Зафиксировать индекс Жаккара множества Дёрфлера θ=.5 и fraction score в supported polar. Не объявлять любой score истинной апостериорной оценкой погрешности.

## 4. Непрерывное поле и кандидат на M4

Для исходных 1200 центров применять неотрицательное компактное Wendland C² на `u=log(1+d_mm/.05)` и сферических Cartesian направлениях (масштабы .75/.60), как P10IN. Проверить непрерывность через φ=±π, северный и южный полюса, отсутствие негативного κ и скачков между патчами. Нормировать κ∈[0,1] без принудительного полярного mask; если исходные данные требуют сдвига максимума от полюса, его сохранять.

**Целевой D-029 gate для будущей реальной M4:** `Veff(M4)/Veff(M3)∈[.50,.75]` в достаточно поддержанных физических областях максимального κ (центральная проектная гипотеза .65), не для каждого Tet10. Перенос P10IN коэффициентов калибровки север/юг не считать измеренным законом M3→M4: сначала source-only оценка и диапазон неопределённости, затем одна отдельная mesh-only попытка лишь после обсуждения и допуска. Сохранить неизменную оригинальную CAD с поворотом сферической параметризации на 90°, surface tags, B6. D-031: minSICN≥.20, minSJ≥.40, gamma≥.15, положительные curved 27/343/729QP detJ и CAD closure. D-030: соседнее q диагностическое, **не** самостоятельный hard gate.
