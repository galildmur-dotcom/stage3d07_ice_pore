## Принципиальное ограничение

По P10BK, `origin` уже GitHub. Независимая проверка GitHub не нашла родительский локальный SHA `c0498f6...`. Поэтому публикация **самого** локального коммита `90fd2559...` как объекта Git может потребовать загрузить всю недостающую цепочку истории с её файловыми объектами, а не только семь согласованных изменений. Нулевой счётчик `SENSITIVE_NAME_PATTERNS` означает лишь отсутствие **распознанных шаблонов в именах**; содержимое исторических документов, CSV и исходников этим тестом не проверено на приватность, лицензии и сведения, не предназначенные для публичного репозитория.

## Два корректных способа продолжения — решение исследователя

**A. Публикация полной локальной истории** (56 достижимых коммитов, несжатые blob ≈15,22 МБ). Позволяет сохранить точно `90fd2559...` как доступный GitHub commit SHA, но **публикует все отсутствующие исторические объекты**. Нужны явное согласие владельца на этот охват и отдельно проверенная процедура создания **новой** GitHub-ветки без force-push/слияния с `master`, а не прежняя PORE-кнопка. Даже такой push не затронет 7 unstaged и 4 untracked записи.

**B. Ограниченный снимок семи исходников** с документированным локальным SHA `90fd2559...`, без отправки всей старой истории. Семь исходных файлов уже зарегистрированы побайтно в `research/sources/P10BF_UNCOMMITTED_20261118/`, а отдельный кандидат с рабочими штатными путями — `research/p10bg-source-integration-20261119`. Можно подтвердить mapping SHA и создать новый архивный commit/manifest в GitHub; **его собственный Git SHA будет отличаться** от Windows-коммита, потому что родительская история другая. История пользователя сохранится локально и в его независимых резервных копиях.

**Рекомендация до отдельного согласия:** не выполнять полный push. Сначала спросить пользователя, хочет ли он сделать публичной **всю** достижимую старую историю; при неопределённости выбрать B. Ни один новый локальный/удалённый push на момент этого отчёта не выполнен. Научные результаты P10BB/P10BE, provenance исторических EXE и недоказанная пространственная сходимость не меняются.
