## Оставшийся критический исходник

Выявлена отсутствующая зависимость **`src/stage3d10az_probe_export.hpp`**: её подключают и новый `stage3d10ba_polar_export.hpp`, и `src/stage3d10p_partial_audit.cpp`, и тест `tests/stage3d10v_analytic_shape.cpp`. Её нет ни в текущем GitHub HEAD, ни среди пяти файлов полученного ZIP. Попытка самостоятельной компиляции unit-теста P10BE завершилась на `fatal error: stage3d10az_probe_export.hpp: No such file or directory`. В данной Linux-среде также нет `cmake` и Windows PowerShell, поэтому полный CMake/MinGW build не проверен.

**Решение о публикации:** точный пользовательский рабочий снимок хранить отдельно как происхождение. **Не подменять им действующие `src/`, `tests/` и `CMakeLists.txt` в GitHub**, пока отсутствует базовый P10AZ header и не собрана/протестирована единая цепочка целей. Это защищает уже существующую ветку от заведомо несобираемого изменения.
