# P10LS — реальная EDV M9: подготовлена независимая диагностика межэлементных скачков

Дата: 2026-11-25. Статус: **SOURCE QA PASS; физический FEM не запускался**.

## Научная постановка

В штатном обратном механическом ходе R/EDV_VAR, xi0, B6=5 mm, M9,
36 шагов по 25 s, фиксируем на каждой из 27 квадратурных точек tet10
конститутивное напряжение `qp.law.response.sigma` и его **геометрическую
вариацию** `law.d_sigma` из `qp.law.jvp(deps,0.,State{})`.
Это геометрическая производная в смысле JVP для заданного возмущения,
**не** пространственный градиент напряжения.

Для обоих полей строятся отдельно P1 и P2 воспроизведения на общих
внутренних гранях, затем диагностики скачка тензора, нормальной тяги
и геометрической вариации. 1200 радиально-полярно-азимутальных корзин
на каждый временной шаг для каждого из P1/P2: ожидаются 86 400 строк
`P10LS_FACE_JUMP_4D.csv`.

Важно: это скачки **восстановленных односторонних следов** из объемных
квадратурных точек, а не непосредственные значения на гранях и не
доказательство сходимости при сгущении сетки. В самом тонком пристеночном
слое `radial_bin=0` нет центроидов внутренних граней, поэтому нулевое
количество означает отсутствие поддержки выборкой, **не** нулевой скачок.

  (сбор значений в QP) и `src/stage3d10p_partial_audit.cpp` (граневой CSV).
- Linux `g++ -std=c++20 -fopenmp -O0 -fsyntax-only` для собранного Windows-пакета: PASS;
  **не** является подтверждением Windows runtime или FEM.
- Независимый Python-аудитор: синтетический положительный тест PASS и

## Исправление R2 после первого Windows `01` (2026-11-25)

Первая сборка пакета ошибочно оставила в `P10LS_M9_FACE_JUMPS.py`
строку `SOURCE_REVISION=P10LS_M9_TWO_TERM_EXPLICIT_INSTRUMENTED_P10LG_V1`,
хотя закреплённый манифест содержал
`P10LS_M9_EDV_P1_P2_FACE_JUMP_PHYSICAL_DIAGNOSTIC_V1`.
Поэтому `01` остановился на строгой проверке ревизии **до** FEM и
расходования маркера. Это ошибка упаковки, а не ошибка расчётной модели.

Исправлен генератор; новый независимый выход —
`p10ls_package_r2/P10LS_M9_FACE_JUMP_WINDOWS_PREPARED_R2.zip`.
Проверено исполнением `preflight()` без Windows-проверки платформы:
**P10LS_M9_PREFLIGHT_PASS_NO_FEM**, `source_count=101`,
`tet10=13166`, `dt_s=25`, `steps=36`, SHA M9 неизменён.
Это проверяет всю реальную логику предварительного аудита, но не
Windows native watchdog, который должен пройти у пользователя через `01`.
**Пакет R1 не использовать.**
