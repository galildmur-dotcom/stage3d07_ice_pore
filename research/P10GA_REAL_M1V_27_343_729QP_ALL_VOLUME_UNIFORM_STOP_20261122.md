# P10GA — реальная M1V: 3D геометрия GO, равномерная адаптация STOP

**Дата:** 22.11.2026. **Научный статус:**
`M1V_GEOMETRY_CURVED_729QP_PASS`,
`M1V_ALL_18_SIGNED_ZONES_15_20_PERCENT_STOP`, **FEM=0**.

- Свежая raw `M1V_CANDIDATE.msh` SHA256

- Ни raw M0, ни raw M1V публично **не публикуются**.

## Независимая геометрия

Независимый парсер MSH2, квадратичные функции формы Tet10,
исходные криволинейные якобианы и объёмный интеграл. Не используются
производственные FEM матрицы, нет Gmsh и forward/adjoint.

| Величина | M0 | M1V |
|---|---:|---:|
| Узлов | 11 699 | 14 169 |
| Tet10 | 7 992 | 9 687 |
| Tri6 поры | 160 | 186 |
| Интегрированный объём, м³ | 0.0001799958140411 | 0.0001799958135175 |
| Минимальный detJ при27QP | 2.72×10⁻¹¹ | 5.79×10⁻¹² |
| Отрицательный detJ при343/729QP | 0 | 0 |
| Максимальная ошибка радиуса узлов поры, м | 5×10⁻¹⁸ | 5×10⁻¹⁸ |
| Северные полярные Tri6 | 18 | 17 |
| Южные полярные Tri6 | 20 | 22 |

**Предварительный геометрический GO**: положительные криволинейные
якобианы и сохранение физического объёма; но локальная гладкость
не сводится к положительному detJ. Производственная QA27 сообщила
соседний jump p95=1.362, max=2.227; около полюсов p95=1.395,
max=2.198 — учитывать отдельно в дальнейшем адаптивном алгоритме.

## Фактическая плотность: строгий критерий M0→M1V

Определение: в **той же фиксированной физической 3D зоне** для
каждой сетки `Veff(Z)=V_QP(Z)/N_fractional_Tet10(Z)`, где доли
определяются интегрированием индикатора Z в 343 или 729 объёмных
точках Тет10. Это сравнение **не** строит ложную пару тетраэдров.

`G=Veff(M1V,Z)/Veff(M0,Z)` должен быть **от 0.80 до 0.85 во всех
18 зонах** (3 радиальных × 3 полярных × север/юг).

| Радиальная зона | Полярная зона | Север G | Юг G |
|---|---|---:|---:|
| 0–100 мкм | `|μ|≥0.8` | **1.080 FAIL** | 0.820 PASS |
| 0–100 мкм | `0.6<|μ|<0.8` | **0.762 FAIL** | **0.641 FAIL** |
| 0–100 мкм | `|μ|≤0.6` | **0.798 FAIL** | **0.788 FAIL** |
| 100–500 мкм | `|μ|≥0.8` | **0.953 FAIL** | **0.798 FAIL** |
| 100–500 мкм | `0.6<|μ|<0.8` | **0.768 FAIL** | **0.745 FAIL** |
| 100–500 мкм | `|μ|≤0.6` | **0.877 FAIL** | 0.849 PASS |
| >500 мкм | `|μ|≥0.8` | **0.851 FAIL** | 0.844 PASS |
| >500 мкм | `0.6<|μ|<0.8` | 0.801 PASS | 0.838 PASS |
| >500 мкм | `|μ|≤0.6` | 0.822 PASS | 0.817 PASS |

Проверка: **7/18 PASS, 11/18 FAIL**. Минимальный G=0.640695,
максимальный G=1.080229; максимальная абсолютная разница
343→729QP для G=0.007347 (меньше зафиксированного допуска 0.02).

При этом общий `Veff(M1V)/Veff(M0)=0.825023`, то есть
**средний объём уменьшается на17.50%**. Глобальная метрика
обманчиво хороша: северный полюс в самом ближнем слое фактически
укрупнён на8.0%, южная переходная зона переразбита на35.9%.

По сравнению с предыдущей отвергнутой M1 (`5/18 PASS`) новая
M1V несколько улучшила число допустимых зон до `7/18`, но
сохранила сильный **северо-южный перекос** и создала иной характер
зональных ошибок. Простой инверсный пересчёт номинального `h³`
по прошлой сетке **не является надёжной локальной моделью Gmsh**.

В частности, северный полюс 0–100 мкм: M1 `G=0.8448` → M1V
`G=1.0802`; южный полюс 0–100 мкм: M1 `1.0959` → M1V `0.8196`.
Эта разная реакция и изменение числа Tri6 требуют отдельного
контроля поверхностной триангуляции в следующем этапе.

## Воспроизводимость и пределы вывода

Исходный независимый скрипт
`scripts/p10ga_verify_m0_m1v_signed_18_729qp.py` использует
проверенные SHA raw MSH, раздельные 343/729QP, 18 знаковых зон,
геометрические объёмы и сам по себе **не запускает Gmsh или FEM**.
JSON с полной точностью:
`research/evidence/P10GA_M1V_UNIFORM_ALL_VOLUME_20261122/derived/P10GA_M0_M1V_SIGNED18_343_729QP.json`.

Контрольная картинка сравнения реальных зон M1 и M1V:
`research/evidence/P10GA_M1V_UNIFORM_ALL_VOLUME_20261122/derived/P10GA_M1_TO_M1V_18_SIGNED_ZONES_729QP.png`.

Промежуточные флаги в JSON: `curved_geometry_gate=true`,
`quadrature_stable_below_0p02=true`, `strict_18_zone_all_pass=false`,
`scientific_mesh_go=false`, `verdict=M1V_ADAPTATION_STOP_NO_FEM`.

**Заключение:** M1V нельзя утверждать в `approvals/` и нельзя
использовать для физического расчёта в текущем исследовательском
протоколе. Одноразовый 3D-запуск P10FX для M1V уже израсходован;
M1V *не* переделывать на том же имени, маркеры не удалять.

**Следующий научный шаг:** разработать новый **отдельный кандидат**
M1W с демпфированной C¹ обратной связью от 18 real QP зон,
сохранением исходной M0 и валидной M1V и предварительным
**необъёмным контролем северного/южного качества Tri6 на поре**.
Экстраполяцию фактической локальной плотности не выдавать за
гарантию. Только после реального независимого 729QP PASS всех 18
зон выдавать GO на свежие forward и same-mesh adjoint.
