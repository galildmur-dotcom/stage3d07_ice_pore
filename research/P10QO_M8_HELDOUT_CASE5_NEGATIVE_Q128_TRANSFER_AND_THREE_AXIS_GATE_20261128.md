# Stage3D07 — P10QO: отрицательный перенос q128 на новый реальный элемент M8 и независимый трёхосный контроль

**Дата:** 28.11.2026. **Предыдущий этап:** [P10QN](P10QN_M8_ADAPTIVE_Q_ORDER_HELDOUT_NEGATIVE_AND_THREE_AXIS_Q128_POSITIVE_20261128.md). **Ветка:** `research/p10bb-w5b2-20261118`.

**Главный результат:** равномерная лучевая квадратура q128, прошедшая три оси на реальном исходном элементе №6008 (P10QN), **НЕ прошла** заранее заданные те же эмпирические пороги `1e-6` на другом реальном элементе M8 **№5865**. Независимый от обучения выбор геометрии — случай №5 прежней подборки P10QJ, сектор `(r=4, μ=0, φ=6)`. Получен воспроизводимый отрицательный результат, без сокрытия неуспеха и без изменения критерия после вычисления. **Физические FEM, 4D/EDV/adjoint запрещены.**

## 1. Зафиксированные исходные условия

- Сетка M8 **не изменялась**; SHA256 `40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d`; искривлённые Tet10 (12 546 элементов). Gmsh, CAD, генерация сетки и физический FEM не запускались. Если в будущем будет вызвана оптимизация Gmsh, использовать **`HighOrderElastic`**.
- От P10QL наследуется независимая от Algoim схема: для каждой физической P4/P2 границы на прямой в опорном тетраэдре находятся интервалы внутри области; истинный кубический числитель P2-FE-градиента **интегрируется по лучу аналитически**; только оставшиеся две переменные интегрируются `n×n` квадратурой Гаусса–Лежандра. Оси `0`, `1`, `2` — разные способы исключить одну переменную.
- Полный неотсечённый полиномиальный момент каждой криволинейной подобласти независимо воспроизведён с относительной погрешностью `<1e-10` и проверкой полного объёма. Это проверка формулы полного момента, **не доказательство точности отсечённого интеграла**.
- На h8 исходный элемент №5865 дал **47 терминальных подобластей**: 8 полностью внешних, 9 внутренних, **23 однограничных + 7 двухграничных**, то есть 30 настоящих cut-областей. Полная сумма объёмов при разбиении имеет невязку `1.28e-14` в долях исходного физического объёма; Bernstein-полоса неизвестного вклада multi до `2.1763e-15 m³`. Этот остаток **не объявляется численной оценкой ошибки** лучевого интегратора.
- Для всех 30 отсечений **без адаптивного подбора** рассчитаны порядки `n=16,32,64,128` для всех трёх осей. На каждую ось затрачено **652 800** поперечных точек только на эти четыре порядка; один q128 — **491 520** поперечных точек на ось. Все 90 комбинаций «cut × ось» вычислены реально.
- Проверка использует **сумму модулей** разностей на одних и тех же 30 cut-областях. Подписанная разность итоговых интегралов не может дать проход при взаимной компенсации ошибок. Норма градиента — модуль полного *отсечённого гибридного* градиентного момента рассматриваемого исходного элемента, норма объёма — полный физический объём исходного элемента.

## 2. Уточнение порядка на каждой независимой оси

Абсолютно во всех строках L1 означает сумму по 30 физически тем же областям: `Σ_cells |I_new - I_old|`.

| Ось лучей | L1 градиента q64→128 / гибридный градиент | L1 объёма q64→128 / полный исходный объём | Результат при `1e-6` |
|---|---:|---:|---|
| 0 | `8.7564e-6` | `1.1608e-6` | оба не прошли |
| 1 | `9.1247e-6` | `1.2167e-6` | оба не прошли |
| 2 | **`1.6226e-5`** | **`2.1509e-6`** | оба не прошли |

Для понимания скорости сближения: на оси 2 относительный L1 градиента падает с `7.8802e-4` (q16→32) до `8.6227e-5` (q32→64), затем лишь до `1.6226e-5` (q64→128). Уменьшение наблюдается, но **порог пока не достигнут**. Аналогичное поведение на остальных осях отражено в полном машинном JSON.

На оси 2 подписанное изменение при q64→128 составляет `−1.8599e-20 m³`, а сумма модулей **`1.7256e-19 m³`** — примерно **9,3-кратная компенсация положительных и отрицательных локальных изменений**. Поэтому проверка только суммарного результата особенно опасна.

## 3. Попарное сравнение независимых осей при фиксированном q128

| Пара осей | L1 градиента / гибридный градиент | L1 объёма / полный исходный объём | Критерий `1e-6` |
|---|---:|---:|---|
| 0 ↔ 1 | `2.0779e-6` | `2.7726e-7` | градиент **FAIL**, объём PASS |
| 0 ↔ 2 | **`2.9872e-6`** | **`3.9644e-7`** | градиент **FAIL**, объём PASS |
| 1 ↔ 2 | `2.6058e-6` | `3.4639e-7` | градиент **FAIL**, объём PASS |

**Четыре независимых агрегированных гейта:**

1. Все три внутрииосевых q64→128 градиентных L1 ≤ `1e-6`: **FAIL**.
2. Все три внутрииосевых q64→128 объёмных L1 ≤ `1e-6`: **FAIL**.
3. Все три межосевых q128 градиентных L1 ≤ `1e-6`: **FAIL**.
4. Все три межосевых q128 объёмных L1 ≤ `1e-6`: **PASS**.

Таким образом **даже положительная межосевая проверка объёма не заменяет проверку сходимости по порядку q**: оба метода могут разделять сопоставимую ошибку. В P10QN q128 давал L1-градиент между осями не более `6.217e-7` на элементе №6008; новый проверочный №5865 показывает, что успешность на одном элементе **не переносится автоматически** на другой.

Максимальные наблюдаемые нормированные несогласованности нового случая: q64→128 — **`1.6226e-5` по градиенту** и **`2.1509e-6` по объёму**; межосевые q128 — **`2.9872e-6` по градиенту** и **`3.9644e-7` по объёму**. Все четыре числа пересчитаны отдельным независимым аудитором из построчных данных, включая воспроизведение полных гибридных сумм.

## 4. Геометрическая диагностика остальных реальных проблемных элементов

Проведена **только** безопасная консервативная подготовка реальных Tet10-подобластей из той же исходной M8; квадратичные числители и аналитические полные моменты записаны в файлы для следующих опытов. Никакого высокопорядкового cut-интегрирования или физического расчёта для случаев 6 и 7 не заявляется.

Из этих данных **не следует**, что сама q128-квадратура на новой h12-геометрии станет точнее: требуется новый независимый опыт. h10/h12 **не** использованы для подмены отрицательной проверки h8.

## 5. Научный вывод и следующий этап P10QP

1. **Запретить распространение режима «равномерный q128 достаточно точен» с случая 4 на другие M8.** Сохранять метку `P10QO empirical_joint_pass=false`; не пересматривать уже установленный критерий и не заменять L1 подписанным результатом.
2. Локализовать наиболее нестабильные cut-области (в JSON сохранены точные индексы, группы и поосевые разности). Следующий эксперимент — независимые q128→q256 и/или дробление **поперечного интегрирования** на таких областях, с заранее замороженными контрольными направлениями. Не выбирать пороги после просмотра результата; явно учитывать стоимость.
3. Для физических P4/P2 границ нужны отдельные диагностические проверки касаний/близких корней и **строгие** корневые/интервальные границы ошибки с контролем направленного округления. Равенство результатов по трём осям остаётся только эмпирическим свидетельством.
4. Только после успеха **на независимых случаях и по глобальным 43 200 4D-ячейкам**, проверки локальной сходимости и получения обоснованного бюджета погрешности обсуждать физические FEM/EDV/shape-adjoint. Никакого FEM на P10QO.
