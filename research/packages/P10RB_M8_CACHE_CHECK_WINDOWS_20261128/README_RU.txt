Stage3D07 / P10RB — проверка сохранённой истории M8

1. Полностью распакуйте ZIP в отдельную папку Windows.
2. Дважды щёлкните файл 01_P10RB_CHECK_EXISTING_M8_CACHE_NO_FEM.cmd.
3. Дождитесь P10RB_PASS; окно может закрыться сразу после завершения.
4. Отправьте один файл из этой же папки:
   P10RB_M8_CACHE_INVENTORY.json

Действия только для чтения:
- проверяется существующая папка G:\ildar\Stage3D07\LOCAL_RUNS;
- определяется наличие forward_history.bin предыдущего успешного M8;
- читается размер файла и прежний манифест, весь многогигабайтный кэш НЕ читается;
- никакой FEM, Gmsh, EDV, adjoint, новые сетки и предыдущие one-shot НЕ запускаются;
- никакие существующие данные проекта не меняются.

При отсутствии истории в JSON будет статус NO_EXISTING_HISTORY_FOUND.
При отсутствии самой папки будет статус RUNS_ROOT_MISSING.
В обоих случаях пришлите JSON — дальнейшее решение примем по результату.

Никаких интерактивных запросов и кнопок в CMD нет.
