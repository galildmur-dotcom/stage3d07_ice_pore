Это *не* независимые доли; их нельзя складывать. Азимутальные сектора φ сохраняются полностью, а не усредняются до маркировки. ## 4. Решение о следующем шаге

1. **P10GW independent 4D comparison PASS.** Новая M1 не только mesh-only GO: один настоящий полный физический R/EDV_VAR/ξ0 расчёт успешен. Не утверждать на основании двух сеток пространственную сходимость D_R jpeak.
2. **`M2 ADAPTATION NOT YET GO`:** P10CG/P10GF требуют ограничить локальную временную неопределённость индикатора до использования межсеточных signed разностей для κ(x). Известная P10BE H2 dt50/25 4D L1 не показала убедительного уменьшения, а наша новая M0/M1 пока только dt150. Временные тренды нельзя извлечь из шести временных вкладов при одном dt как оценку ошибки схемы.
3. Следующий защищённый эксперимент: подготовить *пары* свежих сопоставимых M0/M1 расчётов на уменьшенных dt с одним t_f и теми же 4D **физическими** bins, чтобы оценить `L1_time` относительно `L1_mesh` и отделить погрешность временной сетки от пространственного сигнала; не смешивать отдельные старые H2 результаты с новой M0/M1. Конкретный dt (например 75с) и ограничения ресурсов фиксировать **до** нового native FEM. После первого dt75 возможен dt50/25, если шум велик — без автовыполнения.
4. Если временная неопределённость окажется приемлемой, построить отдельные компонентные 4D `η_B` с нормировкой на объём и QP-support, применить Dörfler-marking, затем C² сглаживание `κ(x)∈[0,1]`; только после этого создавать защищённую M2 с фактической проверкой 15–25% локального характерного объёма при κ=1 и D-025. Для полярных регионов сохранить неполярный контроль.

**Физические расчёты P10GW локально не запускались.** Опубликованный JSON — только независимый разбор двух уже выполненных первичных Windows evidence.
