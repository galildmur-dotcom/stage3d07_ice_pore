# Stage3D07 — P10QU: трёхосная сходимость 30 настоящих криволинейных cut-подобластей M8 с выделением критических точек

**Дата:** 28.11.2026. **Предыдущая научная запись:** [P10QT](P10QT_M8_ALL30_CURVED_CRITICAL_EVENT_AXIS2_EMPIRICAL_PASS_AND_ROOT_GUARD_20261128.md). **Ветка:** `research/p10bb-w5b2-20261118`.

**Итог P10QU:** на одном исходном криволинейном Tet10 №5865 сетки M8 впервые завершён **трёхосный q128/q256-аудит всех 30** реально отсечённых h8-подобластей, включая 7 с двумя физическими границами и 1 с радиальной. Исходный порог **относительного некомпенсированного L1 `1e−6`** выдержан для всех пар **трёх направлений** с новой квадратурой, в том числе при том же бюджете q128, на котором обычная квадратура не выдерживала сравнения. При внешнем порядке q256 L1-различие осей 0 и 1 равно **`1.59228824e−8`** против **`2.07792865e−6`** у прежнего равномерного q128 — сокращение в **130,5 раза**. Это существенное **эмпирическое** подтверждение, но **не интервальная сертификация истинной ошибки** и **не разрешение 4D/FEM**.

## 1. Геометрия, которая действительно использована

- Неизменённая сетка `M8.msh`: SHA256 **`40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d`**, исходный реальный криволинейный **Tet10 №5865**, сектор `(r=4, μ=0, φ=6)`, h8.
- Все **30** cut-подобластей: **22** с одной активной азимутальной границей `[4]`, **7** с радиальной/азимутальной `[0,4]`, **1** с радиальной `[0]`.
- Для осей **0 и 1** вновь получены коэффициенты именно *физических* граничных полиномов на настоящем Tet10, отдельно для каждого внешнего `t`-среза. Условие радиальной границы вообще имеет степень до 4 по лучу, азимутальной — до 2. На данном **конкретном M8-элементе** проверено численное снижение до **P2 и P1 соответственно также по обеим новым осям**. Это не предположение о произвольном Tet10 и не разрешение отбрасывать старшие коэффициенты без проверки на других элементах.
- Ни сетка, ни поле P2-конечного элемента, ни аналитический кубический примитив вдоль луча не изменялись. Для вычисления `det(J)` и градиентного числителя применена **настоящая криволинейная геометрия**. Обычный Гаусс–Лежандр по оставшимся поперечным координатам **не отменён**: его узлы перераспределяются по гладким интервалам, найденным по корням физических ограничений.
- CAD/Gmsh, перестроение/оптимизация сетки, термомеханическая модель, 4D, EDV, adjoint и физический FEM **не запускались**. Любая будущая оптимизация Gmsh — исключительно с обязательным **`HighOrderElastic`**, согласно установленному правилу проекта.

## 2. Зафиксированная методика и предварительная проверка

Для фиксированной внешней координаты `t` и любого исследованного направления луча `w` после *проверенного на данном элементе численного снижения степени*:

\[
R(s,w;t)=a_R(s;t)w^2+b_R(s;t)w+c_R(s;t),\qquad
A(s,w;t)=b_A(s;t)w+c_A(s;t).
\]

Сначала строятся разбиения по `s` из реальных корней радиального дискриминанта `b_R²−4a_R c_R`, значений граничных полиномов на концах луча `w=0,1`, условий изменения степени и результанта пересечения **двух** границ

\[
\operatorname{Res}_w(R,A)=a_R c_A^2-b_R b_A c_A+c_R b_A^2.
\]

Затем для каждого `t` распределяются **ровно 128 внутренних узлов** по полученным интервалам, при внешних порядках **128** и **256**. Вдоль `w` интегрируется аналитический кубический FE-примитив; распределение узлов не подстраивается под полученный q256. **Для каждого cut отдельно** проверены исходные аналитические полные градиентный и объёмный моменты с этим новым разбиением.

**Предварительный полный проход до интегрирования:** `30 × 2 × (128+256) = 23 040` реальных внешних узлов. Он завершён без скрытия неудачных срезов:

| Проверка всех 30 cut и обеих новых осей | Фактический максимум / счёт |
|---|---:|
| Реальных проверенных внешних `t`-срезов | **23 040** |
| Численно удалённых малых старших коэффициентов азимутального события с регистрацией каждого случая | **22 242** |
| Максимум степени `w³,w⁴` радиального P4 относительно масштаба его коэффициентов | **`4.9580923e−12`** |
| Максимум степени `w²` азимутального P2 | **`2.1775083e−14`** |
| Максимальная относительная ошибка независимого восстановления физических P4/P2 | **`6.9577476e−11`** |
| Максимум построенных `s`-интервалов на `t`-срез | **10** |
| Зафиксированные изменения сигнатуры корней на пяти внутренних пробах интервала | **0** |

Как и в P10QT, корректировка **не более `1e−10` по относительной величине** разрешалась только для старшего *численно вырожденного* коэффициента полинома события `azimuth_degree_change`. Строгий тест невязки найденного действительного корня оставлен. Но по конечному набору проб **не доказано** отсутствие незамеченных касаний, а двойная точность и порог удаления малых коэффициентов требуют дальнейшего интервального анализа.

## 3. Независимый L1-аудит против прежнего численного q256 оси 2

Для **каждой из всех 30** подобластей собраны неизменённые реальные q256-значения оси 2 из P10QR/P10QS/P10QT. Независимый P10QU-аудитор заново считал **суммы модулей** `|I_axis,method,k − I_axis2,uniform_q256,k|`, нормированные полным гибридным q128 градиентным моментом **`1.0635010716541399e−14 m³`**. Дополнительно отдельно проверен исходный аудит P10QT с точностью `1e−12` по относительному L1. Оригинальный физический полный объём для объёмного нормирования — **`4.000099545490653e−14 m³`**.

| Все 30 cut; сравнение с осью 2, обычный q256 | Обычный q128 | Критические события q128 | Критические события q256 |
|---|---:|---:|---:|
| **Ось 0, L1 градиента** | **`1.59568462e−6` FAIL** | **`4.50901556e−7` PASS** | `4.12319693e−7` PASS |
| **Ось 1, L1 градиента** | **`1.44649938e−6` FAIL** | **`5.01917690e−7` PASS** | `4.20965759e−7` PASS |
| Ось 2, результат P10QT | **`2.13192242e−6` FAIL** | **`6.88212469e−7` PASS** | `4.38844179e−7` PASS |

**Стоимость на каждую ось:** q128 с критическими событиями — **491 520** точек поперечной квадратуры по всем 30 cut, **ровно столько же**, сколько у обычного q128. Сегментированная внешняя q256 — **983 040** точек; обычная полная двумерная q256 потребовала бы **1 966 080** точек. Результат не объясняется скрытым увеличением бюджета q128.

В отношении того же осевого q256 улучшились **23 из 30** подобластей оси 0 и **22 из 30** оси 1. Остальные **включены в L1**. Улучшение суммы модулей **не** означает, что каждый отдельный cut стал точнее.

## 4. Самое важное — сравнение независимых направлений нового алгоритма

В следующей таблице никакая ось не выступает «истиной»: вычислены непосредственно `Σ_k |I_a,k − I_b,k|` для **трёх независимых построений физических лучей**. Здесь ось 2 берётся из ранее зафиксированного P10QT, оси 0 и 1 — из P10QU.

| Пара направлений, все 30 cut | Критические события q128: относительное L1 градиента | Критические события q256: относительное L1 градиента |
|---|---:|---:|
| **0 ↔ 1** | **`1.85351334e−7`** | **`1.59228824e−8`** |
| 0 ↔ 2 | `4.03408449e−7` | `6.89306063e−8` |
| 1 ↔ 2 | `5.14826533e−7` | `7.61248479e−8` |

**Вывод:** эмпирический порог `1e−6` выполнен **всеми тремя парами осей** уже при новом q128; при q256 максимальное попарное отличие — **`7.6125e−8`**. При равном q128-бюджете для пары осей 0 ↔ 1 **обычный** q128 имел L1 **`2.07792865e−6`** (FAIL), а **новый** — **`1.85351334e−7`** (PASS). Новые q256 в этой паре довели L1 до **`1.59228824e−8`**, сокращение относительно обычного q128 примерно в **130,5 раза**.

Проверки изменения порядка на одной оси также выполнены, все ниже `1e−6`:

| Ось | `Σ|I_critical128−I_critical256|`, относительный L1 |
|---|---:|
| 0 | `4.74260838e−8` |
| 1 | `1.70047368e−7` |
| 2 | `4.43400847e−7` |

Для самой сильной пары 0 ↔ 1 на q256 **некомпенсированный** L1 составляет **`1.693400e−22 m³`**, тогда как подписанная разность **`−2.493804e−23 m³`**: даже здесь имеется компенсация примерно **6,79 раза**. Поэтому только совпадение подписанных интегралов было бы недостаточным основанием для приёмки.

## 5. Научная интерпретация и границы достоверности

1. **Положительно:** на реальной криволинейной M8, без какого-либо сгущения/изменения сетки, *тот же 128×128-бюджет* с явными критическими событиями делает согласованными все 30 cut по **трём осям**, причём L1 без компенсации. Это явно сильнее P10QT с одной осью.
2. **Отдельно важно:** при q256 все три новые осевые оценки лежат намного ближе друг к другу, чем к обычному равномерному q256 оси 2. Значит, последний — лишь **численный компаратор**, а его собственную ошибку ещё нельзя считать пренебрежимо малой. Интерпретация «q256 — точное решение» **запрещена**.
3. **Не доказано:** интервальные границы для вещественных корней, доказанная максимальная ошибка самих значений, отсутствие незамеченных касаний между несколькими точками-пробами, результативность алгоритма на иных элементах M8/секторах, а также перенос вырождения P4→P2/P2→P1 на них.
4. **Не исследованы здесь:** другие ранее проблемные случаи **6/7**, полная совокупность **43 200 4D-ячеек**, термомеханический/EDV/adjoint FEM и истинная производная формы функционала `j_peak`. Текущий тест относится к реальному криволинейному P2-FE градиентоподобному полиномиальному интегралу в одной исходной ячейке, но **не является физическим расчётом**.

**Решение этапа:** принять как **трёхосный эмпирический локальный PASS** для исходного M8 Tet10 №5865 при пороге `1e−6`; не повышать статус до доказанной сходимости всех M8/4D-расчётов и **не начинать физический FEM**.

## 6. Рекомендуемый следующий этап P10QV

- **Интервальная и высокоточная проверка:** на настоящих полиномах P4/P2 проверить границы действительных корней и результатантов, вырождающиеся старшие коэффициенты, почти касательные случаи; получить обоснованную верхнюю оценку локальной ошибки, особенно в направлении оси 2.
- **Независимый перенос на другие проблемные элементы:** минимум реальные случаи **6 и 7**, без автоматического предположения P4→P2. При выявлении истинной quartic по лучу — использовать общий P4/P2 результант и сертифицируемое корневое разделение либо честно остановить тест.
- Только после локальной межосевой и интервальной приёмки обсуждать 3D/4D-глобальное разбиение и дальнейшую физику; соблюдать существующий SOP, включая `HighOrderElastic` при любой будущей Gmsh-оптимизации.
