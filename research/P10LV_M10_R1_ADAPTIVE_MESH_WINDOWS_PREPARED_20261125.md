# P10LU/P10LV — M10 R1, последовательное адаптивное построение сетки

Дата 2026-11-25. Статус: **подготовлен однократный Windows Gmsh-пакет;
M10 ещё не построена и не принята; FEM не запускался**.

## Источник адаптации

Получены действительные прямые/сопряжённые 4D-поля M8 и M9 при совпадающих
R/EDV_VAR, xi0, B6=5 мм, 36×25 с. Вычислена абсолютная межсеточная
разность по 43 200 объёмным пространственно-временным строкам и 36
глобальным строкам с проверкой взаимно однозначной привязки.

Глобальная знаковая разность `sum(M9-M8)` = +0.011951238389 1/м;
сумма модулей локальных разностей = 0.964211175184 1/м. Следовательно
малость знаковой разности скрывает компенсацию между областями.
Последние шесть временных шагов дают 60.785% пространственно-временной L1
разности. Поэтому принят старый утверждённый показатель приоритета:

`score = [0.4 * L1_all/max(L1_all) + 0.6 * L1_last6/max(L1_last6)] * polar_factor`,
где `polar_factor=1.2` для обоих полярных десятых диапазонов.

Координатная интерполяция — проверенная компактная Wendland C2,
с полярным C2-плато. Новый множитель размера элемента:
`(1 - 0.20 * kappa10)^(1/3)`, `0<=kappa10<=1`.
Все предыдущие множители M1–M9 сохранены, меняется только новый
переход M9→M10. Это **номинальное** изменение локального объёма,
фактическое уменьшение в полярных областях должно быть измерено после
построения M10 по 729-точечной интеграции Tet10.
