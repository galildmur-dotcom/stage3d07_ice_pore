# Stage3D07 — P10QS: масштабирование явных критических корней на все 22 азимутальные cut-области M8 и первый физический результант P4/P2

**Дата:** 28.11.2026. **Предыдущий этап:** [P10QR](P10QR_M8_EXPLICIT_P2_CRITICAL_S_EVENT_SPLIT_AND_Q256_CROSS_AUDIT_20261128.md). **Исследовательская ветка:** `research/p10bb-w5b2-20261118`.

**Главный результат:** явное разбиение по полиномиальным критическим корням `s` успешно перенесено с первых 6 на **все 22 настоящие** h8-подобласти элемента M8 №5865, у которых **единственная активная граница — азимутальная P2**. По всем 22 получено независимое численное сравнение с равномерным q256; **восемь q256 рассчитаны впервые на P10QS**. При одинаковых **360 448** поперечных узлах относительная сумма модулей расхождений градиента с q256 уменьшилась с **`1.5478993e−6`** у обычной q128 до **`5.0904376e−7`** у критической квадратуры — **в 3,04 раза**. Значение ниже принятого `1e−6` **только для этих 22 областей**, не для всех 30 cut-областей исходного Tet10, не для трёх осей и не для полной M8/4D-задачи.

Кроме того, для оставшихся **7 двухграничных P4/P2** реальных cut-областей создан численный исходный полиномиальный **результант** между радиальной P4 и азимутальной P2 границами при фиксированной внешней координате. На 35 контрольных срезах построено 23 алгебраических кандидата `s`; **2** прошли независимое физическое пересчитывание обеих границ в декартовых координатах. Это **только предварительная геометрическая диагностика, не вычисление cut-интегралов** для multi-областей.

## 1. Неизменная геометрия и состав подзадач

- **Сетка M8 не изменялась:** SHA256 `40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d`; реальный исходный криволинейный Tet10 **№5865**, сектор `(r=4, μ=0, φ=6)`; h8-подразбиение. Gmsh, CAD, перестроение сетки, FEM, EDV, 4D и adjoint **не выполнялись**. При любой будущей оптимизации Gmsh обязательный метод — **`HighOrderElastic`**.
- Исходных 30 пересечённых криволинейных подобластей: **22 one с активным азимутом №4**, **1 one с активной радиальной P4 №0**, **7 multi с одновременно активными P4 №0 и азимутом №4**. Новая разрешающая численная проверка охватывает первые **22**, оставшиеся **8** не объявляются изученными по данному алгоритму.
- Везде реальный P2-FE-числитель градиентного интеграла **аналитически интегрируется вдоль луча** с настоящим искривлённым Tet10-отображением. Квадратура Гаусса применяется только к двум поперечным координатам после явного разбиения по критическим полиномиальным событиям; это не подмена геометрии линейным тетраэдром или постоянным градиентом.
- Нормировка L1 градиента — полный гибридный q128-момент **того же исходного** элемента (`≈1.0635e−14 m³`), объёма — полный физический объём исходного элемента (`≈4.0001e−14 m³`). Проверяется **`Σ_cut |I_method,k−I_uniform_q256,k|`**, без разрешения по подписанной сумме.
- Ранее реально рассчитанные шесть P10QR сохранены **без повторной подгонки**, остальные шестнадцать выполнены новым четырёхчастным расчётом с теми же замороженными параметрами. Восемь q256, которых ещё не было ни в P10QP/P10QQ/P10QR, впервые рассчитаны на P10QS: **`[5,7,9,15,24,29,35,36]`**. Никаких q256 при выборе правил сегментации не использовалось.

## 2. Разрешающий 22/22 однограничный эксперимент

Метод P10QR для каждого узла внешнего интеграла по `t` вычисляет действительные корни проекционных критических полиномов по внутренней координате `s`: псевдодискриминанта, пересечения начала/конца луча и вырождения старшего коэффициента. Между найденными корнями фиксированный внутренний бюджет **128 узлов Гаусса по `s`** распределяется по длинам интервалов, минимум 8 на интервал. Истинный кубический числитель по третьей, лучевой координате интегрируется **аналитически**. Внешние порядки `t=128` и `t=256` заморожены до новых q256.

**Суммарное сравнение с независимым равномерным q256 на одних и тех же 22 настоящих cut-областях:**

| Метод | Число поперечных узлов на 22 cut | L1 градиента / полный гибридный момент | L1 объёма / полный исходный объём |
|---|---:|---:|---:|
| Равномерный q128 | 360 448 | **`1.5478993e−6`** — FAIL | `2.0356273e−7` |
| **Критические s, внешняя q128** | **360 448** | **`5.0904376e−7` — PASS для 22** | **`6.7396816e−8`** |
| Критические s, внешняя q256 | 720 896 | `3.1244801e−7` | `4.1249583e−8` |

При **том же числе точек** относительное несогласование градиента уменьшилось примерно **в 3,04 раза**, объёма — **в 3,02 раза**. По 22 областям локальный результат `critical_s_t128` оказался ближе к q256 **на 15 из 22**; на **7** результат ухудшился. Все неудачные локальные значения сохранены, поскольку глобальная подписанная сумма могла бы скрыть их компенсацией.

Для критической q128 на всех 22 сумма модулей градиентных расхождений `5.4137e−21 m³`, а подписанная сумма около `−8.1685e−22 m³`: компенсация примерно **в 6,63 раза**. Поэтому используется только L1-критерий.

### 2.1. Строго отдельно: новая восьмёрка q256

| Проверка восьми новых q256 | L1 градиента / гибрид | L1 объёма / исходный объём |
|---|---:|---:|
| Равномерный q128 | `1.6897230e−7` | `2.2521182e−8` |
| **Критические s, внешняя q128** | **`9.1628572e−8`** | **`1.2331825e−8`** |
| Критические s, внешняя q256 | `2.1042161e−8` | `2.8026659e−9` |

Независимая новая восьмёрка показывает **такое же направление улучшения**, хотя индивидуально метод лучше в **5 из 8**, хуже в **3 из 8**. Этот контроль нельзя заменить одним ранее использованным удачным элементом.

Для всех 22 восстановление физической P2-полиномиальной границы на поперечных срезах прошло с контролем коэффициентов. На внешних порядках 128 и 256 проверочные внутренние сигнатуры не обнаружили оставшихся неоднородных интервалов (`0` на всех 22). Полные неотсечённые кубические физические моменты пересчитаны той же сегментированной квадратурой: максимальная относительная невязка градиента/объёма **`3.48e−15`**. Но это **не** строгая гарантия отсутствия скрытых почти кратных корней при арифметике double.

## 3. Новый двухграничный P4/P2-результант: настоящая геометрия M8

Для каждой из семи реальных multi-подобластей `[13,14,20,21,31,37,38]` построены полиномы на фиксированном `t`:

\[
F_4(s,w;t)=\sum_{k=0}^{4}f_k(s;t)w^k,
\qquad
G(s,w;t)=b(s;t)w+c(s;t).
\]

`F_4` — реальная физическая радиальная граница P4, восстановленная из P2-криволинейного отображения Tet10; `G` — физическая азимутальная граница, которая на выбранной оси фактически линейна по лучу. В этом **специальном, но реальном** случае их результант по `w` строится **явной полиномиальной формулой** без неустойчивой общей символьной операции:

\[
\operatorname{Res}_w(F_4,G)
=\sum_{k=0}^{4}f_k(s;t)[-c(s;t)]^k b(s;t)^{4-k}.
\]

Нули этого полинома дают **только кандидатов** проекций совместных пересечений двух границ. Нужна физическая маска: `0<s<1`, `0<w<1`, действительные значения и непосредственное выполнение обоих ограничений в **настоящих декартовых XYZ**.

На 7 реальных двухграничных подобластях проверены 5 заранее указанных внешних срезов `t={0.1,0.3,0.5,0.7,0.9}`:

| Показатель | Результат |
|---|---:|
| Проверенных срезов `7×5` | **35** |
| Действительных корней-кандидатов результанта | **23** |
| Физически подтверждённых совместных пересечений | **2** |
| Наибольшая относительная ошибка восстановления радиального P4 по поперечной координате | `2.01e−11` |
| Наибольшая относительная ошибка азимутального P2 | `2.20e−15` |
| Максимальная невязка радиального ограничения при независимой физической перепроверке | **`2.86e−13`** |
| Максимальная невязка азимутального ограничения | **`9.15e−18`** |

Два физически подтверждённых пересечения найдены в реальных multi-индексах **20** и **38**. Существование множества лишних нулей подчёркивает необходимость *масок* и геометрической фильтрации, как и в общем подходе R. I. Saye, *High-order quadrature on multi-component domains implicitly defined by multivariate polynomials*, **J. Comput. Phys.** 448 (2022), 110720, [DOI:10.1016/j.jcp.2021.110720](https://doi.org/10.1016/j.jcp.2021.110720).

**Оговорка:** пока это только предварительный эксперимент на 35 срезах с обычными плавающими коэффициентами/корнями. Числа `23` и `2` **не утверждают полноту всех реальных пересечений** при произвольном `t`, не дают интервальной сертификации и **не превращаются** в полноценную квадратуру двухграничной области. Надёжность корней почти кратных результантов потребует отдельной проверки.

## 4. Что уже установлено и чего ещё нельзя утверждать

**Установлено эмпирически:**

1. Подкласс **всех 22 азимутальных однограничных h8 cut** исходного элемента №5865 проходит выбранный L1-гейт сравнения с численным q256 при `t=128`, в отличие от обычной q128, **без увеличения числа поперечных точек**.
2. Положительный эффект наблюдается отдельно на **8 новых q256**, а не только на исходной P10QR-шестёрке; все индивидуальные ухудшения сохранены.
3. Для настоящей пары P4/P2 можно явно построить проекционный результант и непосредственно проверять его физические кандидаты на реальной криволинейной геометрии, не прибегая к линейному элементу или CAD.

**Не установлено:** математически сертифицированная точность q256, 3-осная сходимость, обработка оставшихся **7 multi + 1 радиальной P4 one** областей, все исходные элементы M8, глобальные 43 200 4D-ячейки, физические FEM/EDV/shape-adjoint. Численные корни P2/P4 и результанта не снабжены интервальным замыканием с направленным округлением. **Никакого физического FEM не запускать.**

## 5. Следующий научный этап P10QT

1. Разработать полноценное **разбиение по критическим событиям P4/P2** и интегрирование для 7 multi-подобластей с учётом **результанта общих пересечений**, дискриминанта радиального P4 и концов луча. Контролировать ложные и почти кратные корни физическими масками, а оставшиеся неопределённости явно отмечать.
2. Для единственной оставшейся **one с радиальной P4** (индекс 30) изучить тот же полиномиальный подход без линейного азимутального ограничения.
3. Только после успешной проверки всех **30 из 30** отсечений данного элемента, сравнения по трём направлениям и проверки неопределённости корней обсуждать распространение на тяжелые ранее отобранные исходные случаи 6/7. Общая физическая задача пока закрыта.
