## 2. Зачем требуется отражение у полюсов

Непосредственно выбранный обычный гауссов свёрточный фильтр по полуоси `ρ≥0` вообще говоря создаёт в `ρ=0` ненулевую производную `∂ρ w`. После подъёма до `ρ=√(x²+y²)` это давало бы нефизический излом в декартовом градиенте на оси. Чтобы такой искусственный эффект не попасть в будущую адаптацию, P10CN **явно отражает источники** по `ρ=0`.

Для центра ячейки (K) с ((\rho_K,\zeta_K)), объёмом (V_K>0) и весом (w_K), задаём положительное симметризованное ядро

\[
K_{\ell,K}(\rho,\zeta)=\frac{1}{2}\left[
\exp\!\left(-\frac{(\rho-\rho_K)^2+(\zeta-\zeta_K)^2}{2\ell^2}\right)
+\exp\!\left(-\frac{(\rho+\rho_K)^2+(\zeta-\zeta_K)^2}{2\ell^2}\right)
\right],
\]

и сглаженный вес

\[
S_{\ell}[w](\rho,\zeta)=
\frac{\sum_K V_K K_{\ell,K}(\rho,\zeta)w_K}
     {\sum_K V_K K_{\ell,K}(\rho,\zeta)}.
\]

Он сохраняет константу, принадлежит `[0,1]`, симметричен по `ρ→−ρ`, имеет `∂ρ S(0,ζ)=0`, не использует `1/sinθ` и строго инвариантен при вращении `(x,y)` вокруг полярной оси. Это **двумерное зеркально-сглаженное меридиональное ядро**, а не точная осесимметричная трёхмерная гауссова свёртка или решение уравнения теплопроводности. Его физическая ширина — *параметр алгоритма*, не термическая диффузионная длина.

Для оценки чувствительности (не для выдачи готового поля M1) вычислялись

\[
q(\mathbf x;\alpha,\ell)
=\frac{h_{\rm trial}}{h_0}=\frac1{1+\alpha S_\ell[w](\mathbf x)},
\quad
C_{\rm shell}=\frac{\sum_K V_K q_K^{-3}}{\sum_K V_K}.
\]

Здесь `C_shell` — только объёмно-взвешенный *изотропный прокси* относительного количества элементов **в диагностическом слое** при локальном кубическом законе `N∝h^{-3}`. Это **не** прогноз полного числа Tet10, DOF, RAM, wall time, качества M1 или точности её решения: невидимый участок `0–20µm`, внешний B6 и баланс сетки остаются вне модели.

## 3. Девять контролируемых комбинаций параметров

Проверены `ℓ=0.10,0.20,0.35 mm`, `α=0.25,0.50,1.00`. Максимальный градиент численно отслеживался по **17 радиальным × 81 μ** пробным точкам, помимо 200 центров. Он относится только к относительному множителю `q`, без градиента неизвестного `h0(x)`.

**Демонстрационный, не выбранный для FEM режим** `ℓ=0.20mm, α=.50`: max `S` по центрам ячеек 0.829566, min `q=htrial/h0` 0.706822, локальная цена 1.390813×, sampled max `|∇ln q|=0.900625 mm⁻¹`; в точности на оси `∂ρ S=0` для всех девяти вариантов.
