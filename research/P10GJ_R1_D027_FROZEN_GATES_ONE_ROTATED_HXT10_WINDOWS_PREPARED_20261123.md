# Stage3D07 — P10GJ R1: подготовлена одна разрешённая Windows 3D HXT10-попытка M1 (23.11.2026)

**Статус: SOURCE / MOCK / UNIT PASS; РЕАЛЬНЫХ P10GJ `gmsh -3` = 0; FEM = 0.** Это подготовленный исполняемый протокол и пакет, **не** сообщение об успешной M1-сетке. Пользователь отдельно одобрил именно следующий шаг P10GJ; разрешение на FEM отсутствует.

## Научное основание и фиксированное решение D-027

- Исходная фактическая сетка — неизменяемая `G:\ildar\Stage3D07\meshes\M0.msh`, SHA256 `926a9c903765ce77fd560300d10614d3cece3d4cd4d7813027e45e92d33870d6`, 7 992 Tet10 и 11 699 узлов.
- P10GH/P10GI **измерили на Windows Gmsh 4.15.2 только `-2`**: поворот OCC-оси сферической поры на π/2 вокруг X сохранил геометрию/границы и улучшил минимум углового качества углового Tri6 поры `0.321496 → 0.590078`, север `0.51692 → 0.86080`, юг `0.32150 → 0.88283`; p05 поры **снизился** `0.8123 → 0.7876`. P10GI подтверждает лишь поверхностный эффект; положительный результат HXT10 **не гарантируется**.
- Старый P10GE с Gmsh 4.13 и HXT ухудшал число попавших в узкий индивидуальный интервал зон с 9/18 до 7/18. Следовательно, по решению D-027 **18/18 не является обязательным отсечением**; все 18 подписанных QV остаются измеряемой диагностикой.
- Единственный новый кандидат: тот же неизменный M0 C¹ MathEval field, только реальный CAD-axis rotation P10GH, `Mesh.MeshSizeFactor = 0.9378887276834518` (`0.825^(1/3)`), `Mesh.Algorithm3D = 10` (HXT), `Mesh.ElementOrder = 2`; ASCII MSH2 с физическими тегами 1–9. Никаких локальных иных геометрических изменений и оптимизационных переборов.

## Пререгистрация: до 3D, только по M0

Политика `P10GJ_D027_GATE_POLICY.json` зафиксирована в исходном архиве. Windows шаг **01** проверяет байтовые SHA всех GEO, M0, Gmsh4.15.2, восстанавливает независимый фактический M0 27QP аудит и **вычисляет конкретные пороги из M0**. Записывает отдельный подписанный SHA `P10GJ_D027_FROZEN_GATES.json`; выполняет лишь native `-parse_and_exit` (не `-2`, не `-3`, не FEM); proof действителен 24 часа и привязан к источнику, M0, Gmsh EXE и журналу parse.

Основные численные принципы D-027:

1. Глобальное отношение эффективного объёма M1/M0 — `[0.80, 0.85]` (и 27QP предварительно, 343QP/729QP окончательно).
2. Все 27/343/729 выборочных `detJ > 0` (выборочная проверка не является теоремой о непрерывной положительности).
3. CAD/топология/физические группы: относительная ошибка объёма ≤0.005, замкнутые поверхности поры и B6 (Эйлер 2), 7QP Tri6 нормаль/площадь, радиусы поверхности ±10⁻⁸ м, физические теги 1–9; Tri6 pore qmin ≥0.50, p05≥0.70, север и юг qmin≥0.75.
4. Tet10 corner mean-ratio: минимум ≥max(0.015, 0.55*M0min); p01≥0.80*M0p01; near-polar p05≥0.75*M0near-polar p05; максимум 27QP вариации Jacobian ≤max(20,1.25*M0max).
5. Пространственная гладкость размеров соседних Tet10: ограничения для all/near-polar p95, p99, max `max(фиксированный потолок, коэффициент * измеренный M0)` по исходному policy. Измеряются по совместной грани, не по порядку элементов.
6. В физически заполненных QP-макрозонах с M0 N_eff≥50: `0.65≤QV≤1.05`; особо для северной и южной полярной области 0–500 µm: `QV≤0.98`; 343→729 разница каждого из 18 QV≤0.02. Все 18 signed зон выводятся, но **не** требуют 18/18 попаданий в `[0.80,0.85]`.
