## Алгоритм

Для неизменной повернутой оригинальной CAD и закреплённых десяти embedded pore seeds воспроизводится составное поле размера из прежних компонентов M2/M3 (P10HA, P10IE, P10IN), после чего в ту же callback-функцию Gmsh добавляется новый множитель `exp(-0.1435943053641514 κ_M4(x)-δside wpolar(x))` из P10IU, где северная `δ=.11445576719134759`, южная `δ=.12998093714900827`. Это непосредственная **генерация нового 3D кандидата на original CAD**, не изменение координат готовой M3. Последующий независимый D029 compare должен сопоставить её фактические Tet10 региональные Veff с принятой M3. Никаких FEM/FD.

## One Click

1. Распаковать ZIP в новую папку вне `G:\ildar\Stage3D07`.
2. `01_P10IV_PREFLIGHT_NO_GMSH_NO_FEM.cmd` — SHA/GEO/Gmsh API, никаких Gmsh генераций.

Marker создаётся до Gmsh **и в папке, и в профиле LOCALAPPDATA** для предотвращения повторов из разных распаковок. Heartbeat≤30с. Время ограничено 900с, поллинг private RAM<=8GiB, лог<=32MiB, MSH<=250MiB. Превышение / worker STOP расходует оба markers: автоматический повтор запрещён.
4. Передать **один** `P10IV_R1_M4_UNVERIFIED_EVIDENCE.zip`; он содержит лог, guard/worker, markers, новый `.msh` — при слишком большом объёме согласовать отдельную передачу сетки.
