# P10NL — диагностическая копия M13 R2, проверка Gmsh 4.15.2

Статус: **подготовка диагностического исследования, не M13 R3**. FEM и генерацию сетки не выполнять.

Источник: строго зафиксированная M13 R2, SHA256 `57403ba43fa299417d519046cebdf50fa4968b670c071a8b7882748b50f51e9c`.
По P10NK перемещаются только внутренние угловые узлы `8680` (+0.010 мм), `8681` (+0.005 мм), `9115` (+0.005 мм). Радиальные направления — точно из P10NK; срединные узлы затронутых рёбер сдвигаются на полусумму перемещений их концов.

Диагностическая копия имеет ту же связность, поверхностные Tri6 и неизменные координаты всех узлов поры. Меняются 47 глобальных узлов, смежных с 67 Tet10. Не создаётся новая сетка средствами Gmsh. Исходная M13 R2 остаётся нетронутой. Прокси-метрика P10NK — минимум отношения сингулярных чисел якобиана в 729 QP; **это не** канонические `minSJ` и `minSICN` Gmsh.

## На Windows 11

1. Распаковать ZIP в новый каталог, сохранив файлы рядом.
2. Убедиться, что `py -3` запускает Python с `numpy` и Python API `gmsh==4.15.2`.
3. Дважды щёлкнуть `P10NL_RUN_NATIVE_GMSH_QUALITY.cmd`.
4. При успешном завершении прислать файл `P10NL_M13_THREE_NODE_DIAGNOSTIC_GMSH_QUALITY_RESULT.json` (не весь ZIP). Скрипт не перезаписывает прежний результат.

Сравнение самостоятельно вычисляет на обеих MSH канонические `minSICN`, `minSJ`, `gamma`, `minDetJac`, минимумы, нижний процентиль, медиану, номера худших Tet10 и число элементов ниже каждого порога D031. Проверяются SHA256 обеих сеток и число Tet10 (18 004). Скрипт **не** вызывает `mesh.generate`, `mesh.optimize`, `gmsh.write`, не запускает FEM и не трогает маркеры.

Решение о последующей работе можно принимать лишь по полученному нативному результату. Даже успешная диагностическая копия не считается автоматически M13 R3 и не разрешает FEM.
