# Stage3D07 — P10QV-D: топологические t-панели при равной стоимости q512; независимый q1024

**Дата:** 28.11.2026. Непосредственная база: [P10QV-C](P10QV_C_M8_Q512_TWO_NORMALIZATIONS_AND_LOCAL_REFINEMENT_GATE_20261128.md), исследовательский HEAD перед опытом `e47beda5fe267e3b682db8ff853b7d1a707c2799`.

**Научный итог:** замороженное *до сравнения* эмпирическое разбиение внешней координаты `t` по обнаруженным сменам физической топологии корней при неизменной стоимости `512×128` улучшило все три оси случая 7, но **лишь две из трёх** — случая 6. Максимальное расхождение с независимым равномерным `q1024` (нормировка маленьким cut-моментом) для случая 6 уменьшилось только `2.14001e−5 → 1.95256e−5`; для случая 7 — `1.06378e−6 → 4.05366e−7`. Поэтому **метод нельзя принимать как универсально более точный**, а эмпирический cut-local `1e−6` для случая 6 **не пройден**. `q1024` здесь только численный компаратор, НЕ истинное значение и НЕ строгая граница ошибки.

## 1. Независимый, заранее ограниченный эксперимент

- Два исходных реальных h8 multi cut сетки M8 без повторного выбора примеров: case6 исходный Tet10 №5751, h8 child19, активные поверхности `[0,4]`; case7 Tet10 №5847, h8 child10, поверхности `[1,4]`. Только **2 из 178** cut. M8 SHA256 `40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d` подтверждён старым архивным provenance, непосредственный `M8.msh` здесь отсутствует. Проверены точные SHA256 исходных JSON P10QO и ранее замороженных q512 JSON P10QV-C.
- Реальная криволинейная P2-FE геометрия дочернего Tet10, интегрирование кубического P2-FE момента **аналитически вдоль луча**, физические критические `s`-события из P10QV-B. Поперечная квадратура Гаусса: у обеих сравниваемых схем **512 внешних `t`-узлов × 128 внутренних `s`-узлов = 65 536 точек на ось**. Без изменений CAD/геометрии/сетки/Gmsh и **без FEM**.
- Топологические признаки по каждой оси рассчитаны из **41 фиксированного `t`** от 0.005 до 0.995 и **пяти фиксированных `s`** = 0.1, 0.3, 0.5, 0.7, 0.9. Между соседними пробами с различными *физическими* root-signatures поставлена граница в середине `t`-интервала. Распределение ровно 512 узлов по длинам панелей, не менее 8 на панель. **Ни значения интегралов, ни последующий q1024 не использовались для выбора границ.** Это не точная локализация касаний, не непрерывная проверка всех `(s,t)` и не interval certificate.
- Для case6 получено **10 / 7 / 7** t-панелей по осям 0/1/2; для case7 — **8 / 6 / 5**. Проверены положительность длин, сумма узлов, одинаковая стоимость и физически допустимые объёмы.
- Отдельная программа q1024 **не импортирует разбиение `t`**; на тех же cut и осях вычислены 1024 равномерных внешних узла × 128 внутренних = 131 072 точек на ось. Она не выдаёт точного интеграла.

## 2. Важнейшие результаты: нормировка самим cut

Знаменатель каждой строки внутри случая — **минимальный модуль q1024 cut-момента среди трёх осей**, чтобы не подменять мелкий cut большим полным моментом h8. В таблице показаны **абсолютные**, без знаковой компенсации, разности данного направления с q1024.

|---|---:|---:|

## 4. QA, воспроизводимость и STOP

- Все 6 q512 с разбиением и все 6 held-out q1024 интегралов реально вычислены; все процессы завершились `exit0`. Два q512 frozen значения на каждую ось повторно сверены с P10QV-C, не подгонялись по q1024.
- Независимый read-only аудитор сверил диапазон геометрии, M8 provenance, идентификаторы child/поверхностей, бюджеты, интервалы и SHA256 трёх источников каждого case, пересчитал таблицы из сырых моментов и **отверг искусственную 1%-ю порчу** frozen q512 на каждом case.
- Макс. относительная невязка восстановления по q1024 не превышала `1.834e−11`, макс. старший коэффициент по лучу — `4.296e−12`. Эти численные проверки не означают интервального доказательства и не оценивают точно поперечную ошибку.
- **Не выполнено:** сплошная проверка топологии по `(s,t)`; настоящие проекции критических дискриминантов и интервальная корневая сертификация; проверка остальных **176** cut; вычисления сопряжённой задачи и производной формы, j_peak; физический 4D/FEM/EDV. Любой переход к ним — **FEM STOP**.

## 5. Научное решение и следующий P10QV-E

1. Сохранить P10QV-D как **смешанный, воспроизводимый результат**: улучшение 5 из 6 осей относительно q1024 при прежней стоимости; одна регрессия ухудшила case6/ось2 с `1.142e−6` до `1.953e−5` по cut-моменту. Не объявлять общий PASS `1e−6` для двух cut.
2. В P10QV-E исследовать **аналитически или интервально контролируемую проекцию критических `t`-событий** для двух-граничных криволинейных cut и способ адаптивной t-сегментации, способный отследить близкие касания, не пропускаемые только пятью фиксированными `s`-пробами. Предварительно зафиксировать метод до оценочного q2048/q1024 теста; обязательно проверить все оси и обе нормировки; не выбирать лучшее по апостериорному знанию эталона.
3. После успешного контроля представить более широкую предобъявленную выборку h8 cut, затем все 178. Наличие хорошей численной сходимости не отменяет необходимости строгого сертификата перед физическим FEM.
