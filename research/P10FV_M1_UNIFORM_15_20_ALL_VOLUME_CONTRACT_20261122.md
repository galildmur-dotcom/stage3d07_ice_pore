# P10FV — исправленный обязательный критерий первой M1: однородное 15–20% сгущение всего объёма

Дата: 2026-11-22. Явное уточнение исследователя после P10FU.
Суперпозиция по ветке `research/p10bb-w5b2-20261118`;
предыдущие P10FS/P10FT исходные данные остаются неизменными.

## Исправление цели и отмена P10FU

**Для перехода M0→M1 учёный требует фактического уменьшения
локального характерного объёма конечных элементов на 15–20%
по всему физическому объёму льда**, не только у полюсов и
не только по глобальной средней. Интервал отношения:

\[
0.80\leq Q_V(Z)=
\frac{V_{\mathrm{eff}}(Z;M1)}
     {V_{\mathrm{eff}}(Z;M0)}
\leq0.85\quad\text{во всех проверяемых физических }Z.
\]

Здесь **физическая геометрия блока и сферической поры не уменьшается**;
уменьшается характерный объём **Tet10**. Для непарных сеток
`V_eff(Z)=int_Z dV/int_Z(dV/V_T(x))`, как ранее в D-025,
с 343/729QP на *одинаковых фиксированных* физических областях.

**P10FU R1 M1B (южная локальная коррекция) ОТМЕНЁН как способ
построения первой M1: ZIP из предыдущего этапа НЕ ЗАПУСКАТЬ.**
Его поле изменяет предписанный размер по югу и допускает
номинальную долю h³=0.60. Это не соответствует новому требованию
именно равномерного первого шага. На GitHub пакет остаётся
только в историческом коммите с пометкой
`RETRACTED_DO_NOT_RUN`; не стирать историю или previous
one-shot markers. Если P10FU уже запускался, сохранить все
его evidence и НЕ повторять: независимый новый протокол
должен учитывать результаты без изменения файлов.

## Правило для новой M1

1. M0 и CAD — те же исходные, SHA M0 MSH
   `926a9c903765ce77fd560300d10614d3cece3d4cd4d7813027e45e92d33870d6`.
   Никаких P10DG/H0 подмен.
2. **Коэффициент адаптации κ=1 на всём физическом объёме**.
   Первичная номинальная цель центрировать в
   `Q_target=0.825` (**17.5%**):
   `h_target/h_M0=(0.825)^(1/3)=0.9378887276834518`.
   Это только *номинальное* поле; выполненный Gmsh
   не гарантирует реального Q.
3. Приёмка M1 должна проверить **все 9** независимых
   фиксированных 3D радиально-полярных зон:
   d0–100 мкм, d100–500 мкм, d>500 мкм ×
   `|mu|≥.8, .6<|mu|<.8, |mu|≤.6`,
   а также **по отдельности север и юг** в наиболее
   чувствительной стеночной 0–100 мкм зоне.
   Дальше дробить по геометрически обоснованным
   крупным физическим секторам по мере необходимости,
   но не требовать искусственно регулярного расположения
   Tet10 по азимуту.
4. Для каждой зоны `0.80≤Q_V≤0.85` и
   стабильность 343→729QP (контроль
   `|ΔQ|<0.02` как исходниковый допуск проверки
   достаточности дискретизации интеграла).
   Самого знака детерминантов и глобального
   `N(M1)/N(M0)` **недостаточно**.
5. Сохранить одно гладкое C¹ поле размера
   для Tri6+Tet10; физические группы 1–9,
   curved Tet10 high-order detJ>0, near-polar
   adjacent-size-jump и поверхность поры
   проверять отдельно. Доказательство плавности
   предписанного h не подменяет фактическое
   качество сетки.
6. Если глобальное номинальное изменение h
   не даёт однородного фактического Q, сначала
   научно обосновать процедуру **компенсации систематического
   remeshing-отклика во всех пространственных зонах**.
   Такая компенсация допустима только как
   инструмент достижения *равномерной фактической*
   плотности (κ всё ещё единица), а не как выборочная
   физическая адаптация `κ(x)`.
   Ни один предварительный рецепт/прогноз не выдаёт GO.

Отдельная физически ориентированная `κ(x)∈[0,1]` адаптация
предусмотрена **только после** построения и расчёта
принятой равномерной M1, начиная со следующего шага M1→M2.
Предшествующий критерий D-025 15–25% сохраняется для
последующих адаптивных шагов согласно ранее принятым решениям,
но **для первой M1 действует более строгий 15–20%**.

## Дальнейший порядок

**Новый Windows one-shot для первой M1 должен быть
подготовлен заново** под однородное 15–20% фактическое
сгущение **всего физического объёма** и под соответствующий
универсальный spatial QA. Предыдущая P10FU M1B — не
выполнять. Не менять файлы M0/M1, прежние маркеры
и данные P10FS/P10FT. Местный Windows запуск
снова должен быть без обязательного ввода символов,
с сохраняющимся открытым окном и одним доказательным
evidence ZIP. После нового native Gmsh
**ассистент** даст независимый geometry+uniform GO/STOP;
только после GO допускается fresh forward+adjoint
на той же принятой M1. Никаких физических расчётов
на исходной непринятой M1 не требуется.
