Дата: 2026-11-28. **Геометрический аудит PASS, сходимость точного
отрезанного объёма по нужному допуску НЕ достигнута.**

Окончательный машинный статус независимого контроля:
`PASS_INDEPENDENT_PHYSICAL_BRACKETS_48x13`;
дополнительного четырёхбинового опыта:
`PASS_4_BIN_DEPTH16_PHYSICAL_BRACKET_PILOT`.

Продолжение P10PZ. Исходная **принятая M8** неизменна:
SHA-256 `40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d`,
18 331 узел, 12 546 настоящих криволинейных Tet10. CAD, Gmsh,

обратная задача, перенос истории и подписанные 4D-производные не запускались.

## 1. Устранение ключевого ограничения P10PZ

P10PZ оценивал неопределённость в *референсном* объёме кандидатов;
она не равна физическому объёму криволинейного Tet10. В P10QA
весом каждой подобласти становится истинный `det J(uvw)` принятой M8.

Для квадратичного изопараметрического отображения `F(uvw)` матрица
`J=dF/d(uvw)` **аффинна**, а `det J` — полином **степени не выше 3**.
В P10QA получаются **20 коэффициентов Бернштейна кубического
полинома `det J`** из трёх аффинных столбцов `J` по точной формуле
мультлинейности определителя. Расположение `det J` между минимумом
и максимумом этих коэффициентов обеспечивает геометрическую оценку
знака на всём тетраэдре в точной арифметике.

**Новая проверка всей M8:**

- положительный минимум коэффициентов Бернштейна **для всех
  12 546/12 546** Tet10, а не только в исходных 27 точках;
- глобальный минимум одного коэффициента `6.195489181e-13`;
- интегральный физический объём всей M8:
  **`0.00017999581243661032 м³`**, согласуется с ранее принятым P10PX.

Эта процедура соответствует подходу к геометрической корректности
криволинейных КЭ: [Johnen, Remacle, Geuzaine, *Geometrical validity of
curvilinear finite elements*, JCP 233 (2013)](https://doi.org/10.1016/j.jcp.2012.08.051).

**Ограничение по арифметике:** проверки выполняются в `float64` с
масштабной защитой при проверке знака, а не при строгом направленном
интервальном округлении. Поэтому математическое обоснование
положительности через Бернштейна есть; формального машинного
интервального сертификата ещё нет.

## 2. Независимая проверка степени интегрирования q

Объём любой дочерней области вычисляется интегралом её истинного
кубического `det J` с учётом якобиана аффинного разбиения.
Для этого применена симметричная пятиузловая формула на тетраэдре,
точная для полиномов степени 3. Она независимо сверена с прямой
трёхкратной квадратурой Гаусса с Duffy-преобразованием при
`q=2,3,4`.

На **120** реальных исходных и дочерних подобластях восьми
репрезентативных Tet10 M8:

| Проверка | Максимальная относительная невязка |
|---|---:|
| Коэффициенты Бернштейна `det J` против прямого `det(XᵀdN)` | `1.1093e-13` |
| Пятиузловая кубически точная формула против независимой Duffy `q=4` | **`3.1988e-14`** |
| Независимая Duffy `q=3` против `q=4` | **`2.7149e-14`** |
| Независимая Duffy `q=2` против `q=4` | `1.5765e-06` |

`q=3` достаточно для практически точного интегрирования **самого
кубического якобиана**. Это **не доказательство сходимости
квадратуры разрывной функции принадлежности отрезанному объёму**:
последняя пока не интегрируется по неопределённым листьям.

## 3. Физические интервалы вместо референсных долей

Для каждой исходной пары «Tet10 × 4D-бин» разбиение идёт по P10PZ:

1. по знакам реальных полиномиальных границ доказуемо в точной
   арифметике классифицируются дочерние области `IN/OUT/UNKNOWN`;
2. у каждой `IN`-области физический объём входит в **нижнюю** оценку;
3. у каждой `OUT`-области физический объём исключается из **верхней**;
4. физический объём `UNKNOWN` остаётся шириной интервала:

   `V_lower = V_IN`,
   `V_upper = V_total_candidates − V_OUT`,
   `V_upper − V_lower = V_UNKNOWN`.

Исходный физический объём `V_total_candidates` и массы разрешённых
подэлементов вычислены **по истинному `det J` M8**, не по упрощённому
линейному тетраэдру и не заменой на референсные доли.

Проверено **48 бинов × 13 глубин (0–12)**. Для каждого бина
интервалы вложены (`V_lower` не убывает, `V_upper` не возрастает),
сохраняется физический объём, а последовательность неразрешённых
листьев побайтно совпадает по значениям с P10PZ на всех глубинах.

### Ширина интервала после глубины 12

Агрегация по всем 12 азимутам каждой группы:

| Радиальный слой, полюс | Физический интервал, м³ | Относительная ширина к середине |
|---|---|---:|
| 0–0.02 мм, юг | `[7.0271e-12, 3.4883e-11]` | **132.9%** |
| 0–0.02 мм, север | `[8.4792e-12, 3.4852e-11]` | **121.7%** |
| 0.25–0.50 мм, юг | `[5.0894e-10, 6.9375e-10]` | **30.7%** |
| 0.25–0.50 мм, север | `[5.0435e-10, 6.9891e-10]` | **32.3%** |

По **физическому отрезанному объёму** точной сходимости **пока нет**:
относительно искомого объёма диапазоны гораздо шире, чем доли
неопределённости относительно *кандидатов* в P10PZ. Нельзя
интерпретировать предыдущие `0.1%` «многоквартчных» областей как
ошибку физической квадратуры.

## 4. Независимый аналитический эталон для идеальной сферы

Поскольку контрольные бины — сферические секторы с
`Δμ=0.2` и `Δφ=π/6`, для **идеальной** сферы их объём можно
вычислить без сетки:

`V_ideal = (rho_hi³ − rho_lo³) · Δμ · Δφ / 3`.

- радиальный слой `0–0.02 мм`: **`2.1365622571e-12 м³`**
  на один азимутальный полярный сектор;
- радиальный слой `0.25–0.50 мм`:
  **`4.9632800604e-11 м³`** на сектор.

**Все 48 из 48** идеальных аналитических значений лежат внутри
численно построенных физических интервалов глубины 12.
Это сильная внешняя проверка порядка величин и отсутствия грубой
ошибки знака или единиц. **Однако** идеальный CAD-сектор не
тождественен объёму области, ограниченной дискретным искривлённым
отображением Tet10. Совпадение с аналитическим эталоном само по
себе не подтверждает точную квадратуру дискретной области.

## 5. Продолжение глубины 12→16 на четырёх разных полярных секторах

Чтобы не запускать чрезвычайно дорогой полный 48-биновый расчёт
глубины 16, проверены четыре характерных сектора, охватывающие
оба слоя, оба полюса и разные азимуты. **Независимый аудит PASS**:
до глубины 12 результаты в точности повторили полный прогон,
а на 13–16 интервал монотонно сузился.

В таблице отношение **ширины физического интервала** к объёму
идеального сферического сектора (это не ошибка midpoint):

| Бин `(r,mu,phi)` | Глубина 12 | Глубина 14 | Глубина 16 | Неопределённых листьев в 16 |
|---|---:|---:|---:|---:|
| `(0,0,0)` | 108.9% | 67.6% | **42.3%** | 167 341 |
| `(0,9,6)` | 107.6% | 67.3% | **42.8%** | 157 485 |
| `(4,0,0)` | 31.3% | 19.8% | **12.5%** | 228 877 |
| `(4,9,6)` | 32.7% | 20.5% | **12.9%** | 207 600 |

Обе характерные зависимости уменьшаются, но примерно **0.63× за
каждые дополнительные две глубины** при увеличении числа листьев.
Четыре пилотных бина на глубине 16 уже дают суммарно **761 303**
неопределённых листа. Распространять чистое h-разбиение на все
48 бинов с дальнейшим углублением экономически неразумно.

Таким образом, новый физический тест подтвердил сужение интервала,
но **не подтвердил приемлемой точности** для 4D-FEM даже на глубине 16.

## 6. Решение — следующий P10QB

**M8 фиксируется и сохраняется.** Не возвращаемся к M9–M21 для
данной проверки. Нельзя запускать физические производные, пока не
подтверждён с нужной точностью действительный отрезанный интеграл.

Следующий алгоритмический этап:

1. для `IN/OUT` продолжить мгновенную обработку с точными
   физическими весами `det J`;
2. для оставшихся `UNKNOWN` с **одной** активной сложной границей
   локально применить высокопорядковую квадратуру по отсечённой
   подобласти (Algoim / одноуровневая геометрия), не деля до
   глубины 20–26;
3. для `2+` активных полиномиальных границ использовать только
   направленное адаптивное разбиение с проверкой геометрии;
4. разделить исследование **`h`-сходимости классификации** и
   **`q`-сходимости фактического отрезанного физического объёма**;
5. сравнить результат как с независимой физической квадратурой
   M8, так и с аналитическим эталоном идеального сферического сектора;
6. отдельно провести машинный интервальный аудит знаков, если будет
   требоваться формальный сертификат.

После этих геометрических тестов можно безопасно решать вопрос
об интегрировании подписанных 4D-механических и температурных
вкладов с историей EDV.

Исследовательские первоисточники:

- A. Johnen, J.-F. Remacle, C. Geuzaine, *Geometrical validity of
  curvilinear finite elements*, Journal of Computational Physics 233
  (2013), 359–372, DOI `10.1016/j.jcp.2012.08.051`.
- R. I. Saye, *High-order quadrature on multi-component domains
  implicitly defined by multivariate polynomials*, Journal of
  Computational Physics 448 (2022), 110720,
  DOI `10.1016/j.jcp.2021.110720`.
