# P10EA R1 — подготовлена программа одной новой M2 3D mesh-only попытки, SOURCE-ONLY

**Дата:** 22.11.2026. **Разрешение:** пользователь ответил «разрешаю, подготовь m2» после P10DZ. Это санкция на **создание и проверку пакета**, не разрешение на Gmsh -3 и не разрешение на physical FEM. Реальных новых Gmsh запусков ассистент не выполнял.

## Научная новизна и контекст

Старая P10DO 3D попытка с вложенными MathEval F3/F4/F5 остановлена после 900с на стадии 1D кривых14/17, one-shot использован. P10DU определил нерекурсивный механизм MathEval в Gmsh4.15.2 по исходному коду; P10DV точно раскрыл формулу в один 494-символьный inline MathEval F6, содержащий только ссылку на базовый Threshold F2. P10DX исправил ложный Windows SHA STOP из-за CRLF. P10DY подтвердил native GEO parse2/2, P10DZ реальный Windows Gmsh -1 с **точным** F6, exit0/wall0.425с, успешно прошёл кривые14/17. Ни один из этих фактов не доказывает объёмную M2.

**Новый вопрос:** построится ли качественная криволинейная Tet10 M2 по исправленному F6 и какова фактическая локальная интенсивность сгущения относительно принятой M1? P10EA готовит новый независимый, ограниченный и одноразовый mesh-only опыт с последующей проверкой всего M2, не повторяя закрытые попытки.

## Неизменные исходные объекты и физическая постановка

- M1 — именно оригинальная ранее принятая P10DG P10DG_M1_CANDIDATE.msh, SHA-256 **ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f**, 14145 nodes / 9736 Tet10 / 178 pore Tri6 по прежнему Windows evidence. Не H0/U0, не новая сетка; raw M1 отсутствует у ассистента, заново SHA проверится на Windows исследователя.
- Полное исходное поле — точный P10DV_M2_INLINE_FIELD20.geo, SHA-256 **32f8f959002cbd41539e355a80437c2ca3be12fdd3ba12de31eadf2c021b9561**, CAD SHA **8029a6ed22bcf312701cd6abc46bbe5575e52df16fd5218dd936b01d5cd6fcf0**. Native Gmsh4.15.2 EXE SHA **317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1** по прежнему Windows manifest; raw EXE локально не аттестован заново.
- κ гладкая C¹, во всей области льда 0≤κ≤1. Радиальное поле максимально в первых 0.1мм от поры и затухает до 0 на 0.5мм; угловой taper |μ|=0.6…0.8, приоритет полярной пристеночной области; текущая кандидатная карта независима от φ, что **не** доказывает симметрию точной механики. Целевой размер h2/h1=(1−0.20κ)^(1/3), целевой локальный объём Vtarget2/Vtarget1=1−0.20κ∈[0.8,1]. Это размерный **target**, не гарантия изменения каждого фактического тетраэдра на 0…20%.
- P10DO/P10DQ/P10DR/P10DT/P10DW one-shot, M1, H0 cache, forward/adjoint/FEM не изменяются. Для P10EA предусмотрены новые два маркера, не подменяющие ни одного старого.
