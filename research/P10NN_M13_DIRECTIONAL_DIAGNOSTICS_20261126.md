# P10NN: ограниченное исследование касательных перемещений внутренних узлов M13 R2

После P10NM (критерий D031 не выполнен, единственный проблемный Tet10 №9478) исследуется новое направление геометрической коррекции. При фиксированном радиальном смещении узла 8680 `+0.0125 мм` и соседних узлов 8681, 9115 `+0.005 мм` на узел 8680 накладываются два ортогональных касательных смещения по сетке `−.006, −.003, 0, +.003, +.006 мм` (25 комбинаций). Первый касательный вектор — проекция направления 8680→8681 на плоскость, нормальную радиальному вектору по центроиду ближайшей грани поры; второй — векторное произведение нормали и первого касательного.

Для каждого кандидата согласованно корректируются срединные узлы рёбер Tet10, без движения узлов поры. Учитываются все 67 соседних Tet10 и все 729 точек: необходимы detJ>0 и индивидуальные отношения криволинейных объёмов в [0.9,1.1]. Предварительная метрика — наименьшее отношение сингулярных чисел, **не эквивалентное** Gmsh `minSJ` или `minSICN`. Отобраны исходный радиальный вариант и до 4 лидеров по предварительной метрике; все 25 тестов сохранены в манифесте.

## Windows

1. Распаковать ZIP в отдельную папку.
2. Требуются Python с numpy и `gmsh==4.15.2`.
3. Запустить `P10NN_RUN_NATIVE_QUALITY.cmd`, дождаться завершения.
4. Прислать только `P10NN_M13_DIRECTIONAL_GMSH_QUALITY_RESULT.json`.

Нативная проверка сопоставит все копии с исходной M13 R2 по `minSICN >= .20`, `minSJ >= .40`, `gamma >= .15`, `minDetJac > 0`; выдаст минимумы, худшие теги, число нарушающих элементов. Все файлы имеют контрольные суммы SHA256. Ни одна копия **не является M13 R3** и не разрешает FEM. Скрипт не запускает Gmsh generation/optimization, не использует маркеры и не перезаписывает результат.
