## Реализованный минимальный метод

`research/tools/p10nr_coordinate_topology.py` импортирует существующий `sample` P10NQ, заново загружает точную M13 R2, повторяет `HighOrderElastic` строго в памяти (без записи .msh). На каждой физической границе:
1. строит строгую биекцию старых/новых узлов по евклидовым координатам с допуском 1e-12 м; неоднозначные или неинъективные совпадения дают STOP;
2. переводит Tri6 старой сетки в новые идентификаторы и сравнивает мультимножества граней без привязки к ID элемента;
3. сопоставляет не только тройки вершин, но и соответствия срединных узлов каждому из трёх рёбер (01,12,20), независимо от ориентации;
4. выдаёт для групп 2–9 числа недостающих и лишних граней, а также отдельный итог; Interior Tet10 JVP/качественные показатели этим тестом **не доказаны**.

Условие классификации: `all_boundary_tri6_preserved=true` только если каждая физическая группа имеет нулевые counts missing/extra. При ненулевых counts выяснять реальное переподключение до любой оценки качества. **Нельзя** восстанавливать элементы по исходным ID или объявлять M13 принятым лишь на основании равенства облаков.
