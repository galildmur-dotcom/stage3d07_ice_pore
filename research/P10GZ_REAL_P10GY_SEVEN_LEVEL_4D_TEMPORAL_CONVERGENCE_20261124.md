### Время как четвёртая координата — отдельно, без сокрытия проблемы

В исходных time bins каждой сетки границы для разных dt **не совпадают**. Для сравнения получена диагностическая консервативная кусочно-постоянная реконструкция подписанного вклада на общем временном разбиении (с сохранением интеграла, но **без физического повторного QP интегрирования**). При dt36→25:

- Нативный 4D intermesh L1(dt25) = **6.340921 м⁻¹**.
- Дрейф реконструированного полного 4D межсеточного индикатора = **0.583948 м⁻¹ (9.21%)**; независимая max-по-сеткам сумма временной изменчивости по 4D bins = **1.614708 м⁻¹ (25.46%)** от того же сигнала. Это различие связано с коррелированными временными ошибками M0/M1 и не должно скрываться.
- Дрейф max-временной изменчивости / intermesh L1 после объединения 25/50/75/150-секундных физических временных окон: **25.46% / 25.04% / 17.79% / 9.81%**. Укрупнение окон снижает норму ценой потери временной локализации; это не доказательство 25-секундной точности.

**Математическая граница:** `D_Rjpeak(t_f)` — скаляр, отдельные 4D signed bins — вклады фиксированного интервала в градиент на *том же* горизонте `t_f`; не `D_Rjpeak(t_n)`. Кусочно-постоянная временная реконструкция — только обозримый proxy. Без нового анализа с согласованной физической временной интеграцией нельзя говорить, что каждое 25-секундное 4D сечение независимо сошлось.

## Решение P10GZ

1. **Допустить подготовку source-only первого кандидата spatial поля κ(x)** из *компонентных* (explicit/equilibrium/history/thermal) **межсеточных разностей на общей физической spatial сетке**, интегрированных по t только после показанного 7-уровневого контроля. Обязательны QP support, нормировки, знаки, анализ 36↔25 и стабильность Дёрфлера при изменении порогов (пилот θ=0.5, не зафиксированный научный допуск). Выделить приполюсные и неполярные контрольные зоны. Высокая амплитуда G сама по себе не свидетельствует об ошибке.
2. При построении кода *не терять 4D*: архивировать исходные `G^α_{K,n}`, временные профили и отдельно маркировку временной неустойчивости. Ориентировать spatial κ на time-integrated component differences с прозрачным правилом агрегации; для time-resolved 25с сигналов, не подтвердивших устойчивость, использовать только diagnostic/uncertain flag, не приписывать им строгий вес ошибки.
3. **Не объявлять M2 geometrical GO или FEM GO** по P10GZ. Следующий шаг — численный read-only/prototype κ с C² пространственным сглаживанием и проверкой χ∈[0,1], построение только mesh-only через новый изолированный Gmsh package после source/unit/field QA и D-025 локальных 15–25% по `κ=1`. Физика на M2 после геометрического GO и отдельной научной проверки.
4. Истинная апостериорная оценка DWR производной и доказанная асимптотическая/пространственная сходимость **пока не получены**; отдельная M4 нужна по прежнему протоколу.

Дополнительно: P10GY R2 исходные использованные one-shot markers и raw Windows evidence оставить нетронутыми. Из нашего локального исследования новых FEM=0. Все численные утверждения сверены непосредственно с исходными 14 ZIP/CSV по независимому скрипту, а не приняты из меток `PASS` одного manifest.
