# Stage3D07 / P10PZ — прямые коэффициенты Бернштейна границ 4D-ячеек на M8

Дата: 2026-11-28. **PASS_INDEPENDENT_DIRECT_BERNSTEIN_M8_ALL48**.

Продолжение P10PY на принятой **исходной M8**, фиксированной по SHA-256
`40949482ac74d80ae7ac44c88af527a705650d34c1ffcd0de7cd01dc2bd2fa8d`:
18 331 узел и 12 546 настоящих криволинейных Tet10.

**Операции строго геометрические:** без новой CAD, Gmsh, оптимизации,
смещения узлов, построения сетки, FEM, EDV, сопряжённой задачи, вычисления
знаковых 4D-производных и изменения исходных 27 квадратурных точек.
Обязательное условие для будущей оптимизации Gmsh — `HighOrderElastic`.

## 1. Научная гипотеза

В P10PY использовалась консервативная, но грубая классификация знаков
неравенств через ограничивающие параллелепипеды выпуклой оболочки
геометрического полинома Tet10. Она переоценивает возможные значения
нелинейных выражений, так как теряет зависимости между координатами.

В P10PZ ограничиваются **не координаты по отдельности**, а сами
полиномиальные функции границ 4D-ячейки. Для заданного изопараметрического
криволинейного Tet10 отображение `F(uvw)` имеет степень 2; квадрат
расстояния до центра и коническая граница полюса являются полиномами
степени 4 от референсных координат.

На каждом дочернем тетраэдре после точного аффинного ограничения:

- `r²-rho_lo² >= 0` и `rho_hi²-r² >= 0` — радиальные границы;
- `s*z >= 0`, `s=+1/-1` — выбор северного/южного полюса;
- `0.36*z²-0.64*(x²+y²) >= 0` — конус `|mu|>=0.8`;
- два линейных по `x,y` полупространства — азимутальный клин 30°.

Для двух полиномов в базисе Бернштейна порядка 2 используется
**аналитическое произведение коэффициентов**, без обращения матриц:

`B_alpha^2 B_beta^2 = [C(2,alpha) C(2,beta) / C(4,alpha+beta)] B_(alpha+beta)^4`.

После свёртки 10×10 пар исходных контрольных коэффициентов получаются
**35 истинных коэффициентов Бернштейна** каждого полинома степени 4.
Свойство выпуклой оболочки базиса даёт строгие знаковые оценки в точной
арифметике. Используемая реализация — IEEE double с масштабными защитными
допусками (`512 eps` для квадратов, `128 eps` для полупространств),
**без направленного интервального округления**; формальной машинной
интервальной гарантии пока нет. По P10PY сохраняется проверка на
противоречие уже установленным AABB-знакам.

## 2. Реальное сравнение на всех 48 приполюсных областях

Использованы `radial_bin = 0,4`; `mu_bin = 0,9`; все
`phi_bin = 0..11`. Для обоих алгоритмов исходные кандидаты
«криволинейный Tet10 × 4D-бин» совпадают. Процесс аффинного
бинарного `h`-разбиения по длинному физическому ребру также совпадает.
На каждом уровне 0–12 сравниваются доли **референсного объёма
исходных кандидатов**, а не реальные значения 4D-физического интеграла.

Доля, на которой сохраняется неопределённость двух или более
четвертичных ограничений (P10PY → P10PZ):

| Слой и полюс | Глубина 4 | Глубина 12 |
|---|---:|---:|
| 0–0.02 мм, юг | 25.996% → **22.756%** | 0.26554% → **0.12214%** |
| 0–0.02 мм, север | 27.492% → **24.105%** | 0.24597% → **0.10929%** |
| 0.25–0.50 мм, юг | 6.264% → **2.113%** | 0.11813% → **0.04472%** |
| 0.25–0.50 мм, север | 7.364% → **2.740%** | 0.13569% → **0.05114%** |

После глубины 12 **общая** доля ещё неопределённых пересечений
(не обязательно многочетвертичных) тоже уменьшилась:

| Слой и полюс | P10PY, % | P10PZ, % |
|---|---:|---:|
| 0–0.02 мм, юг | 6.1405 | **4.8762** |
| 0–0.02 мм, север | 6.8428 | **5.4842** |
| 0.25–0.50 мм, юг | 4.7991 | **3.5690** |
| 0.25–0.50 мм, север | 4.9982 | **3.6941** |

**Суммарно по 48 сочетаниям «элемент × бин»:**

- листьев с неопределённым знаком в конце: **1 907 728 → 1 456 417**;
  уменьшение **23.657%**;
- сумма референсных масс, для которых нельзя исключить **две и более
  четвёртичные границы**: `14.462890625 → 5.99267578125`
  в единицах исходного референсного тетраэдра;
  уменьшение **58.565%**;
- оба показателя не хуже P10PY на **каждом** из 13 уровней во всех
  48 отдельных бинах, а не только в среднем;
- ни одного противоречия между AABB-предикатом и прямыми
  полиномиальными оценками (`0`).

Количество листьев — сумма по бин-кандидатам; разные угловые бины могут
обрабатывать области **одного и того же** физического Tet10. Это не
количество новых конечных элементов.

## 3. Независимая проверка алгебры и геометрии

Аудитор повторно читает M8 и проверяет SHA-256, 48 комбинаций, все
13 уровней, сохранение референсного объёма, его распределение по
группам активных четвертичных ограничений, монотонность и покомпонентное
улучшение над P10PY. Не полагаясь на исходный код аналитической свёртки,
аудитор независимо восстанавливает коэффициенты полинома степени 4
из 35 точечных значений `F(uvw)` на реальном Tet10, решая отдельную
систему Вандермонда:

- **75 независимых тестов**: 5 реальных элементов M8, глубины 0–3;
- максимальная относительная невязка этих коэффициентов и
  аналитической свёртки: **`9.16423e-14`**;
- число обусловленности матрицы контрольной интерполяции:
  **15.1379**;
- референсные массы во всех дочерних подобластях замыкаются;
- статус **`PASS_INDEPENDENT_DIRECT_BERNSTEIN_M8_ALL48`**.

Второй аудитор не доказывает автоматически корректность знака при
любом машинном округлении; перед окончательным промышленным
сертификатом необходим интервальный режим или строгая аналитическая
оценка ошибок округления каждой операции.

## 4. Интерпретация и решение

Эксперимент **подтверждает гипотезу**: непосредственные коэффициенты
Бернштейна полиномиальных границ заметно лучше грубых оболочек
физических координат, прежде всего в более удалённом радиальном слое.
Вместе с тем остаётся ~**1.46 млн** неопределённых листьев. Поэтому
запуск Algoim на каждом листе с высоким порядком `q` без дальнейшего
сокращения **не рекомендован**.

**Важно:** это **не** сходимость физических 4D-производных формы.
Метрика — референсная доля вычислительно неопределённых подэлементов.
Уменьшение на 58.6% нельзя превращать в процент улучшения точности
физического интеграла. Переход от референсных объёмов к физическим
требует истинного `det J`, а поверхностные и объёмные механические
поля должны интегрироваться со своими весами и знаками.

## 5. Следующий этап — P10QA

Продолжать на **принятой M8** без модификации сетки.

1. Пробный физический объём `V(B)` в выбранных пересекаемых 4D-бинах:
   использовать `det J` истинного искривлённого Tet10, независимую
   граничную квадратуру и/или интервальное ограничение остаточного
   неопределённого объёма.
2. Выполнить независимое `h/q` сравнение для нескольких порядков
   квадратуры, включая активные одно-/многоповерхностные случаи.
3. Отдельно оценить стоимость, долю листьев, `q`, влияние
   полярной сингулярности `phi` и возможную общую геометрию между
   соседними 4D-бинами.
4. До проверки **реального** отрезанного объёма не запускать
   полный механический/температурный 4D FEM/EDV расчёт.

Схема продолжает идею многоуровневой квадратуры для областей,
заданных несколькими алгебраическими поверхностями:
[R. I. Saye, JCP 448 (2022), 110720](https://doi.org/10.1016/j.jcp.2021.110720).

## 6. Файлы воспроизведения

- `research/tools/P10PZ_M8_DIRECT_BERNSTEIN_PREFILTER.py` —
  построение коэффициентов и геометрический прогон 48 бинов;
- `research/tools/P10PZ_M8_BERNSTEIN_INDEPENDENT_QA.py` —
  независимая интерполяционная проверка и аудит 48×13;
- `research/P10PZ_M8_ALL_AZIMUTH_BERNSTEIN_QA.json` —
  покомпонентный протокол всех уровней;
- `research/P10PZ_M8_BERNSTEIN_SUMMARY_QA.json` —
  результаты независимого аудита;
- `research/P10PZ_M8_BERNSTEIN_CONVERGENCE.csv` —
  сопоставимые с P10PY ряды для построения графиков и статьи.

Пример запуска на имеющейся M8 (для репликации, не инструкция
пользователю запускать PowerShell):

```
python P10PZ_M8_DIRECT_BERNSTEIN_PREFILTER.py \
  --mesh M8.msh --baseline P10PY_M8_ALL_AZIMUTH_ADAPTIVE_QA.json \
  --max-depth 12 --output P10PZ_M8_ALL_AZIMUTH_BERNSTEIN_QA.json
python P10PZ_M8_BERNSTEIN_INDEPENDENT_QA.py \
  --mesh M8.msh --baseline P10PY_M8_ALL_AZIMUTH_ADAPTIVE_QA.json \
  --candidate P10PZ_M8_ALL_AZIMUTH_BERNSTEIN_QA.json \
  --output P10PZ_M8_BERNSTEIN_SUMMARY_QA.json \
  --csv P10PZ_M8_BERNSTEIN_CONVERGENCE.csv
```
