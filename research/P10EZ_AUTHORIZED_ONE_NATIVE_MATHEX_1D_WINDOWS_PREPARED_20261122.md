# P10EZ — подготовлена одна разрешённая native Windows MathEx 1D проба (22.11.2026)

## Исходная точка и санкция

Исследователь после P10EY ответил «разрешаю» и поручил продолжить последний
незавершённый этап. Разрешение относится **исключительно к одной** короткой
проверке действительного вычисления исправленного размерного поля `Field[6]`
в Gmsh4.15.2 посредством `-1`, не к новой M2 `-3` или FEM.

Исходный source-only P10EY GEO SHA256
`2aec3e2626b3500388954e428d880c702a4bb820116af93924b8d590bf9b26f1`
содержит семь StrCat частей `[600,600,600,600,600,600,597]`,
точно 4197 знаков. Фиксирован native Windows Gmsh4.15.2 EXE SHA256
`317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1`.
P10EX one-shot consumed, его markers неизменны и 02 запрещена.

## Проверяемое утверждение

Из точного `Field[6]` GEO удаляется только исходная 3D OCC геометрия:
формула и настройки size field переносятся дословно в отдельный 1D GEO.
Три непересекающиеся короткие линии в координатах, метры:

- север `{x=y=0, z=0.03105…0.03305}`, физический тег 101;
- юг `{x=y=0, z=0.02895…0.02695}`, физический тег 102;
- экватор `{y=0,z=0.03,x=0.00105…0.00305}`, тег 103.

В каждом случае радиальное расстояние от центра поры превышает 1 мм;
локально κ≈1 в полярных сегментах, κ≈0 на экваториальном сегменте.
Критерий PASS: native exit0, отсутствие Gmsh Error, непустой MSH2,
наличие одномерных элементов по всем тегам 101/102/103. Это
проверяет вычислительную грамматику и возможность 1D meshing с полем,
**но не** доказывает правильный size-response в 3D или D-025.

## Защита и ограничения

Отдельный изолированный Windows пакет `research/packages/P10EZ_R1_ONE_MATHEX_THREE_LINES_1D_WINDOWS_20261122.zip`.
Button01 проверяет точные SHA, реальный native GEO parse и сохраняет
24-часовой proof. Button02 требует вновь точные SHA/preflight и ручную
фразу `RUN ONE P10EZ MATH 1D`, затем создаёт двумя эксклюзивными
операциями `x` локальный и пользовательский однократные маркеры **перед**
единственным вызовом Gmsh -1. Любой STOP после маркера расходует попытку.
Ограничения запуска: wall20с, child private≤2GiB, log≤2MiB,
MSH≤10MiB, -nt2; доступная RAM≥4GiB, диск≥300MiB. Не читать/изменять
исходный Windows Git, M1/H0 или старые markers; никаких -2/-3/FEM.

## Уровень доказательства

На момент публикации — **source/unit и package only**, native Windows
1D не исполнен, M2 не построена, D-025 неизвестен, FEM0. После
действительного оригинального `P10EZ_EVIDENCE.zip` выполнить независимую
проверку full log, SHAs, трёх тегов и manifest. Только затем отдельно
согласовать **новый один** M2 mesh-only -3; старое разрешение P10EX нельзя
повторно использовать.
