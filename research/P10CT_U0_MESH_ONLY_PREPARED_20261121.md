# P10CT R1 — ограниченная U0 mesh-only попытка подготовлена, Windows ожидается

**Дата:** 21.11.2026. **Статус:** `P10CT_R1_PREPARED_UNIT_PASS_WINDOWS_MESH_PENDING_NO_FEM`. Это первый новый инструмент для создания **квазиравномерной по всему объёму** U0 после D-018/P10CS. Не новая физическая история, не M1 и не апостериорная оценка ошибки.

## Проверка новизны

P10CJ/CM/CQ/CR уже исследовали сеточное распределение, компенсацию, полярные индикаторы и объёмный binning прежних H4W. **Новый объект P10CT — ещё не существующая объёмная квазиравномерная сетка U0**, её физические группы, размеры и ограничение ресурса. Ранее U0 .msh не генерировалась. Приполюсная причина больших производных UNKNOWN; геометрическое качество не доказывает механическую ошибку.

## Геометрическая программа приёмки

Один Windows One Click вызывает: (1) пять SHA-256-гейтов по исходникам; (2) три независимых Python synthetic selftest; (3) Gmsh с наблюдаемыми мягкими остановками (до 900 секунд, 8 ГиБ process private, 750 МиБ .msh), только если не менее 16 ГиБ свободной RAM и 4 ГиБ диска; (4) Python read-only QC полученного U0 .msh. На Linux доступны unit, но **нет Gmsh/Windows PS5.1**; runtime Gmsh и реальная сетка остаются неизвестными. Прогноз для ПК i7-7700K/64 ГБ: 1–10 мин генерация, дополнительно ~1–5 мин аудит, низкая уверенность; для QA нет отдельного time cap.

Новый QC:

- читает только MSH 2.2 ASCII; проверяет физические группы по tag и имени, ориентацию всех corner Tet10, размеры p05/p50/p95, quality/edge ratio и объёмный corner proxy;
- экспортирует 4 радиальные зоны (`0–20µm`, `20–100µm`, `100µm–5mm`, `вне B6`) ×10 равных μ-полос ×12 φ-секторов = **480 ячеек-отчётов** (corner centroid proxy, не реальные объёмы пересечений);
- вычисляет sampled curved Tet10 Jacobian по 27 QP: *все* Tet10 со centroid в 0–100µm, каждый десятый приполюсный в остальной области, каждый сотый глобально (пересечения считаются один раз), не объявляя positivity всем пространством;
- сверяет положение midside узлов поверхности поры на сфере, отдельно обе крайние μ-полосы и неполярные поля. Структурный geometry-only PASS не означает пригодность U0 для FEM, особенно при грубом h=2 мм и R=1 мм.
