# P10CW — первый реальный поверхностный контроль U1_geo, без 3D/FEM

**Дата 21.11.2026.** Исходный `gmsh/P10CV_U1_GEO_ANGULAR_NEUTRAL_CANDIDATE.geo` под D-018A, wall20мкм/band200мкм/far2мм. **Реальная 2D-сетка сгенерирована в окружении ассистента**; это не Windows Gmsh4.15.2 и не 3D Tet10.

## Барьер новизны

- Уже проверено: P10CT R2 — грубая глобально равномерная U0 h2мм, 20 Tri6 pore, 0 nearwall corner-centroids, 27QP Tet10 sampled PASS. P10CU — только кубическая ресурсная экстраполяция. P10CV — исходник U1_geo, без генерации.
- Новый различающий тест: реально сгенерировать **поверхность поры** с новым полем h(d), измерить 120 угловых ячеек, curved CAD-совпадение, качество Tri6, отдельно проверить оба полюса. Это не повтор P10CK/CL (другие сетки и Tet10), не новый FEM.
- GO/STOP: удостовериться, что поровая поверхность физически размечена, не имеет вырожденных прямолинейных угловых треугольников и не получила сильного полярного перекоса по размерам. В случае локального `quality<0.1` — отдельный STOP на переход к 3D до уточняющего теста Gmsh4.15.2.

## Исполнение и воспроизводимость

1. Временная диагностическая установка Python-обёртки `gmsh==4.15.2` обнаружила **фактически подгружаемую библиотеку Gmsh4.13.1** (`General.Version`), не 4.15.2. Команда `-parse_and_exit` успешно загрузила OCC геометрию и GEO поля, код 0. Данный этап маркировать **Gmsh4.13.1**, никакой аттестации 4.15.2.
2. **Один** `-2 -nt 2 -format msh2` с 120-секундным watchdog, native exit0 за несколько секунд; выход 175630 узлов, 87812 элементов всех поверхностных групп, MSH2 около 16MiB; файл сохранён только в scratch, в Git не включён. Размер исходного `.msh` 16MiB округлён; оригинальный SHA256 `3e71273ce32c700d63d453c697bacbaa938e12f3a915b79defb14c8c1269f2a4`.
3. Read-only анализ `research/proposals/P10CW_SURFACE_QA_20261121/p10cw_surface_qa.py` на исходной MSH2 с использованием Gmsh API/NumPy; JSON `research/evidence/P10CW_LINUX_SURFACE_20261121/derived/P10CW_SURFACE_QA.json` (хеш оригинальной MSH2 внутри). В JSON сохранены все 120 угловых групп 10 равноплощадных μ ×12 φ; сумма count=74592. `.msh` не является необходимым для прочтения сводки, но нужен для независимого повторного аудита всех узлов.

## Интерпретация и решение

- Surface `h=20мкм` достигнут почти однородно по сфере в этой **2D** реализации; геометрия поры и физическая группа корректно считались. Отношение медианных размеров полюса/средние широты ≈1.002 не указывает на общий систематический полярный bias.
- Локальный Tri6 с низким corner-quality показывает **STOP_SURFACE_POLE_SLIVER** перед объёмной U1_geo. Никаких 3D Tet10, 27QP curved detJ, 0–20/20–100мкм физических объёмов, RAM/времени 3D и физических механических/тепловых производных этим тестом не получено.
- Следующий минимальный различающий тест: **один** ограниченный 2D-only запуск/QA того же U1_geo на пользовательском Gmsh4.15.2, фиксируя самое плохое Tri6 по обеим полярным областям, сравнение качества и размеров; при низком качестве — только mesh-only разбор полярного CAD-параметрического дефекта / high-order smoothing, не пытаться обойти проблему сразу 3D. После этого отдельная ресурсная и геометрическая 3D feasibility gate, ещё без FEM.

**Новые 3D meshes=0, FEM=0, analytic shape derivative changes=0, M1=0.** D-018A и правило STOP_DUPLICATE сохраняются.
