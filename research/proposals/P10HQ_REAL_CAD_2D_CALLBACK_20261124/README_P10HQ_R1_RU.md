# P10HQ — одна контролируемая поверхностная сетка с прямым κ

На P10HP пользователь подтвердил нативное построение **1D исходного CAD** с физическим прямым κ: 4193 вызова, 244 узла, 123 одномерных элемента, 0.329 с. P10HQ делает **только один следующий 2D опыт** на том же исходном CAD/B6 и точном Field[7] из P10GT. Физические расчёты на M0/M1 не повторяются; основание κ механическое, из подписанных результатов 4D.

- Запустить двойным щелчком `01_P10HQ_REAL_CAD_ONE_2D_GUARDED.cmd` после распаковки в отдельную папку.
- Внешний тайм-аут **180 секунд** убивает процесс, предельное число вызовов κ — **1 млн**. Нет автоматического повтора.
- Скрипт вызывает **ровно один** `gmsh.model.mesh.generate(2)`. Нет `generate(3)`, FEM, M2 или записи огромного `.msh`.
- Проверяется действительная CAD-топология, исходное поле, число треугольников и узлов Tri6, а также κ в настоящих узлах поверхности поры, раздельно север (`μ≥0.8`), юг (`μ≤−0.8`) и неполярная область (`|μ|<0.8`). Центры *прямолинейных* треугольников на кривой стенке не подменяют физические точки.
- Если Gmsh вызывает κ внутри полости, это **научный STOP**, без переназначения координат.

Нужны Python/NumPy и Gmsh 4.15.2 Python API. При отсутствии последнего создаётся локальное окружение и загружается точная версия (системная установка не меняется). Оценка времени на i7‑7700K: **10–180 секунд** плюс возможная установка окружения 1–5 минут.

Прислать `P10HQ_GUARD_RESULT.json`, `P10HQ_GMSH_LOG.txt` и, при наличии, `P10HQ_RESULT.json`. При STOP дополнительно `P10HQ_WORKER_ERROR.txt` или `P10HQ_INSTALL_LOG.txt`. **Это ещё не разрешение M2:** нужен независимый аудит поверхности и только затем отдельные 3D D-025/343/729 проверки.
