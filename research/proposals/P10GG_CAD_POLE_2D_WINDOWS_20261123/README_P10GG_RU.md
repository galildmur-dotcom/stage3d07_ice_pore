# P10GG R1 — исследование CAD-полюсов сферической поры (Gmsh 4.15.2)

**Научный статус:** подготовленная диагностика только поверхностной сетки,
без новой объёмной M1 и без FEM. Решение D-027 заменило обязательный
18/18 критерий M0→M1 устойчивой приёмкой, но ещё не выдало допуск
ни одной новой сетке. Исторические M1/M1V/M1W остаются STOP.

## Что сравнивается

Одна и та же исходная M0 OCC-геометрия: блок 60×60×50 мм,
сфера R=1 мм с центром (0, 0, 30 мм), B6 радиуса 6 мм, метки 1–9.
Вариант A — исходная OCC-параметризация, вариант B — единственный
поворот **параметрической оси** на 90° вокруг центра сферы до
`BooleanDifference`. Физические полюса, ось `z` и координаты областей
не поворачиваются.

Для обоих вариантов используется **байтово идентичное поле M0**
`Field[3]` и коэффициент `Mesh.MeshSizeFactor=0.825^(1/3)`;
различаться могут только CAD-параметризация и результат перестроения.
2D алгоритм Delaunay5, элементы Tri6, формат MSH2.2.
Это тест поверхности, а не новое 2D механическое исследование.

Из фактического `.msh` независимо извлекаются теги физических
поверхностей 2–9, координаты, максимальное отклонение радиуса
поверхностей поры/B6, численность северных/южных полярных Tri6,
минимальное и квантильное качество угловых треугольников,
положительность поверхностного Jacobian в трёх точках, приближённая
площадь и координаты худшего элемента. Положительное качество
поверхности **не доказывает** 3D Tet10 качество или объёмные q.

## Ограничения и безопасность

- Первый этап 01: источник SHA, точные исходные M0/CAD, Gmsh 4.15.2,
  две команды `-parse_and_exit`; **ни одной сетки**.
- Только при PASS 01 и не позднее 24 часов: одна кнопка 02.
- Кнопка 02 расходует два независимых постоянных одноразовых маркера
  **до** запуска; выполняет строго **два** `gmsh -2`, исходный и
  повернутый. При STOP повтор 02 запрещён, маркеры не удалять.
- Для каждого `-2`: не более 120 с, аппаратно ограниченная память
  процесса 2 ГиБ, два потока, `.msh` до 12 МиБ и журнал до 4 МиБ.
  При невозможности создать защиту Windows запуск запрещён.
- Нет `-3`, FEM, записи в `meshes`, `approvals`, изменений M0, M1V,
  M1W или их одноразовых маркеров. Новая папка `LOCAL_RUNS`.
- Пакет использует только стандартный Python 3; Python API Gmsh для
  этого двухповерхностного сравнения **не требуется**.

## Две кнопки без ввода команд

1. Распакуйте **новый** ZIP в
   `G:\ildar\Stage3D07\P10GG_TOOLS_R1`.
2. Нажмите двойным щелчком `01_P10GG_PREFLIGHT_ONLY.cmd`.
   Окно останется открытым. Если `P10GG_PREFLIGHT_PASS_NO_MESH`
   отсутствует — **02 не запускать**; прислать `P10GG_01_RESULT.txt`.
3. При PASS нажмите **один раз** `02_P10GG_ONE_2D_PAIR_ONLY.cmd`.
   Никаких слов, путей или подтверждений вводить не нужно.
4. Из новой папки
   `G:\ildar\Stage3D07\LOCAL_RUNS\P10GG_CAD_POLES_...`
   пришлите **один** `P10GG_CAD_POLE_2D_EVIDENCE.zip`.
   Он содержит обе исходные `.msh`, все `.geo`, журналы и метрики.
   При раннем STOP без ZIP прислать `P10GG_02_RESULT.txt`.

Ожидаемое время на i7-7700K для двух `-2` — обычно секунды,
но предусмотрен защитный предел до 4 минут суммарно; максимум памяти
одного процесса 2 ГиБ. Следующий шаг после независимого аудита ZIP —
выбор **одного** нового объёмного HXT10 кандидата M1 и предварительная
фиксация его критерия D-027. Никакого автоматического FEM GO нет.
