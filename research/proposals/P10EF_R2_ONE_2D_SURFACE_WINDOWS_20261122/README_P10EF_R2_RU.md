# P10EF R2 — разрешённая одна Windows попытка Gmsh 2D, без 3D/FEM

**Разрешение исследователя 22.11.2026: ровно ОДНА новая native Gmsh 4.15.2 `-2` попытка** для кандидатной поверхности B; никаких `-3`, forward, adjoint, FEM, H0 cache. Этот новый R2 ZIP следует распаковать **отдельно** от P10EF R1/P10EA и вне `G:\ildar\Stage3D07`. Старые пакеты и маркеры нельзя очищать/использовать повторно.

## Научная постановка

Кандидат B `B_P10EF_EXACT_F6_ALG5_SURFACE_ONLY.geo` имеет точную SHA256 `2765018d8ddd2e83f28bd60af7c87b65172ac5da8389ede187d8bb9eea9d74c5`. Эталон A — original P10EA F6, SHA `32f8f959002cbd41539e355a80437c2ca3be12fdd3ba12de31eadf2c021b9561`; B отличается **одной строкой `Mesh.Algorithm = 5;`** при неизменных CAD/F6/κ/размерах. Контроль A повторно не мешировать. Алгоритм5 проверяется только на 2D поверхности; результат P10EA алгоритм6 уже известен из старой raw M2.

Исходная принятая M1: **оригинальная P10DG** `P10DG_M1_CANDIDATE.msh` SHA `ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f` (9736 Tet10, 178 pore Tri6). Историческая неудачная M2 алгоритм6 — **оригинальная P10EA** `P10EA_M2_CANDIDATE.msh` SHA `ba1f1a0553a568c1b399acadd52bce1c1dc32e8d1c6b3ab1ce6759c547e5dee5` (9750 Tet10, 170 pore Tri6). Программа только читает оригиналы и проверяет SHA. Gmsh exe `C:\gmsh-4.15.2-Windows64\gmsh.exe`, SHA `317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1`. При другом расположении EXE задайте `P10EF_R2_GMSH_EXE` до CMD.

## Порядок — две кнопки

1. Распакуйте именно **P10EF R2** ZIP в новый каталог. Нужен Windows, Python 3 (stdlib), установленная указанная Gmsh 4.15.2; желательно свободно ≥4 GiB RAM и ≥1 GiB места.
2. Один или несколько раз (по необходимости, без расходования попытки) запускайте **`01_P10EF_R2_SAFE_PREFLIGHT_ONLY.cmd`**. Укажите пути к оригинальным raw M1 и исторической raw M2 или Enter для предложенных путей. Программа проверяет PIN9/9, one-line source diff, SHA обоих raw, EXE+версию, native `-parse_and_exit` A/B — **только разбор GEO, без сеточного запуска**, формирует `P10EF_R2_EVIDENCE.zip` и сертификат на 24 часа.
3. После PASS01 и не позднее 24 часов запустите **`02_P10EF_R2_ONE_2D_SURFACE_ONLY.cmd`**. Повторная проверка SHA и native GEO parse; затем **строго вручную** введите фразу:

   ```
   RUN ONE P10EF 2D SURFACE
   ```

   Пустой Enter/другая фраза = STOP без расходования маркера.
4. Непосредственно перед единственным native Gmsh `-2` программа эксклюзивно создаёт **новые** `P10EF_R2_ONE_2D_USED.json` в `P10EF_R2_RUNS` и `P10EF_R2_ONE_2D_<M1_SHA>.json` в `%LOCALAPPDATA%\Stage3D07`. **Любая неудача после этого, код 2, timeout или отсутствие .msh расходуют запуск. Никогда не удаляйте маркеры и не повторяйте 02.** Маркеры P10EA/P10DO/P10DW остаются неизменными.
5. Ограничения: **120 сек wall; 2 GiB private RAM с опросом (не жёсткий лимит ОС); 25 MiB 2D `.msh`; 4 MiB Gmsh log; `-nt 2`**. Только после завершения native выполняется read-only Python curved Tri6 15×15 QP QA ≤60 сек с тем же polled private, без FEM.
6. При PASS или STOP отправьте **один оригинальный `P10EF_R2_EVIDENCE.zip` из последней папки `P10EF_R2_RUNS\P10EF_R2_*`**. ZIP намеренно содержит **новую raw 2D MSH** для независимого пересчёта; **не публикуйте его автоматически в открытый GitHub**. Original raw M1 и historical raw M2 в evidence **не включены**, только exact SHA и метрики.

Если native `-2` завершился с exit0, в ZIP находятся Gmsh full/tail log, exact GEO, result, run manifest, surface QP audit JSON и новая raw 2D MSH. Величина `0.8^(2/3)=0.861773876` — **целевой** характерный полярный коэффициент площади B/M1, не гарантированная фактическая сетка. Текущий этап определяет разницу north/south/both_poles, но **не утверждает GO-допуск к 3D**, даже при хорошем 2D. Физические M0/M1 задачи и 3D M2 требуют новых самостоятельных разрешений.

Типичное ожидание на ПК с i7-7700K: preflight ~1–3 минуты, ограниченная native-часть максимум 2 минуты плюс ≤1 мин поверхностный QA; **это оценка, не гарантия**. `P10EF_R2_RESULT.txt`, `P10EF_R2_GMSH_FULL.log`, `P10EF_R2_MANIFEST.json` и ZIP дают статус. Ошибка/тайм-аут не оправдывает повтор native-2D.
