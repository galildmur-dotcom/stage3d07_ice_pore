# P10DO R1 — одна новая геометрическая сетка M2 по полю κ, без расчёта FEM

**Сначала прочитайте полностью.** Это строго **mesh-only** этап: ни новая прямая, ни сопряжённая задача, ни механическая/тепловая `(r,θ,φ,t)` производная здесь **не вычисляется**. M0=H0 и физическая M1 остаются зафиксированными результатами. Старые P10DG/P10DL маркеры, исходную сетку и `forward_history.bin` не изменять и не удалять.

## Что именно сгущаем

По решению исследователя: **κ∈[0,1] на всей области льда с гладким C¹ переходом**; κ1 значит целевой объём M2 равен0.8 от базового *целевого* объёма M1, κ0 значит без нового сгущения; все промежуточные значения линейно интерполируют уменьшение объёма:

`Vtarget_M2/Vtarget_M1 = 1−0.2κ; htarget_M2/htarget_M1 = (1−0.2κ)^(1/3)`.

**Первая кандидатная карта** из P10DN: κ1 у обоих полюсов до0.1мм от поры, плавно к0 на0.5мм; полярные переходы |cosθ|=0.6–0.8, без φ-узоров пока из-за слишком малых QP в бинах H0/M1. Ни одно количество узлов не задаётся заранее. Сама новая дискретизация может иметь фактические объёмы отдельных тет10 вне указанного целевого отношения; 9-зонный M1/M2 отчёт описывает **непарные** наблюдаемые объёмы, и не является доказательством локального −20% для каждого тетра.

## Перед запуском

- Windows 11, Python3, установленный **Gmsh 4.15.2** по адресу по умолчанию `C:\gmsh-4.15.2-Windows64\gmsh.exe` (или переменная `P10DO_GMSH_EXE` по нужному точному пути). Не нужен Qt Creator, MinGW, компиляция и FEM.
- Строго **исходный** уже принятый `P10DG_M1_CANDIDATE.msh`, SHA256 `ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f`, 14145 узлов и9736 Tet10. Путь по умолчанию — старый оригинальный каталог P10DG в `G:\Downloads\...`; если файл перенесён, вводите его полный путь при запросе. H0/U0/новая M1/подставленная сетка — STOP.
- Архив распаковать **в новый отдельный каталог**, не поверх P10DN/P10DL/P10DG и не в `G:\ildar\Stage3D07`. Не запускать непосредственно из ZIP.
- Требуется не менее16GiB **свободной** ОЗУ и4GiB свободного места. Ограничения именно на один новый запуск Gmsh: **900с wall/8GiB private/750MiB `.msh`/30MiB log**, 2 потока, дополнительный этап QA не более300с.
- Примерная длительность на i7‑7700K — **1–5 минут суммарно**, но это оценка: M2 ранее на вашем ПК не строилась; при приближении к ограничениям принудительная остановка. Старые one-shot механизмы не использовать для повтора.

## Кнопки — в строго заданном порядке

**1. `01_P10DO_CHECK_M1_AND_GEO_ONLY.cmd`.** Безопасная проверка. Проверит SHA источников и оригинальной M1, наличие Gmsh 4.15.2, ресурсы, выполнит 27-точечный синтетический QA и реальный Gmsh `-parse_and_exit` **без построения 3D-сетки**. Одновременно Python **разметит все 9736 исходных Tet10 M1** значениями κ по центроидам и экстремумами по10 узлам в новой изолированной папке. Получится небольшой `P10DN_M1_COEFFICIENT_SUMMARY.json` и локальный CSV. Preflight не создаёт one-shot marker: его можно исправлять и повторять при STOP; сохраните `P10DO_EVIDENCE.zip` для диагностики. Если ExitCode!=0 — **НЕ переходить к кнопке 2**.

**2. `02_P10DO_ONE_M2_MESH_ONLY.cmd`.** Только после успешного шага1. Снова проверит исходный M1, GEO, SHA и ресурсы, предложит ввести полный путь при необходимости и спросит точную фразу **`RUN ONE P10DO M2 MESH`**. Фраза вводится только во второй запрос, **не вместо пути к сетке**. До введения фразы никакой M2 Gmsh и никакой marker. После фразы создаются отдельный marker в P10DO и второй в `%LOCALAPPDATA%\Stage3D07` на принятую SHA M1, а затем запускается **одна** Gmsh3 генерация. Даже при STOP/QA не повторять шаг2 и не удалять marker без отдельного анализа.

Новая M2 остаётся на компьютере в папке `P10DO_RUNS\P10DO_M2_*\P10DO_M2_CANDIDATE.msh`. QA независимо проверяет физические группы, все **27 curved QP каждого Tet10**, ориентации, сферическую стенку поры, суммарный объём CAD, полную маркировку κ и девять радиально-полярных зон. В отчёте представлены непарные медианы локальных объёмов M1 и M2. **QA_OK означает геометрическую целостность и наличие отчёта, но не окончательное признание адаптивного M2 для физики**: его ещё нужно обсуждать с исследователем.

## Что прислать

После **каждой кнопки, если она STOP**, или после второго успешного шага — **только один небольшой** `P10DO_EVIDENCE.zip` из соответствующей новой папки `P10DO_RUNS\P10DO_M2_*`. Архив содержит manifest, полный 9-зонный CSV/JSON, M1-coefficient summary и хвост лога. **Не загружать** большой `.msh`, M1 `.msh`, `forward_history.bin`, тяжёлые VTU и прежние evidence повторно. Достаточно прислать один последний успешный ZIP (или STOP ZIP).

На этом этапе **физический M2 FEM=0**. Отдельный физический запуск M2 и следующее сгущение допускаются только после независимой оценки реальной M2 геометрии и решения исследователя.
