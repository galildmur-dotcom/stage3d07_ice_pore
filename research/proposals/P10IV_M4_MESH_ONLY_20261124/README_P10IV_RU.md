# P10IV — одна защищённая попытка построения 3D-сетки M4 (только Gmsh)

Этот пакет НЕ содержит физического расчёта FEM. Он использует принятую сферическую CAD и поле M0→M1→M2→M3, добавляет физически информированную поправку P10IU M3→M4. Базовые исходники M2 и принятая M3 включены и защищены SHA256. Не копируйте его поверх старых P10IO/P10IR папок.

## Использование на Windows

1. Распакуйте архив в **новую чистую папку вне `G:\ildar\Stage3D07`**. Ничего не перемещайте из `LOCAL_RUNS`, `build`, `meshes`.
2. В Gmsh Python необходимо иметь API **4.15.2**, доступный через `py -3` (или `python`), и `numpy`.
3. Двойной щелчок `01_P10IV_PREFLIGHT_NO_GMSH_NO_FEM.cmd`. Ожидается `P10IV_R1_PREFLIGHT_PASS_NO_GMSH_NO_FEM`. Если STOP, не запускайте 02: пришлите текст ошибки.
4. После PASS двойной щелчок `02_P10IV_ONE_M4_MESH_ONLY.cmd`. **Только один раз**, никакого ввода `RUN ONE` или подтверждающих фраз. Отчёт о работе каждые 30 секунд. Максимальное время 900 с, контроль памяти 8 ГиБ и ограничение размера выходного файла 250 МиБ. При STOP маркер израсходован: нельзя удалять его и повторять 02; сообщите причину для новой ревизии.
5. После завершения прислать **один** `P10IV_R1_M4_UNVERIFIED_EVIDENCE.zip`. В него входят журнал Gmsh, guard/worker JSON, one-shot marker и новый `P10IV_M4_CANDIDATE_UNVERIFIED.msh`. Если файл больше лимита передачи, отправить только JSON+LOG, а сам `.msh` — отдельно после согласования.

## Научные границы

- Имя `UNVERIFIED`: успешный выход Gmsh ещё не означает принятия сетки. Независимая D031 проверка всех curved Tet10 и D029 поддержанных региональных реальных Veff(M4/M3) обязана последовать.
- D031: minSICN≥0.20, minSJ≥0.40, gamma≥0.15, detJ>0 на 27/343/729 QP, CAD closure.
- D029: фактическое региональное отношение Veff(M4/M3)∈[0.50,0.75] в достаточно поддержанных высокочувствительных регионах; `q` только диагностика D030.
- Никаких FEM/adjoint/GH3, никаких повторов P10IO/P10IJ/P10IR, не заявлять сходимость D_R Jpeak до нового физического расчёта.

На пользовательском i7-7700K предварительный бюджет Gmsh — **до 15 минут** и **не более 8 ГиБ контролируемой памяти процесса**; фактическое время M4 ранее не измерялось. При превышении ограничений будет STOP.
