# P10CX R1 — один ограниченный 2D опыт Gmsh 4.15.2 (без FEM)

**Цель:** проверить, остаётся ли обнаруженный Gmsh4.13.1 единичный вытянутый Tri6 у южного полюса при **Gmsh4.15.2** на той же геометрии U1_geo с размерами 20/200/2000 мкм. Это научная проверка версии геометрического построения, **не** новый 3D Tet10/FEM и не проверка механических градиентов формы.

## Как запустить

1. Распаковать этот ZIP в новый отдельный каталог на Windows, например `C:\P10CX_R1\` (не в `G:\ildar\Stage3D07`). Не перемещать и не изменять старые расчёты.
2. Убедиться в наличии `C:\gmsh-4.15.2-Windows64\gmsh.exe` и Python 3 (`py -3` или `python`). Устанавливать дополнительные модули Python не требуется.
3. **Один раз** дважды щёлкнуть `01_RUN_P10CX_SURFACE_ONLY.cmd`. При ошибке не повторять ту же кнопку; сообщить STOP и архив, если он создан.
4. Передать ассистенту **только один** `P10CX_EVIDENCE.zip`, найденный в подкаталоге `P10CX_RUNS\P10CX_<дата>\`. Сам файл `.msh` (до 150 МиБ) остаётся у исследователя.

## Жёсткие границы

- Gmsh 4.15.2, только `-2` (2D-поверхности), `-nt 2`, MSH2 ASCII; нет `-3`, нет FEM, нет CMake, нет Qt Creator target.
- Ограничение времени 180 с, приватной памяти процесса 2 ГиБ, MSH-файла 150 МиБ; предварительно нужно 4 ГиБ свободной оперативной памяти и 1 ГиБ места. Расчётная длительность на i7-7700K — примерно **5–90 с** (низкая уверенность), полный лимит 3 мин; расход памяти ожидается существенно ниже 2 ГиБ, но не измерен на Windows.
- SHA-256 трёх входных файлов и `gmsh.exe` записываются. Проверяются native exit кода Gmsh и Python, stdout и stderr, результат 120 угловых ячеек, минимум качества и худший элемент. Только читает исходники, пишет новый вывод рядом с распакованным пакетом.
- Если худший Tri6 имеет quality<0.1, результат `P10CX_STOP_SURFACE_POLE_SLIVER_NO_3D_NO_FEM`; иное успешное завершение не разрешает 3D или физический FEM без новой проверяемой сеточной программы.
- `01_RUN_P10CX_SURFACE_ONLY.cmd` не является Git-патчем и не изменяет `G:\ildar\Stage3D07`. Один экземпляр распакованного пакета — один запуск.
