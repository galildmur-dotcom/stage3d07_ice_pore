# P10EU — только подготовка и проверка исходников Gmsh для M2

**22.11.2026. Это НЕ разрешение и НЕ кнопка запуска нового Gmsh.**
Пакет содержит единую C¹ формулу распределения размера на стенке поры и
в объёме, точный исходный CAD, производный JSON-аудит и одну кнопку
только для проверки источников.

## Действие пользователя (необязательно до выдачи разрешения)

1. Распаковать ZIP в новый отдельный каталог Windows, не смешивать со
   старыми P10EA/P10EK/P10EN каталогами.
2. Дважды щёлкнуть 01_P10EU_SAFE_SOURCE_PREFLIGHT_ONLY.cmd.
3. При корректных файлах увидеть P10EU_SOURCE_PREFLIGHT_PASS и exit0.
   Окно не строит новую M2, не запускает Gmsh, не выполняет FEM и не
   создаёт одноразовый маркер. При STOP передать точную строку ошибки.

Кнопки 02 намеренно нет: для нового нативного mesh-only M2 требуется
отдельное разрешение исследователя. После разрешения может быть
подготовлен новый однократный защищённый запуск; прямой и сопряжённый
FEM требуют следующего согласования после geometry + D-025 GO.

## Параметры и происхождение

- Предполагаемая версия Gmsh — 4.15.2; исходный
  sphere_pore_B6_refined.geo SHA256
  8029a6ed22bcf312701cd6abc46bbe5575e52df16fd5218dd936b01d5cd6fcf0.
- Новый P10EU_M2_C1_JOINT_SURFACE_VOLUME_SOURCE_ONLY.geo SHA256
  4c4a4aeb4f97bfec350e1e057a57e275d436c09d63a02438a8acfe4ad386253a.
- Единое Field[6]=MathEval без вложенных MathEval: не два нестыкующихся
  поля размеров. Исходное Field[2] сохраняется в CAD, а Background Field=6
  переопределяется после включения геометрии.
- Размер от точек, кривизны и распространение с границы отключены;
  алгоритмы двумерной сетки 5 и трёхмерной 10, порядок элементов 2
  унаследован без изменений.
- 7620 синтетических проверок исходников на Linux, максимальная
  относительная невязка 2.7247e-16. Это НЕ доказательство парсинга
  выражения конкретным исполнимым Gmsh и НЕ измерение размера реальной M2.
- Единственный количественный обязательный D-025: новый реальный
  характерный объём Tet10 в каждой фиксированной 3D полярной шапке
  Veff(M2)/Veff(M1) должен быть в [0.75,0.85] с контролем 343→729QP.
  При κ=0 стремиться сохранить размер, плавность контролировать на
  смежных Tet10. Площадь Tri6 и равномерность по азимуту не жёсткие gate.

Исходная M1 и приватные evidence MSH не входят в ZIP. Локальные
каталоги пользователя, старые пакеты и маркеры не изменяются.
