# P10CT R1 — одна сетка U0, только генерация и аудит (21.11.2026)

**Стадия:** технический mesh-only опыт после D-018/P10CS. Никакой термомеханической прямой/сопряжённой задачи здесь нет: PHYSICAL_FEM=0. Это не адаптивная M1 и не доказательство сходимости производной.

## Что делает одна кнопка

- Берёт точную исходную 3D OCC-геометрию: блок 60×60×50 мм, сферическая пора радиуса 1 мм, B6 радиуса 6 мм, физические группы 1–9.
- Вызывает Gmsh 4.15.2 только один раз с **постоянным целевым размером 2 мм во всём объёме**, без специального сгущения около стенки или полюсов; формат MSH2.2 ASCII Tet10/Tri6. Это очень грубая *пробная* сетка: качество разрешения поры ещё неизвестно.
- Проверяет девять физических групп, фактическую объёмную структуру, размеры и качество элементов, отдельно слои 0–20 мкм, 20–100 мкм, 0.1–5 мм, наружную область и 10 полос по μ=cosθ × 12 секторов φ. Оба полюса сравниваются с неполярными областями.
- Проверяет положительность 27 точек якобиана искривлённого Tet10 на заявленной выборке: все тетраэдры до 100 мкм, часть полярных и дальних элементов. **Это выборочная проверка, не гарантия detJ>0 повсюду.** Сетку нельзя допускать к FEM автоматически.

## Как запустить на вашем Windows 11

1. Скачать архив `P10CT_R1_U0_MESH_ONLY_WINDOWS_20261121.zip` из ветки GitHub, распаковать **в новую отдельную папку вне** `G:\ildar\Stage3D07` и вне существующих каталогов расчётов. Архив не является патчем; в проекте на G: ничего менять не нужно.
2. Убедиться, что доступен `C:\gmsh-4.15.2-Windows64\gmsh.exe` (путь из прежней рабочей конфигурации), а также Python 3 (`py -3` либо `python`). Если исполняемый файл Gmsh расположен иначе, скрипт допускает только явно заданную переменную `P10CT_GMSH_EXE`; по умолчанию никакие пути не ищутся.
3. Дважды щёлкнуть **`01_RUN_P10CT_U0_MESH_ONLY.cmd`**. Отдельное окно покажет `RESULT` и путь к единственному небольшому evidence ZIP. На повторную попытку в том же каталоге установлена блокировка.
4. Передать мне **только `P10CT_EVIDENCE.zip`** из папки `P10CT_RUNS/P10CT_...`. При STOP достаточно того же ZIP или строки `RESULT` вместе с `STOP_REASON`. Новую `.msh` присылать не нужно: она остаётся у вас для будущей проверки.

**Не используйте Qt Creator и не запускайте расчётный EXE на этом шаге.** Не переносите `.msh` в действующие `G:\ildar\Stage3D07\meshes` и не подменяйте H0–H4. Новая сетка останется только в извлечённой папке пакета.

## Ограничения и оценка времени

| Параметр | Значение |
|---|---|
| Задаваемый размер | h = 0.002 м, одна попытка |
| Gmsh | 4.15.2, 2 потока, MSH2 ASCII, Tet10 |
| Предстартовый контроль | свободная ОЗУ ≥16 ГиБ, свободный диск ≥4 ГиБ |
| Программный STOP Gmsh | 900 с, процесс private >8 ГиБ, `.msh` >750 МиБ |
| Ориентировочное время | Gmsh 1–10 мин, Python QC дополнительно ~1–5 мин; **неизмеренная оценка** для i7-7700K, 64 ГБ |
| Новые физические FEM | 0 |
| Новые сетки в пользовательском проекте | 0 |

Указанные пороги для Gmsh — наблюдаемые программные остановки, **не жёсткие аппаратные квоты**. После остановки остаются частичные журналы и, возможно, неполная `.msh` в изолированной папке. Python QC считывает сетку после успешного Gmsh; отдельного принудительного лимита времени для него пока нет.

## Что означают результаты

- `P10CT_U0_GEOMETRY_QA_OK_NO_FEM`: аудит геометрической структуры пройден. Это **не** подтверждение равномерности, пригодности для shape derivative или сходимости. Необходимо отдельно оценить статистики и близость к стенке.
- `P10CT_STOP_NO_FEM`: нет Gmsh/Python, не прошли хеши, лимиты, генерация или геометрия; повтор не выполнять автоматически, сначала разбор причины.
- `P10CT_U0_SUMMARY.json` и `P10CT_U0_3D_SIZE_BINS.csv` — только **сетка и её corner-centroid/selected-QP геометрия**, без механических, тепловых, временных полей. Не смешивать с требуемым позднее 4D распределением производной.

## Контроль исходников

Все пять текстовых исходников SHA-256 проверяются до Gmsh, включая воспроизводимые P10CK/P10CP Python-функции. На Linux до публикации: Python selftest 3/3 PASS; реальный Gmsh и Windows PowerShell 5.1 **не исполнялись** (соответствующей среды здесь нет). Это исходник для одного контролируемого mesh-only Windows опыта, не готовый физический результат.
