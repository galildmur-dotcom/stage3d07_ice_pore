# P10HS — одна реальная кандидатная 3D-сетка, только Gmsh, без FEM

P10HR подтвердил фактическое, хотя небольшое, перераспределение поверхностной сетки: 180→178 треугольников на поре, север 16→19, медиана ребра на севере 0.425→0.413 мм и на юге 0.394→0.378 мм. При этом общее число треугольников уменьшилось, поэтому **нельзя объявлять выполнение D-025 по 2D**.

Эта программа делает **одну** ограниченную 3D-попытку на точно исходном CAD P10GT с прямым полем механического κ, без физических расчётов. Генерируется файл **`P10HS_M2_CANDIDATE_UNVERIFIED.msh`** — кандидат, а не утверждённая M2. Сохраняется оригинальная M1 и вся подписанная 4D-физика M0/M1.

1. Распаковать ZIP в отдельную папку.
2. Запустить `01_P10HS_ONE_CANDIDATE_3D_NO_FEM.cmd` двойным щелчком.
3. При успехе отправить **только** `P10HS_M2_UNVERIFIED_CANDIDATE_EVIDENCE.zip`. Внутри уже находятся сетка `.msh`, лог, числовой отчёт и статус защитной оболочки.
4. При ошибке/тайм-ауте отправить `P10HS_GUARD_RESULT.json`, `P10HS_GMSH_LOG.txt` и, если есть, `P10HS_WORKER_ERROR.txt`; при проблеме Python API — `P10HS_INSTALL_LOG.txt`.

Ограничения: ровно один `gmsh.model.mesh.generate(3)`; **600 секунд** нативного времени, максимум **4 млн** запросов κ, жёсткая проверка правильности исходного CAD, Tet10 и нахождения узлов в области льда. Пробы внутри полости помечают результат STOP. Нет автоматического повтора, FEM, построения M3 или использования кандидата в физике.

Ожидаемое время на i7‑7700K/64 ГБ: ориентировочно **1–10 минут** плюс возможная установка Gmsh Python API в локальное окружение; если продолжительность превышена, программа завершит дочерний процесс.

Дальнейший независимый этап — сравнить файл с закреплённым **оригинальным M1**, проверить собственно локальные объёмы криволинейных Tet10 с 343/729 точками квадратуры, дифференцировать север/юг/неполярные области, гладкость размеров и требование D-025 (**реальное уменьшение локального объёма 15–25% при κ=1**). **Пока запрет на FEM сохраняется.**
