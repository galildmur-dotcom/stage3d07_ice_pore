# P10IY — новая однократная попытка построения M4 с двумя изменениями поля

Исходное P10IV R1 mesh-only закончилось геометрическим STOP по D031 и отдельным северным D029 target miss. **P10IV R1 нельзя повторять.** В этом архиве новая независимая ревизия P10IY, иная программа и маркеры; оригинальная CAD не меняется, FEM не выполняется.

## Кратко о гипотезах

- Северный параметр log-size delta увеличен .11445577→.18; северный D029 ratio ≈.711 — только феноменологический прогноз по одной наблюдавшейся M3/M4 паре, **не** измеренный результат новой M4.
- Вдоль физической поверхности поры возле трёх corner узлов отклонённого Tet10 10378 добавлен компактный C² patch: поддержка по angular chord .45 и расстоянию от стенки .5мм, дополнительная log-size амплитуда до .10. Переходы на шве и полюсах корректны. Изменение размера **не гарантирует** улучшение minSJ/SICN.
- Южный полярный coefficient оставлен прежним. 10 CAD embedded seeds сохранены для контролируемого сравнения первой новой ревизии; это не объявляется постоянным научным инвариантом.

## Windows запуск

1. Распаковать ZIP **в отдельную новую папку**, вне `G:\ildar\Stage3D07`; не копировать поверх P10IV R1. Не удалять старые markers.
2. Двойной щелчок по `01_P10IY_PREFLIGHT_NO_GMSH_NO_FEM.cmd` — ожидать `P10IY_R1_PREFLIGHT_PASS_NO_GMSH_NO_FEM`. Нужны Python, numpy, Gmsh Python API 4.15.2. При STOP НЕ запускать 02.
3. После PASS запустить **ровно один раз** `02_P10IY_ONE_M4_REPAIR_MESH_ONLY.cmd`. Никаких фраз подтверждения вводить не нужно. Будут heartbeat каждые ≤30с. Предел: 900с и мониторинг 8ГиБ private RAM, журнал 32МиБ, сетка 250МиБ. Маркер P10IY создаётся и локально, и в профиле Windows до Gmsh; при любом STOP повтор запрещён. 
4. Отправить **только** `P10IY_R1_M4_REPAIR_UNVERIFIED_EVIDENCE.zip` (Gmsh log, guard/worker, marker, новый MSH). При ограничении передачи файла — сперва сообщить, не удаляя/не повторяя запуск.

## Следующее научное решение

Успешное завершение Gmsh само по себе не является GO. Я независимо проверю все curved Tet10 по D031: minSICN≥.20, minSJ≥.40, gamma≥.15, 27/343/729 detJ positive, CAD closure; а также отдельный статус D029: реальный supported N/S `Veff(M4_candidate)/Veff(M3)` в [.50,.75] и N_eff. Соседнее q — только диагностика D030. Без полного геометрического GO физику не запускать.

Ресурсный **лимит** на Windows: до 15 минут, до 8 ГиБ, 4 потока; фактическая продолжительность исправленной сетки заранее неизвестна. Предыдущая попытка заняла около 10 секунд, но это не гарантия следующей.
