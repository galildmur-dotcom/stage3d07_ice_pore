# P10GP R2 — подготовленный защищённый 2D тест адаптивного поля

**SOURCE/UNIT PASS. Реальный native Windows Gmsh `-2` не запускался. Данная подготовка не заменяет отдельное разрешение исследователя на запуск. Нет 3D/FEM.**

Задача: на **одной и той же повёрнутой OCC-геометрии** построить две сопоставимые поверхностные Tri6 сетки: A прямое исходное F3; B самодостаточное F7 с гладким южным множителем [0.94,1.00]. Глобальный фактор `0.9378887276834518`, исходная M0 и D-027 неизменны. Цель — проверить, влияет ли локальное поле на *фактические* размеры и качество элементов поверхности, прежде чем рассматривать 3D.

Самодостаточный Windows ZIP: `P10GP_R2_GUARDED_WINDOWS_2D_ONLY.zip`. Пять файлов (source-only P10GP R1 ZIP, pinned проверенный модуль P10GH для Windows job/2D QA, новый Python driver, две CMD). Источник из P10GO без вложенных F3/F4/F5, MathEval 10 201 source sample/4 C¹ PASS. ZIP CRC, unpack, native-disabled Linux selftest, изменённый ZIP STOP — PASS.

## Последовательность, когда отдельное разрешение будет получено

1. Распаковать ZIP в **новый** `G:\ildar\Stage3D07\P10GP_2D_TOOLS_R2` (не поверх старого P10GO/P10GP).
2. Запустить двойным щелчком `01_P10GP_PREFLIGHT_NO_MESH.cmd`: проверяет исходные SHA, M0, Gmsh4.15.2 и две команды `-parse_and_exit`. Сообщение об успехе `P10GP_PREFLIGHT_PASS_NO_MESH`. Не строит сетки.
3. Только по **отдельному явному разрешению** запустить **ровно один раз** `02_P10GP_ONE_2D_PAIR_ONLY.cmd` в пределах 24 ч после preflight. Новые local/profile one-shot markers создаются до первого `-2`; при любом STOP не удалять и **не повторять** 02. Нет ввода пути или слов подтверждения.
4. Передать **один** `LOCAL_RUNS\P10GP_2D_PAIR_*\P10GP_2D_EVIDENCE.zip`; если архива нет — `P10GP_02_RESULT.txt` или текст окна. Архив включает небольшие .msh обоих вариантов, исходные GEO, логи, независимые диагностические JSON, но не EXE, FEM, истории или checkpoint.

Ресурсный потолок на один native `-2`: 120 с, Windows Job private RAM 2 GiB, `-nt 2`, msh≤12 МиБ, log≤4 МиБ; обновление `P10GP_HEARTBEAT` в окне каждые ~2 с. Два `-2` последовательно: максимум около 4–5 мин с накладными расходами. Если первый STOP — второй не вызывается. Предварительная `01` обычно до минуты, но native Windows время ещё не измерялось.

После 02 независимый анализ должен подтвердить: геометрию pore/B6, physical2–9, curved Tri6 Jacobian/area, полярные `q_corner`, фактические медианные длины рёбер **north/south/equator**, их отношения B/A, непрерывность характерного размера. Не приравнивать nominal h factor к измеренному размеру элементов. Провал/успех 2D не является автоматическим 3D GO. M1 STOP, FEM0. Действует frozen D-027 (global volume ratio 0.80–0.85, физические полярные макрообъёмы ≤0.98, положительный detJ 27/343/729QP, 18 signed зон диагностически).
