# P10EX R1 — одна новая M2 по точному проверенному C¹ StrCat-полю

**Назначение:** один защищённый native Gmsh -3 **только для построения сетки**.
Физических расчётов, forward, adjoint, H0 replay, изменения старой M1,
старых markers и каких-либо Git-операций на рабочем Windows ПК здесь нет.

Предыдущая история:

- P10EV безопасно остановился на GEO-парсере: исходная строка
  MathEval имела 4198 символов при лексическом пределе 1023.
- P10EW R1 заменил только запись этой формулы на семь буквальных
  частей в `StrCat`, математическое выражение восстановлено побайтно.
- Исследователь передал оригинальный `P10EW_EVIDENCE.zip` SHA-256
  `ca9a6dcd0127a6c7a3aeeef21e822b0674c58a2886c4671a9fe5d49351c79821`:
  **обе настоящие Windows Gmsh4.15.2 проверки -parse_and_exit прошли**.
  Новый Gmsh -3 не вызывался, разрешённая одна попытка остаётся неиспользованной.

## Два действия, строго по порядку

1. Скачайте ZIP `P10EX_R1_ONE_C1_STRCAT_M2_3D_WINDOWS_20261122.zip`,
   распакуйте в **новую отдельную папку**, ни в `G:\ildar\Stage3D07`,
   ни поверх P10EV/P10EW. Запустите
   **`01_P10EX_SAFE_PREFLIGHT_ONLY.cmd`**. Введите путь к неизменной
   `P10DG_M1_CANDIDATE.msh` SHA-256 `ca6b6b65...` или Enter для
   предложенного первоначального пути. Ожидается
   `P10EX_PREFLIGHT_PASS_NO_M2_NO_FEM`. При любом STOP **не запускать 02**,
   прислать новый `P10EX_EVIDENCE.zip` для проверки.
2. Только при **реальном PASS 01 не старше 24 ч** запустите **один раз**
   `02_P10EX_ONE_M2_3D_ONLY.cmd`. Перед запуском программа ещё раз
   независимо сверит SHA источников, M1, Gmsh EXE и оба GEO parser PASS.
   На вопрос подтверждения введите вручную **точно**
   `RUN ONE P10EX M2 3D MESH`. Эта строка разрешает одну попытку -3,
   непосредственно перед которой навсегда создаются новые
   P10EX локальный и profile one-shot markers. **Не удалять markers
   и не запускать 02 снова**, даже при timeout, crash или STOP.

Пределы native -3: `-nt 2`, wall ≤900 с (15 минут), опрашиваемая
private memory ≤8 ГиБ, raw MSH ≤750 МиБ, Gmsh log ≤16 МиБ,
дополнительный curved27QP geometry QA ≤300 с (5 минут).
Оценка на i7-7700K/64 ГБ при прежнем масштабе ~10k Tet10:
как правило несколько минут, **жёсткий лимит 15 минут на meshing**,
ещё до 5 минут на QA; величина памяти ориентировочно до 8 ГиБ
по программному ограничителю. Это ограничения, а не измерения P10EX.

Оригинальный `P10EN` curved27QP geometry QA и исходная принятая M1
проверяются; **устаревшие P10EA 9 зон с α=.20 не являются научным
объёмным тестом текущего C¹ поля**. Поэтому успешный 3D geometry QA
помечается `D025_PENDING`, а не научным GO.

## Что передать

**Один новый `P10EX_EVIDENCE.zip`** из `P10EX_R1_RUNS/P10EX_...`,
как при PASS, так и при STOP. При raw M2 ≤32 МиБ ZIP автоматически
содержит `RAW/P10EA_M2_CANDIDATE.msh`, SHA/manifest, native Gmsh log,
geometry QA и source pins. Не передавайте H0/forward/adjoint/cache.
Если M2 >32 МиБ, сообщите: большой raw понадобится отдельно только
для независимой геометрической проверки.

**После нового 3D:** независимая оценка в двух фиксированных 3D
полярных объёмах, криволинейные Tet10 343→729QP,
\(V_{\mathrm{eff}}(M2)/V_{\mathrm{eff}}(M1)\in[0.75,0.85]\)
**одновременно север/юг**, κ0 сохранение локальных размеров насколько
возможно, плавность; площадь Tri6 и азимутальная равномерность —
диагностика, не самостоятельные STOP. **Физический FEM только после
отдельного последующего разрешения исследователя.**

Во вложенном `P10EW_PINNED_PARENT` исторические P10EV/P10EW/EN/EA
источники и их старые 02 предназначены только для точных SHA-гейтов.
Никакие вложенные CMD не запускать. Сохранять все прежние ZIP/журналы
и one-shot markers.
