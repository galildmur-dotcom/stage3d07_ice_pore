# P10EW R1 — исправление длины строки Gmsh, только безопасная проверка

Статус: SOURCE-ONLY; реальный Windows Gmsh 4.15.2 ещё не проверял исправленный файл.
В новой версии имеется **только кнопка 01**. Команды построения M2, физических
расчётов и запуска Gmsh -3 в корневом P10EW нет.

## Причина предыдущего P10EV STOP

Оригинальная формула `P10EU` длиной 4198 символов была записана целиком в
один строковый литерал `Field[6].F`. Лексер Gmsh 4.15.2 (`Gmsh.l`,
`parsestring`) использует `char tmp[1024]` и требует строку не длиннее
1023 символов. Поэтому P10EV безопасно остановился на второй команде
`-parse_and_exit`: `Error : String too long`. Новый M2 не создавался,
одна разрешённая попытка Gmsh -3 не расходовалась, FEM=0.

P10EW исправляет **только способ записи формулы**:

- прежнее поле `Field[6] = MathEval` и весь текст 4198-символьного
  выражения сохранены побайтно;
- ровно 7 строк по 600/600/600/600/600/600/598 символов соединены
  штатной `StrCat(...)`, без вложенных MathEval-полей;
- аналитическое \(C^1\)-поле, \(\kappa=0\), север/юг, целевой интервал
  объёма [0.75,0.85], алгоритм 3D и исходный M1 не изменены;
- до реального Windows `-parse_and_exit` статус только
  **source-only гипотеза исправления**.

## Одно действие пользователя

1. Скачайте пакет `P10EW_R1_STRCAT_SAFE_PARSE_ONLY_WINDOWS_20261122.zip`
   и **распакуйте в новую директорию**, не в `G:\ildar\Stage3D07`.
   Не распаковывайте поверх P10EV.
2. Запустите **только** `01_P10EW_SAFE_PARSE_ONLY.cmd`.
3. По запросу подтвердите путь **прежней принятой** M1
   `P10DG_M1_CANDIDATE.msh` (SHA-256 начинается с `ca6b6b65`).
4. Программа проверит PIN/SHA, математические тесты, исходный M1,
   **ровно два** реальных `gmsh.exe -parse_and_exit` и
   M1-label, если парсер пройдёт.
5. При PASS или STOP передайте один новый `P10EW_EVIDENCE.zip`
   из `P10EW_R1_PARSE_RUNS/P10EW_...`.

Выполняется только проверка исходного GEO и старого M1. Новая 3D сетка и
физика **не запускаются**, проверка не расходует ни одну новую попытку -3.
Старые `P10EV_EVIDENCE.zip`, результаты и все historical markers сохранять.
**Не нажимайте старую кнопку P10EV 02 или любые 02 во вложенном
`P10EV_PINNED_PARENT`**: вложенные источники предназначены исключительно
для проверки SHA/подлинности.

После получения настоящих журналов P10EW отдельно решим, готовить ли
исправленный одноразовый mesh-only 02. Без подтверждённого PASS
строить M2 по P10EW нельзя; физику — тем более.
