# P10EK R1 — новая M2: одна Gmsh 3D mesh-only попытка с алгоритмом поверхности 5

**Разрешение исследователя:** «создадим сетку M2 и выполним физический расчёт».
В этом пакете реализован **только первый этап**: построение и 27QP-контроль
новой M2. Физический прямой/сопряжённый расчёт не запускается этой кнопкой
и будет подготовлен после независимой проверки нового оригинального M2
свидетельства. Пользовательское разрешение на научную программу не отменяет
геометрического GO/STOP барьера между сеткой и FEM.

## Научная постановка

Исходная принятая M1 — **только** original P10DG
`P10DG_M1_CANDIDATE.msh`, SHA256
`ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f`.
Сохранены CAD SHA `8029a6ed22bcf312701cd6abc46bbe5575e52df16fd5218dd936b01d5cd6fcf0`,
интеграционная B6, Tet10, 3D HXT10, гладкое `kappa∈[0,1]`,
`h_new=h_M1*(1-0.2*kappa)^(1/3)`. **Единственное изменение GEO**
против исторической неудачной P10EA M2: `Mesh.Algorithm = 5;`
перед прежним `Background Field=6;`. Candidate B SHA256
`2765018d8ddd2e83f28bd60af7c87b65172ac5da8389ede187d8bb9eea9d74c5`.
При `kappa=1` целевой характерный локальный объём уменьшается максимум
на 20%; при `kappa=0` стремимся сохранить прежний локальный размер.
Плавность обязательна, **равномерность размеров Tri6/Tet10 по φ не требуется**
(D-023/D-023A). Не добавлять второй коэффициент0.8 к поверхности!

## Две кнопки в отдельной папке

1. Распаковать **новый P10EK ZIP** в новую отдельную папку, не внутрь
   `G:\ildar\Stage3D07` и не в каталоги старых P10EA/P10EF запусков.
   Нужны Windows11, Python3, исходная M1 и Gmsh4.15.2 по пути
   `C:\gmsh-4.15.2-Windows64\gmsh.exe` SHA256
   `317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1`.
2. Нажать `01_P10EK_SAFE_PREFLIGHT_ONLY.cmd`. Программа проверит original
   M1 SHA, исходники, математическое поле17075 точек, криволинейную
   Tet10 27QP единичную/отрицательную QA, native GEO `-parse_and_exit` A/B.
   Никакого `gmsh -3`, FEM или one-shot marker в 01 нет. При STOP прислать
   лог и не переходить к 02.
3. После PASS01, в течение24ч, **один раз** нажать
   `02_P10EK_ONE_M2_3D_ONLY.cmd`. Ввести дословно латиницей:

   `RUN ONE P10EK M2 3D MESH`

4. Непосредственно перед native `gmsh -3` программа создаёт две **новые**
   эксклюзивные P10EK метки: `P10EK_R1_RUNS/P10EK_R1_ONE_3D_USED.json` и
   `%LOCALAPPDATA%/Stage3D07/P10EK_R1_ONE_3D_<M1_SHA>.json`. **После их
   создания даже ошибка/тайм-аут расходуют единственную попытку**.
   Никогда не удалять метки и не повторять02. Метки P10EA/P10EF
   остаются нетронутыми.
5. Дождаться Gmsh, геометрического QA и передать **один**
   `P10EK_EVIDENCE.zip` из последней папки `P10EK_R1_RUNS`.
   Внутренние имена протоколов `P10EA_*` сохранены от точно
   SHA-проверенного, ранее испытанного базового решателя; внешняя упаковка
   и две постоянные метки — только P10EK. В корне пакета есть лишь
   две новые запускаемые кнопки; исторические P10EA CMD скрыты внутри
   служебного каталога `P10EA_PINNED_PARENT`, **их не запускать**.
   Raw `P10EA_M2_CANDIDATE.msh`
   сохраняется **локально** в P10EK каталоге и не публикуется в GitHub.
   Если независимому аудиту будет нужен оригинальный raw, попрошу его
   отдельно, без повторного построения.

## Ресурсы и границы

- Gmsh native `-3`, 2 потока, wall≤900с, polled private≤8GiB,
  `.msh`≤750MiB, полный лог≤16MiB.
- 27QP geometry/9-zone QA wall≤300с, polled private≤8GiB; требуется
  свободно ≥16GiB RAM и ≥4GiB диска.
- На вашем i7-7700K предыдущая P10EA M2 `-3` занимала менее 1с;
  **новый алгоритм5 может отличаться**. Ожидаемо минуты, защитный
  максимальный интервал Gmsh+QA до20мин плюс preflight. Это оценка,
  а не обещание времени.
- **FEM=0** в этом пакете. Новой M2 невозможно безопасно присвоить
  исходный H0/M1 `forward_history.bin`: сначала требуется новая прямая
  история **на этой M2**, затем сопряжённая задача **на той же M2**.
  Только после подтверждённой геометрии подбираются конкретный Qt/CMake
  target, аргументы и отдельный ресурсный лимит физического запуска.

## Научный статус

P10EF R2 2D доказал возможность сгущения поверхности при alg5,
но **не доказал** качество последующей 3D сетки или сходимость производных.
Новый M2 считается лишь кандидатом до геометрического QA, физических
градиентов и сравнения серии M0/M1/M2. Отсутствие обязательной
азимутальной равномерности не отменяет smooth size field и проверку качества.
Физический расчёт при любом геометрическом STOP запрещён.
