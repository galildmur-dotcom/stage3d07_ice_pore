## Кнопка 01 — только источник и безопасный preflight

1. Распакуйте ZIP **отдельно**, вне `G:\ildar\Stage3D07` и прежних ZIP.
   Нужен Python 3 с стандартной библиотекой, Windows 11 и Gmsh 4.15.2.
2. Откройте `01_P10EA_SAFE_M1_F6_PREFLIGHT_ONLY.cmd`.
3. Укажите путь к исходной M1 или нажмите Enter для сохранённого пути.
4. Скрипт сверит source PIN23/23, оригинальные M1/GEO/CAD/EXE SHA,
   17 075 аналитических точек F6, синтетический Tet10+27QP QA,
   ресурсы (≥16GiB свободной RAM и ≥4GiB диска),
   два **`gmsh -parse_and_exit`** (F2 и F6), разметит κ всех
   9736 M1 Tet10. Это **не** `-1`, `-2`, `-3` и не FEM.
5. Получите `P10EA_RUNS\P10EA_...\P10EA_EVIDENCE.zip`. Присылайте
   только этот небольшой ZIP. При STOP ничего не повторяйте вслепую.
   Успешный preflight действует 24 часа для **новой** кнопки 02.

## Кнопка 02 — НЕ разрешена текущим решением о подготовке

Только после отдельного разрешения физически построить M2, успешной 01 и
уточнения ресурсных рисков один раз запустить
`02_P10EA_ONE_M2_3D_MESH_ONLY.cmd`, затем буквально ввести:

`RUN ONE P10EA M2 3D MESH`

При Enter или неверной фразе новый one-shot **не расходуется**.
При точной фразе программа повторяет SHA и preflight, затем
**непосредственно до единственного нативного Gmsh `-3`**
создаёт два эксклюзивных P10EA marker: локальный и в
`%LOCALAPPDATA%\Stage3D07`. Даже при timeout/ошибке/QA STOP
попытка израсходована. **Никогда не стирайте marker и не запускайте 02 повторно.**

Ожидаемая команда нативного этапа (путь GEO создаёт 01/02):

`C:\gmsh-4.15.2-Windows64\gmsh.exe "<новая папка>\GEO\B_EXACT_INLINE_F6.geo" -3 -nt 2 -format msh2 -o "<новая папка>\P10EA_M2_CANDIDATE.msh"`

Предельные ресурсы Gmsh: **900с** (15 мин), **8GiB private
по периодическим измерениям**, **750MiB MSH**, **16MiB журнала**,
**2 потока**. Проверка сетки отдельно ≤300с, ≤8GiB private
по измерениям и ≤4MiB собственного журнала. Реальное время 3D **неизвестно**:
0.425с успешного 1D не позволяет его предсказать. При превышении —
принудительный STOP; после STOP сохраняется локальный полный Gmsh log.
Измерение private дискретное и не является аппаратным лимитом памяти.

При успешном построении read-only QA проверяет M1/M2 полные 27 curved
QP/Tet10, знак Якобиана, CAD-объём и поверхность поры, физические теги,
качество, каждую κ и 9 зон 3 радиальных ×3 по |μ|. Сравниваются
**непарные** локальные медианные объёмы по угловым тетраэдрам и по
интегрированным искривлённым Tet10 (27 точек квадратуры), что лишь характеризует результат
и не доказывает точно 0–20% для каждого Tet10. Не принимать сетку для
физики автоматически: исследователь изучает 9 зон и корректность M2.

Выход — только `P10EA_EVIDENCE.zip`: точные GEO, full native Gmsh
log (если в лимите), manifest/result/stop trace, QA JSON и два CSV.
Многомегабайтный `.msh` и старые forward/cache не высылать и не удалять.
Здесь отсутствуют физические forward/adjoint/FEM; все такие опыты требуют
нового решения после независимой геометрической аттестации.
