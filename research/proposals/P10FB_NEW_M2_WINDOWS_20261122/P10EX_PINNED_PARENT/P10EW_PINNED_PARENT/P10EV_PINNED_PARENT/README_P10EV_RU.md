# P10EV — одна разрешённая новая 3D M2, только сетка, без физики

Исследователь 22.11.2026 разрешил **одну новую mesh-only попытку M2**
после выполнения P10EU source-only. Это отдельный пакет: старые
P10EA, P10EK, P10EN, их маркеры и исходные каталоги не затрагиваются.
Исходная M1 — только точная P10DG SHA ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f.

## Подготовка

1. Распаковать весь P10EV ZIP в **новую** папку, **не внутрь**
   G:\ildar\Stage3D07, и не совмещать со старыми ZIP.
2. Дважды нажать 01_P10EV_SAFE_PREFLIGHT_ONLY.cmd.
3. Когда программа спросит исходную M1, нажать Enter, если исходная
   P10DG_M1_CANDIDATE.msh находится по показанному пути; иначе вставить
   **полный путь к точной оригинальной M1**. Нельзя передавать H0/U0/M2.
4. Дождаться P10EV_PREFLIGHT_PASS_NO_NEW_M2_NO_FEM, exit0. Кнопка 01
   проверяет SHA, оригинальную M1, исходники и реальные Gmsh -parse_and_exit
   двух GEO, выполняет старые геометрические selftest, но НЕ строит M2
   и НЕ расходует новый one-shot маркер. Если STOP — не нажимать 02.

## Единственная разрешённая M2

5. В течение 24 часов после успешной 01 один раз нажать
   02_P10EV_ONE_M2_3D_ONLY.cmd.
6. Когда попросит подтверждение, ввести строго:

   RUN ONE P10EV M2 3D MESH

7. Программа заново проверит исходники и native parse2/2. Сразу
   перед **единственным** Gmsh -3 она навсегда создаст новый
   **отдельный** локальный и глобальный P10EV marker. Повторять 02
   запрещено даже при STOP; не удалять маркеры.
8. Максимумы: 900 секунд на Gmsh, 300 секунд на геометрическое QA,
   8 ГиБ памяти отдельного процесса, 750 МиБ MSH, 16 МиБ журнал.
   До запуска необходимо от 16 ГиБ свободной RAM и 4 ГиБ диска;
   два потока. Оценка по старым M2: порядка **1–5 минут** весь
   цикл на i7-7700K при благоприятном поведении нового MathEval,
   но **не гарантия**; принудительный предел 15+5 минут.
9. Готовый результат/STOP — один файл P10EV_EVIDENCE.zip в последней
   подпапке P10EV_R1_RUNS. В нём журналы, GEO, геометрический QA и
   оригинальная RAW M2, если её размер не превысил 32 МиБ.
   **Передать мне только P10EV_EVIDENCE.zip**, старые логи не перепечатывать.
   Если в evidence нет RAW M2 из-за размера, отдельно сообщить об этом.

## Научные ограничения

- Новый единый P10EU C¹ source field контролирует размер поровой Tri6
  и соседнего Tet10; parent GEO и все физические группы неизменны.
- Унаследованный P10EA геометрический 9-zone QA содержит **исторический**
  аналитический коэффициент alpha=.20; он **не соответствует** новому
  полю P10EU и **не** используется для решения D-025.
  Отдельный P10EV manifest отмечает этот факт явно.
- Даже если geometry QA PASS, это **не D-025 GO**. После отправки
  исходной M2 я независимо вычислю фиксированные физические
  полярные 3D шапки с 343→729 QP. Реальный характерный объём
  должен уменьшиться на **15–25%** на **каждом** полюсе отдельно;
  в зонах kappa=0 стремимся сохранить прежний размер. Не требуется
  равномерность по азимуту и глобальное ограничение роста Tet10 +25%.
  Поверхность Tri6 и соседние перепады размера используются для
  диагностики плавности.
- **FEM=0:** никакой прямой, сопряжённой, термической или механической
  задачи пакет не содержит. На принятый FEM M2 понадобится отдельное
  последующее согласование.
