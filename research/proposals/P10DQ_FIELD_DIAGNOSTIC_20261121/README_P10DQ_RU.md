# P10DQ R1 — локализация задержки Gmsh на 1D, без 3D/FEM

Исходная P10DO R1 израсходовала единственную попытку Gmsh -3: STOP после 900 с на двух кривых. Повтор P10DO запрещён. Здесь **новый отдельный** ограниченный опыт только Gmsh -1 без пересоздания M1/M2, правок старых файлов и FEM.

## Пять контрольных вариантов

Исходная OCC/CAD геометрия и nearSize=0.00042855883184652975 м / farSize=0.0070524788853066865 м неизменны.

1. A_BASE_M1_FIELD2: исходное Background Field=2.
2. B_F2_MATHEVAL_PROXY: Field[6].F="F2" — проверить обращение к F2 через MathEval.
3. C_F5_LINEAR_DIAGNOSTIC: Field[6].F="F2*(1-0.02*F5)" — малое диагностическое сгущение, **не** утверждённый закон M2.
4. D_F5_POWER_EXACT: Field[6].F="F2*(1-0.2*F5)^(1/3)" — тот же целевой объём 0–20%, без exp/log.
5. E_F5_ORIGINAL_LOGEXP: побайтный оригинал P10DO с F2*exp(log(1-0.2*F5)/3).

Программа прекращает последовательность при первом отказе. Успех 1D **не доказывает** возможности 3D, адекватности M2 или сходимости.

## Порядок Windows

1. Распакуйте P10DQ ZIP в **новую папку**, отдельно от P10DO/P10DG/P10DL и G:\ildar\Stage3D07. Старые сетки, cache, marker не изменять.
2. Выполните **01_P10DQ_PREFLIGHT_ONLY.cmd**. Проверяются SHA, шесть числовых точек κ, Gmsh 4.15.2 и пять GEO parse-only. Ни 1D, ни маркеров эта кнопка не создаёт. При STOP пришлите evidence, вторую кнопку не запускать.
3. После P10DQ_READ_ONLY_PREFLIGHT_OK выполните **02_P10DQ_ONE_1D_DIAGNOSTIC.cmd**. На отдельный запрос введите точно:

   RUN ONE P10DQ 1D DIAGNOSTIC

   До ручной фразы ни маркера, ни Gmsh -1. После фразы два новых однократных маркера только P10DQ. Старые P10DO/P10DG/P10DL маркеры не читаются и не изменяются. При любом STOP повтор второго запуска запрещён.

Используется Gmsh4.15.2 по пути C:\gmsh-4.15.2-Windows64\gmsh.exe, точная SHA-256 317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1. Если путь другой, допустима переменная P10DQ_GMSH_EXE, SHA должна совпасть. Исходная M1.msh не требуется.

**Лимиты:** каждому из пяти 1D вариантов — 25 секунд, 4 ГиБ private, 20 МиБ mesh, 2 МиБ log, 2 потока. Сумма Gmsh -1 ≤125 секунд, плюс preflight. Ориентир 1–4 минуты суммарно (прогноз, не измерено). Требуется ≥8 ГиБ свободной ОЗУ и ≥1 ГиБ диска; Qt/MinGW/FEM не нужны.

## Единственный файл для ответа

При PASS или STOP пришлите **P10DQ_EVIDENCE.zip** из новой P10DQ_RUNS\P10DQ_1D_* папки. Там manifest, статусы, точные GEO/SHA и хвосты логов. Большие MSH, forward_history.bin и старые ZIP не нужны.

**Научная граница:** причина задержки пока не доказана. Варианты позволяют различить простое поле2, ссылку F2, цепочку F5, степенную форму и exp/log. Исследователь принимает последующие выводы после оригинального Windows evidence. M2 3D и FEM остаются НЕ ВЫПОЛНЕНЫ; D-019/M1 неизменна.
