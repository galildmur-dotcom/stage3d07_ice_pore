# P10DD R2 — запуск с библиотеками MinGW, без перекомпиляции EXE

**Дата:** 21.11.2026. **Причина:** при запуске исходной кнопки из Проводника
Windows не смогла найти libgcc_s_seh-1.dll. Ранее обе программы успешно
работали в Qt Creator, чей PATH содержит каталог библиотек MinGW. Это
ошибка динамической загрузки, **не численный результат FEM**. В старой
кнопке --help/--selftest выполняются до записи одноразового marker;
если ошибка возникла на этом этапе, физическая попытка не начиналась.
Если marker уже есть, ничего не удалять и не повторять.

## Одна новая кнопка для уже собранной P10DD R2

1. Распаковать **этот небольшой архив** в отдельную новую папку,
   например G:\Downloads\P10DD_RUNTIME_GATE_R1_20261121, **рядом** с
   G:\Downloads\P10DD_R2_M0_H0_FULL4D_WINDOWS_20261121.
2. Дважды щёлкнуть **01_P10DD_START_WITH_MINGW_RUNTIME.cmd**.
3. Обёртка автоматически найдёт распакованную R2 (если имя или место
   другие, попросит полный путь к **папке R2**, не к EXE).
   Проверит неизменность трёх исходных файлов R2 по SHA-256,
   отсутствие прежнего одноразового marker.
4. Из уже созданного Qt Creator файла
   R2\build\Desktop_MinGW_Release\CMakeCache.txt считывается
   точный CMAKE_CXX_COMPILER. Проверяется, что CMake собрал
   именно эту R2, что в каталоге данного g++.exe есть
   libgcc_s_seh-1.dll и libstdc++-6.dll. Каталог добавляется
   к PATH **только для дочерних процессов**, не глобально.
5. После сообщения P10DD_RUNTIME_PREFLIGHT_OK physical_FEM=0
   автоматически запустится **неизменённый исходный R2**
   P10DD_one_click_h0.py. Он спросит путь к прежнему
   stage3d10dd_m0_h0_full4d.exe (показанный выше) и
   к **совместимому существующему H0** forward_history.bin.
   Использовать U0 cache нельзя. Если H0 cache отсутствует,
   Enter вызывает STOP без нового нелинейного прямого расчёта.
6. Для одной отдельно разрешённой H0 adjoint-only попытки
   после всех проверок вручную ввести RUN ONE H0 P10DD.
   Ограничения и выходы прежние: 900с wall/8GiB private/1GiB
   результатов, 4 потока, 6×150с физического времени,
   точная H0 SHA и один P10DD_EVIDENCE.zip.

Не скачиваются и не копируются никакие DLL, не меняются системные
переменные и рабочие научные исходники. Существующие R2 EXE,
G:\ildar\Stage3D07, H0/U0 и прежние LOCAL_RUNS не трогаются.

**Проверки подготовки:** CRC/хеши архива, Python selftest парсера
CMakeCache и отрицательного контроля отсутствующей DLL. Это не
Windows FEM. Реальную работоспособность новой кнопки устанавливает
сообщение исследователя; полноценный физический 4D audit — только
после P10DD_EVIDENCE.zip.
