# P10DL R1 — один ограниченный физический M1 forward + adjoint + полный signed 4D

Разрешение 21.11.2026: **подготовить** P10DL для одной физической попытки M1 с ограничениями. Архив, Linux-сборка и тесты не запускают настоящий FEM. Реальный FEM возможен **только у исследователя на Windows после отдельного осознанного запуска кнопки и ввода фразы**. Действующая M1 (D-019) уже построена однократно: Gmsh не запускать снова, не удалять marker, не заменять сетку.

## Порядок на Windows 11 / Qt Creator

1. Скачайте `P10DL_R1_M1_FRESH_FORWARD_ONE_SHOT_WINDOWS_20261121.zip` и распакуйте в **новую** папку, не поверх P10DK и не в `G:\ildar\Stage3D07`. Исходные H0/P10DD/P10DG и прежние расчёты не менять.
2. Откройте из новой папки `CMakeLists.txt` в Qt Creator с тем же MinGW Release (обычно build/Desktop_MinGW_Release). Соберите **обе** цели: `p10dl_4d_synthetic_unit` и `stage3d10dl_m1_full4d`. Название нового EXE принципиально отличается от source-only P10DK.
3. Для безопасной проверки выполните `p10dl_4d_synthetic_unit.exe`, затем `stage3d10dl_m1_full4d.exe --selftest`. Ожидаются `P10DD_4D_SYNTHETIC_UNIT_OK`, `P10I_PRODUCTION_ADJOINT_OK`, `P10W_DEPENDENCY_SELFTEST_OK`, `P10DD_FULL4D_BINS_SELFTEST_OK`, `P10DL_EXE_PHYSICAL_GUARD_SELFTEST_OK`. Синтетика — не физический расчёт M1.
4. **Когда будете готовы использовать разрешённую одну физическую попытку:** двойной щелчок `01_RUN_ONE_P10DL_M1.cmd` в корне новой папки. Встроенный Python повторно сверит SHA всех исходников, CMakeCache и g++.exe/DLL именно из Qt Creator, безопасность `--help`/`--selftest`, M1 SHA, наличие памяти и диска, отсутствие одноразового marker. Можно нажать Enter на запрос пути M1, только если она всё ещё в исходном P10DG каталоге; иначе введите путь **к оригинальному** `P10DG_M1_CANDIDATE.msh`.
5. Перед фактическим FEM программа покажет ограничения и предложит **ввести вручную** `RUN ONE P10DL M1`. Любой другой ответ — STOP без физического расчёта. После ввода фразы **два одноразовых marker** пишутся **до запуска EXE**: локальный `P10DL_OUTPUT/P10DL_ONE_SHOT_CONSUMED.json` и пользовательский `%LOCALAPPDATA%\Stage3D07\P10DL_M1_ca6b6b6588dc72c5_ONE_SHOT_CONSUMED.json`. Второй блокирует повторную попытку даже после распаковки ZIP в другую папку. Отсутствие ответа от компьютера или STOP **не является основанием повторять**; marker никогда не стирать ради перезапуска.
6. По окончании передайте **один маленький файл** `P10DL_EVIDENCE.zip` по пути, выведенному в консоли. При отсутствии ZIP пришлите последние сообщения STOP и `P10DL_SOLVER_STDOUT_STDERR.txt`; не присылайте большой `forward_history.bin`, `*.vtu` или всю M1.msh. Сохраните выходную историю, оригинальную сетку, журнал и marker.

## Физика и ограничения

- **Та же конкретная M1** для новой прямой истории и аналитической сопряжённой: M1 SHA256 `ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f` (точность по Windows P10DG manifest). 9736 Tet10 / 178 pore Tri6. Сетка H0 и любой `--reuse-forward` запрещены.
- `R / EDV_VAR / ξ=0 / jpeak / B6 cutoff 5mm`, полная signed mechanical+thermal `(r,θ,φ,t)` интеграция; 6 шагов по 150 секунд (**900 секунд модельного времени**, не продолжительность работы EXE). 27 мех и 64 тепл Gauss QP на Tet10, Robin на верхней границе; полный export 7206 строк.
- **Время работы процесса ≤1800с; PrivateUsage ≤8ГиБ; совокупный новый вывод ≤1ГиБ**, свободное место ≥4ГиБ, доступная физическая RAM ≥12ГиБ. Windows Job Object ограничивает память ядром и завершает процессное дерево при закрытии; Python дополнительно следит за временем/памятью/выводом. Предварительный прогноз 3–15мин и 1–4ГиБ не является измерением.
- Никаких `--preflight`: он в оригинальном solver не является чисто диагностическим. Один процесс без Gmsh, без повторной генерации M1 и без переписывания существующих cache.
- При native exit0 независимый Python M1 auditor проверяет знаковое замыкание QP/step/global к `P10W`, 9736 Tet10 и 7206 строк. Только `COMPLETED_M1_4D_VERIFIED` является физическим PASS. Любые другие статусы — STOP, данные сохранить без повторного запуска.

## Проверки исходной поставки

Локальный builder `P10DL_build_bundle.py` генерирует детерминированный ZIP, SHA-inventory и изолированные negative-тесты. `P10DL_one_click_m1.py --selftest` не запускает FEM/Gmsh и доступен на Linux. `P10DK_audit_evidence.py --selftest` отдельно проверяет 7206 synthetic rows и отклоняет H0 count/mesh label. Реальные Windows MinGW и настоящая физика M1 до получения Windows-логов/архива **не проверены**.
