# P10GV R1 — только одна физическая M1, подписанное 4D

**Это пакет для компьютера исследователя, а не выполненный расчёт.**

## Основание

- M0 SHA `926a9c903765ce77fd560300d10614d3cece3d4cd4d7813027e45e92d33870d6`: P10FS fresh R/EDV_VAR/ξ0, полный независимый signed 4D PASS. **M0 не пересчитывать.**
- Новая M1 P10GT HXT10 SHA `47460969be26c2bd0a15e0b1425806fa350aa09aa2b4ac9f80605b433fc65ca7`: P10GU D-027 geometry mesh-only GO; на ней **ещё нет физики**.
- Первая сопоставимая пара: R, EDV_VAR, ξ=0, B6=5мм, 6×150с, target t=900с. В новой M1 один fresh forward, сопряжённые на той же M1, без FD геометрии, signed 4D в физических `(d,mu,phi,t)` корзинах. Поля `j6,jpeak,jen` и компоненты explicit geometry, equilibrium, EDV history, thermal; 7200 объёмных строк + 6 верхних Robin с независимым замыканием к global.

## Установка и кнопки

1. Распаковать архив в **новую** папку `G:\ildar\Stage3D07\P10GV_TOOLS_R1`. Не распаковывать поверх P10FP/P10GT и не чистить `LOCAL_RUNS` или one-shot markers.
2. Утилита автоматически ищет исходный ZIP `P10GT_HXT10_EVIDENCE.zip` в `G:\ildar\Stage3D07\LOCAL_RUNS` и `P10GT_TOOLS_R1`. Если не найдёт, достаточно **скопировать его** рядом с кнопкой `01`; не переименовывать. Сеть не нужна.
3. Двойным щелчком `01_P10GV_PREFLIGHT_NO_FEM.cmd`: только CRC/SHA/D-027/source inventory/approval и сравнимость режима; **FEM0**, Gmsh0. Окно остаётся открытым. Должно быть `P10GV_PREFLIGHT_PASS_NO_FEM` и `P10GV_PREFLIGHT_EXIT=0`. При STOP прислать `P10GV_01_RESULT.txt`.
4. Затем один раз `02_P10GV_ONE_M1_FULL4D.cmd`. Программа сохранит из ZIP только **новую изолированную копию** `LOCAL_RUNS\P10GV_M1_HXT10_IMMUTABLE_STAGING\M1.msh` с закреплённым SHA; существующий `meshes\M1.msh` и старая история **не меняются**. Внутри используется ранее проверенный P10FN R4 solver, единичный marker перед native, компиляция MinGW с `-std=c++20 -O2 -fopenmp`, fresh forward + same-mesh analytical adjoint + 4D independent closure. На исходную P10GT/старые P10FN markers не влияет. При STOP **02 не повторять**.
5. Для ответа передать `P10GV_02_RESULT.txt` и **один** новый `LOCAL_RUNS\P10FN_PHYSICS_M1_R_*\P10FN_M1_R_PHYSICS_EVIDENCE.zip` (без тяжёлой `forward_history.bin`). На машине бинарная история сохранится с SHA.

Ожидаемое время при i7-7700K/64ГБ: ориентировочно 3–15 минут плюс компиляция; это оценка по прошлым M0, не обещание. Жёсткий wall cap **30 минут**, Job memory cap **8GiB private**, ограничение новых выходов **2GiB**, 4 потока. При нехватке ресурсов/ошибке — STOP, без автоповтора. Размеры сравнительно небольшие: M0 7992 и M1 9623 Tet10.

После evidence независимо проверить SHA, exit0, 7206 4D строк, физические границы всех 7200 `(d,mu,phi,t)` bins, signed components и полное замыкание глобальных производных. Провести разностный анализ M1−M0 по *всем четырём осям* и отдельно контроль временной неопределённости. Только после этого можно обсуждать `κ(x)` для M2; высокая амплитуда производной сама по себе не означает высокую ошибку.
