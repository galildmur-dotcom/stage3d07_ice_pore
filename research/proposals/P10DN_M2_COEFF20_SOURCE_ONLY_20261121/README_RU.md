# P10DN: коэффициент локального сгущения M2, не более −20% целевого объёма

**Текущий статус — только разработка и проверка функции коэффициента, НЕ генерация M2.** Исследователь установил правило: непрерывный коэффициент κ∈[0,1] по всему телу льда; в опасных точках κ=1 — уменьшение **целевого объёма** на20%, там, где дальнейшее сгущение не требуется, κ=0 — прежний **целевой размер M1**. Плавные переходы обязательны. Реальные Gmsh Tet10 будут новой дискретизацией: κ=0 не гарантирует сохранения того же конкретного тетра, κ=1 не гарантирует фактического отношения объёмов ровно0.8; это требуется проверять после генерации на отдельных локальных объёмных группах.

\[\frac{V_{\text{target,M2}}(x)}{V_{\text{target,M1}}(x)}=1-0.2\kappa(x),\qquad
\frac{h_{\text{target,M2}}(x)}{h_{\text{target,M1}}(x)}=(1-0.2\kappa(x))^{1/3}.\]

Для κ=1 множитель длины 0.928317766722556, для κ=0 — 1. **Никакого уменьшения объёма на20% в каждой области без учёта κ.**

## Почему в первой версии поле не зависит от φ

В P10DM 144 полярных/пристеночных/поздних 4D бина дали56.91% суммы модулей различий H0/M1; при независимом P10DN анализе **62.26%** этого различия приходятся на пары, где одна из двух сеток имеет менее10 мех QP. Азимутальные сектора показывают резкое чередование знака; пока нет оснований отражать это шумное, малонаселённое распределение в размерах M2 и вводить неоднозначную величину при θ→0,π. В дальнейшем φ-структура может быть добавлена по новым данным. Первая версия задаёт одинаковую приоритизацию по всем азимутам **при заданных r,θ**.

## Утверждаемый для рассмотрения профиль κ

- Отступ от стенки поры `d=√(x²+y²+(z−0.03)²)−0.001` м.
- `μ=(z−0.03)/√(x²+y²+(z−0.03)²)`; используется μ², чтобы функция была гладкой через оба полюса.
- Радиальная часть R(d)=1 при d≤0.1мм, плавно уменьшается до0 при d≥0.5мм.
- Угловая часть A(μ)=0 при |μ|≤0.6, плавно растёт до1 при |μ|≥0.8 (две крайние полярные полосы).
- κ=R(d)×A(μ), плавный кубический переход 3s²−2s³ с нулевой первой производной на обоих концах интервала (**C¹**). κ=1 у полюсов в первых0.1мм, κ=0 вне буфера или вне полярных углов.

Конкретные радиальные/угловые ширины буфера являются **предлагаемыми параметрами P10DN после физической пары**, не автоматически доказанным оптимумом, и подлежат обсуждению перед M2 Gmsh. В файле `P10DN_M2_FIELD20.geo` новая цель размеров Field[6] умножает **исходное M1 поле Field[2]** из прежнего `sphere_pore_B6_refined.geo`, CAD и группы не переписываются; отдельно Field[5] — κ. Исходный Gmsh 4.15.2 ещё не проверял этот GEO на Windows; никаких новых сеток сейчас не создано.

## Безопасная необязательная маркировка уже существующей M1 на Windows

1. Скачайте и распакуйте P10DN source-only ZIP в новую папку. Ничего не устанавливать сверх Python 3.
2. Двойной щелчок `01_P10DN_LABEL_M1_ONLY.cmd`.
3. На запрос пути к точной исходной `P10DG_M1_CANDIDATE.msh` **можно просто нажать Enter**, если сетка всё ещё в исходном каталоге P10DG; иначе ввести её полный путь. Это запрос пути, **не вводите никакую фразу запуска FEM**.
4. После независимого SHA256 exact M1 и MSH2/9736 Tet10 проверки скрипт присвоит коэффициент всем 9736 тетрам (κ в линейном центроиде4 угловых узлов, min/max по10 узлам), сохранит в новой папке `P10DN_OUTPUT` CSV + JSON. Это маркировка, не настоящая сетка M2, без изменения оригинала M1, маркеров, H0 cache и без Gmsh/FEM. При желании пришлите **только маленький JSON**, полный CSV не требуется.

Самопроверка на любом компьютере: `python P10DN_m2_coefficient.py --selftest` (нет физического запуска). Проверяются κ=0/1, промежуточные коэффициенты, Vratio0.8–1, hratio0.92831777–1, φ-инвариантность и C¹ переходы.

Следующий отдельный шаг после обсуждения поля — M2 mesh-only с Gmsh4.15.2, curved27QP и фактическим QA объёмов/геометрии, после него самостоятельное решение о физическом M2 fresh forward+adjoint signed4D. **Не запускать M2 из этого пакета, не повторять P10DL или P10DG.**
