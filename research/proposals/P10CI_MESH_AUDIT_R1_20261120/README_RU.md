# P10CI R1 — безопасная геометрическая диагностика сеток (без FEM)

**Назначение:** выяснить, могут ли качество и направленность Tet10, распределение элементов по полярному/азимутальному углам и пересечение ячеек `(d, μ)` быть причиной локализации межрасчётных различий около `±z`. Это только первый геометрический тест гипотезы, а не доказательство физической/численной причины.

## Научное уточнение P10CH

Индикатор P10CH содержит **ровно 200 ячеек в слое 0.02–0.10 мм от поверхности поры**: 20 радиальных корзин ×10 по `μ=cosθ`, `φ` в первичных данных уже интегрирован. Доли приполюсных абсолютных различий 87.01% / 87.80% / 94.45% относятся к этому локальному сравнению и не характеризуют весь B6 (до 5 мм). Этот аудит отдельно формирует 10 полярных строк для ранее **не представленного слоя 0–20 мкм**.

## Ограничения метода

- Вход: **только** три исходные `.msh`, точно сверяемые с опубликованными SHA-256, и ранее проверенный `P10CH_M1_OFFLINE_CANDIDATE_200CELLS.csv` (SHA-256 `84b738960d712ba11eca880a86f98782905dc6dcc6cd3c72c70e4c97c42406c3`).
- Gmsh v2 ASCII, элементы типа **11 Tet10**. Парсер читает узлы и элементы, считает геометрию **прямолинейных тетраэдров по четырём вершинам** и относительное смещение шести срединных узлов. Это **НЕ** проверка Jacobian `Tet10` на настоящих 27/64 QP: криволинейный элемент может быть невалидным даже при хорошем straight-corner proxy.
- Локализация элемента — по центроиду четырёх вершин, **НЕ** распределение QP по физическим корзинам. Отдельно считаются элементы, пересекающие полярные/радиальные границы (по четырём углам), и полярная неопределённость `φ` на оси.
- Качество прямого тетра: безразмерный mean-ratio `q=12(3V)^(2/3)/Σ l_edge²`, у регулярного `q=1`; `q<0.1` — только предварительный диагностический флаг, не принятая пользователем норма FEM качества.
- Для `φ` — 12 секторов по центроидам, занятость/неравномерность, угол, перекрываемый четырьмя вершинами, и `axis_unresolved`. Это геометрическое распределение **без** истинного поля производной по `φ`.
- Нет ни построения адаптивной `.msh`, ни решения теплопроводности/механики/сопряжённых уравнений, ни изменения исходных источников и Git.

## Одна кнопка

1. Распаковать ZIP в **новый отдельный каталог**, например в `Downloads\P10CI_MESH_AUDIT_R1_20261120`. Не распаковывать в `G:\ildar\Stage3D07` и не заменять старые инструменты.
2. Дважды щёлкнуть `01_RUN_P10CI_MESH_ONLY.cmd`. Нужен Python 3; внешние пакеты, NumPy, Tkinter, CMake, Gmsh и сборка FEM **не нужны**.
3. Подождать завершения и прочитать `RESULT`. Прогноз без измерения на i7‑7700K: **2–10 минут**, менее ~1.5 ГиБ оперативной памяти и менее ~5 МБ новых CSV/ZIP; **оценка, не жёсткая квота**. Если выполнение долго не отвечает (>15 минут) — остановить и прислать наблюдения, **не повторять** автоматически.
4. Появится **новая** папка `P10CI_RUNS\P10CI_<timestamp>_UTC_<id>` рядом с CMD. Она содержит результат, небольшие CSV и один `P10CI_EVIDENCE.zip`.
5. **Пришлите ровно один файл — `P10CI_EVIDENCE.zip`**, независимо от PASS/STOP. Не присылайте `.msh`, `build`, `LOCAL_RUNS`, `.exe`, большие результаты. Если Python не найден до старта программы, сообщите только напечатанный STOP (ZIP не будет создан).

`P10CI_200CELL_MESH_GEOMETRY.csv`: 600 строк (200 × 3) с качеством, длинами рёбер, `φ`-занятостью, radial/polar cross и смещением срединных узлов; `P10CI_0_TO_20UM_UNCOVERED_POLE_GEOMETRY.csv`: 30 строк (10×3) отдельно для ранее пропущенного слоя; `P10CI_GROUP_SUMMARY.csv`: 12 строк top40/other160/polar/middle; `P10CI_MESH_COUNTS.csv`: 3 строки; `P10CI_RESULT.txt` — SHA/статус.

**Успех:** `P10CI_MESH_ONLY_GEOMETRY_OK_NO_FEM` и mesh SHA PASS 3/3. **STOP:** другое имя, другие SHA, ошибка MSH2, несоответствие counts, незапускаемый Python и т.п. Любой результат не означает, что истинная ошибка уже объяснена, полная 4D производная вычислена или M1/пространственная сходимость доказаны.
