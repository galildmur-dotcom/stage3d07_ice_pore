**Пользователь отдельно одобрил одну новую сеточную HXT10 `-3` попытку после измеренного P10GJ D-027 STOP и реального P10GK native parse-only PASS. FEM НЕ разрешён.** Этот пакет содержит два однокнопочных Windows шага: сначала preflight (только parse-only), затем **ровно одна** `-3`, строго без физического расчёта и без повторов. На машине разработчика новые native Windows `-3` не проводились: это подготовленный релиз.

## Два щелчка, без ручного ввода

1. Распаковать ZIP целиком в новую папку `G:\ildar\Stage3D07\P10GL_TOOLS_R1`, НЕ поверх старых P10GJ/P10GK.
2. Двойным щелчком **`01_P10GL_PREFLIGHT_NO_MESH.cmd`**. Выполнит source SHA/ZIP CRC, независимую прежнюю M0 27QP геометрическую QA, перепроверит исходный P10GK C¹ field на 12 221 точках, сверит M0-frozen D-027, Gmsh4.15.2, выполнит только native wrapper **`-parse_and_exit`**, не построит даже 1D/2D/3D и не запустит FEM. Результат `P10GL_PREFLIGHT_PASS_NO_3D_D027_FROZEN`.
3. **Только при этом точном PASS**, не позднее 24 часов, двойным щелчком **`02_P10GL_ONE_HXT10_3D_ONLY.cmd`** **ОДИН РАЗ**. До Gmsh создаются два постоянных эксклюзивных marker-файла (в `LOCAL_RUNS/P10GL_LOCKS` и профиле Windows); при любом STOP повтор запрещён. Ни удалять маркеры, ни перезапускать 02 нельзя.
4. После 02 прислать **ОДИН** `G:\ildar\Stage3D07\LOCAL_RUNS\P10GL_M1_SOUTH_C1_HXT10_*\P10GL_M1_HXT10_EVIDENCE.zip` — **даже при STOP**. Если ZIP не создан, прислать `P10GL_02_RESULT.txt`. При STOP **никаких повторов**. При STOP 01 **02 не запускать**, прислать `P10GL_01_RESULT.txt`.

## Жёсткие технические границы и время

- Единственный `gmsh.exe ... -3 -nt 2 -format msh2`, нативная версия 4.15.2, максимум **900 с/15 мин**, Windows Job hard cap **≤8 GiB private bytes**, физически свободная RAM ≥12GiB, свободный диск ≥4GiB, output ≤2GiB, кандидат MSH ≤128 MiB; отдельный 27QP/Tri6/sliver/gradation audit может прибавить минуты.
- На пользовательском i7-7700K предыдущий P10GJ HXT10 `-3` занял ~0.5 с внешнего замера. Для локально усиленного P10GK размеры/время заранее не гарантированы; разумная оценка — **секунды или несколько минут**, с жёстким 15-минутным пределом именно Gmsh. Шаг 01 может занять несколько секунд или минут из-за повторной M0 27QP проверки.
- Все MSH, журнал Gmsh и SHA/QA только в новой `LOCAL_RUNS/P10GL_*` папке; historical canonical не перезаписываются; NumPy и Gmsh Python API на Windows не нужны.
- Даже статус `P10GL_NATIVE_27QP_PRELIM_PASS_343_729_PENDING_NO_FEM` **не равен приёмке M1**: независимый 343/729QP, макрозоны и решение D-027 обязательны; **FEM не запускать и не разрешать автоматически**.
