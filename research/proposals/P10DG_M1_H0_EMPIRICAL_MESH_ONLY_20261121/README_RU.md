# P10DG R1 — ОДНО построение новой M1 в Windows, без физических расчётов

**Эта редакция — новая попытка по отдельному согласованию исследователя.** Старая P10DE R1 уже отработала, ошибочно использовала размеры H3 и завершилась QA STOP. **Не повторяйте P10DE и не удаляйте её одноразовый маркер.**

## Научная цель

M0 — неизменная существующая **H0.msh**: 7388 Tet10, 136 поровых Tri6, SHA-256 `e28d6049afc4b20b474152d315952361b01dce7052f7642d03a20ce8274d41f8`. M1 требуется с типовым объёмом элемента примерно 80% от H0 при сохранённом исходном радиальном сгущении у поры. **Для M1 никаких физических/адаптивных индикаторов**: только эмпирический геометрический source-only кандидат P10DF.

Пробные параметры: `nearSize=0.428558832 мм`, `farSize=7.052478885 мм`, те же CAD/B6/9 групп/Tet10/threshold distances 1.5–18 мм. Это **не известные аутентичные H0 настройки и не уже проверенная M1**; геометрический QA должен показать, попали ли мы в цель. Ориентир для числа элементов при идеальном масштабе — ≈9235 Tet10, но это **не результат Gmsh**.

## Перед запуском

1. Скачать **`P10DG_R1_M1_EMPIRICAL_H0_MESH_ONLY_WINDOWS_20261121.zip`** по ссылке из GitHub и сверить SHA-256, опубликованный в отдельном научном отчёте P10DG. Архив распаковать **в новую отдельную папку**, например `G:\Downloads\P10DG_R1_M1_EMPIRICAL_H0_MESH_ONLY_WINDOWS_20261121`. Не помещать содержимое в `G:\ildar\Stage3D07` и не распаковывать поверх P10DE.
2. На ПК должны быть `G:\ildar\Stage3D07\meshes\H0.msh` и `C:\gmsh-4.15.2-Windows64\gmsh.exe`. Если фактические пути другие, пакет допускает заранее заданные переменные окружения `P10DG_H0_MSH` и `P10DG_GMSH_EXE`. При другой H0 SHA и другой версии Gmsh выполнение **STOP**, не переименовывайте U0 в H0.
3. Дважды щёлкнуть **`01_RUN_P10DG_M1_MESH_ONLY.cmd`**. Это Python3 stdlib+Gmsh4.15.2, не Qt Creator. До подтверждения проверяются 12/12 SHA источников, H0 SHA, native Gmsh version/exit, свободные ≥16ГиБ RAM/≥4ГиБ диска, независимые 27QP/QC synthetic+negative тесты.
4. Только увидев `P10DG PREFLIGHT PASS`, вручную ввести **`RUN ONE P10DG M1 MESH`** и нажать Enter. Любой иной ввод = STOP, без нового Gmsh. Непосредственно **до** Gmsh записывается новый маркер `P10DG_RUNS\P10DG_ONE_SHOT_USED.json`. При любом STOP после этого маркер **не удалять и кнопку не повторять**: сначала анализ результата.
5. Найти `P10DG_RUNS\P10DG_M1_...\P10DG_EVIDENCE.zip` в новой папке, загрузить мне **только этот небольшой ZIP** независимо от успеха или STOP. Полный `P10DG_M1_CANDIDATE.msh` и полный лог остаются у вас, не включаются в ZIP. Исходный H0.msh, P10DE marker, forward_history.bin, рабочие G: исходники и прежние данные остаются неизменны.

**После этого не запускать физический FEM M1 автоматически.** Он будет рассматриваться лишь после независимой проверки ZIP и отдельного разрешения.

## Ограничения и ориентир времени

| Операция | Оценка | Жёсткая программная граница |
| --- | --- | --- |
| Один Gmsh 3D Tet10 (2 потока) | по опыту P10DE native Gmsh на 102 тыс. Tet10 занял 3.009 с; для P10DG предположительно секунды–десятки секунд, **не гарантия** | 900 с wall, 8 ГиБ опрошенной private, 750 МиБ файла .msh, 30 МиБ лога |
| Сравнение H0 и M1 по 27QP/Tet10 | ориентир 10–60 с на ожидаемой более грубой M1, **не измерение** | 300 с |
| Новые физические задачи | **0** | никакого исполняемого FEM в архиве |

Memory guard опрашивает private bytes процесса Gmsh, это **не аппаратный предел**. Если Gmsh выйдет не с кодом 0, QA вернёт STOP, либо выйдет за лимит — сохраняется только evidence и старый результат не подменяется. Программа не запускает повторные попытки и не корректирует размеры автоматически.

## Фактическая геометрическая приёмка

- Для обеих сеток полная проверка ASCII MSH2.2, имен/тегов физ. групп 1–9, H0 SHA+7388 Tet10/136 pore Tri6 и новой сферической поровой поверхности.
- Все 27 искривлённых QP **каждого** Tet10, detJ sampled positive, corner orientation, качество, целостность объёма против CAD. Положительность только в проверенных точках **не** гарантирует её во всех точках элемента.
- Отношение **непарных** глобальных медиан объёма M1/H0 в широком коридоре **0.65–0.95** (цель 0.8), число Tet10 M1 должно быть больше H0.
- Кроме глобальной медианы — 7 радиальных полос ×10 угловых μ ячеек. Для полос с ≥100 H0 Tet10 проверяется отношение **взвешенных медиан биновых медиан объёма** в интервале **0.55–1.15**; при систематическом несоответствии STOP. Зоны с малым H0 N, в частности 0–20мкм (1 Tet10), только описываются, не используются как достоверный объемный критерий.
- Физические производные, механические/тепловые QP, polar error и spatial convergence **здесь не вычисляются**. После отказа нельзя «подгонять» и повторять Gmsh без нового решения.

В ZIP доказательств: `P10DG_RESULT.txt`, `P10DG_RUN_MANIFEST.json`, геометрический JSON, 2 маленьких radial CSV, короткий вывод Python QA, хвост Gmsh лога или STOP traceback. Большие бинарники и .msh не требуются.
