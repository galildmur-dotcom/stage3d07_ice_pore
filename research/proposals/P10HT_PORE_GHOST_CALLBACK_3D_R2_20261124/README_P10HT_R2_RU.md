# P10HT R2 — исправление запросов Gmsh внутри полости

На реальном P10HS R1 Gmsh успешно построил 3D (около 0.959 с, 14071 узлов; 10924 тетраэдра до преобразования в Tet10). Однако программа остановилась после построения: Gmsh девять раз запрашивал размер в точках **внутри воздушной полости**. Из-за запрета не был сохранён `.msh`. **Это не означает, что в полости есть узлы или элементы: такие проверки выполняются отдельно.**

В P10HT R2 для **служебных запросов размера за пределами ледяной области** использовано радиальное продолжение значения κ с ближайшей точки поверхности поры, при той же угловой координате. Эта операция применяется только к несуществующему в физической задаче материалу полости, не меняет κ в льду, физические расчёты M0/M1, CAD или исходный `Field[7]`. В итоговом JSON отдельно сохраняются число таких запросов, максимальная глубина и координаты первых 30. При запросе точно в центре поры возвращается базовый `lc` без присвоения κ.

Далее выполняется **жёсткая проверка всех узлов полученной 3D-сетки**: внутри полости не допускается ни одного. Требуются только Tet10. Кандидат сохраняется в `P10HT_M2_CANDIDATE_UNVERIFIED.msh` и автоматически упаковывается вместе с журналом и JSON в один `P10HT_M2_UNVERIFIED_CANDIDATE_EVIDENCE.zip`.

Запуск: распаковать архив в отдельную папку, двойной щелчок `01_P10HT_R2_ONE_3D_GHOST_GUARDED.cmd`. **Одна 3D-попытка, максимум 600 секунд, максимум 4 млн запросов**, сообщения каждые 15 секунд. Никакого FEM, повторов или признания кандидата утверждённой M2. Ожидаемое время на i7‑7700K **1–10 минут**, с учётом возможных накладных расходов и отдельной установки Gmsh Python API.

При PASS вернуть **только** `P10HT_M2_UNVERIFIED_CANDIDATE_EVIDENCE.zip`; при STOP — `P10HT_GUARD_RESULT.json`, `P10HT_GMSH_LOG.txt`, `P10HT_WORKER_ERROR.txt` (если есть). После получения проверим фактическое 3D-сгущение в ледяных областях по криволинейному Tet10 с 343/729 точками квадратуры и D-025. Пользователь допускает небольшую локальную перемену размеров и перераспределение, но требование научной проверяемости и плавности не снимается.
