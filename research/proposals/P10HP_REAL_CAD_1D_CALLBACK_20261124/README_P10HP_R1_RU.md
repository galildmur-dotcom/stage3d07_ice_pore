# P10HP — одна ограниченная проверка на реальном CAD, только 1D

Исходный P10HN успешно проверен Gmsh на компьютере пользователя: 6140 вызовов; истинное `lc/Field[7]=1` без погрешности; 13 узлов, 14 элементов, 2.8864 с. Это допускает отдельную осторожную попытку на оригинальной геометрии.

Пакет включает закреплённые CAD и `Field[7]` (P10GT); геометрия состоит из внешнего ледяного объёма и области B6, а также сферы-полости. Не меняет оригинальные файлы, не строит 2D/3D, не создаёт M2, не выполняет FEM. **Ровно одна попытка `gmsh.model.mesh.generate(1)`** на настоящих CAD-кривых. Никаких автоматических повторов и продолжений.

1. Распаковать ZIP в отдельную папку.
2. Дважды нажать `01_P10HP_REAL_CAD_ONE_1D_GUARDED.cmd`.
3. Отправить `P10HP_GUARD_RESULT.json` и `P10HP_GMSH_LOG.txt`; если появился — дополнительно `P10HP_RESULT.json`, либо `P10HP_WORKER_ERROR.txt`. При проблеме Python API — `P10HP_INSTALL_LOG.txt`.

Пределы: внешний 120-секундный тайм-аут убивает дочерний процесс, 300 000 запросов κ (свыше этого возвращается исходный `lc`, результат считается STOP). Запись `.msh` и FEM отсутствует. Поле κ имеет строгую физическую проверку `r >= R_pore`: при запросе внутри полости — STOP и журнал, не автоматическая подмена поля.

Ожидаемая продолжительность на i7‑7700K: **примерно 5–120 секунд**, предел 120 с без учёта первой установки Gmsh Python wheel в локальное окружение (возможны дополнительные 1–5 минут). Значительное время возможно при большом числе нативных запросов. **Получение PASS не разрешает M2**: следующий этап — проверка поверхностного адаптивного размера, плавности и D-025 на кандидатной 3D-сетке в отдельном протоколе.
