# P10CX R2 — восстановление проверки версии и один 2D-тест поверхности

R1 завершился до генерации сетки: `STOP_REASON=STOP: Gmsh -version native exit ` (пустое значение). Исходные SHA3/3 прошли, Gmsh EXE SHA256 `317c43391e5b1fab3a1dd80dc5245dad6e2d087910f4b8ebc234bd6d4b8f41a1`. Причина отсутствующего кода ещё **не доказана**. R2 не повторяет R1 и использует новый запуск .NET `Process` с явным `WaitForExit`/`ExitCode`, записывает `P10CX_R2_VERSION_STDOUT.txt` и `P10CX_R2_VERSION_STDERR.txt` даже при version-STOP.

## Действия исследователя

1. Скачать R2 ZIP, распаковать **в новую папку**, отдельно от R1 и `G:\ildar\Stage3D07`, например `C:\P10CX_R2`.
2. Один раз дважды щёлкнуть `01_RUN_P10CX_R2_SURFACE_ONLY.cmd`. Кнопку R1 **не повторять**.
3. Передать ассистенту только **`P10CX_R2_EVIDENCE.zip`** из `P10CX_R2_RUNS\P10CX_R2_<дата>` или текст STOP, если архив не создан. Большую `.msh` не передавать.

## Лимиты и статус

Только Gmsh4.15.2 `-2`, 2 потока, Tri6 на всей стенке. Время не более **180 c**, private memory не более **2ГиБ**, MSH не более **150МиБ**; свободная память4ГиБ, место1ГиБ. Оценка i7-7700K: **5–90 секунд**, низкая уверенность; ограничитель3мин. Источники GEO/base/audit SHA pinned, EXE строго той же SHA как в R1, Python3 только stdlib.

Результат при успешно построенной поверхности: поровый Tri6-count, 10 μ ×12 φ, плохие элементы, худший q/местоположение. Если q<0.1, статус STOP_SURFACE_POLE_SLIVER, **новый 3D/FEM не разрешён**. Пакет никогда не вызывает Qt/CMake/FEM или Gmsh `-3`.
