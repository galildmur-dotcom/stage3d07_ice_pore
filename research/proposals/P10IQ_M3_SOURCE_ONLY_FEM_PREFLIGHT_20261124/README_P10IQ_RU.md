# P10IQ — проверка готовности M3 к первому FEM, без запуска FEM

Распаковать ZIP в отдельную папку Windows на диске G:. Дважды нажать только
`01_P10IQ_M3_PREFLIGHT_NO_FEM.cmd`. Дождаться `P10IQ_SOURCE_ONLY_PASS_NO_FEM`
и `P10IQ_PREFLIGHT_EXIT=0` либо сообщения STOP.

Вернуть **один маленький файл** `P10IQ_M3_PREFLIGHT_RESULT.json`.
Если STOP произошёл до создания файла — прислать текст окна. Повтор этой
проверки допустим: она не создаёт FEM, сеток или one-shot markers.

В ZIP находятся неизменённые исходники прежнего M2 solver и точная M3 сетка,
SHA256 `3d6ce765dced7d146ef5228be3b0a8210b4466ed08a0c9f5a20d1917dc2a8c3a`.
Встроенный Python проверяет 90+ исходных файлов по исходным SHA, M3 SHA,
10,063 Tet10, 262 Tri6 поры, теги физических поверхностей 2..9,
знаки криволинейного Jacobian в 27 точках на элемент и совместимость интерфейса
решателя. Независимая 729QP/D031/D029 проверка уже выполнена на P10IP.

Параметры будущего **отдельно утверждаемого** FEM: R / EDV_VAR / ξ0,
B6 5 мм, 900 с, 36 шагов по 25 с, 4 потока. Прямая и сопряжённая задачи
на одной M3. Перед первым физическим запуском потребуется отдельный
one-shot guard, предел RAM/времени и прогресс в окне каждые 30 с.

**Нельзя запускать старые скрипты M2 из архива.** Физический M3 запуск этим
пакетом намеренно не предусмотрен.
