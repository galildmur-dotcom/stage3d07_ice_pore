# P10HB — решение: механический индикатор как основной для адаптации M2

**24.11.2026. Решение исследователя:** «так как тепловой вклад в погрешность гораздо меньше механического, то в таком случае можно его не учитывать при адаптации сетки».

## Численное основание на действующих реальных M0/M1

Для текущего режима `R, EDV_VAR, ξ=0, B6=5 мм, t_f=900 с`, при `Δt=25 с`, независимый P10GZ вычислил L1 **подписанных пространственных межсеточных разностей, суммированных по времени**:

| Вклад | L1, м⁻¹ |
|---|---:|
| Механический (explicit + equilibrium + EDV history) | **5.131050922** |
| Тепловой (mass + diffusion + Robin) | **0.018330036** |
| Тепловой / механический | **0.00357237 = 0.3572%** |

Из 1200 пространственных bins только **5** имеют `|ΔG_thermal|>|ΔG_mechanical|` при signed-суммировании внутри каждой группы. Их доля в общей механической L1-массе — всего **0.001245%**. Они не должны молча исчезнуть из QA; отдельно отметить при дальнейшем анализе геометрии и квадратуры.

Оговорка терминологии: `M1−M0` здесь является **наблюдаемой межсеточной разностью**, а не доказанной апостериорной оценкой истинной ошибки; малая явная тепловая составляющая адъюнтной формулы не означает, что можно выключить теплопроводность/температурное поле **в физической задаче**. Тепловая история продолжает влиять на механические решения через связку; полный transient forward+adjoint остаётся неизменным.

## Замороженное на данном этапе правило P10HB

1. Для **первого прототипа M1→M2** основным источником κ становится механический вариант P10HA: отдельные `explicit geometry`, `equilibrium`, `EDV history` signed межсеточные компоненты, после полного суммирования 4D вкладов по времени. **Тепловые компоненты не участвуют в score/ранжировании/κ и Dörfler**.
2. Во избежание скрытого знакового сокращения эти три компоненты нормируются на собственные L1-массы и объединяются по среднему абсолютному score. При временной проверке `dt36↔25` отдельные компоненты сохраняются; C² smoothing продолжает работу с радиальной и трёхмерной угловой геометрией.
3. Тепловые слагаемые, полный 4D архив, signed замыкание, все QP и QA не удалять. Внешняя проверка M2 должна продолжать **обе** сопряжённые физические задачи. Если для других функционалов, деформаций формы, GH3 узлов или режимов тепловая межсеточная разность возрастёт, решение о её исключении из κ пересматривается.
4. Выход `P10HA_SPATIAL_KAPPA_1200_BINS.csv`: поле **`kappa25_primary_for_M2_source_only`** теперь явно ссылается на механический candidate; пятикомпонентные поля сохранены только для контрольно-сравнительной чувствительности. Запрещено объявлять этот CSV непрерывным размерным полем Gmsh и запускать M2 автоматически.
5. Следующий этап — непрерывная CAD-привязка механического κ(x) с независимой проверкой обоих полюсов, азимутальных секторов, двух bins без полной QP support; затем source/mesh-only контроль D-025 локального `Veff(M2)/Veff(M1)∈[0.75,0.85]` при κ=1. Физика M2 только после отдельно положительного геометрического GO.

**Проверка:** реальный P10GY 12× native остаётся нетронут, новый FEM=0 и Gmsh=0. Синтетические проверки κ/Dörfler/периодического φ выполнены. Изменение касается только научного выбора основного источника адаптивного поля, не PDE и не прежних физических данных.
