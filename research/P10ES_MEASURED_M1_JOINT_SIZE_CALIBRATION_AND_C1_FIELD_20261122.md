# P10ES — калибровка размерного поля по исходной M1 и гладкая ограниченная поправка

**22.11.2026.** `SOURCE_ONLY_CALIBRATION_PASS / INVERSE_GMSH_NOT_IDENTIFIED / NEW_M2_NOT_AUTHORIZED / FEM=0`.
Это следующий самостоятельный шаг после P10ER, **без новых Gmsh -2/-3,
без прямой/сопряжённой задачи и без расходования Windows one-shot markers**.

## 1. Научный вопрос и источники

Проблема P10ER: исходная приполярная M1 содержит только ~12–13
эффективных Tet10 в слое 0–100 мкм; P10EK/P10EN почти полностью
перестраивают поровую Tri6 и не реагируют на глобальный α
монотонно. Требовалось обоснованно построить из **фактической M1**
плавную локальную модель `h_M1,cal` и установить, достаточно ли
предсказательна эта модель для следующей Gmsh-попытки.

Проверены оригинальный приватный `P10DG_M1_CANDIDATE.msh` SHA-256
`ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f`,
9736 Tet10/178 pore Tri6; первичный `P10EN_EVIDENCE.zip` SHA-256
`4cccb95b22ea2575452a2b7b684c8e311a8d9628272775a8a633d3297b70b4bc`
CRC17/17 с оригинальными M1 `Field[2]` GEO SHA
`c6ec88a3fe91db0f3c369391a91aefbd1bc83f1d3033b38a985c3033c605ddd8`
и общей CAD GEO SHA
`8029a6ed22bcf312701cd6abc46bbe5575e52df16fd5218dd936b01d5cd6fcf0`.
В исходниках подтверждены `nearSize=0.42855883184653 мм`,
`farSize=7.05247888530669 мм`, переход **1.5–18 мм** и отключённые
дополнительные размерные источники Gmsh.

Все результаты получены с `scripts/p10es_m1_measured_smooth_sizing_calibration.py`:
прямой curved Tet10 27QP, геометрические угловые рёбра Tet10 и Tri6,
проекция центроидов поровых Tri6 на точную сферу, независимые
геометрические измерения. Только малые JSON/CSV в
`research/evidence/P10ES_M1_MEASURED_FIELD_20261122/derived/`;
исходные `.msh`, оригинальный ZIP и пути Windows в Git **не входят**.

## 2. Три разные длины исходной сетки нельзя отождествлять

В приполярном слое `d=0..100 мкм` (`|mu|>=0.8`), миллиметры:

| Измерение на фактической M1 | Север | Юг | Что измеряется |
|---|---:|---:|---|
| Медиана **6 угловых рёбер Tet10** | **0.46529** | **0.43811** | Линейные хорды углового тетраэдра |
| Эквивалентное ребро по **27QP объёму** | **0.42197** | **0.38586** | `(6√2 V_T)^(1/3)`, точно для *правильного* тетраэдра |
| Медиана **3 угловых рёбер порового Tri6** | **0.39018** | **0.38972** | Хорды на поверхности поры |
| Исходная цель `Field[2].SizeMin` | **0.42856** | **0.42856** | Предписанный размер, не фактическая длина |

Следовательно, частное `V_T^(1/3)` нельзя объявлять длиной
ребра, а равный по полюсам размер поверхностных Tri6 **не
означает** одинаковой геометрии соседних Tet10. Калибровка
одним множителем к исходному `Field[2]` по произвольно выбранной
медиане дала бы смещённый результат.

Для сопоставления трёх **наблюдательных операторов** использована
κ=0 экваториальная область той же M1 у поры:

| Показатель, исходный κ=0 | Число наблюдений | Медиана `h_proxy/h_Field2` |
|---|---:|---:|
| Угловые рёбра Tet10 | 67 | **1.0404343** |
| Правильный тетраэдр по криволинейному объёму | 67 | **0.9945529** |
| Рёбра поровых Tri6 | 103 | **0.9338592** |

Эти коэффициенты **только нормализуют различные определения размера**;
они не являются неизвестными параметрами физической модели и
не требуют выравнивания элементов по φ.

## 3. Восстановление гладкого полярного профиля — пробная ограниченная инверсия

Пусть `d=|x-c|-R`, `mu=(z-c_z)/|x-c|`, `S(t)=u²(3−2u)`,
`u=clamp(t,0,1)`, и κ — прежнее независимое C¹ пространственное
поле, равное1 в двух полярных шапках и0 вне зоны необходимости
сгущения. Введены C¹ локальные веса:

\[
\begin{aligned}
&w_N=S((\mu-0.6)/0.2),\quad w_S=S((-\mu-0.6)/0.2),\\
&w_C=S((\mu-0.8)/0.1),\\
&\beta(\mathbf{x})=\kappa(\mathbf{x})
 [b_Nw_N+b_Sw_S+b_Cw_Nw_C],\\
&h_{M1,\mathrm{cal}}(\mathbf{x})=h_{F2,C^1}(d)\,e^{\beta(\mathbf{x})}.
\end{aligned}
\]

Отдельные исходные наблюдения трёх типов предварительно делятся
на их измеренные в κ=0 коэффициенты из таблицы выше. По данным
**206 Tet10** (два коррелированных прокси на каждом) и **62 Tri6**
с κ>0.04 выполнена регуляризованная линейная подгонка трёх
логарифмических коэффициентов с L² штрафом. Диагностика:

| Показатель логарифмических невязок | Значение |
|---|---:|
| Среднеквадратичная невязка исходного нормализованного `Field[2]` | **0.22420** |
| Невязка подогнанной трёхпараметрической модели | **0.20473** |
| Невязка после обязательного ограничения `|β|<=0.018` | **0.22054** |
| Сырые `b_N / b_S / b_C` | **+0.171265 / +0.119826 / −0.029572** |
| Диапазон максимального `|β|` перед ограничением | **0.171265** |
| Коэффициент общего безопасного сжатия параметров | **0.105100** |
| Ограниченные `b_N / b_S / b_C` | **+0.018000 / +0.012594 / −0.003108** |

**Важный отрицательный результат калибровки:** прямое применение
неограниченного `β≈0.17` изменило бы требуемую длину порядка18.7%,
а номинальный объём порядка67% — несоразмерно допустимому
адаптивному шагу. Поэтому **сырые fit-коэффициенты не допускаются
в поле новой сетки**. Пробный C¹ профиль использует
`|β(x)|<=0.018` (измеренные коэффициенты уменьшены примерно в9.5 раза),
но это **ограниченная диагностическая модель**, не доказанное
восстановление того поля, которое при повторном Gmsh воспроизвело бы M1.
Снижение ошибки для **разрешённой ограниченной** модели составляет лишь
`0.22420→0.22054`; лучший результат0.20473 достигнут только при
неприемлемой для такого шага исходной величине поправки.
Предел `0.018` выбран внутри безопасной симметричной номинальной
полосы `0.80*exp(±3*0.018)≈[0.758,0.844]`, **не как
доказательство фактической D-025 адаптации**.

Кросс-проверка с исключением каждой из четырёх четвертей φ показала
улучшение предсказания для трёх четвертей, но **не** для четвёртой:
ошибка четвёртой `0.19956→0.20278`. Следовательно, даже модель
исходных размеров M1 **не идентифицирована с высокой точностью**;
её нельзя объявлять пригодной для реальной M2 без независимого
испытания. Четверти здесь средство проверки переноса модели,
**не требование** азимутальной равномерности сетки.

## 4. C¹ переход базового размерного поля и сохранение κ=0

Исторический Gmsh `Threshold Field[2]` линейно интерполирует h
на `d=1.5..18 мм` с постоянными участками до/после. На границах
перехода **сам Field[2] имеет излом производной**, т.е. непрерывен,
но строго **не является C¹**. Простое умножение на гладкую κ
излома не устраняет. Для математически C¹ прототипа поле
`h_{F2,C¹}` сохраняет исходный линейный участок **везде кроме**
двух коротких интервалов `d=a±ε`, `d=b±ε`, `ε=0.05мм`:

\[
\begin{aligned}
&m=(h_\mathrm{far}-h_\mathrm{near})/(b-a),\\
&h(a-\varepsilon+2\varepsilon u)
 =h_\mathrm{near}+m\varepsilon u^2,\\
&h(b-\varepsilon+2\varepsilon u)
 =h_\mathrm{far}-m\varepsilon(1-u)^2,\quad 0\le u\le1.
\end{aligned}
\]

На обоих концах каждого интервала значения и первые производные
совпадают с плато/линейным участком: это простая C¹ сшивка Эрмита.
Сетка пробных точек в 3D и односторонние разности производных
в четырёх узлах сшивки прошли проверки. На κ=0 сам **поправочный
множитель e^β=1 точно**; только C¹ сглаживание старого Field2
создаёт локальный сдвиг размера **не более1.171%** в двух кольцевых
полосах при `1.5` и `18мм`. Вне этих полос исходный размер там,
где κ=0, сохраняется **точно**. Это только заданное поле,
не прогноз фактического объёма нового Tet10.

## 5. Контроль номинального размера и соседней плавности

Для исследовательской, **не выпускаемой в виде исполняемого GEO**
формулы с номинальным `α=0.20`:

\[
h^{\mathrm{trial}}_{M2}(\mathbf{x})=
h_{M1,\mathrm{cal}}(\mathbf{x})
(1-0.20\kappa(\mathbf{x}))^{1/3}.
\]

- В полной зоне `κ=1` отношение **заданных** объёмов
  `[(h_trial/h_M1,cal)^3]` точно **0.800000**. При сравнении с
  историческим *формальным* `Field[2]` вместо реконструкции M1
  диапазон `(h_trial/h_Field2)^3` получился **0.83080–0.84439**.
  Это внутри формальной полосы D-025, **но не фактически
  измеренный** объём ещё не построенной M2.
- В κ=0 при исходной M1 медианное изменение заданного размера
  **0%**, максимальное **1.171%** только из-за C¹ округления
  изломов старого Field2.
- На тех же смежных приполярных парах M1 (393 пары) 95-й процентиль
  отношения **предписанного** размера `h_trial` равен **1.03584**,
  а у реально существующих элементов M1 по `V_T^(1/3)` ранее
  измерено **1.316**. Это разные показатели. **Плавное поле
  не гарантирует гладкое фактическое разбиение**: данный опыт
  сам по себе не устраняет дискретный remeshing на поверхности.

В Gmsh4.15.2 пока **не выполнялся даже `-parse_and_exit`** для нового
поля. Предусмотренного D-025 GO и физического FEM нет. Все числа
подтверждены только независимой Python-квадратурой и проверками
аналитических функций на исходной M1.

## 6. Вывод для следующего исследования

**Доказано:** исходные измеренные размеры Tri6, угловые рёбра Tet10
и эквивалентный объём имеют различные шкалы; замена F2 на
один эмпирический множитель неправомерна. Исторический F2 требует
C¹ сшивки, если гладкость h понимается строго. Ограниченная
северно-южная локальная модель C¹ по источнику существует и
сохраняет размер при κ=0 с погрешностью исходного излома ≤1.171%
лишь в узких радиальных полосах.

**Не доказано:** что регрессия с остаточной лог-ошибкой≈0.205
является достоверным обратным генератором Gmsh M1; что
ограниченная пробная `α=.20` даст после реального ремешинга
северный/южный D-025 допуск; что достаточно одного локального
веса без контроля surface Tri6. Поэтому **не выпускать новую
one-shot M2 кнопку и не начинать физику**.

**Следующий минимальный источник-only этап:** сформировать
*топологически контролируемый* размерный протокол —
отдельная проверка реконструкции размеров M1 у поровой поверхности
и в первом объёмном слое, назначение плавных полярных весов без
требования равномерности φ, предрегистрация целей по
`N_eff` север/юг и по фактическим соседним скачкам; исходный
`κ=0` сохранить. Только после этого предложить **один** новый
mesh-only Gmsh с отдельной санкцией исследователя и независимым
сырьевым 27→729QP D-025 контролем. Прямая и сопряжённая FEM
только на одной и той же **принятой** M2, без старых cache.
