# P10GR R1 — комплексный подбор параметров поверхностной адаптации: SOURCE/UNIT

Дата 23.11.2026. Научная цель: по сравнительной серии заранее зарегистрированных вариантов определить компромисс между локальным сгущением у южного полюса, качеством криволинейных Tri6, соседней градацией и стоимостью сетки. Это этап разработки **алгоритма адаптивного построения сетки**, не FEM и не проверка производных формы.

## Основание

P10GQ независимо проверил два реальных P10GP MSH (исходный ZIP SHA `875497809d59b08920aeb951cb690a7272b31722b1daedd2a824dd61c8f36cf2`): при alpha=.06 south median edge ratio B/A=.945181; pore qmin 0.590078→0.499980; maximum neighbor size jump all pore1.788608→2.010587. Поэтому нельзя автоматически принять alpha=.06: требуется серия с контролем неблагоприятных хвостов качества/соседства.

## Дизайн и фиксированные условия

**20 кандидатов = 2 алгоритма × [1 baseline + 3 амплитуды × 3 ширины углового перехода].** Алгоритмы `Mesh.Algorithm=5` (Delaunay) и `6` (Frontal-Delaunay), alpha∈{0.03,0.06,0.09}, plateau physical south mu≤−0.8 и mu_end∈{−0.7,−0.5,−0.2}. Радиальная P10GK C¹ зона d≤0.5мм с затуханием до 1мм фиксирована; изменение только радиальной ширины бессмысленно для самой стенки поры при d=0. Точно закреплены original rotated OCC CAD/B6, физические теги, самодостаточный полный F3-inline MathEval без вложенных ссылок, factor0.9378887276834518, order2 и прочие прежние опции. Ни один исторический P10GP run не повторять; новый baseline нужен каждому из двух алгоритмов для честных парных сравнений.

Для каждого кандидата сохраняются журналы Gmsh, MSH2 Tri6, SHA, время, число элементов, физические группы/площадь/Jacobian/радиус, qmin/q05/median, north/south/equator median actual edge sizes, p95/max межэлементных переходов в физически северной и южной области. Выгружается объединённый `P10GR_COMPARISON.csv` с отношениями к baseline **того же алгоритма** и диагностическим screening. Критерий screening: south ratio≤0.98, leakage по north/equator≤3%, qmin≥0.45, neighbor max≤2.2. Это предварительная научная фильтрация, **не** D-027 и не автоматический выбор оптимальной M1; после измерений анализировать компромисс/Парето без подгонки критериев.
