# P10ME→P10MF — единственный дефектный Tet10 и M11 R2 локальная C2-коррекция

Дата 2026-11-25. Пользователь загрузил
`P10ME_M11_R1_BAD_TET10_LOCATIONS.json`, точная M11 R1 SHA256
`244249fcc62d0b26877164dae1cc6a6528edd1d1e5973edad4dc79aad7872dab`.

## Паспортизация локального дефекта

Из **15 191 Tet10** пороги D031 нарушает **ровно один** элемент
`tag=17197`, и именно на нём одновременно
`minSICN=0.186243894736 <0.20` и
`minSJ=0.391751163216 <0.40`. Для всей M11
`gamma>=0.25195`, `minDetJac>2.63e−13 m³`.

Центроид проблемного элемента (метры):
`[6.6736773608749115e−6, 8.410310311933411e−4, 3.073658511697876e−2]`;
расстояние от стенки поры **0.118005 mm**, cos(theta)=**0.658839**,
не полярная шапка (`|mu|<0.8`). Проблема локализована, но сама по
себе не доказывает, что соседние элементы не изменятся при ремешировании.

## Новая независимая M11 R2 Gmsh попытка

Предложена малая дополнительная **C2-коррекция размера**, наложенная
поверх полностью неизменённой M1–M11 адаптивной функции:

`h_R2(x)=h_R1(x)*exp(-0.045*w(x))`, где `w=1` для
`distance(x,x_bad) <= 0.02 mm`, `w=0` при `distance>=0.30 mm`,
а между границами — `1-smoothstep5(t)`.
Следовательно максимальное локальное снижение характерного размера
`1-exp(-0.045)≈4.4%`, с нулевой добавочной коррекцией за пределами
0.30 mm. Это заранее заданная эмпирическая локальная попытка, **не
гарантированный способ** поднять minSICN/minSJ; требуется повторная
независимая D029/D031 после построения.

Защита P10MF R2: новый локальный и профильный one-shot marker,
отдельный код и отдельный evidence ZIP; исходная M11 R1 и её
израсходованный маркер сохраняются. Паспорта M11 R1 и P10ME
жёстко сверяются по SHA. Один запуск Gmsh 3D Tet10, 10 CAD seeds,
без физического FEM и автоматического повтора.

Архив:
`P10MF_M11_R2_LOCAL_C2_REPAIR_MESH_ONLY_WINDOWS_FINAL_20261125.zip`.
01 preflight/65-секундный Windows native watchdog — без маркера;
02 отдельный единственный mesh-only Gmsh, лимит 1200 s / 8 GiB.
Ожидаемый расчёт 1–5 минут, пользователю вернуть один
`P10MF_R2_M11_UNVERIFIED_EVIDENCE.zip`.

Локальная проверка: 42/42 SHA PIN, 3 GEO Includes, Python AST,
`P10MF_R2_PREFLIGHT_PASS_NO_GMSH_NO_FEM`, ZIP CRC PASS.
До D029/D031 на R2 никакого M11 FEM.

Возможный альтернативный метод в Gmsh — встроенные оптимизаторы
`HighOrder`, `HighOrderElastic`, однако в данном контролируемом
опыте они не включаются: корректируется только размерный C2 callback,
чтобы сохранить воспроизводимость исходного алгоритма адаптации.
