Источник — зафиксированный ранее P10DO R1 ZIP SHA256 `6c6f4f574e6a8c436d8319e059e5d1341c8ecbeda5ba38fbc2587c03abb15535`, его состав не изменён.

Исходная принятая **M1 D-019**:

- SHA256 `ca6b6b6588dc72c5dd3ed2e92e24794560ee2407e350c8a44858e9c3c7d0360f` **по пользовательскому Windows manifest**;

## 2. Независимая проверка P10DP

Новый `scripts/p10dp_verify_p10do_preflight.py` по **оригинальным байтам ZIP** проверил SHA256/CRC, соответствие исходному source ZIP, статусы, точную SHA/basename принятой M1, структурные counts, все три категории κ, формулу целевых Vratio0.8–1 и hratio, версию/native exit Gmsh parse и синтетические 27QP/κ selftests. Все **6** преднамеренно испорченных вариантов (сумма label counts, SHA M1, статус, скрытый native mesh-run, parse-exit и target-size) получили STOP. Получен машинный JSON `research/evidence/P10DP_P10DO_READONLY_M1_GEO_20261121/derived/P10DP_PREFLIGHT_AUDIT.json` с `P10DP_WINDOWS_M1_LABEL_AND_GEO_PARSE_VERIFIED`.

Отдельно проверен контрольный поток кода P10DO: в режиме `--preflight-only` `launch()` не вызывается и новый one-shot marker **не создаётся программой**. Однако **реальное состояние файлов marker в `%LOCALAPPDATA%` исследователя непосредственно не наблюдалось**, утверждение относится к опубликованному pinned source. Отсутствие поля `native_Gmsh_argv`, native mesh exit/M2 SHA и результатов M2 QA в оригинальном manifest подтверждает, что представлено свидетельство именно **первой кнопки**, а не второго запуска.

## 3. Следующий разрешаемый этап

Предусловия для **одной** попытки новой M2 mesh-only подтверждены по Windows источнику: точная оригинальная M1, проверенная формула, native Gmsh4.15.2 parse exit0 и ample resources. Можно предложить исследователю отдельно вручную запустить `02_P10DO_ONE_M2_MESH_ONLY.cmd` из **той же распакованной папки**, подтвердить исходный путь M1 и затем точно `RUN ONE P10DO M2 MESH`. Скрипт перед native Gmsh ставит **два новых marker** и ограничивает Gmsh 900с wall/8GiB private/750MiB mesh/30MiB log (две нити), отдельную full27QP геометрическую QA 300с. Оценка суммарно **1–5мин**, фактическая не измерена. Один STOP/исходный `P10DO_EVIDENCE.zip` — повод остановиться и анализировать, **никаких повторов/удаления marker** без нового решения. Большие `.msh` и `forward_history.bin` присылать не нужно.

**Итог:** первая Windows подготовка физически завершена, полная κ-разметка M1 и native GEO parse PASS. **M2.msh=0; M2 physical FEM=0; 27QP M2 и фактическое локальное сгущение ещё не измерены**. Следующее научное суждение — независимый анализ полученной M2 до любого нового механико-теплового расчёта.
