# P10GG R1 — защищённая проверка двух параметризаций OCC-сферы, только Gmsh 2D

**Дата:** 23.11.2026. **Статус:** исходники, автономные проверки и Windows ZIP
подготовлены; **реального Windows Gmsh 4.15.2 `-2` пока не было**, 3D=0,
FEM=0, новой принятой M1 нет. Не смешивать исходниковый PASS с native PASS.

## Единственный новый научный вопрос

На реальной Gmsh 4.15.2 исследователя, при **одинаковом полном поле
размеров**, повышает ли смена CAD-параметризации сферической поры
качество физической поверхности около полюсов (Tri6)?

Предпосылка: P10GE (изолированная Gmsh 4.13.1) наблюдала рост
`min q_corner` от 0.2304 до 0.6380 при повороте параметрической оси
на 90°, но реальный 3D HXT `PASS18` при этом ухудшился 9/18→7/18.
Следовательно, **2D эффект повторно измеряется на пользовательской 4.15.2,
а не выдаётся за успешную новую 3D M1**.

## Двухкнопочный Windows контракт

1. `01_P10GG_PREFLIGHT_ONLY.cmd`: исходные source/SHA/каноническая M0,
   Windows 11, `gmsh.exe -version` (4.15.2), SHA фактического EXE;
   два `-parse_and_exit` по исходному и повернутому `.geo`. **Ни 1D,
   ни 2D/3D сетка не создаётся.** Сохраняется датированный proof не
   старше 24 часов и предварительный evidence ZIP.
2. `02_P10GG_ONE_2D_PAIR_ONLY.cmd`: при действительном proof и
   отсутствии двух новых exclusive markers атомарно расходует оба
   **до первого** Gmsh `-2`. После этого исполняет по одному `-2`
   исходной и повернутой геометрии; `-save_all` не используется, чтобы
   не потерять физические группы в MSH2. Никакого `-3`/FEM,
   `meshes` и `approvals` не изменяются, исторические markers не удаляются.
   Любой STOP расходует one-shot — **повтор запрещён**.
3. Каждый native `-2`: `-nt 2`, ≤120 с, Windows Job hard private ≤2 GiB,
   исходная `.msh` ≤12 MiB, журнал ≤4 MiB; оба вывода в новом
   `LOCAL_RUNS/P10GG_CAD_POLES_*`. Python3 (stdlib), Gmsh Python API
   пока не требуется. Windows-защиту невозможно установить → STOP.
4. Отдельный MSH2-аудит читает **исходные** Tri6: все surface physical
   groups2–9, обе physical полярные шапки `|μ|≥0.8`, максимальную
   погрешность радиуса узлов поры/B6 ≤1e−8 м, отсутствие вырожденных
   `q_corner≤0.001`, 3-point curved surface Jacobian>0, приблизительную
   площадь поры в [0.90,1.10]×4πR² (лишь грубый геометрический guard).
   Записывать `q_corner min/p05/median`, полярные min, координаты худшего,
   `N Tri6`, качество криволинейной поверхности и все SHA/время/память.
   **Число Tri6 и qcorner не являются критериями 3D FEM GO**.
