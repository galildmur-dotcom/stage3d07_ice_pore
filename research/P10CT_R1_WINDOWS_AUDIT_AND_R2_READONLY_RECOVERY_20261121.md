Она не подтверждена без чтения реальной `.msh`; другие исключения возможны. **Первичная U0 не проходит приёмку для физического FEM** до независимого анализа.

## 2. Новый P10CT R2 — восстановление без повторного mesher (подготовлено, Windows pending)

Подготовлен пакет `P10CT_R2_READONLY_U0_QA_WINDOWS_20261121.zip`, **26 539 байт**, SHA256 `200565c7ddcc7cafa109ac5230050533f34b9a8c925e3f8bda320bbc637ac28a`, CRC **6/6**, Python tests 3/3 PASS. Он **не вызывает Gmsh/CMake/Qt/FEM**, не меняет исходный `.msh`; всё пишет только в собственную свежую папку. Вход допускается исключительно по **точному** original `.msh` SHA256/размеру, путь берётся из оригинального Gmsh stdout; другие файлы не подставляются.

В отличие от R1, Python subprocess сохраняет **полные stdout/stderr и traceback**, независимо от exitcode. Обновлённый QA:

1. Не объявляет ошибкой само по себе положение straight-corner centroid внутри сферической полости; учитывает это отдельной **пятой диагностической зоной** (поэтому **5×10×12=600** углово-радиальных геометрических ячеек вместо прежних 480).
2. Проверяет **все 27 QP каждого Tet10** и сохраняет количество nonpositive-QP samples, число проблемных Tet10, разбиение по зоне и до 30 худших Gmsh element ID с `(d,μ,φ)`, hmax, corner quality, detJ. Всё ещё sampled-QP, не строгая гарантия detJ>0 на непрерывном элементе.
3. Сохраняет именно фактические размеры и качества для обоих полюсов, экватора, слоя возле поры, B6 и объёма вне B6; не подменяет графиком signed-механического/теплового поля, которого на новой U0 ещё нет.
4. Завершённое отрицательное геометрическое заключение (например, найдено detJ≤0) помечает **QA_COMPLETE / GEOMETRY_REJECTED**, а не смешивает с техническим STOP. При аварии всё равно упаковывает полный traceback.

В окружении ассистента R2 прошёл `py_compile`, синтетический P10CK/P10CP/P10CT_R2 selftest **3/3** (в том числе отрицательная физическая метка B6), smoke-test STOP отсутствующего источника и CRC ZIP. **На исходной реальной Windows U0 R2 пока не запускался**. Ограничение времени subprocess 600с, без физического FEM. D-012/D-017/D-018 без изменений, однократный физический H1 P10CD закрыт.
