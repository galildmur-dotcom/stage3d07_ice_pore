# P10EN — разрешённая новая M2 после пересмотра допуска D-025

**22.11.2026. Статус: `P10EN_SOURCE_ONLY_BUNDLE_OK_NO_NATIVE_GMSH_NO_FEM`.**
Исследователь прямо разрешил следующую M2 и изменил обязательный
региональный допуск фактического уменьшения характерного объёма в
приоритетных `kappa=1` областях: **15–25% вместо строгого максимума20%**.
При `kappa=0` размер желательно сохранить. Плавность поля обязательна,
секторная/азимутальная равномерность элементов не требуется.

## 1. Исходное научное свидетельство и выбор коэффициента

В оригинальном P10EM с `alpha=.20` новая P10EK M2 SHA
`f7183efdaff22b0ed7c281104ee00e18499c0d53f087100e08959a7d4a43250b`
дала 729-QP региональные M2/M1 в той же физической полярной 3D области:
север `0.724231` (−27.58%), юг `0.803180` (−19.68%), оба полюса
`0.763502` (−23.65%). И при новом допуске **север нарушает 25%**,
поэтому M2 P10EK — геометрически PASS, но D-025 STOP, FEM=0.

Данное пользователем разрешение первоначально следовало за предложением
`alpha=.10`, но **новая нижняя граница15% его делает неудачным начальным
ориентиром**. Для P10EN использован пробный `alpha=.17` в
единственном поле размеров:

\[
h_{\rm target}(x)=h_{M1}(x)(1-0.17\kappa(x))^{1/3},\quad
v_{\rm target}/v_{M1}=1-0.17\kappa(x).
\]

При `kappa=1` целевое `v`=0.83, `h`=0.9397796375,
поверхностная площадь при том же h ориентировочно `A`=0.8831857671.
**Не** добавлять самостоятельный множитель на поверхность поры.
Грубая одноточечная секущая к эксперименту `.20` даёт ориентир
северный −23.44%, южный−16.73%, оба−20.10%. Эти числа — **прогноз,
не доказанный отклик Gmsh**; разброс из-за ремешинга может оказаться
существенным. Значение `alpha` выбиралось ДО следующего опыта.

## 3. Защищённый Windows запуск по отдельному разрешению исследователя

В новую папку распаковать ZIP, открыть
`01_P10EN_SAFE_PREFLIGHT_ONLY.cmd`, получить source/M1/EXE/math/nat.
parse **PASS** (нет `gmsh -3` и FEM). В течение24ч **ровно один раз**
открыть `02_P10EN_ONE_M2_3D_ONLY.cmd`, дословное подтверждение
**`RUN ONE P10EN M2 3D MESH`**. Новые эксклюзивные local/profile метки
P10EN создаются до Gmsh `-3`; расходуются даже при fail/timeout.
P10EA/P10EF/P10EK historical markers не трогать. Защита native
900с/8GiB private polled/750MiB MSH/16MiB log/2 потока;
QA300с/8GiB, до старта свободно RAM≥16GiB и disk≥4GiB.
Оценка для i7-7700K: десятки секунд — несколько минут,
жёсткий лимит примерно20мин вместе с QA; P10EK был 0.61с native и
10.45с QA, но новая топология может отличаться.

Новый evidence ZIP **включает приватную original raw M2** при её размере
до32MiB (в P10EK было ~1.7MiB). Исследователь присылает **один**

в GitHub. Если M2 превышает32MiB, понадобится отдельно raw.

## 4. Условие дальнейшей физики — не автоматический GO

После Windows PASS независимый Tet10 curved27QP и 3³/5³/7³/9³
фиксированный QP-анализ сравнивает `Veff(M2)/Veff(M1)` на *обоих*
полюсах, **отдельно севере и юге**, в тех же физических зонах
`kappa=1`. Требование: **0.75≤ratio≤0.85** на устойчивом тонком
пространственном показателе; при сильной чувствительности
квадратурного индикатора — дополнительное QP исследование до GO.
Новые свойства κ=0 контролировать диагностически без самостоятельной
равномерности или лимита общего числа КЭ.

Только после положительного geometry/adaptivity GO — **отдельный**
ресурсно защищённый свежий M2 forward и затем adjoint на **той же**
M2 с `ANALYTIC_TET10`, signed mechanical+thermal `(r,theta,phi,t)`;
никакого использования H0/M1 forward-cache. Отрицательный GO — STOP,
не считать опыт физической проверкой сходимости.
