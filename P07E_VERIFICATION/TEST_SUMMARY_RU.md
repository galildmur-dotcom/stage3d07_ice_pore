# Stage 3D-07E — протокол проверки

- C++20 GCC 14.2, Release, конфигурация с OpenMP: CMake + цели `stage3d07e_smooth`, `stage3d07d_shells`, `stage3d07_inventory` собраны; 8 из 8 CTest прошли.
- C++20 GCC 14.2, Release, конфигурация без OpenMP: те же цели и те же 8 из 8 CTest прошли.
- Производственный решатель не модифицирован, изменена только исходная единица `src/stage3d07d_shells.cpp` с макроразделением нового функционала и стандартный `CMakeLists.txt`.
- Изолированная H0 с синтетическим аффинным перемещением: среднее первое главное напряжение по любой ненулевой весовой зоне воспроизведено с относительной погрешностью менее 1e-9; аналитический сферический объём и доля полярного конуса подтверждены независимыми Python-формулами.
- Выходные P07D_STATUS.csv, P07D_SHELLS.csv и P07D_COMPARISON.csv сравниваются байт-в-байт между P07D и P07E в отдельном тесте.
- Проверка полного переноса пользовательских EDV checkpoint H2/H3/H4 возможна только на ПК пользователя, потому что их бинарные файлы не включены в доступный пакет проекта.
- Все таблицы MANUFACTURED_H0_* являются синтетической проверкой метода интегрирования, **не результатами научной кампании H2–H4**.
