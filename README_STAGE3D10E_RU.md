# Stage 3D-10E — BCSR-решатель и сопряжённая система во времени

Дата: 04.11.2026. Предусловие: пройдены P10B, P10C и P10D на Windows/MinGW.

## Новое в сравнении со Stage 3D-10D

1. Для формирования касательной матрицы применяется **действующая структура BCSR** (блоки $3\times3$, Tet10) с локальной сборкой по существующим алгоритмическим касательным E/ED/EDV.
2. Граф BCSR строится один раз на геометрию и повторно используется для всех шагов Ньютона и обратного сопряжённого прохода.
3. Матрица транспонирования вычисляется как $K^\mathsf{T}v$ **без предположения численной симметрии**. Специальный обратный граф обеспечивает параллельную сборку результата без гонок OpenMP; оставлен независимый последовательный контрольный вариант.
4. Добавлен итерационный решатель BiCGStab с имеющимся блочным предобусловливателем Якоби ($3\times3$). Применяется отдельно к $K$ и $K^\mathsf{T}$, всегда проверяет невязку прямым умножением.
5. Повторены 12-шаговые проверки полной истории для шести сочетаний E/ED/EDV × CONST/VAR. Отдельно выполнен тест на **намеренно несимметричной** BCSR-матрице и тест графа на 2110 узлах (с OpenMP при его наличии).

## Содержимое архива

- `src/stage3d10e_bcsr_adjoint.hpp` — новый модуль разреженной сборки, транспонированного SpMV, обратного графа и BiCGStab.
- `tests/stage3d10d_transient_adjoint.cpp` — **обновлённый файл теста Stage10D**, содержащий дополнительную условную ветвь Stage10E. При обычной сборке Stage10D используется прежний плотный метод; для Stage10E — BCSR. Следовательно, новый файл устанавливается вместо старого теста, но не затрагивает промышленный `src/spatial_reology.cpp`.
- `PATCH_CMAKE_Stage3D10E.txt` — блок CMake для добавления **один раз**.
- `STAGE3D10E_SCIENTIFIC_NOTE_RU.md` — подробная научная записка.

## Установка на вашем Windows-компьютере

1. Убедитесь, что прежний Stage10D выполнен. Закройте его в Qt Creator.
2. Скопируйте новый `src/stage3d10e_bcsr_adjoint.hpp` в папку `src` текущего проекта.
3. Замените только тест `tests/stage3d10d_transient_adjoint.cpp` одноимённым обновлённым из пакета. Если вы самостоятельно редактировали тест, предварительно сохраните вашу версию.
4. Допишите содержимое `PATCH_CMAKE_Stage3D10E.txt` в конец *имеющегося* `CMakeLists.txt`. Не заменяйте весь CMakeLists.txt.
5. В Qt Creator обновите CMake. Выберите **Desktop MinGW Release** и соберите цель `stage3d10e_bcsr_transient_adjoint`.
6. Запустите `stage3d10e_bcsr_transient_adjoint`.

| Параметр | Значение |
|---|---|
| Конфигурация | Desktop MinGW Release |
| Цель | `stage3d10e_bcsr_transient_adjoint` |
| Аргументы | ПУСТО |
| Рабочий каталог | Стандартный каталог сборки Qt Creator |
| OpenMP | При наличии используется до 4 потоков |
| Оценка времени компиляции на i7-7700K | 20–120 секунд |
| Оценка времени теста на i7-7700K | 1–20 секунд |
| Большие сетки, CSV, VTU | Не требуются |

Для завершения достаточно передать **одну заключительную строку** `P10E_BCSR_TRANSIENT_ADJOINT_OK ...`. При ошибке — скопировать текст ошибки и несколько строк перед ней. Ничего архивировать из `runs` не нужно.

## Важные ограничения

Stage10E — переходный **тестовый модуль**, работающий на исходных классах BCSR и Tet10, но не полный пересмотр главного `spatial_reology.cpp`. Пока не проведён крупносеточный сравнительный замер производительности BiCGStab с MC-SGS/IC0; нынешний простой блок-Якоби не следует автоматически назначать для HP4/HP8. Тестовый функционал является диагностическим, геометрические частные производные — центральными разностями, температурная задача — заданной узловой историей. На данном этапе не создан непрерывный поверхностный градиент формы.

Следующий этап после успешной проверки под MinGW: подключение физически обоснованных функционалов $j_6$, $j_{\mathrm{peak}}$, $j_{\mathrm{safety}}$ и управление памятью обратного прохода через checkpoint/recompute, прежде чем масштабировать adjoint до реальной поры.
