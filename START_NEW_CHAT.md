## Научный статус, который нужно сохранить

3D сферическая пора радиуса 1 мм в пресноводном льду; нестационарное термомеханическое нагружение, квазистатическая механика; E/ED/EDV и CONST/VAR; R/tz/y20; j6/jpeak/j_safety; GH3 в общей постановке. **Текущая серия:** EDV_VAR, R, ξ=0, горизонт 900 с, область B6, аналитические геометрические производные `ANALYTIC_TET10`.

**Решение P10AO:** прямая и сопряжённая задачи **внутри каждого FEM-расчёта на одной сетке**; сравнение полных согласованных расчётов между сетками разрешено, межсеточное сопряжение отложено. **Пространственная сходимость `D_R jpeak` не доказана.** Малые невязки, совпадение FD/adjoint и близость интегралов не заменяют оценку пространственной ошибки. Требуется аудит геометрии/квадратуры, QP, теплового/механического сопряжения и большой компенсации разнознаковых локальных/компонентных вкладов.

**Новый факт P10BE:** H2 `dt=150/75/50/25 с`, 6/12/18/36 шагов, общий горизонт 900 с; `D_R jpeak = 2.3396363 / 2.3332270 / 2.3345022 / 2.3378099 м⁻¹` — ряд немонотонен. Для двух близких слоёв 200 радиально-полярных ячеек дают коэффициент компенсации различий 150−25 с **≈11.01**, а 50−25 с **≈102.26** (малый знаменатель; не оценка погрешности). В полярных поясах `|μ|≥0.8` сосредоточено **≈94.24%** суммы абсолютных различий 150−25 при **19.49%** QP. Полярные балансы по четырём временным шагам проверены с невязкой ≤`3.33e−16 м⁻¹`. Манифест Δt=25 с подтверждает `completed`, exit 0, 900 с, SHA сетки совпадает с P10BD; `.exe` P10BE — другая цель с иным SHA; Git SHA сборки `UNKNOWN`. Полученный [`P10BE_RESULT.txt`](https://github.com/galildmur-dotcom/stage3d07_ice_pore/blob/research/p10bb-w5b2-20261118/research/evidence/P10BE_H2_20261118/input/P10BE_RESULT.txt) имеет `P10BE_H2_DT25_COMPARE_OK`; независимая проверка даёт 155/200 ячеек и 14/20 радиальных интервалов с уменьшением абсолютной разности при переходе от 75−50 к 50−25 с, но локальное L1 уменьшается лишь на 5.55%.
