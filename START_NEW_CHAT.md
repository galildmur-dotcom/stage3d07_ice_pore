## Научный статус, который нужно сохранить

3D сферическая пора радиуса 1 мм в пресноводном льду; нестационарное термомеханическое нагружение, квазистатическая механика; E/ED/EDV и CONST/VAR; R/tz/y20; j6/jpeak/j_safety; GH3 в общей постановке. **Текущая серия:** EDV_VAR, R, ξ=0, горизонт 900 с, область B6, аналитические геометрические производные `ANALYTIC_TET10`.

**Решение P10AO:** прямая и сопряжённая задачи **внутри каждого FEM-расчёта на одной сетке**; сравнение полных согласованных расчётов между сетками разрешено, межсеточное сопряжение отложено. **Пространственная сходимость `D_R jpeak` не доказана.** Малые невязки, совпадение FD/adjoint и близость интегралов не заменяют оценку пространственной ошибки. Требуется аудит геометрии/квадратуры, QP, теплового/механического сопряжения и большой компенсации разнознаковых локальных/компонентных вкладов.

**Новый факт P10BE:** H2 `dt=150/75/50/25 с`, 6/12/18/36 шагов, общий горизонт 900 с; `D_R jpeak = 2.3396363 / 2.3332270 / 2.3345022 / 2.3378099 м⁻¹` — ряд немонотонен. Для двух близких слоёв 200 радиально-полярных ячеек дают коэффициент компенсации различий 150−25 с **≈11.01**, в полярных поясах `|μ|≥0.8` сосредоточено **≈94.24%** суммы абсолютных различий. Подробнее и точные источники — P10BE-отчёт по ссылке выше.

## Что делать в начале нового чата

1. Открыть **этот файл**, затем **рабочую ветку** GitHub и ссылки выше. Проверить актуальный HEAD, важные отчёты P10AZ/P10BA/P10BB/P10BD/P10BE и наличие свежих коммитов после 18.11.2026; не доверять заранее известному короткому SHA как «последнему».
2. Сначала закончить **воспроизводимость и научный анализ P10BE**. Единственное явное отсутствие в данных на 18.11: ещё не получен оригинал `G:\ildar\Stage3D07\LOCAL_RUNS\P10BE_H2_DT25_20261118_182525\RUN_MANIFEST.json`, а также подробный `P10BE_RESULT.txt`. Запрашивать только эти **два маленьких файла**, если они всё ещё отсутствуют; не просить исходные гигабайтные истории.
3. Сопоставить временную компенсацию P10BE с **сеточной** P10BB и P10AZ, количественно разделить ошибки во времени и пространстве; подготовить короткие графики/гипотезы и проверяемый минимальный следующий эксперимент. Не делать преждевременных выводов об асимптотической сходимости.
4. По результатам анализа внести научные выводы в Git: `docs/RESEARCH_LOG.md`, `article/EVIDENCE_REGISTER_CURRENT.md`, при утверждённом новом решении `docs/DECISIONS.md`, и отчёт эксперимента; сохранять оговорки, исходные CSV, manifests и SHA. Не переписывать исторические версии без причины.
5. При программных изменениях сохранять согласованность исходников с пользовательским Windows/Qt Creator C++20 MinGW Release, использовать **PORE ONE CLICK** для локальных патчей/экспорта; тестировать `git apply --check`, указывать точные запускаемые цели, время на **i7-7700K / 64 ГБ / 4 потока**, и список только нужных выходов.
