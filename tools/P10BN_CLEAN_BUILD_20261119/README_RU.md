# P10BN ONE CLICK — новая чистая Windows сборка из опубликованного SHA

**Дата:** 19.11.2026. **Статус:** пакет подготовлен; на пользовательском Windows пока **не выполнялся**. Внутренняя статическая проверка на Linux не заменяет Windows испытание CMD/PowerShell 5.1.

## Для чего нужен

P10BM успешно опубликовал пользовательский commit `90fd2559c0224ac0a7d2dbe2fe081a6a319080e4` в отдельной GitHub ветке `research/p10bi-local-seven-sources-20261119`. Исходники восстановлены, но предыдущие четыре Qt Creator P10BH запуска доказывают исполнение **имеющихся** EXE, а не их точный build provenance.

P10BN собирает **новые** EXE в новой чистой копии, фиксирует Git SHA, параметры и вывод CMake, SHA-256 новых исполняемых файлов и четыре коротких unit/selftest. Никакого H2/H4/H4W* FEM, сеток, checkpoint и временных историй не запускает.

## Одна кнопка

1. Скачать ZIP [`tools/P10BN_CLEAN_BUILD_ONECLICK_20261119.zip`](../P10BN_CLEAN_BUILD_ONECLICK_20261119.zip) из GitHub и распаковать **в любую обычную папку**, например `G:\ildar\PORE_GIT_TOOLS\P10BN`. Не нужно копировать ничего в действующий `Stage3D07`.
2. Дважды щёлкнуть **`01_P10BN_CLEAN_BUILD.cmd`**. Файлы GitHub/Qt Creator не изменятся на этапе предварительной проверки. Запуск читает `G:\ildar\Stage3D07\build\Desktop_MinGW_Release\CMakeCache.txt`, чтобы найти установленный пользователем реальный MinGW компилятор и Ninja/MinGW Make, и проверяет наличие CMake/Git. Если инструменты не обнаружены, он остановится, сохранив отчёт; самостоятельно искать и вводить пути в PowerShell не требуется.
3. Убедиться, что в окне показано `PREFLIGHT=OK_READ_ONLY_ORIGINAL`, прежний каталог `G:\ildar\Stage3D07`, точный Git SHA и новая выходная папка. Для подтверждения **явно напечатать** `BUILD P10BN` и нажать Enter. Просто Enter = только отчёт, без clone/build.
4. Дождаться `RESULT=P10BN_NEW_WINDOWS_BUILD_AND_FOUR_TESTS_OK` либо `RESULT=P10BN_STOPPED`. **При ошибке не запускать повторно до разбора отчёта.** Отправить ChatGPT **один файл `P10BN_EVIDENCE.zip`**, который сценарий покажет на экране. Он лежит в новой папке `G:\ildar\P10BN_ATTEST_ГГГГММДД_ЧЧММСС_PID\`. Сценарий не архивирует CMakeCache, исходники, EXE, сетки, большие результаты и пользовательский Git.

## Что создаётся

- **Читает:** только фактический локальный Git HEAD/status и прежний `CMakeCache.txt` для определения Qt Creator MinGW Release. `origin`, локальные ветки и пользовательские файлы не изменяет.
- **Новый отдельный каталог** рядом со Stage3D07: `G:\ildar\P10BN_ATTEST_<stamp>_<pid>\source` — отдельный `git clone --single-branch --no-checkout` **с публичного GitHub**, затем checkout **точно** коммита `90fd2559...`; новая `build` папка. Старые `G:\ildar\Stage3D07\build` и рабочее дерево нетронуты.
- **Собираемые цели, строго четыре:** `stage3d10v_analytic_shape_unit`, `stage3d10y_analytic_shell_unit`, `stage3d10be_temporal_unit`, `stage3d10be_temporal_polar_audit`. Последняя цель запускается **только** с `--selftest`, остальные без аргументов. Каждая короткая проверка ограничена 120 с; задержка — остановка с ошибкой.
- **Доказательства:** `P10BN_RESULT.txt`, `logs/cmake_configure.txt`, `logs/cmake_build.txt` и stdout/stderr четырёх тестов. Архив `P10BN_EVIDENCE.zip` содержит только эти малые текстовые файлы. Вывод делится на первичные логи и диагностический summary, без присвоения прежним бинарникам нового SHA.

## Время, память и ограничения

Предварительная оценка для i7-7700K, 64 ГиБ ОЗУ: **5–20 минут** на загрузку отдельной копии и сборку четырёх целей, **~2–8 ГиБ ОЗУ** (оценка, не измерение). Тесты обычно занимают секунды; компиляция большого P10BE translation unit может занять основную долю времени. Свободное дисковое место желательно не менее **3 ГиБ** в `G:\ildar` с запасом. Нужен доступ к GitHub для `git clone` и рабочий Qt Creator MinGW Release kit с сохранённым CMakeCache.

**Важная граница:** даже успешный P10BN доказывает новую сборку из указанного Git SHA при описанной конфигурации и успешность четырёх коротких тестов; не доказывает точную историческую сборку `P10BE_H2_LOGS_20261118_182525`, работу больших FEM, корректность теории или пространственную сходимость полной форменной производной. `P10W_DEPENDENCY_SELFTEST_OK analytic_coupling_verified=0` не повышать до независимого доказательства всей аналитической связи.

Перед передачей отчёта можно открыть ZIP и проверить, что системные пути/сведения конфигурации допустимы для публичной GitHub доказательной записи. Сам архив **не отправляется в GitHub автоматически** — сначала проверяется ChatGPT.
