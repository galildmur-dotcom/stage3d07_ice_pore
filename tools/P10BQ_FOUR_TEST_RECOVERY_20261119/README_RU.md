# P10BQ — закончить четыре коротких теста из уже готовой сборки P10BP

Дата: 19.11.2026. **Подготовлен инструмент; его запуск на пользовательском Windows ещё не подтверждён.**

## Почему это нужно

В первичном `P10BP_EVIDENCE.zip` чистые исходники exact SHA `90fd2559c0224ac0a7d2dbe2fe081a6a319080e4` успешно сконфигурированы и все четыре EXE собраны (`CONFIGURE_EXIT=0`, `BUILD_EXIT=0`). Первый P10V вывел `P10V_ANALYTIC_SHAPE_UNIT_OK`, но поле `TEST_EXIT_...` пустое. P10BP использовал `Start-Process` / `ExitCode`; **код возврата первого EXE документально не установлен**, несмотря на контрольный текст. Три последующих теста P10BP не запускал. Нет основания объявлять ни провал вычислительной проверки, ни четыре пройденных теста.

P10BQ **не повторяет клонирование и компиляцию**. Он использует исходный отдельный каталог `G:\ildar\P10BP_ATTEST_20261119_173658_19404` и проверяет перед тестами точный Git SHA/чистоту `source`, CMakeCache `build`, SHA-256 четырёх EXE и сохранённый первичный отчёт. P10V EXE дополнительно должен совпасть с известной суммой `02f14785...4721` из P10BP. Каждый EXE запускается напрямую из Windows PowerShell, код возврата читается **сразу из `$LASTEXITCODE`**. Не используется ненадёжный в предыдущем запуске `Start-Process.ExitCode`.

## Одна кнопка

1. Сохранить `P10BQ_FOUR_TEST_RECOVERY_ONECLICK_20261119.zip` из GitHub; распаковать в **новую** папку, например `G:\ildar\PORE_GIT_TOOLS\P10BQ`.
2. Дважды щёлкнуть `01_P10BQ_RUN_FOUR_TESTS.cmd`. Он **не изменяет** `G:\ildar\Stage3D07`, Git или существующую P10BP сборку. Если указанного каталога P10BP больше нет, безопасно остановится с отчётом; не запускайте P10BP повторно.
3. При `PREFLIGHT=OK_FOUR_EXISTING_BINARIES_AND_ISOLATED_SOURCE` ввести ровно `TEST P10BQ` (Enter без текста — только проверка, без тестов).
4. Ожидать около **1–3 минут**, ориентировочно менее **1 ГиБ ОЗУ** (это оценки, не замеры). Три unit EXE запускаются **без аргументов**, `stage3d10be_temporal_polar_audit.exe` — с `--selftest`. **Тяжёлых FEM задач нет**.
5. В новой папке `G:\ildar\P10BQ_TESTS_...` проверить `P10BQ_RESULT.txt` и выслать **один `P10BQ_EVIDENCE.zip`**. Внутри только текстовый отчёт и четыре коротких журнала; EXE, mesh, исходники и личные файлы не упаковываются.

## Критерии и границы

- `RESULT=P10BQ_FOUR_FRESH_WINDOWS_TESTS_OK`, `TESTS_PASSED=4/4`, четыре `TEST_EXIT_...=0`, четыре точных маркера, source clean и unchanged original status/HEAD. Только после просмотра ZIP можно говорить об аттестованных четырёх unit/selftest из фиксированного SHA.
- При `P10BQ_STOPPED` **не** очищать, не исправлять вручную, не запускать повторно без разбора. Отправить ZIP, даже если он содержит только STOP-отчёт.
- Это аттестация коротких тестов **новой** GNU/MinGW сборки. Она не доказывает связь с историческим EXE расчёта `P10BE_H2`, пространственно-временную сходимость `D_RJ` и корректность физической интерпретации.
