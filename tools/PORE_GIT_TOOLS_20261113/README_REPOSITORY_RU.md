## Обнаруженные несовместимости и предостережения

1. `Apply-Patch.ps1` фиксирует `$Branch = 'master'` и `$Remote = 'origin'`; **актуальные материалы P10BB–P10BF находятся в `research/p10bb-w5b2-20261118`**. Скрипт с текущими настройками для научной ветки непригоден. Он прекращает работу при расхождении локального и удалённого `master`, а не делает синхронизацию веток.
2. Сценарий показывает устаревшее слово **GitFlic** при подтверждении и успехе, хотя фактическая цель push задаётся `origin` на пользовательском ПК. Только `git remote -v` устанавливает, куда он отправит коммит. **Не считать запись в GitFlic записью в GitHub**.
3. Исходная инструкция от 13.11 утверждает, что рядом лежит `Stage3D07_P10Z_MESH_SHELL_AUDIT_ONECLICK_20261113.patch`; в верхнем уровне полученного архива `.patch` **нет**. Также встречается устаревшая фраза «Verified PowerShell scripts: 5», хотя в полученном комплекте их **шесть**. Эти несоответствия сохранены как часть оригинальной версии, не исправлены задним числом.
4. `Install.ps1` использует фиксированные пути на `G:`, Windows PowerShell 5.1 и создаёт ярлыки на рабочем столе. В Linux нет проверки исполнения/синтаксиса PowerShell 5.1. Контроль состоял в чтении программ, проверке безопасности состава архива и побайтовом сравнении верхних 13 файлов.
5. Эта папка **не обеспечивает автоматическую двустороннюю синхронизацию** ПК↔GitHub. Для неё нужны локальный Git for Windows, правильный `origin`, разрешённая аутентификация, отдельное решение о ветке и коммиты. Большие `LOCAL_RUNS`, `.msh`, `.bin`, `.exe` не должны попадать в Git случайно.
