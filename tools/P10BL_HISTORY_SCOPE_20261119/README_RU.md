## Почему проверка необходима

В P10BK подтверждено, что `origin` уже настроен на `https://github.com/galildmur-dotcom/stage3d07_ice_pore.git`, но локальный SHA `90fd2559…` **не был отправлен** (`UPSTREAM=NONE`). При проверке GitHub **не обнаружил его родительский SHA `c0498f6dc98628b62eff996a76844297c7a35094`**. Значит обычная отправка ветки может передать на GitHub *много других старых коммитов и исторических файлов*, а не только семь новых исходников. До такой операции следует оценить объём и возможное наличие приватных файлов в истории.

## Как запустить

1. Скачать архив `P10BL_HISTORY_SCOPE_ONECLICK_20261119.zip` и распаковать **два файла** в новую папку.
2. Дважды щёлкнуть `01_P10BL_AUDIT_HISTORY_BEFORE_PUSH.cmd`.
3. Отправить ChatGPT **только один текстовый `P10BL_HISTORY_SCOPE.txt`** из папки `P10BL_CHECK_*` рядом с программой. Исходники, `.git`, EXE, расчётные каталоги и Git bundle **не присылать**.

## Проверки и ограничения

Сценарий требует прежнюю ветку/HEAD/родитель и точный GitHub URL из P10BK. После этого **только локальными читающими Git-командами** подсчитывает достижимые коммиты и объекты, количество исторических файловых объектов, несжатый суммарный размер blob и размер максимального blob, а также верхнеуровневые группы каталогов. Подозрительные имена вроде секретов/ключей отмечает **числом**, но имена отдельных исторических файлов в отчёт не записывает. Если объектов больше 100 000, измерение размеров ограничивается и требуется отдельный разбор.

**Ни одной** команды `git push`, `fetch`, `pull`, `switch`, `checkout`, `merge`, `reset`, `clean`, `commit`, `stash`; сети, FEM и изменения пользовательских файлов нет. Отчёт не показывает пароли/токены. Существующие семь unstaged и четыре untracked записи сохраняются. При несоответствии состояния — остановиться и прислать отчёт, не исправлять вручную.

Оценка на i7-7700K/64 ГБ: обычно 1–3 минуты, ориентировочно до 5 минут для большой Git-истории; память обычно менее 100–300 МБ. Проверка Windows PowerShell 5.1 на пользовательском ПК ещё не проводилась. Только после получения отчёта решать, отправлять ли полную историю или ограничиться отдельным снимком исходников с точной ссылкой на локальный SHA.
