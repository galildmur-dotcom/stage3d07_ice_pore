Сохранилась нормализация Windows-путей из R1; опубликованный P10BY CMake `ad65850d...` в Git не менялся. Изменения не затрагивают научные формулы или тестовые main.

## Одна кнопка

1. Скачайте **именно** P10BZ_WINDOWS_NATIVE_PREFLIGHT_R2_20261120.zip из опубликованной исследовательской ветки GitHub. **Не повторяйте R1**, P10BP или P10BQ. Сверьте SHA-256 ZIP с указанным в новом отчёте (при желании).
2. Распакуйте его **целиком** в отдельный новый каталог **вне** G:\ildar\Stage3D07, например в «Загрузки» Windows. Избегайте очень длинных путей. Не распаковывайте в старый build, source, LOCAL_RUNS или архив прежнего инструмента.
3. Дважды щёлкните 01_P10BZ_RUN_NATIVE_TESTS.cmd. Сначала виден read-only preflight. При PREFLIGHT=OK_READ_ONLY_SOURCE_TOOLCHAIN_ORIGINAL введите ровно **TEST P10BZ**. Просто Enter отменяет без создания файлов сборки.
4. **Оценка:** 5–20 минут на Windows i7-7700K, ОЗУ приблизительно 2–8 ГиБ, новое место до 1 ГиБ. Это консервативный бюджет, не измерение. Параллельная сборка ограничена двумя заданиями; если что-то неожиданно длится существенно дольше, не запускать сценарий ещё раз вслепую.
5. В соседней новой папке P10BZ_RESULTS_... ожидаются P10BZ_RESULT.txt и **P10BZ_EVIDENCE.zip**. При техническом STOP создаётся P10BZ_STOP_... с отчётом, если это безопасно. Передайте **только один P10BZ_EVIDENCE.zip**. Он содержит небольшие текстовые журналы и результат, но не исходники/EXE/сетки/бинарную историю.

**Норма успеха:** RESULT=P10BZ_WINDOWS_UNIT_ONLY_OK, TESTS_PASSED=2/2, оба native TEST_EXIT_...=0, нужные маркеры, ORIGINAL_STATE_PRESERVED=YES_BY_READ_ONLY_COMPARISON. При P10BZ_STOPPED не менять исходники/путь/компилятор, не повторять старую кнопку — сначала отправьте короткий evidence для диагностики.
