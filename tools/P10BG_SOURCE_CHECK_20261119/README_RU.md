# P10BG — безопасная сверка локальных исходников Stage3D07

Этап: 19.11.2026. Утилита **только читает** `G:\ildar\Stage3D07`, семь небольших исходных файлов и сведения `git rev-parse`, `git status`; **не запускает FEM, сборку, CMake, git pull, git checkout, git push или патч**. Записывает два текстовых отчёта **рядом с извлечённым комплектом**, а не в проект.

## Что сделать на Windows 11

1. Скачать `P10BG_SOURCE_CHECK_ONECLICK_20261119.zip` из GitHub и **извлечь оба файла** в отдельную папку. Запускать CMD непосредственно из ZIP не нужно.
2. Дважды щёлкнуть `01_CHECK_LOCAL_SOURCE.cmd`. Путь проекта уже указан: `G:\ildar\Stage3D07`. Откроется окно PowerShell; возможны стандартные системные предупреждения безопасности.
3. После надписи `P10BG_SOURCE_CHECK_OK` открыть рядом с CMD папку `P10BG_SOURCE_CHECK_<дата>_<PID>` и прислать в чат **только два файла**: `P10BG_LOCAL_SOURCE_REPORT.txt` и `P10BG_SHA256.csv`.

Время на i7-7700K: обычно **менее 1 минуты**. ОЗУ существенно меньше 100 МБ сверх системных служб. Состояние локального Git-дерева, расположение ваших `build`, `meshes` и `LOCAL_RUNS` не меняются.

`EXACT_SHA256` означает побайтовое совпадение конкретного файла с ранее переданным пользовательским экспортом (CRLF учитываются). `DIFFERENT_BYTES` **не означает ошибку численного метода**: причиной могут быть более новые изменения или формат переводов строк. Точный локальный HEAD при экспорте P10BF был `c0498f6dc98628b62eff996a76844297c7a35094`, но он не обязан совпадать с текущим.

## Статус самой программы

Создана и проверена на уровне текста/архива в Linux; **реальный запуск `.cmd`/PowerShell 5.1 на вашем Windows пока не подтверждён**. Если выдаст `FAILED`, пришлите сообщение окна; ничего не исправляйте вручную в исходниках. Файлы в GitHub и исходные отчёты P10BF остаются неизменными.
