## Что делает программа

1. До любых изменений проверяет, что Git HEAD и ветка **точно** соответствуют ожидаемым, что семь файлов имеют ожидаемые SHA-256 и статусы `M/??`, а в Git **нет уже подготовленных (staged) изменений**. Если что-то изменилось, немедленно останавливается.
2. Создаёт **побайтовую резервную копию всех семи** исходников в отдельной папке рядом с распакованной программой; сверяет каждый хеш.
3. Показывает на экране, какие семь путей планируется записать, и ждёт **ручного ввода ровно `COMMIT 7`**. Нажатие Enter вместо фразы оставляет Git без изменений и сохраняет только резервную копию/отчёт.
4. После подтверждения повторяет проверки, создаёт **новую локальную ветку** `research/p10bi-local-seven-sources-20261119` от исходного `master`, ставит в индекс **только** семь согласованных файлов, проверяет список и создаёт **один локальный коммит**. Проверяет новый HEAD и имена файлов в коммите.
5. Создаёт `P10BI_RESULT.txt` рядом со своей папкой и выводит адрес отчёта. **Не** выполняет `git push`, `git fetch`, `git pull`, `git reset`, `git clean`, `git stash`, `git checkout --`, копирование в G: или FEM.

В случае ошибки программа останавливается и не выполняет автоматического отката, чтобы не повредить состояние пользователя. Если ошибка возникла после создания ветки, **не запускать повторно** без анализа отчёта. Инструмент сохраняет другие изменения рабочего дерева, но не проверяет/не включает их в коммит.

## Действия пользователя (Windows 11)

1. Скачать `P10BI_LOCAL_COMMIT_ONECLICK_20261119.zip`, распаковать **оба файла** (`.cmd` и `.ps1`) в новую папку, например на G: в «Загрузки». Не запускать скрипт прямо из ZIP.
2. Закрывать Qt Creator и другие программы необязательно, но не редактировать исходники во время проверки. Дважды щёлкнуть `01_P10BI_CHECK_AND_COMMIT.cmd`.
3. После предварительного отчёта и резервной копии внимательно посмотреть семь путей. Чтобы остановиться без коммита, нажать **Enter**. Чтобы создать локальный коммит, набрать в окне **`COMMIT 7`** и нажать Enter.
4. Прислать в ChatGPT **только** созданный `P10BI_RESULT.txt`. Не присылать резервную копию, исходники, EXE, mesh или весь Git-проект. Пока не нажимать историческую кнопку PORE «Apply and Push».

PowerShell-скрипт написан для Windows PowerShell 5.1; **прямой запуск на пользовательском Windows до получения результатов ещё не проверен**. Проверка SHA/состояния защищает от применения к изменившемуся дереву.

**Принципиальное различие:** локальный коммит на новой ветке — это источник для будущей воспроизводимой сборки, а **не доказательство**, что исторические P10BE `.exe` были собраны именно из этого коммита.
