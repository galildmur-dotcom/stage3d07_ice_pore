## Как запустить в Windows 11

1. Скачать `P10BM_PUBLISH_HISTORY_ONECLICK_20261119.zip`; распаковать **оба файла** (CMD+PS1) в новую папку, не запускать напрямую из ZIP.
2. Дважды щёлкнуть **`01_P10BM_PUBLISH_LOCAL_HISTORY.cmd`**. Скрипт сначала проверит точный путь `G:\ildar\Stage3D07`, Git root, локальную ветку/HEAD, 56 коммитов, ровно семь файлов в последнем коммите, исходный родитель и локальный `master`, текущий статус (ожидается 0 staged/7 unstaged/4 untracked), единственный GitHub `origin`, отсутствие зеркального режима/нестандартных push refspec/hook, а также через читающий `git ls-remote` — отсутствие целевой удалённой ветки.
3. Если все проверки завершились успешно и показано `REMOTE_HEAD_BEFORE=ABSENT`, **набрать ровно `PUSH 56`** и нажать Enter. Обычное Enter завершит только проверку, не отправляя данные. Никаких Git-команд самостоятельно вводить не нужно.
4. Git может открыть штатное окно авторизации GitHub; войти в **свой** аккаунт при необходимости. Пароли и токены не присылать ChatGPT.
   После подтверждения дождаться возвращения управления из `git push` — несколько минут окно может не выводить новых строк. **Не закрывать CMD во время отправки.**
5. Прислать **только `P10BM_PUSH_RESULT.txt`** из созданной `P10BM_CHECK_*` папки рядом с программой.

## Защитные ограничения

- Только явный рефспек `HEAD:refs/heads/research/p10bi-local-seven-sources-20261119`, **без** `--force`, без `--mirror`, без tags и без submodule push, без создания/изменения других **удалённых** refs.
- Перед push дважды проверяется, что удалённой ветки ещё нет. Если она уже есть с *точно тем же* SHA, инструмент фиксирует `ALREADY_PUBLISHED_VERIFIED_NO_PUSH`; при другом SHA останавливается.
- После push повторным `git ls-remote` проверяется, что публичная ветка указывает **ровно** на `90fd2559...`. Если проверка не удалась, повторно запускать программу самостоятельно **нельзя**: push мог уже состояться.
- **Никаких** `git fetch`, `pull`, `switch`, `checkout`, `merge`, `reset`, `clean`, `stash`, `commit` или FEM. Локальные 7 unstaged и 4 untracked записи не входят в Git push и не изменяются. Старый `PORE_GIT_TOOLS/01_APPLY_PATCH_AND_PUSH.cmd` не использовать.
- При отказе сети, GitHub-авторизации, настроенных hooks/нестандартной конфигурации или изменившемся Git-состоянии программа останавливается с отчётом. Она не пытается обойти разрешения сервера.
