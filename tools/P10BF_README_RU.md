# P10BF — один экспорт исходников и исходных CSV для Stage3D07

**Для Windows 11, Qt Creator/MinGW Release, Python 3.13.** Тяжёлых FEM-расчётов нет.

1. Скачайте маленький архив `P10BF_ONECLICK_EXPORT_20261118.zip` из исследовательской ветки GitHub.
2. Распакуйте его целиком в отдельную папку Windows (например, `Загрузки/P10BF_EXPORT`).
3. Дважды щёлкните **`P10BF_EXPORT_ONECLICK.cmd`**. Никаких команд вводить не нужно.
4. Дождитесь `P10BF_EXPORT_OK`. Рядом с программой появится **один** архив `P10BF_EVIDENCE_EXPORT_YYYYMMDD_HHMMSS.zip`.
5. Пришлите в чат **только этот ZIP**. Не прикрепляйте `forward_history.bin`, `.msh`, `.vtu` или всю папку проекта.

В зависимости от количества каталогов в `LOCAL_RUNS` ожидаемое время **примерно 1–5 минут** на i7-7700K (оценка, не измерение). При большом числе каталогов возможны отклонения. Искать будет только на `G:\ildar\Stage3D07` в `LOCAL_RUNS` и `LOCAL_RUNS_OPTIMIZED`; архивный диск F сканироваться не будет.

## Что экспортируется

- Пять конкретных исходных файлов, которых требует проверка цепочки P10BA→P10BD→P10BE (CMake, header, два C++ и test).
- Текущий Git HEAD и короткий статус именно этих пяти файлов.
- SHA-256 имеющихся `.exe` для P10AZ, P10BA, P10BD, P10BE, **без** упаковки исполняемых файлов.
- До трёх оригинальных `P10BA_QP_POLAR_RADIAL.csv` (400 строк каждый), соответствующих W4B2, W4B20, W5B2. Они определяются **по независимым числовым суммам**, а не только по именам папок.
- `EXPORT_MANIFEST.json` с перечнем найденных и отсутствующих данных, исходными путями и SHA-256.

**Ограничение:** текущий Git HEAD или совпадение SHA файла `.exe` **не доказывают**, что текущая копия C++ была исходником исторического бинарника. Подлинное происхождение сборки оценивается отдельно по исходным версиям, рабочему дереву, CMake и журналам. Скрипт ничего не исправляет и не коммитит самостоятельно.

Если увидите `warnings > 0`, всё равно пришлите готовый ZIP: в нём будет точный список того, что не удалось собрать. При ошибке `P10BF_STOP` пришлите только текст ошибки или снимок окна.
