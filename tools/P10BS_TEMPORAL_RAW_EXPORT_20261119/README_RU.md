# P10BS — экспорт четырёх уже существующих полярных CSV без FEM

**Дата:** 19.11.2026. **Назначение:** получить недостающие исходные покомпонентные поля `explicit/equilibrium/history` для P10BD/P10BE на одной H2 сетке из **уже завершённых** запусков. Нужен **один** небольшой ZIP, не четыре отдельных пересылки. Это не сборка, не новый расчёт, не аттестация старого EXE.

После исходникового аудита [P10BS](../../research/P10BS_SOURCE_EXPORT_AND_COMPONENT_SCOPE_20261119.md) выяснено: `P10BE_CELL_TEMPORAL_COMPARE.csv` содержит только суммарную механику. Первичные `P10BD_QP_POLAR_RADIAL.csv` содержат по каждому шагу и 200 ячейкам все три механические составляющие и объём QP. **Даже в P10BE Δt=25 с имя файла остаётся `P10BD_QP_POLAR_RADIAL.csv`** — так устроен общий экспортёр. Поскольку четыре запуска уже выполнены, повторять их нельзя и не нужно.

## Пользователю: одна кнопка

1. Скачать `tools/P10BS_TEMPORAL_RAW_EXPORT_ONECLICK_20261119.zip` из исследовательской ветки GitHub, распаковать **в новую пустую папку** на Windows. Не копировать поверх `PORE_GIT_TOOLS` или других версий.
2. Дважды щёлкнуть `01_P10BS_EXPORT_EXISTING_CSV.cmd`. Сценарий прочитает только четыре заранее названных CSV из `G:\ildar\Stage3D07\LOCAL_RUNS`; проверит структуру, 1200/2400/3600/7200 строк, временные метки, 200 ячеек на шаг, разделение QP и SHA. После этого сохранит побайтные копии и отчёт **в новом `G:\ildar\P10BS_EXPORT_...`**. Архив получится там же.
3. Проверить в `P10BS_RESULT.txt`: `TOOL_REVISION=P10BS_R1_EXISTING_FOUR_RAW_POLAR_CSV`, `ALL_FOUR_PREFLIGHT=OK`, `SOURCE_FOUR_SHA256_UNCHANGED=YES`, `RESULT=P10BS_FOUR_EXISTING_RAW_POLAR_CSV_READY_NO_FEM`.
4. Отправить в этот чат **только `P10BS_EVIDENCE.zip`** из этой новой папки. Не нужны `.msh`, `forward_history.bin`, `.exe`, VTU, логи повторного расчёта, весь Git или папки LOCAL_RUNS.

При `P10BS_STOPPED` **не удалять ничего и не повторять вслепую**: отправить образовавшийся `P10BS_EVIDENCE.zip` с отчётом или, если ZIP создать не удалось, один `P10BS_RESULT.txt`.

| 25 | `P10BE_H2_DT25_20261118_182525` | 7200 |

В каждой папке читается файл с **одинаковым** именем `P10BD_QP_POLAR_RADIAL.csv`. Пути к P10BD взяты из оригинального `research/evidence/P10BD_H2_20261118/RESULT.txt`, путь P10BE — из оригинального manifest. Если они изменились, программа безопасно остановится; она не ищет другие файлы «по похожему имени».

**Воздействие на ПК:** только чтение четырёх исходных CSV и запись новой независимой директории; никаких Git, patch, configure/build, FEM, перемещений, удаления, перезаписи, копирования mesh/EXE/cache, изменения Qt. Оценка: 1–3 минуты, память менее 1 ГиБ при указанных 14400 строках (оценка, не замер). Безопасная программа для Windows PowerShell 5.1; если отсутствуют файлы, STOP.

**Научное ограничение:** получаем только механические компоненты во времени и локальный QP объём. Температурные поля и локальный тепловой shape-вклад **отсутствуют даже в этих файлах**; глобальная тепловая сумма уже известна из `P10BE_TEMPORAL_SUMMARY.csv`. Для неё будет отдельное решение после анализа поступивших первичных CSV.
