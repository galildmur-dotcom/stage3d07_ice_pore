# H1 / EDV_VAR (Stage 3D-06) — запуск в Qt Creator

Эта версия — **дополнение к уже проверенному на Windows проекту**. Настройки модели не менялись.

**Перед обновлением:** не удаляйте `LOCAL_RUNS/H2_dt300_q3` и `restart.bin` — это ваши успешно полученные результаты H2.

## Вариант А. Малый патч (предпочтительно)

1. Закройте Qt Creator (или закройте проект).
2. Распакуйте `Stage3D06_QtCreator_H1_PATCH_2026-10-10.zip` непосредственно в папку `Stage3D06`, где лежит `CMakeLists.txt`, **с заменой двух файлов** `CMakeLists.txt` и `src/qt_creator_runner.cpp`. Внутри патча файлы расположены относительно корня `Stage3D06` (без вложенной папки `Stage3D06`). Патч содержит также этот документ.
3. Откройте тот же `CMakeLists.txt` в Qt Creator, выберите **Desktop MinGW / Release**. При необходимости выберите **Сборка → Запустить CMake / Переконфигурировать проект**.
4. Соберите проект (`Ctrl+B`); в «Проекты → Запуск» выберите `stage3d06_qt_H1` и нажмите **Запустить** (`Ctrl+R`). Поле аргументов оставьте пустым.
5. В выводе должны появиться `Mesh: H1, model: EDV_VAR, dt=300 s, tend=3600 s, quadrature=3`, затем сообщения о температурной и механической задачах и `SUCCESS`.

Если в списке нет `stage3d06_qt_H1`, выполните **Сборка → Запустить CMake**, затем сборку ещё раз. Убедитесь, что Qt Creator открывает исправленную папку проекта, а не старую.

## Вариант Б. Без патча

В уже существующем проекте выберите `stage3d06_qt_run` и задайте в Qt Creator → «Проекты → Запуск → Аргументы командной строки»:

`--mesh H1 --law EDV --modulus VAR --dt 300 --tend 3600 --quad 3`

Затем запускайте как обычно. Этот вариант функционально эквивалентен новой цели.
