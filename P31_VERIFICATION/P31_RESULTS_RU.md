# Stage 3D-06-P3.1. Результаты и ограничения

**Исходное сравнение на компьютере пользователя (Windows/Qt Creator, H0, EDV/VAR, q=3, 4 потока):**
Jacobi 842 CG / 0.859 с PCG / 2.048 с весь шаг; исходный MC-SGS 347 CG / 1.300 с PCG / 2.545 с весь шаг. Численные показатели Psi6 совпали с относительным расхождением ~5.15e-12.

**Что сделано:** сохраняется старая ветка `mcsgs` и добавляется `mcsgs-fast`, использующий предрассчитанные номера нижних/верхних BCSR-блоков для каждого узла. Цвета, порядок строк, проходы D+L и D+U, блочные обратные диагонали, матрицы, уравнения, физическая постановка, закрепления НЕ меняются. Списки соседей сохраняют порядок прежнего обхода блоков.

**H0 graph:** 10845 узлов, 294663 BCSR блока, 7388 Tet10, 17 цветов. 34 цветовых прохода на применение MC-SGS; последний цвет содержит 14 узлов.

**Linux interleaved tests, три прогона на вариант:**
- Original MC-SGS median PCG: 1.1438 с; apply 0.8410 с; step 2.0263 с.
- Indexed MC-SGS-fast median PCG: 1.0015 с; apply 0.7175 с; step 1.8873 с.

Колебания отдельных замеров заметны, поэтому эти измерения не являются подтверждением ускорения на Windows. Подтверждение требует парных многократных замеров на i7-7700K.

**Тесты:** исходный и быстрый MC-SGS выдают битово одинаковый предобусловленный вектор на трёх тестовых графах (включая Tet10 и частично закреплённые DOF), 4/4 OpenMP unit/dry-run, 4/4 non-OpenMP unit/dry-run; реальная H0 регрессия шести физических веток E/ED/EDV × CONST/VAR с сравнением полной checkpoint при 1e-6. Native launch H0 пройден.

**Ограничения:** тесты Linux GCC, не Windows MinGW. Проверки H2 и H4 на `mcsgs-fast` не выполнены; долгую кампанию H4 НЕ запускать. Jacobi остаётся рекомендуемым для научной серии, пока нет проверенного ускорения на крупных сетках.
