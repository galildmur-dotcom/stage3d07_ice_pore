# STAGE 3D-00 v4 — утверждённая базовая постановка

Дата: 2026-10-09. Проект: самостоятельная трёхмерная научная статья для журнала «Вычислительная механика сплошных сред» (Computational Continuum Mechanics). Название: «Численное исследование геометрической чувствительности термовязкоупругого пресноводного льда со сферической воздушной порой при случайном охлаждении».

**Статус:** научные решения Stage 3D-00 v4 утверждены пользователем в диалоге. **Численный код 3D в этот пакет не входит; расчётные значения из справочных CSV являются аналитическими, не FEM-результатами.** Следующий исполняемый этап — Stage 3D-01, см. `STAGE3D01_TECHNICAL_TASK.md`.

## Состав
- `3D_BASELINE_SPEC_v4.md` — каноническая непрерывная постановка и постановка задачи чувствительности.
- `MATERIAL_E_T_v4.md` — относительная температурная зависимость мгновенного модуля E, исходные публикации, тесты.
- `FUNCTIONAL_AND_SHAPE_v4.md` — наблюдаемые величины, производные и сферические гармоники.
- `DECISIONS_STAGE00_v4.md` — реестр окончательных решений и ограничений.
- `STAGE3D01_TECHNICAL_TASK.md` — конкретное техническое задание для геометрии и Tet10.
- `3D_CAMPAIGN_v4.csv` — этапы и матрица исследовательских экспериментов.
- `TEST_CATALOG_v4.csv` — формализованные контрольные тесты (критерии успешного прохождения).
- `GEOMETRY_REFERENCE_v4.csv` — точные аналитические геометрические величины.
- `E_T_REFERENCE_VALUES_v4.csv` — таблица нормированного закона Синхи.
- `SOURCE_AND_TRACEABILITY_v4.md` — источники и прослеживаемость решений.
- `CHANGELOG_v4.md` — отличие от v3.

## Что не входит в статью
Никаких глав, рисунков, результатов или сравнений двумерной задачи; отсутствует ссылка на неопубликованную 2D-статью. Старые программные наработки можно использовать для внутренней инженерной организации, но не для обоснования научных результатов 3D.

## Правило перехода
3D-01 → 3D-02 только после прохождения G01 (геометрия/квадратуры/Tet10/теги/VTU). E → ED → EDV; полноценный EDV-run и производные формы до контрольных проверок запрещены.
