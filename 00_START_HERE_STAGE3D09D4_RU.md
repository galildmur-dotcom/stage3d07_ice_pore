# Stage 3D-09D4: сетки HP2/HP4/HP8 для расчёта геометрической чувствительности

**Только для нашего 3D-проекта:** 3D пресноводный лёд / сферическая пора / квазистатика / EDV/VAR / функционалы j6, jpeak(p=8), jen. Старые H4 и HP, результаты и `LOCAL_RUNS` не изменяются.

## Сетки (действительно измеренное ребро Tri6 у поры)

| mesh | характерный размер поля на поре, мм | медиана ребра, мм | узлы | Tet10 | Tri6 на поре |
|---|---:|---:|---:|---:|---:|
| HP  | 0.085000 | 0.08452 | 172031 | 124641 | 4212 |
| HP2 | 0.042500 | 0.042385 | 241442 | 167420 | 16668 |
| HP4 | 0.021250 | 0.021227 | 710804 | 483780 | 66140 |
| HP8 | 0.010625 | 0.010620 | 3996868 | 2817419 | 263274 |

Все значения — для границы поры, не для всего тела. На расстоянии до 0.06 мм действует дополнительное ограничение поля, затем размер постепенно переходит к базовой HP. Геометрия и физические группы тождественны. HP8 в десятки раз дороже HP по числу узлов/тетраэдров; **доступность полноценной 3D EDV/VAR-кампании HP8 при RAM 64 ГБ не доказана**.

## Установка

1. Распакуйте `Stage3D09D4_WALL_LEVELS_PATCH_QtCreator.zip` в `C:\Users\Admin\Downloads\` (архив уже содержит `Stage3D07\`). Разрешите замену исходного C++ и `CMakeLists.txt`.
2. Распакуйте `Stage3D09D4_WALL_LEVELS_MESHES.zip` в ту же папку — он содержит `Stage3D07\meshes\HP2.msh`, `HP4.msh`, `HP8.msh`.
3. **Не удаляйте `Stage3D07\LOCAL_RUNS`.** Вместо двух архивов можно использовать единый FULL-архив, но он не должен заменять Ваш LOCAL_RUNS.
4. В Qt Creator: CMake → Reconfigure, Desktop MinGW **Release**, цель `stage3d09c_shape_three`.

## Режимы проверки и запуска

Вставьте аргументы ниже в Qt Creator; меняйте только HP2 → HP4 → HP8. Рекомендуется выполнять уровни последовательно, начиная с HP2.

### A. Сначала проверка файла сетки (ничего не создаёт)

`--mesh HP2 --modes y20 --laws EDV --moduli VAR --dt 300 --tend 3600 --quad 3 --peak-p 8 --delta-um 5 --cutoff-mm 5 --threads 4 --reuse-p08d off --dry-run`

Должно появиться `P09D4_MESH_OK` и `P09C_DRY_RUN_OK`.

### B. Затем полная проверка исходной и обеих возмущённых геометрий, без FEM

`--mesh HP2 --modes y20 --laws EDV --moduli VAR --dt 300 --tend 3600 --quad 3 --peak-p 8 --delta-um 5 --cutoff-mm 5 --threads 4 --reuse-p08d off --geometry-only`

Ожидается `P09D4_GEOMETRY_ONLY_SUCCESS` и файл `P09D4_GEOMETRY_ONLY_OK.txt`. Программа создаёт формы `y20 ±5 мкм`, проверяет знаки якобианов Tet10 в 27 точках квадратуры, неподвижность внешней границы и B6. При ошибке геометрии длительный FEM не запускать.

### C. Только затем расчёт температурного и механического состояния

`--mesh HP2 --modes y20 --laws EDV --moduli VAR --dt 300 --tend 3600 --quad 3 --peak-p 8 --delta-um 5 --cutoff-mm 5 --threads 4 --reuse-p08d off`

Это 3 узла GH3 × 2 знака возмущения = **6 новых тепловых и 6 механических траекторий на сетку**, 12 временных шагов по 300 секунд каждая. Результаты старых HP/H4 термически несовместимы и не используются. Параметры E/ED/EDV и сравнение CONST/VAR **в этой кампании не изменены**: EDV/VAR как в прежних H3/H4/HP для чистого сравнения сеток.

Директория: `Stage3D07\LOCAL_RUNS\SHAPE_STAGE09\P09C\HP2_dt300_q3_t3600_GH3_p8_delta5p000um_modesy20_lawsEDV_EVAR\`. Для других сеток первый фрагмент меняется соответственно.

По завершении перешлите 4 небольших файла из каталога результата: `P09C_STATUS.txt`, `P09C_SENSITIVITIES.csv`, `P09C_NODES.csv`, `P09C_SAMPLES.csv`. Большие папки thermal/mechanics/restart не нужны.

## Если нужно повторно сгенерировать сетки в Gmsh

Gmsh 4.15.2: используйте файлы `gmsh/sphere_pore_HP2_wall.geo`, `...HP4...`, `...HP8...`; Windows `gmsh/GENERATE_HP_LEVELS.cmd HP8` (аналогично HP2, HP4). Скрипт **не перезаписывает** существующие сетки. Для замены сначала явно перенесите старую `.msh` в архив. `Mesh.HighOrderOptimize=1` обязателен, в особенности на HP8; без оптимизации проверка обнаруживала инвертированные элементы.

Проверка Python: `python tools\audit_wall_refinements.py`. Последнее слово — проверка `--geometry-only` на 27 точках квадратуры для **трёх** состояний.

## Ограничение вычислительных ресурсов

HP8 ~4 млн узлов, ~2.8 млн Tet10, квадратичные формы, EDV и 12 шагов. Сама ASCII `.msh` ~0.5 ГБ, а механические матрицы, история внутренних переменных и результаты требуют существенно больше памяти/диска. **Не запускайте сразу HP8**; сначала оцените пиковый расход RAM и свободное место на HP2/HP4. Даже при 64 ГБ оперативной памяти успешное завершение HP8 не гарантировано. Не запускать две кампании одновременно.
