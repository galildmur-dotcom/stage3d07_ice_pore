# Отчёт Stage 3D-06-P2 — независимая верификация

Вспомогательные файлы:

- `P2_SPMV_LINUX_H0_H4_SCALING.csv` — реальный граф BCSR из H0–H4, синтетические коэффициенты; корректность выхода = точное совпадение для тестового вектора при одинаковом порядке суммирования.
- `P2_FEM_LINUX_COMPARISON.csv` — измеренное время реального EDV_VAR расчёта на H0 и H2, собранная исходная и оптимизированная матрица, одинаковый preconditioner=jacobi.
- `P2_H2_PROJECTED_VS_LEGACY_CHECKPOINT.csv` — локальное сравнение всех компонент конечного состояния H2.
- `P2_P06_CTEST_11_PASS.log` — последовательный запуск всех относящихся к P06/P2 тестов, 11/11 PASS.
- `FULL_CTEST_INTERRUPTED.log` — попытка полной регрессии прервана по времени, не доказательство её успешного окончания.

Специальный инвариант: стандартный PCG зануляет правую часть на закреплённых DOF; блочный Якоби/SSOR и операции обновления сохраняют нули в решаемых векторах. Поэтому `mul_projected` умножает на нулевые компоненты, а не пропускает их по флагу закрепления. С учётом конечности коэффициентов это физически эквивалентно старому ядру; численная эквивалентность дополнительно проверяется регрессией полных перемещений и EDV-истории.

Предыдущая Stage3D06-P была локально принята пользователем на Windows H0–H4: это отдельное историческое свидетельство, **не** Windows-верификация текущего P2. Результаты P2 обязательно перепроверять на 4 физических / 8 логических потоках i7-7700K.
