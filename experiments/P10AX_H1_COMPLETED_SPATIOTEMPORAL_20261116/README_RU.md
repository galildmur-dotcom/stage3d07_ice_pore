# P10AX — H1 закрывает пробел в серии H0–H4

Самостоятельный пакет постобработки: новые результаты P10AW на H1 плюс сохранённые P10AU и геометрический аудит P10AR. Новых FEM-расчётов, изменений Git и модификаций исходной программы нет.

## Быстро открыть

1. `REPORT_RU.md` — научные результаты, ограничения и происхождение данных.
2. `figures/P10AX_H0_H4_ALL_THREE_DERIVATIVES.png` — главные графики трёх производных H0–H4, включая H1.
3. `figures/P10AX_JPEAK_SURFACE_WITH_VOLUME_SPREAD.png` — отдельные объёмные варианты при том же Tri6.
4. `figures/P10AX_H0_H4_JPEAK_TIME_CURVES.png` — временные вклады в итоговую производную.
5. `figures/P10AX_INTERACTIVE_3D_12_MESHES.html` — вращаемый автономный график для j6/jpeak/jen.

Все исходные числовые значения сохранены в `input/` и не изменялись. Выходы в `derived/` воспроизводятся командой `python REBUILD.py`. Присутствует `SHA256SUMS.txt`. Пакет предназначен для анализа и последующей регистрации в Git отдельным решением; пока **не утверждает** доказанную пространственную сходимость.
