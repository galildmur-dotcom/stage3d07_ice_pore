Почти полное совпадение W4B2 и W5B2 **не воспроизводится** при B20. Изменение при W4→W5 по B20 в **~180,95 раза** больше по модулю, чем по B2. В то же время объемная чувствительность B2→B20 уменьшается от W4 к W5 (~3,44 раза по модулю) — благоприятное, но недостаточное для доказательства сходимости наблюдение.

Дискретное смешанное отличие (взаимодействие двух направлений уточнения):

$$I_{45} = [D_{W5,B20}-D_{W4,B20}]-[D_{W5,B2}-D_{W4,B2}].$$

Для `jpeak` получено $I_{45}=+0,000414145137424$ на метр, то есть около 0,01750% от $D_{W5,B20}$. Это **эффект взаимодействия дискретизаций**, а не смешанная непрерывная производная формы или универсальная константа модели.

## 4. Почему для $j_{peak}$ возникла «ложная стабилизация»

При W4B2 → W5B2 изменение полной производной всего +2,301522·10⁻⁶ на метр. Однако её слагаемые изменяются существенно сильнее:

- явный вклад: **+0,003686470615497**;
- механическое равновесие: **−0,002205847282019**;
- внутренняя реологическая история EDV: **−0,001492376500424**;
- тепловая сопряжённая часть: **+0,000014054688948**.

Сумма абсолютных изменений слагаемых больше изменения полной производной примерно в **3215 раз**. Это не потеря точности арифметической операции: проверка сумм по CSV проходит с расхождением порядка $10^{-15}$, но является признаком сильной **компенсации численных изменений**.

При W4B20 → W5B20:

- явный вклад: **+0,003755897508713**;
- равновесие: **−0,002226289875518**;
- реологическая история: **−0,001124438159834**;
- тепловая часть: **+0,000011277186067**;
- **итог: +0,000416446659426**.

В этом случае отношение суммы модулей изменений четырёх слагаемых к итоговому изменению составляет ~17,09, то есть компенсация намного слабее.

Для B2 отрицательные изменения первых пяти шагов (−0,000891392301) почти компенсируются положительным изменением шага 900 с (+0,000879639134), а тепловая часть компенсирует остаток. Для B20 первые пять шагов дают −0,000556702642, последний +0,000961872115, поэтому остаток становится заметно положительным. На шаге 750 с даже происходит смена знака межсеточного изменения.

Важное отличие: сами функционалы $j_{peak}$ также меняются, но медленнее. Например, W4B20 → W5B20: изменение $j_{peak}$ составляет примерно −0,000716%, тогда как изменение его производной +0,017602%. Проверка только функционала была бы недостаточной для оценки сеточной чувствительности градиента.

## 5. Проверки правильности данных

- Сопоставлены 12 первичных файлов P10W для W4B2, W4B20, W5B2, W5B20 и архивная сводка P10AC с двумя W2 сетками.
- Для каждой из 4 первичных сеток и 3 функционалов проверены: `компоненты → механическая часть`, `шесть шагов → механическая часть`, `механическая + тепловая → полная`.
- Максимальная абсолютная ошибка всех этих равенств **2,22·10⁻¹⁵** (масштаб самих слагаемых для `jpeak` — единицы-десятки).
- Пересечения исторической сводки P10AC с первичными CSV совпали.
- В пределах одинакового уровня W ранее отдельно подтверждено совпадение геометрии поверхности поры B2/B20 в пределах $10^{-11}$ м. При W4→W5 поверхность поры дискретизована **иначе**; такие переходы отражают также изменение аппроксимации геометрии.
- Другие внешние поверхностные сетки в паре B2/B20 могут отличаться; поэтому названия «объёмное» и «пристеночное» уточнение описывают план эксперимента, а не строгое изменение одного параметра при полном совпадении всех остальных дискретных данных.

## 6. Вывод для статьи

На исследованном семействе тонких сеток значения полных производных уже близки относительно собственной величины. Однако совпадение по одной последовательности может возникать из-за взаимной компенсации меняющихся по сетке механических и тепловых вкладов. Двухпараметрическое уточнение выявило ненулевое взаимодействие пристеночной и объёмной дискретизации, особенно выраженное для регуляризованного пикового функционала. Следовательно, представленная серия подтверждает **малый межсеточный разброс**, но **ещё не** асимптотический режим, универсальный порядок сходимости или оценку истинной ошибки.

Рекомендуется формулировать результат как «сравнительная оценка сеточной устойчивости и диагностика компенсации вкладов производной формы»; выражение «доказана пространственная сходимость» преждевременно.

### Ограничения серии

1. Уровни W2/W4/W5 и B2/B20 не задают единого известного отношения характерного размера $h$; поэтому обычная экстраполяция Ричардсона здесь не обоснована.
2. Продемонстрирована устойчивость по **одному** временному шагу 150 с, одному режиму `R` и одной детерминированной реализации `ξ=0`; нельзя автоматически переносить вывод на весь GH3 или другие моды формы.
3. Часть результатов W2 извлечена из старой архивной сводки, а не из предоставленных заново сырых первичных CSV. Первичные W2 не проверялись построчно в этом пакете.
4. Погрешности линейных невязок малы, но не являются математически строгими верхними границами погрешности градиента.

## 7. Разумный следующий этап

**Не запускать ещё одну многочасовую FEM-кампанию немедленно.** Сначала внести P10AK в реестр подтверждений, обновить раздел статьи о сходимости и определить отдельный эксперимент для разделения ошибок аппроксимации поверхности поры, объёмной сетки и интегрирования в окрестности поры. При необходимости пространственного разложения по слоям следует учитывать, что существующие три CSV P10W дают только **временное**, а не полное пространственное распределение. Для новых тонких сеток пространственные вклады потребуют нового диагностического сопряжённого прохода либо отдельного сохранения контрактируемых полей.
