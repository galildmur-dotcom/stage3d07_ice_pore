# P10Y/H4W2/R — компактные данные и графики

Дата фиксации: 2026-11-12. Это **экспериментальные данные одной сетки**, а не доказательство пространственной сходимости.

* `data/P10Y_SHELL_SUMMARY.csv` — первичный выход P10Y, 3 функционала × 10 радиальных интервалов = 30 строк.
* `data/P10Y_PARTITION_AUDIT.csv` — первичный аудит сумм (3 строки).
* `data/P10Y_H4W2_RADIAL_DENSITY_CUMULATIVE.csv` — производные значения: среднее расстояние, ширина, удельный вклад и накопленная механическая производная.
* `figures/P10Y_H4W2_{j6,jpeak,jen}_radial.{png,svg}` — две панели для каждого функционала.
* `tools/rebuild_radial_figures.py` — воспроизводит CSV и рисунки из первичного CSV (Python 3 + matplotlib). Запускать из любого каталога: `python experiments/P10Y_H4W2_R_20261112/tools/rebuild_radial_figures.py`.
* `RUN_REGISTRY_ENTRY.csv` — **предложенная строка** общего реестра. Она содержит пустые поля для неподтверждённых Git SHA, mesh SHA, путей к расчёту/архиву; она не является фактическим RUN_MANIFEST.

См. `docs/STAGE3D10Y_H4W2_R_EVIDENCE_20261112.md` для формул, контрольных сумм, строгой интерпретации, ограничений и логов.

Все графики пока **диагностические**, не окончательные рисунки статьи. `j6`, `jpeak` и `jen` соответствуют выходам решателя; `jen` не тождественно `j_safety`. Тепловой вклад по слоям отсутствует, данные `P10N_DELTA_SCAN(5).csv` (H4/y20) сюда не включены.

Примечание: для Git окончания строк в CSV нормализованы к LF (числовые значения и заголовки не изменены); SVG фиксируются как созданные векторные артефакты.
