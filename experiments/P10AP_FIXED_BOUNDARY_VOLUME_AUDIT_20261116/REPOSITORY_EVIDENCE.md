# P10AP — паспорт доказательного пакета для Git

Числовое содержание перенесено из проверенного аналитического архива `P10AP_FIXED_BOUNDARY_VOLUME_AUDIT_20261116.zip` (SHA-256 архива: `f6f8aa7089871f4f8cbdec3af169c1a2a482e272e5a673a3325af8ae4688973d`). Для строгой проверки Git применена текстовая нормализация LF и удаление завершающих пробелов; в `REBUILD.py` добавлен явный LF-терминатор CSV для побайтово воспроизводимых Git-таблиц. Это не меняет числовые данные и формулы, но **байтовые SHA файлов отличаются от исходного ZIP**. `SHA256SUMS.txt` пересчитан для репозиторной версии; новый `REPOSITORY_EVIDENCE.md` включён в список контрольных сумм. Исходный ZIP остаётся неизменным и идентифицируется указанным SHA.

- Объект: `H4W4B2` и `H4W4B2_VSTAR12000_P10AM3` — самостоятельные согласованные прямые и сопряжённые расчёты на **каждой** сетке.
- Данные: `input/P10W_BASE_*`, `input/P10W_VSTAR_*` и `input/P10W_W4B20_REFERENCE.csv`; в `input/` находятся также манифест сетки P10AM3 и результат P10AM4.
- Проверка: `REBUILD.py` повторно собирает `derived/P10AP_*` из первичных CSV, включая балансы трёх функционалов и 18 временных вкладов на каждой сетке.
- Результаты: `REPORT_RU.md`; сравнительный вывод и пределы экстраполяции — `docs/P10AQ_P10AP_VSTAR_COMPARISON_20261116.md`.
- Статус доказательства: **A** для числовых значений, воспроизводимых из CSV; **B** для проверки геометрической сопоставимости по предоставленным контрольным логам; **D** для гипотезы доказанной пространственной сходимости.
- Не подменять первичные даты/версии: точные Git SHA исходников и SHA исполняемого файла на момент P10AN не установлены; не приписывать их позднейшему коммиту документации.
