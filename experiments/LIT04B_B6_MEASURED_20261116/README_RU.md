# LIT04B — доказательная база геометрического аудита

- `input/LIT04_B6_H3_H4.csv`: непосредственный результат Q3 аудита Tet10 на H3/H4.
- `input/LIT04_B6_W2_W4_W5.csv`: непосредственный результат на W2/W4/W5.
- `input/P10AM0_SURFACE_GEOMETRY.csv`, `input/P10AM0_MANIFEST.txt`: независимая предыдущая проверка Tri6 Q6 на трёх W-сетках.
- `input/P10AX_216_VERIFIED_STEP_COMPONENTS.csv`, `input/P10AX_FINAL_DERIVATIVES_12_MESHES.csv`: сводные проверенные экспериментальные данные из архива P10AY.
- `derived/`: пересчитанные таблицы с эталонными ошибками и сопоставлением составляющих.
- `SOURCES_ORIGINAL_SHA256.txt`: контроль SHA256 трёх файлов, поступивших с переводами строк CRLF; эти строки нормализованы в LF для Git, числовое содержимое не изменено.
- `SHA256SUMS.txt`: SHA256 каждого входного и производного файла в этом каталоге.

Все результаты относятся к уже существующим сеткам, не являются оценками ошибки решения FEM или доказательством сходимости производной.
