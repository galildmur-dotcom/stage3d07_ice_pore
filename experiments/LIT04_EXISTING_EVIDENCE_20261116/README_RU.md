# LIT-04 — вторичный анализ существующих геометрических данных

Основание: первичные `P10AR_GEOMETRY_H0_H4.csv`, `P10AX_216_VERIFIED_STEP_COMPONENTS.csv`, `P10AX_FINAL_DERIVATIVES_12_MESHES.csv` из пакета `P10AY_REGISTER_P10AW_P10AX_20261116(1).zip`, и Git snapshot `486e0a74fc37`.

- `LIT04_H0_H4_RECHECK.csv` — геометрические показатели, геометрический (не FEM!) surrogate объёма и производной B6, полные и компонентные производные.
- `LIT04_PAIRS_RECHECK.csv` — изменения между H0/H1/H2/H3/H4 и коэффициенты компенсации, пересчитанные непосредственно из 216 строк.
- `LIT04_GEOMETRY_B6_SURROGATE_H0_H4.csv` — расширенная таблица геометрических surrogate и их сравнения с идеальными сферами.

Все три таблицы сгенерированы здесь без FEM. Для проверки заново: `01_RECHECK_P10AR_P10AX.py` в автономном архиве LIT04. Архив содержит копии трёх малых входных CSV и Windows-команды.

**Ограничение:** в исходном наборе отсутствуют фактические вычисленные P10V `observed_volume` и `observed_volume_derivative` по центроидной маске B6. Они требуют отдельного дешёвого геометрического аудита уже готовых `.msh`. Для новых геометрических результатов применяется `lit04_mesh_audit.py` — не изменять и не подменять их числами в таблицах surrogate.
