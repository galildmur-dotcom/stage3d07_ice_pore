# P10AU — завершённый этап без нового FEM

Этот архив содержит результаты объединения **P10AT + P10AS + P10AR** для 11 сеточных вариантов. На локальном компьютере повторять FEM не требуется. На каждой сетке прямая и сопряжённая задачи были рассчитаны согласованно.

**Сначала посмотрите** `REPORT_RU.md`, `figures/P10AU_JPEAK_3D_ALL_MESHES.png`, `figures/P10AU_JPEAK_SPREAD_HEATMAP_W2_W4_W5.png`, `figures/P10AU_INTERACTIVE_3D_ALL_FUNCTIONALS.html`.

Файлы для численного анализа:
- `derived/P10AU_198_VERIFIED_STEP_COMPONENTS.csv`: 11 × 3 × 6 строк, включая точное происхождение исторических P10W;
- `derived/P10AU_TIME_SURFACE_VOLUME_SPREAD.csv`: min/max и диапазоны по группам, пустое поле разброса для одиночных поверхностей;
- `derived/P10AU_SIGNED_DIFFERENCES_FROM_B2.csv`: разности при одинаковом числе поверхностных Tri6;
- `derived/P10AU_BALANCE_QA.csv`: компонентные балансы и полный D_R из P10AS;
- `derived/P10AU_DUPLICATE_RUN_QA.csv`: числовое совпадение повторов H4/H4W2.

**Воспроизведение:** `python REBUILD.py`. Скрипт создаёт все производные CSV и графики заново из `input/`. Нужны numpy, matplotlib; для автономного интерактивного HTML дополнительно plotly. Скрипт никак не касается локальных FEM-файлов, не меняет Git и не запускает FEM.

**Научное ограничение:** X=Tri6 не единственная степень свободы сетки, Y=время шага, Z=вклад шага в итоговую механическую производную. У объёмной сетки отдельная категориальная переменная. Графики не устанавливают пространственную сходимость и не являются поверхностью `D_RJ(N,t)`.
