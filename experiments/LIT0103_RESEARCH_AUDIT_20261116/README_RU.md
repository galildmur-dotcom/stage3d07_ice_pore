# LIT-01—03 — малые воспроизводимые контрольные таблицы

**Дата:** 16.11.2026. **Статус:** вспомогательные таблицы для исследовательского анализа; не отдельный расчёт FEM и не новая экспериментальная серия.

- `LIT02_JPEAK_CONSECUTIVE_CANCELLATION.csv` — вычисленные изменения компонент `D_Rjpeak` и коэффициент `κ_Δ` для последовательных H0–H4, из ранее проверенных P10AX 216 строк (серия EDV_VAR, ξ=0, R, 6×150 с). Исходная трассируемость: P10AX/P10AW и `docs/P10AY_P10AW_P10AX_SCIENTIFIC_RESULT_20261116.md`.
- `LIT02_H3_H4_TIME_STEP_DELTA.csv` — изменения *пошагового вклада в финальную производную при T=900 с*, а не отдельная серия `D_RJ(t)` с переменным горизонтом наблюдения.
- `LIT03_B6_EXACT_VOLUME_20261116.csv` — геометрический аналитический эталон при двух концентрических сферах 1 и 6 мм; сравнение центральной разности со строгой производной. Это не FEM-измерения и не погрешность пространственной производной `jpeak`.

Оригинальные крупные расчётные данные сохраняются по принятой архивной схеме на F:, в Git они не перемещаются. Не использовать эти таблицы для объявления доказанной пространственной сходимости. Исходные длинные таблицы P10AX в данном ZIP не дублируются.
